# Line-structure formulas

Degeneracy gj = 3*(2 + (-1)**(j%2)) -> even j: 3*3=9, odd j: 3*1=3 (N2 nuclear spin statistics).

Partition sums use fixed ranges: vibrational v_ in 0..19, rotational j_ in 0..99.

Branch coefficients for cross-section d^2 (see susceptibility op):
- Q (branch 0): d2 = Const_Raman**2 * (1 + (4/45)*pt*(G/A)**2) * (v+1) * cd
- O/S (branch -2,+2): d2 = Const_Raman**2 * (4/45)*pt*(G/A)**2 * (v+1) * cd
Then d = sqrt(d2).

hc/k = 1.44 cm*K used in all Boltzmann exponents.
