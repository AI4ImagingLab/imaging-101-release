# Actual mathematical approach

This is the SMU modal dynamic residual formulation (paper Eq6 with derivatives Eqs25–26), using the author's four-story laboratory example, not its simulated eighteen-story example. Let d be the four adjacent-floor drift vectors in README. Assemble influence matrices Kj=10 dj djᵀ and K(alpha)=Σ(1+alpha_j)Kj. M=(12.060/386.088)I retains the native lbf/in/s unit system. lambda_i=(2πf_i)². Normalize measured modes by their signed largest absolute entry; q_i is that entry's floor index. The complete mode u_i concatenates three normalized observations and one latent scalar z_i.

State x=(alpha1,...,alpha4,z1,z2). Residual r stacks (K−lambda_i M)u_i, mode-major, length8; objective is Σr² with all mode weights1. There is no regularizer or statistical noise precision. Analytic Jacobian columns1–4 are Kj u_i, and the latent column for its own mode is column4 of K−lambda_i M; the other latent column is zero. Bounds alpha∈[−1,1],z∈[−3,3]; accepted stiffness is strictly positive. This bilinear problem is nonconvex.

Twelve fixed initial alpha vectors are the original Octave uniform draws with seed2, archived before extraction and copied as source configuration (not target-derived calibration). For each, solve K v=lambda M v, take the first two modes, and normalize each by its own largest measured entry; initialize z with its fourth value. The cleaned generic optimizer is scipy.optimize.least_squares, method='trf', analytic Jacobian, ftol=xtol=gtol=1e−12, max_nfev=1000, default unit x_scale and linear loss. Every start is run; select smallest sum-square residual. The original verified execution used its published lsqnonlin path through Octave optim1.6.2's lm_svd_feasible backend with1000 iterations, tolFun=tolX=1e−12. It is not a MATLAB interior-point reproduction. The standard method/objective/Jacobian/bounds are preserved across the documented backend port.

Supplementary notebook comparisons preserve all three published formulations. Form1 stacks relative eigenvalue discrepancy (lambda_obs−lambda_model)/lambda_obs and 1/sqrt(MAC)−1, where MAC=(aᵀb)²/[(aᵀa)(bᵀb)] for measured/model mode subvectors. Form2 replaces the MAC term by the two differences at measured entries other than q_i; both modal vectors have value1 at q_i. These have4 variables and bounds[−1,1]. Their generalized eigenvalue derivative is vᵀKjv/(vᵀMv); mode derivatives solve the reduced system (K−lambda M) dv=(d_lambda M−Kj)v after removing row/column q_i, with dv(q_i)=0. The MAC derivative is −1/sqrt(MAC)[aᵀ/(aᵀb)−bᵀ/(bᵀb)]dv. This implements the original normalized-eigenvector sensitivity directly. No domain library or numerical differentiation is used for core objectives.

Original MAC start1 finds a bad boundary minimum and other MAC runs hit their iteration cap; original MDR start6 finds a bad boundary minimum.
