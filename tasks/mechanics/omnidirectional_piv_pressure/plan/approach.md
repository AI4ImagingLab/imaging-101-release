# Implemented pressure integration

The task binds the native1001² author Taylor-vortex model. Visible $g=(g_x,g_y)$ is dimensionless pressure gradient in normalized coordinates $q=x/L_0$; $L_0=.001$m and $P_0=.001$Pa. Input arrays retain source VTKfloat32 quantization. Computation is float32 except the original double intermediates and final Pa conversion. Use $h=q_1-q_0$ evaluated in float32, not nominal .006 recomputed in float64. Both axes have the same coordinate vector. Array order is y,x, the transpose in memory of the MATLAB ndgrid description, preserving x-fast VTK order.

For possibly rectangular spacings $h_x,h_y$, weights are $c_x=h_y/[2(h_x+h_y)]$, $c_y=h_x/[2(h_x+h_y)]$. Each valid horizontal edge i→j has measured pressure increment $d_{ij}=h_x(g_{x,i}+g_{x,j})/2$; vertical uses $h_y$ and $g_y$. An oriented edge incidence matrix B gives edge pressure increments. Minimize $\frac12\sum_e c_e((Bp)_e-d_e)^2$, with no additional regularizer. Its normal equations are $Ap=b$, $A=B^T C B$, $b=B^T C d$. The component $b_i$ is minus outgoing positive-direction increments plus incoming increments, each weighted. A's diagonal is the sum of available edge weights; offdiagonal is minus the corresponding edge weight. Exterior edges are omitted, which preserves the author's omnidirectional boundary treatment. Constant pressure is the only null mode on this connected domain. No mean subtraction, boundary clamp, or ridge regularizer is added.

Preserve original arithmetic: center coefficient $1-c_x m_x-c_y m_y$, where m counts missing neighbors; ordered subtraction x+,x−,y+,y−; RHS ordered addition x+,x−,y+,y−. Each original gradient sum and coefficient product is float32, multiplication by h/2 and accumulation into R uses double before each float32 assignment. CPU dot products use sequential float32 multiply-and-accumulate; local np.cumsum implements that order. This matters because the singular system and float32 CG amplify rounding differences.
