# Shipped interfaces and execution flow

`python -m src.main` calls main(), loading data/raw_data.npz with load_data(path="data/raw_data.npz"), reconstructing, and writing output/reconstruction.npz. It prints measured runtime and update count. main() returns pressure(H,W) float64 Pa and history(K,3) float64. Importing it has no plotting-backend side effect.

preprocessing.load_data validates public batch-first float32 observations, increasing coordinates, square geometry and finiteness, returning gradient(2,H,W) and coordinate(W). Constants PRESSURE_SCALE_PA=.001 and LENGTH_SCALE_M=.001 match README calibration. physics_model.spacing(coordinate) returns float32 first stored difference. weights(dx,dy=None) returns two float32 face weights, default square grid. matrix_apply(pressure,dx,dy=None) casts input to float32 and returns float32(H,W) weighted graph product; boundaries exclude missing edges. build_rhs(gradient,dx,dy=None) returns float32(H,W) ordered gradient divergence with source-compatible mixed-precision edge accumulation. edge_residual(pressure,gradient,dx) returns float64 horizontal(H,W−1),vertical(H−1,W) normalized pressure-increment residuals; pressure argument must be normalized, not Pa.

solvers.sequential_dot(a,b) multiplies elementwise float32 then cumulatively sums the flattened C-order array in float32; returns scalar. solve(gradient,coordinate,relative_tolerance=1e-4,absolute_tolerance=1e-6) returns float64 physical pressure(H,W) and history(K,3), with columns index,relative residual,absolute residual. Iteration safeguards raise ArithmeticError. No references are accessed. Original CG nullspace, initialization, implicit residual convention and OR stopping condition are preserved.

generate_data.generate(n=1001) returns gradient(2,n,n) float32,coordinate(n) float32,analytic pressure(n,n) float64 Pa. Its CLI is maintainer-only and can regenerate public data and hidden truth; standard main never imports it. This is author-defined new simulated data, not downloaded measured observations. No seed is used. Different grids are sensitivity experiments, not distinct tasks.

visualization contains metrics, plot saving and measured comparisons used by the active six-chapter notebook. Notebook calls the same load_data and solve for the complete bound native grid, records actual runtime, evaluates through the independent Judge, compares identified upstream result, runs actual sensitivity reconstructions, and saves figures only when an external maintainer figure directory is configured. Original arrays in notebooks/reference_outputs/upstream_measurements.npz are comparison references, never fresh substitutes. Frozen fixtures in test/fixtures have explicit parity/physics consumers. Temporary execution notebooks and figure exports live outside this task.

Standalone evaluation/judge.py uses only pathlib,argparse,json,sys,numpy. evaluate(prediction,asset_dir=None) resolves hidden assets relative to its own file unless a test explicitly provides another asset root. It validates exact sole key reconstruction,shape(1,1001,1001),real float64,finiteness and fixed datum. Analytic ground_truth.npz takes precedence over optional baseline_reference.npz. metrics(estimate,reference) returns NCC and dynamic-range NRMSE; zero estimate yields NCC0, invalid constant reference is an evaluator error. CLI writes UTF8 JSON with status,passed,metrics,thresholds,errors; return codes0pass,1valid low quality,2invalid/evaluator/report failure. No submitted or reference solver is imported.
