# Shipped callable and data flow

Only local source and general NumPy/SciPy primitives implement the inverse; Matplotlib serves review. There are no original-domain, cross-task or hidden-reference imports in runtime. Main import does not select a plotting backend.

* preprocessing.load_observations(path) strictly validates all public float64batch shapes and finite values, returning a dict of unbatched arrays: accelerations[20001,5],observation_time[20001],reconstruction_time[100001],mass/stiffness/damping[10,10],sensor_matrix[5,10]. observation_indices(observation_time,reconstruction_time) returns integer positions using native four-decimal matching; every observation must lie on the output grid.
* physics_model.modal_model(mass,stiffness,damping,sensors,dt,modes=3) returns known mechanical/modal matrices and dimensions: Phi_r[10,m],Omega2_r/Gamma_r[m,m],A_c[2m,2m],B_c[2m,m],G_c[5,2m],J_c[5,m],G_e[10,2m],J_e[10,m],Transf[20,2m],A/B/G/Jdiscrete aliases, frequencies and damping ratios. modal signs are fixed by roof component, independent of hidden data. matern52(hyperparameters,dt) returns explicit3-state F_c/L_c/H_c,F/L/H,stationaryP,discreteQ,q,hp,sigma_w,nz. augmented_model(model,hyperparameters) returns F_ac,Q_ac,P_0,F_ad,Q_ad[(5m),(5m)],H_ad[5,5m],H_ae[10,5m] and constituent blocks.
* hellinger_squared(reference_std,model_std,npoints=500) evaluates explicit normal densities/trapezoids, returning mean squared Hellinger. hyperparameter_cost(normalized,observations,model) maps two normalized scales to physical bounds, constructs stationary calibration and compares full measured marginals. No fixed reference scales are substituted.
* solvers.fit_hyperparameters(observations,model) returns learned physical scales[2] and optimizer dict normalized,objective,iterations,message,history. kalman_rts(transition,noise,measurement,measurement_noise,observations,indices,count,initial_covariance,maps=None,callback=None) executes explicit forward/backward recursions, returns mean[count,state] and dict variance(mapped names to[count,outputs]),covariance_samples[3,state,state],first10filtered/predicted means/covariances. Original matrix-vector orientation adapters are documented in fixtures. reconstruct(data,modes=3,hyperparameters=None,callback=None) returns fields dict reconstruction/velocity/acceleration[count,10] and modal_force[count,m], plus all diagnostics, model,augmented,hyperparameters,optimization,state,runtime_seconds. Supplying hyperparameters is only a stage-isolation test/comparison helper; the standard path learns them. Alternate modes is a labelled ablation, never the default benchmark shortcut.
* main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz',callback=None) reads public inputs, runs the complete default learned-scale inverse, writes exactly the three batched declared arrays and returns fields,info. CLI python -m src.main exposes --input/--output and prints progress/runtime. It does not import or invoke Judge.
* generate_data.simulate(mass,stiffness,damping,force_matrix,forces,dt=.001,initial_displacement=None,initial_velocity=None) returns full u,v,a[time,dof]. resample(time,values,new_time) linearly interpolates each channel. generate(forcing_path,calibration_path,raw_output,truth_output,noise_path=None,seed=0) accepts explicit private NPZforcing/noise and public calibration, generates complete observations and noiseless truth, writes requested destinations and returns runtime. Defaults generate a new Gaussian measurement noise realization unless exact private native noise is passed. CLI requires explicit forcing/raw-output/truth-output; standard reconstruction never invokes generation.
* visualization.metrics computes known cosine/dynamic-range metrics; field_panel plots physical time/floor fields with specified common/signed limits. welch_power(values,dt) explicitly implements symmetricHann lengthN//8,50%overlap,nextpower2FFT,one-sided power normalization with no detrending. It labels power units, clarifying the source pwelch('power') plots labelled PSD. These are display comparisons, not inverse stages.

evaluation/judge.py is independent of src. It resolves actualtruth then optionalbaseline relative to itself, validates exact keys/batchshape/realfloat32or64/finite values and all thresholds, scores every floor independently, writes required UTF8JSON and exits0/1/2 for pass/quality-fail/error. Invalid input/evaluator failures produce empty metrics. CLI paths follow caller working directory; report-write failure is stderr/exit2. Extreme finite arrays use scaled/logarithmic metric arithmetic and finite representational saturation, never NaNJSON.

The notebook actively reconstructs complete raw data, writes/evaluates fresh submission, then loads identified original arrays and actualtruth for comparisons. No hidden data affect the standard inverse. It uses fresh one-mode, integration and perturbation experiments; source force/uncertainty/hyperparameter comparisons remain labelled. Frozen source operator/state/KF/generation fixtures feed tests; upstream_measurements and force_truth_diagnostic feed labelled notebook comparisons. Hidden ground_truth contains only the three true response fields. All source checkouts, MATfiles, capture scripts, source logs and executed notebooks remain outside the task. Requirements list only validated shared runtime packages, with pytest/Jupyter in development tooling.
