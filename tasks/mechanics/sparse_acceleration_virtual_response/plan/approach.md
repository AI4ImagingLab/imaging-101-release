## Explicit filtering and smoothing

Initial mean is zero and covariance P0. Match observation times by four-decimal rounding as in source. The native filter begins at the second output time: time-zero observation participates in hyperparameter fitting but is not separately assimilated into the initial state. Preserve and document this convention. For each time k, predict mp=T mfprev,Pp=T Pfprev T^T+Q. At measured times compute innovation e=y-Hmp, S=H Pp H^T+R and gain K=Pp H^T inv(S); update mf=mp+Ke and Joseph covariance Pf=(I-KH)Pp(I-KH)^T+K R K^T. ## Generation, reference roles and evaluation

generate_data.py implements full10DOF average-acceleration Newmark (gamma=.5,beta=.25), same force/calibration inputs and linear resampling, with explicit measurement noise. It caches a constant matrix inverse rather than repeatedly evaluating the same inverse; no physical equation changes. Independent constant-force and conserved-energy cases supplement original generation parity.
