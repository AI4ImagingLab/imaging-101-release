# Shipped design and execution flow

All runtime modules are local and have no upstream or cross-task imports. NumPy and SciPy provide arrays, interpolation and generic dense least squares; Matplotlib serves notebook plots only. Requirements pins document the tested shared environment. Importing main has no plotting/backend side effect.

* `preprocessing.load_observations(path)` reads batch-first float64 coordinates/displacements and returns two finite [N,2] mm arrays. It checks matching dimensions. `transform(coordinates,displacements,tip=CRACK_TIP,angle_deg=CRACK_ANGLE_DEG)` returns rotated [N,2] positions and vectors without mutating input. `fitting_grid()` returns r,phi,x,y float64 [231,559], with length mm and angle rad. `sample_displacements(coordinates,displacements,grid_x,grid_y)` returns ux,uy [231,559] mm and tip displacement [2] mm; the shared vector interpolant removes the origin offset and preserves missing values as NaN.
* `physics_model.displacement_basis(r,phi,terms=TERMS,young_modulus=72000.,poisson_ratio=.33)` returns x,y arrays [2*K,*gridshape] in mm per coefficient unit. `assemble_system(sampled_x,sampled_y,r,phi,terms=TERMS)` returns finite-equation A [M,2*K], target [M] mm, and a Boolean mask [2*grid_size]. `stress_field(coefficients,r,phi,terms=TERMS)` returns [3,*gridshape] MPa, xx/yy/xy. `stress_intensity(coefficients,terms=TERMS)` returns [2] MPa sqrt(m) and requires exactly one n=1 order.
* `solvers.reconstruct(coordinates,displacements,terms=TERMS)` calls these stages, performs GELSS, checks rank, returns stress [3,231,559], intensity [2], and diagnostics dict. Diagnostics contain points,displacements,r,phi,x,y,sampled_x,sampled_y,tip_displacement,A,b,valid_equations,coefficients,residual,rank,singular_values. Residual is A@coefficients-b in mm. No files are written.
* `main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads observations, reconstructs fresh, creates output parent and saves reconstruction [1,3,231,559] and stress_intensity [1,2], returning stress,intensity,diagnostics,elapsed_seconds. `python -m src.main` parses optional --input/--output, calls run and prints runtime/intensity. It does not run the evaluator.
* `visualization.metrics` and `field_panel` provide notebook review helpers. The standalone `evaluation/judge.py` has its own independent metrics and NPZ validation and never imports src. It resolves hidden assets relative to itself; actual truth would take precedence, but this task supplies only a baseline. Its CLI writes the required JSON and returns 0/1/2 for pass/quality-fail/error.

The active notebook resolves task root from task or notebooks working directory, calls the local reconstruct path on raw observations, writes the standard submission, invokes independent Judge, and loads identified original measurements for comparison. Its separate singular-only and noise experiments call local reconstruct and cannot substitute for the complete standard run. Figures expose measurements, fields, parity, measured-space residuals, truncation and robustness. Tests load frozen upstream numeric cases, never upstream modules. Fixtures have a single documented consumer (`test/comparing_test/test_upstream.py`); upstream measurements feed notebook comparisons; baseline_reference feeds Judge. No synthetic observations are generated for this measured benchmark, so generate_data.py is absent.


The notebook additionally computes eight full noise-perturbed reconstructions (two scales by four draws), all from public positions/displacements, and plots intensity/residual/field sensitivity. Each signed map uses zero-centred limits; comparison maps use physical radius and azimuth axes.
