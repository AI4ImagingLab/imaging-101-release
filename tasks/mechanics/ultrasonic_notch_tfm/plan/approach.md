# Implemented approach

The physical unknown is a two-dimensional direct-wave echo-amplitude envelope in an aluminium contact inspection. The measured half-matrix contains64 surface elements and2080 pairs. Every trace is750 float64 digitizer samples at40ns spacing; positions and times retain their stored SI values. The array is centred along x at y=z=0. The homogeneous longitudinal speed is6300m/s. The reconstruction grid includes201 x-coordinates from-0.02 to0.02m and251 depth coordinates from0 to0.05m, with0.0002m spacing.

For grid point r and element centre p_i the one-way time is tau_i=norm(r-p_i)/c. The single-scattering approximation is s_ij(t)=integral a(r)h(t-tau_i-tau_j)dr+n_ij(t). The local code evaluates the Euclidean travel times directly. It does not invert multiple reflection or elastic mode conversion. The impulse response is implicit in the finite measured bandwidth. No quantitative scattering calibration or actual reflectivity truth is available.

Preprocessing designs a fifth-order Butterworth bandpass with0.5MHz and6MHz cutoffs normalized by the12.5MHz Nyquist frequency. scipy.signal.filtfilt applies its standard zero-phase forward/backward filter, including default padding. The analytic transform computes an FFT, doubles positive non-Nyquist bins, preserves DC/Nyquist and zeroes negative bins before the inverse FFT.750 is even. FFT signs and normalization follow NumPy defaults; parity is checked against upstream scipy.signal.hilbert.

The complex coherent field is b(r)=sum_pairs w_ij q_ij[tau_i(r)+tau_j(r)]/M. Here q is the filtered analytic trace, M is the number of selected recorded pairs and w=1 for i=j or2 otherwise. This is upstream's recorded-pair normalization, which is not normalization by the sum of weights. Nearest-sample evaluation uses index=round((tau_i+tau_j-t0)/dt) with ties-to-even. Out-of-record contributions are zero, without renormalizing the number of valid pairs. The declared reconstruction is abs(b), in dimensionless digitizer-amplitude units. No optimization objective, regularizer, initialization, iterations, step-size or stopping rule applies to this closed-form focusing calculation.

The standard computation selects all pairs. Notebook comparisons recompute pulse-echo-only data, pairs where both zero-based indices are even, and a3% increased assumed sound speed. These compare acquisition/model sensitivity on the same observations, not accuracy against unknown physical truth. Each subset uses its own recorded-pair count and unchanged reciprocity rule. Plotting uses a shared upstream/full-array peak for dB display, but submitted arrays retain their unnormalized physical scale. The dominant full-field peak is a backwall response; peak values are not automatically interpreted as notch locations.

Evaluation uses flattened cosine NCC without mean subtraction and RMSE divided by reference dynamic range. No alignment, crop, mask, fitted scale or magnitude coercion is applied by the Judge. Actual truth takes precedence if provided; this task has only an independently reproduced upstream method reference. Strict NCC>=0.999999 and NRMSE<=1e-7 boundaries are justified by repeated CPU double-precision parity (<1e-15 maximum absolute difference), allowing ordinary numerical variation while rejecting pulse-echo, aperture-reduced and speed-mismatch outputs.
