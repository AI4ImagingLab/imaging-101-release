# Shipped interfaces and execution

`preprocessing.load_data(path='data/raw_data.npz')->dict` loads allow_pickle=False and removes the batch axis. It returns all10 visible arrays with stored dtypes and validates the full acquisition count and positive first-frame determinants. `element_deformation(triangles:(696,3), shape_gradients:(696,3,2), displacement:(383,2))->F:(696,2,2)` uses calibrated gradients and measured displacements.

`physics_model.features(F:(N,2,2) or (N,4))->(Q:(N,171),G:(N,171,4))` implements dimensionless features and derivatives. `law(F,theta:(171,))->(W:(N,),P:(N,2,2))` returns MPa energy/stress. `weak_operator(triangles,shape_gradients,areas,feature_gradient,nnode)->A:(383,2,171)` assembles force/MPa per unit thickness. `frame_system(A,free_dofs,boundary_masks,reactions,balance=20)->(H:(171,171),b:(171,),C:float)` returns one frame's twice-normal equations and quadratic constant.

`solvers.assemble(data,progress=None)->(H,b,C)` actively visits all600 frames, keeping one feature tensor at a time; optional progress receives completed frame count. `positive_quadratic(M,v,tol=1e-12)->(x,iterations)` implements explicit feasible working-set updates. `solve(H,b,C,seed=0,penalty=10000)->(theta,info)` implements corrected positive IRLS and checks original full KKT; info contains floor-stage history, residual and seed. `objective(theta,H,b,C,penalty=10000)->dict` computes unnormalized weak SSE, physical penalty, total and sqrt(V/C). `reconstruct(data,seed=0)->(theta,info,(H,b,C))` runs active assembly and solving and reports elapsed seconds.

`python -m src.main` calls load_data then reconstruct, creates output if needed, saves only reconstruction:(1,171) float64 in output/reconstruction.npz and prints diagnostics. It has no plotting/backend side effect and imports no upstream module. Raw data and geometry are its only numerical inputs; frozen systems appear solely in hidden tests/evaluation.

`visualization` provides figure helpers consumed by the notebook, not the CLI. Notebook actively calls reconstruct on raw observations; optional comparisons reuse the freshly assembled normal system for penalty/calibration probes. It separately loads named native failed comparisons and independent certificate from notebooks/reference_outputs. It never substitutes them for fresh recovery. Derived spatial W/P maps are visualization of the recovered homogeneous law evaluated at observed F, not new unknown maps.

evaluation/judge.py is independent of src. load_prediction(path) accepts exactly reconstruction:(1,171), real float32/float64, finite and nonnegative, returning float64 theta[171]. Integer, complex, float16 and object arrays are malformed. validated_arrays(path,shapes) verifies all required hidden keys, exact shapes, float64 dtype and finite values. load_assets() returns operators and reference dictionaries: Q[2189,171],G[2189,171,4],H[171,171],b[171],scalarC, energy[1,2189],stress[1,2189,2,2]. PositiveC, nonzero operators and nondegenerate reference norms are required before scoring.

Actual ground_truth.npz, if present, takes precedence for energy/stress; malformed truth raises an evaluator error and never silently falls back. Acquisition operators may remain in baseline_reference.npz, independent of which law is the reference; if no baseline exists, truth must also carry the operators. This task ships only the conditional baseline and does not invent actual truth. Synthetic temporary truth-priority cases exist only in unit tests.

relative_l2(operator,theta,reference) scales matrix/coefficient products and computes relative norms using log-sized amplitudes. weak_residual_relative_l2(theta,H,b,C) preserves ordinary physical quadratic arithmetic and uses scaled/log arithmetic when finite coefficients could overflow. finite_from_log(value) caps a nonnegative score only beyond the representable float64 maximum. measure(theta,operators,reference) returns the three declared metrics. These routines preserve the scientific formulas, units and frozen thresholds. A huge but finite nonnegative prediction is valid and returns quality fail1 with finite JSON scores, rather than malformed/error2.

evaluate(prediction) returns report and code0/1/2; the CLI requires --prediction/--report, creates report parents and writes strict UTF8 JSON. Hidden paths resolve from __file__; submitted solver code is never imported. Missing/malformed input, hidden-asset validation failures and report-write failures return2; invalid-input reports have empty metrics.


Fixtures: small_math_probe is consumed by feature/Jacobian/weak parity; original_first_stage by actual first-frame feature parity; original_full_normal_system by active600 assembly parity; corrected_optimizer by corrected source-operator solution parity. Baseline_reference contains qualified theta/law and independent original operators consumed only by Judge. Named notebook reference arrays each have an explicit comparison cell. No generation module is present because all bound observations are reused real measurements.
