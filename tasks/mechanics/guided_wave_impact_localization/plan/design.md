# Shipped interfaces and flow

preprocessing.load(path="data/raw_data.npz") loads allow_pickle=False and removes only batch dimension, returning calibration_tdoa[35,6]float64s, calibration_positions[35,2]float64mm, sensor_positions[6,2]int32mm and observations[3,35,6]float64s. prepare(data,normalization="sample",sensors=None) returns CPU float32 Torch x[35,S],y[35,2],z[105,S]. Optional sensors selects columns and re-references the minimum. sample normalizes each row; feature uses calibration-only mean/std(correction=1); none leaves seconds. Zero norms/std and unknown modes raise errors.

physics_model.GP(dtype=torch.float32) holds seven ParameterDict tensors. kernel(a,b) returns RBF[Na,Nb]; task() returns task covariance[2,2]; noise() returns observation variance[2]; mean(n) returns interleaved[2n]; cov(x) returns full observation covariance[2N,2N]. nll(x,y) returns scalar normalized negative marginal likelihood. predict(x,y,test) returns mean[Ntest,2] and full predictive covariance[2Ntest,2Ntest]. General Torch softplus, exp, Kronecker products, Cholesky and cholesky_solve are the only covariance/conditioning primitives; formulas are explicit locally. No domain GP framework.

solvers.fit_model(x,y,iterations=5000,seed=0) initializes model/Adam and returns trained GP and actual float64 loss_history[iterations]. reconstruct(data,normalization="sample",sensors=None,iterations=5000,seed=0) prepares, trains on reference only and conditions on all105 rows. Returns (result,aux): result only reconstruction[1,3,35,2]float64mm; aux model/train_x/train_y/test_x/Torch tensors, covariance[210,210]float32 and loss_history. Its seeded initialization has no effect on observation row order. main.main sets CPU threads1, loads standard data, calls full reconstruct, writes output/reconstruction.npz and runtime. Library imports do not select a Matplotlib backend.

visualization.localization_comparison(truth,methods,sensors,title) creates one panel per condition showing true versus reconstructed coordinates and physical error vectors; plotting consumes explicitly supplied private truth. It is not called by CLI. ellipses may consume actual computed covariance, explicitly one SD. Notebook separately loads original reference outputs/hidden actual truth only for maintainer review, actively runs standard and all comparison paths and invokes standalone Judge with explicit UTF8 subprocess decoding.

evaluation.judge.coordinate_metrics(prediction,truth) returns nine millimetre-valued physical error metrics, using all rows. CLI strictly validates all required output shape/dtype/finites, exact metric set/comparisons/finitepositivebounds and hidden truth shape. Truth resolves relative to Judge. Physical coordinate bounds additionally apply. Status0/1/2 distinguishes pass/qualityfail/invalid-or-evaluatorerror. Evaluation imports no solver, model or submitted code. Report paths are caller-relative; parent creation and write-failure handling are explicit.

Tests consume two original numeric fixtures: upstream_gp_stages for initial covariance/loss/gradient/Adam, upstream_gp_posterior for original preprocessing and fixed learned-parameter conditioning. Active output physical-accuracy test uses actual independent controlled positions; analytic scalar conditioning and float64 finite-difference gradients do not use source-generated expected formulas. Notebook reference outputs label original model as original, never truth.
