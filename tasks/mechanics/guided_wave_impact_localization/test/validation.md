## Physics, coordinates and primary discrepancies
Six PIC255 PZT coordinates are [(0,0),(80,0),(160,0),(0,120),(80,120),(160,120)]millimetres. This is the local instrumented160-by-120mm frame on a290-by-200-by-4mm quasi-isotropic M21/T800 laminate, not the full-panel edge coordinates. Reference impacts use100g,2.5cm,90degrees,24°C, with2MHz acquisition. HEI uses5cm and ANG45degrees. Final Table3 says elevated temperature70°C while source README says80°C; both are disclosed, not silently reconciled. Temperature is not a numeric input to this selected empirical calibration inverse, so the discrepancy does not alter inference constants.

The primary travel-time equation subtracts a reference sensor; the physical supplied vectors specifically subtract the earliest-arriving sensor per impact, not permanently sensor1. Every row's exact minimum is zero. Relative times are seconds, not microseconds. No independent anisotropic group-speed field is supplied; known-position calibration is used as an empirical wave response and no constant speed is invented. Sample-direction normalization is invariant to a common positive scale only; true environmental changes can alter more than scale.
