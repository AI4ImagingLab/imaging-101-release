## Investigated numerical and scientific limitations
Original source covariance is2*inverse Hessian of NLL, whereas conventional asymptotic MLE is inverse Hessian. Both are shown and labeled; no claim of validated uncertainty coverage. Original Allan data overlaps but EDF invocation uses Greenhall nonoverlap default; retained as the actual effective-weight objective, not silently “corrected.” Nominal35PSD bins produce34complete overlapping segments after integer rounding; source gamma shape35 retained and documented. Original kstest diagnostic compares signed residuals to chi-square, which is not a valid calibrated residual-law test: it is not used as an acceptance metric or physical claim; all source printed results stay private. We do not treat these approximations as ground truth.

Gradient accumulation was investigated without changing frozen tolerances: at the original PSD no-noise optimum, original reverse grad(NLL) and original grad(NLL wrt mean)@jacobian(mean) differ by[-3.60e-4,2.76e-5] in dimensional units because of cancellation. Private debug_tweezer_autograd.py and tweezer_derivative_debug.npz preserve this independent evidence. A transparent local NumPy chain applies each elementary derivative and the same reduction order, yielding exact0difference for threecases and2.7e-20 in the fourth noise component on frozen upstream statistics. Tensor Hessians agree within the original1e-8 stage bounds. Derivative tests isolate original statistic inputs; preprocessing has separate parity and all four complete reconstructions are independently compared. A finite-difference test away from the stationary point confirms the derivative's mathematical meaning. The generic Nelder-Mead inverse itself uses no gradients, so the accumulation convention does not calibrate output values.
