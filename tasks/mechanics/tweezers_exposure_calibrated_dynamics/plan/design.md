# Shipped interfaces and execution

`src.preprocessing.load_data(path)` loads allow_pickle=False, validates finite float64(1,13631), and returns a copied(13631,)nm trajectory. Constants FS=400Hz and KT=4.1pNnm match README. `spectrum(trace,bins=35)` returns dict x(frequencies Hz),y(two-sided density nm²/Hz),shape(dimensionless); default arrays(378,). It explicitly builds windows/centers/FFT/normalization, with scipy.fft.fft as the numerical primitive. `allan(trace)` returns corresponding dict with12 averaging times(s), variances(nm²), and gamma shapes. `noise_id(trace,m)` estimates the exponent; `greenhall_weight(n,m,alpha)` evaluates the selected d=2 nonoverlap EDF formula directly.

`src.physics_model.prediction(x,parameters,kind='psd',exposure=True)` returns the expected density or variance. Parameters are length2(g,k) or3(g,k,e); missing e means exactly zero. `negative_log_likelihood(parameters,data,kind='psd',exposure=True)` returns scalar normalized gamma NLL, infinity for invalid/nonpositive model. `derivatives(parameters,data,kind='psd')` returns parameter gradient and dense Hessian, using transparent NumPy elementary reverse-chain gradient accumulation and general tensor Hessian differentiation for diagnostics; it is not called by the solver. NumPy and tensor arithmetic preserve the formula; derivative precision review is recorded in validation.

`src.solvers.reconstruct(trace,kind='psd',tracking_error=True,bins=35,exposure=True)` constructs observations, initializes from variance plus generic bead/water starting values, runs unbounded Nelder-Mead, raises on optimizer failure, and returns parameters,data,model,residual,nll,aic,iterations. Residual denominator is observed y/sqrt(shape). The standard call returns all3 physical parameters; notebook explicitly invokes four published comparisons and additional exposure/bin/half-record checks.

`src.visualization.relative_error(prediction,reference)` returns max relative absolute difference for nonzero reference components; `residual_rms(residual)` returns RMS. `src.main.main()` resolves task root from its own file, reads data/raw_data.npz, actively reconstructs, creates output/, writes output/reconstruction.npz with reconstruction(1,3)float64, and prints parameters. It does not select a plotting backend on import.

`evaluation/judge.py` independently loads and validates submissions, reads thresholds relative to its own file, prioritizes actual ground_truth.npz if present over baseline_reference.npz for parameter comparison, and always obtains independently measured observation PSD arrays from baseline_reference.npz. Those arrays are derived only from the public trajectory. It implements the PSD formula independently without solver imports. `load(path)`, `evaluate(path,assets=ROOT)`, `main(argv=None)` are used by contract tests and CLI. Reports use strict JSON and exit0/1/2. Caller-relative prediction/report paths remain caller-relative.

Fixture upstream.npz is consumed by stage/parity/physics tests. Notebook upstream_comparisons.npz supplies labeled original point estimates,NLL,covariance only; fresh_results.npz is generated by the active notebook and records fresh comparison estimates/metrics, not truth. The notebook actively reads raw data and local modules and writes a fresh output submission before independent evaluation. No runtime cross-task or original-package imports are present. Original sources, PDFs, logs and capture scripts stay outside this task.
