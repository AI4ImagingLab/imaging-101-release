# Shipped interface and execution flow

Standard command is `python -m src.main` from the task workspace. `src.main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads all measurements, reconstructs all three repeats and writes one NPZ, creating its parent. It returns the submission dictionary. Import has no plotting-backend effect.

`src.preprocessing.load_data(path='data/raw_data.npz')` returns t,c with shape(3,192), float64, units microseconds and dimensionless. It requires the two batch-first public arrays to have shape(1,3,192), finite entries and strictly increasing lags. `select_lags(t,g)` takes two native1D arrays and returns copies selected by the original public reliability rule. Constants define optical geometry and physical units; README agreement is tested.

`src.physics_model.scattering_vector(n=N,angle=ANGLE_DEGREES,wavelength=WAVELENGTH_NM)` returns scalar q in nm^-1. `stretched_exponential(t,amplitude,rate,exponent)` evaluates the optical short-lag model. `correlation_forward(msd,intercept,q=None)` returns c with MSD shape. `msd_from_field(g1,q=None)` returns nm². `modulus(t,msd,alpha,radius=RADIUS_NM,temperature=TEMPERATURE_K)` returns three1D arrays omega,storage,loss, units s^-1,Pa,Pa.

`src.solvers.cross_validation(t,g,p0)` returns unweighted leave-one-out MSE. `estimate_intercept(t,g)` returns scalar beta, interval(2,), fitted parameters(3,), CV scores(9,). `field_correlation(t,g)` returns g1 plus those four fit outputs. `local_power_law(t,msd,bandwidth=.1)` returns smooth MSD and alpha, each matching t. `reconstruct_one(t,g,bandwidth=.1,stride=1)` first selects reliable lags and optionally subsamples them; returns diagnostic dictionary with time,correlation,g1,raw_msd,msd,exponent,omega,storage,loss,intercept,window,parameters,cv_scores. Default stride1 computes the full benchmark.

`reconstruct(t,g,bandwidth=.1)` takes all3native curves and returns(submission,rows), where rows is a3-element list of diagnostic dictionaries. Submission has reconstruction(1,488,2), msd(1,488), exponent(1,488), intercept(1,3); all float64. The488 axis concatenates188+145+155lags in native repeat order. The last modulus axis is storage then loss. It performs no file IO. `laplace_alternative(t,msd,bandwidth=.01)` returns two1D modulus components and is only an explicit notebook comparison.

`src.visualization.metrics(estimate,reference)` returns standard NCC,NRMSE and rejects a zero-norm/constant reference. `diagnostic_figure(rows)` returns a Matplotlib Figure with six diagnostic panels. This module neither selects a backend nor saves files. Notebook owns plotting.

The notebook loads the same raw NPZ, actively calls reconstruct, writes its fresh result, runs the standalone Judge and produces fresh comparison/ablation plots. Archived upstream reference NPZ is explicitly labeled and used only for parity. Full upstream stages in test/fixtures are consumed by parity tests. Evaluation/baseline_reference is consumed only by the independent Judge. There is no actual truth asset and no generator because observations are measured.

`evaluation/judge.py --prediction PATH --report PATH` resolves hidden files against its own directory; submitted paths are caller-relative. It validates float64, shape, required keys and finiteness before scoring. It evaluates every output and forward consistency using public calibration constants. Invalid inputs/evaluator assets produce error, empty metrics and exit2; a valid poor result returns fail/exit1; pass returns0. Report-write failures return2 and stderr diagnostics. It never imports src or submitted code. Tests cover arbitrary caller directory, hidden asset failure, missing/malformed files, keys/shapes/dtypes/nonfinites, zero output and write failure.
