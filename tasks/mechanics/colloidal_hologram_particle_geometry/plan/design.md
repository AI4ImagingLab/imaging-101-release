# Shipped interfaces
preprocessing.load(path="data/raw_data.npz") returns native uint8 image and background (1024,1280), plus float64 normalized intensity. regions(normalized) yields each float64 crop, coordinates(3,N) in pixels and bool valid(N), in public ROI order.
physics_model implements local LMObject property plumbing and Particle/Sphere/Instrument/LorenzMie. Sphere.mie_coefficients(a_p,n_p,k_p,n_m,wavelength) returns complex128 coefficients(l,2). LorenzMie(coordinates,particle,instrument).hologram() returns float64 intensity(N). Positions are pixels, wavelengths and radii micrometres.
solvers.model_at(parameters,coordinates) maps one float64 five-vector and coordinates(3,N) to intensity(N). reconstruct(normalized,robust=True,seed=0,global_search=True) returns float64(1,2,5), and per-particle cost/nfev/success dictionaries. Global initialization uses a public-data subset and local refinement uses all valid pixels. Main.main() loads raw, reconstructs and writes output/reconstruction.npz; importing it changes no plotting backend.
visualization.comparison(normalized,parameters,title) produces observation/model/residual panels for both regions and returns the matplotlib Figure. Notebook calls the local solver actively, compares separately labeled upstream arrays, and runs controlled ablations. Judge is standalone with its own extracted forward equations, imports no solver, validates contract and evaluates the public objective against raw observations. No cross-task imports or upstream domain library calls exist in the shipped task.
