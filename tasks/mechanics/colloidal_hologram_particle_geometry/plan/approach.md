# Implemented inverse mathematics
The public Maxwell/Lorenz-Mie model fixes wavelength0.447um, nm1.34, pixel spacing0.048um. Normalize native image/background after subtracting13counts. Each ROI uses native image coordinates and removes only its maximum normalized pixel. The sphere relative index is np/nm; size is2pi nm a/lambda. Sphere.mie_coefficients evaluates downward logarithmic-derivative and upward outgoing Riccati-Bessel recurrences, then an electric/magnetic vector multipole sum. Field phase follows negative-z illumination. No scalar/radial approximation replaces vector scattering.
The objective is mean log(1+r2), r=(H-J)/.05. The .05scale is robust model scale. Differential evolution initializes z,a,np on a fixed2% uniform valid-pixel subset with seed0, population10per dimension,maxiter200,polish true,one worker; x/y initialize to the ROI center. It minimizes summed squared standardized residual, matching the upstream global-initialization family. Local scipy least_squares uses all valid pixels, trf,Cauchy loss,x_scale=jac,max_nfev300,ftol=xtol=gtol=1e-9,finite-difference Jacobian and physical bounds stated publicly. No extra regularizer is used. Output is the five fitted parameters for both particles. Notebook variants use linear residual loss, omit global exploration, or perturb normalized observations; these are comparisons, not the shipped standard.
Local starts, tolerances and random sampling are maintainer numerical choices. The public conditional objective accepts any equal/better solution; finite algorithm identity and reference parameter equality are never scored.
