# Implemented physical inverse method

All calculation uses SI internally. Observed displacement is converted from mm only when estimating Dc; the author comparison coordinate remains mm. Define M=7798.2 kg/m², K=90.5e9 Pa/m, sigma=40e6 Pa, Vref=3e-6 m/s and Vini=3e-7 m/s. The loadpoint X(t)=Vini*t+DeltaV*logcosh(t-tj)/2+DeltaV*t/2-DeltaV*logcosh(-tj)/2, DeltaV=2.7e-6 m/s, tj=24.8s; transition width is 1s. Stable logcosh avoids overflow and preserves source operation order.

Active states are slider displacement x, velocity V and psi=ln(Vref*theta/Dc). Here ln is the natural logarithm; log10 denotes base-ten logarithms only in fit parameters. Set b=a+ba. The source force friction is muReg=a*asinh[V/(2Vref)*exp((mu0+b*psi)/a)]. Dynamics are x'=V, V'=K/M*(X+Xini-x)-sigma/M*muReg-C/M*V, psi'=-(V/Dc)*(ln(V/Vref)+psi). The continuous VlnV limit is zero; the selected full trajectory must stay strictly positive. C=3e-6*2sqrt(K*200)=25.5264568634 Pa s/m preserves the author's helper argument/default-mass convention, rather than inventing measured damping. The two other source states are constant pressure deviation zero and porosity .1; they decouple, but their five-state error-norm convention is retained. Initial V=Vini, x=0, psi from the source regularized steady-friction inverse (numerically near ln(10)), with Xini=sigma*muIni/K+C*Vini/K.

Preprocessing takes all914 measurements. Let j be the nearest time to tj. Set ba=(mean(mu[:j+1])-mean(mu[-51:]))/ln(10), and mu0=mean(mu[:j+1])+ba*ln(.1). These are constrained steady-portion estimates, not independently true material parameters. Initial a=(max(mu)-mean(mu[:j+1]))/ln(10) with floor .0021; initial Dc uses the source exponential decay estimate at fractional tail offset .33, repeatedly halved if inadmissible. Exact rounding and positivity conventions are in initial_guess.

Integration uses explicit local Rosenbrock23 with d=1/(2+sqrt2), c32=6+sqrt2. With h the step, J=df/du, ft=df/dt and W=I-h*d*J, stages are k1=W^-1(f0+h*d*ft), fm=f(t+h/2,u+h*k1/2), k2=W^-1(fm-k1)+k1, unew=u+h*k2, fn=f(t+h,unew), k3=W^-1(fn-c32*(k2-fm)-2*(k1-f0)+h*ft). The embedded estimate is h*(k1-2k2+k3)/6. Exact local state Jacobian and ft=(0,K/M*X',0) replace source automatic differentiation without changing the ODE. General LU only solves these three-state systems.

Default original atol=1e-6 and rtol=1e-14 are retained. Error is sqrt(sum((estimate/(atol+rtol*max(abs(u),abs(unew))))²)/5). Hairer initial-step selection uses original five-state norms and order2. PI control uses beta1=.35, beta2=.2, safety .9, qmin=.2, qmax10 (first acceptance10000), previous error floor1e-4, and adaptive-implicit deadband1<=q<=1.2. Reject when error>1, reduce by min(5,error^.35/.9). Maximum100000 steps and underflow checks fail explicitly. Every accepted node is retained. Full equations and implementation roles are locally executable; no domain solver is called.

Reported friction is mu0+a*log(V/Vref)+b*psi, the author's positive-velocity output convention. Interpolate this, V and psi linearly against X(t)*1000 at observed displacement, with source linear extrapolation; theta=Dc/Vref*exp(interpolated psi). Thus interpolation precedes the state exponential.

Fit z=(log10(a),log10(Dc)) using scipy.optimize.least_squares TRF, default two-point Jacobian and default ftol/xtol/gtol, max_nfev10000, bounds a .002..04 and Dc1e-7..1e-3m. Return the complete914-vector (muObserved-muPredicted)/.0004. Objective is half sum of squared standardized residuals. This explicitly corrects the released scalar chi-square interface: scalar s=rᵀr gives objective .5s² and Gauss-Newton rank<=1, incompatible with standard NLS and two-parameter covariance. No regularizer or custom parameter difference-step is added. No physical equation, bound or initial estimate is changed by this correction.

Judge evaluates separate absolute a,b,Dc errors, maximum theta error, velocity relative L2, maximum friction error and measured-friction RMS. There is no alignment, rescaling or hidden crop. All limits were frozen independently before local vector-interface extraction and retain the prior stricter physical/observation limits. No ground truth is available; the hidden baseline is an independently repeated corrected original-method result. Reference agreement does not establish true contact parameters.
