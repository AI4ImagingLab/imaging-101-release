# Shipped interfaces and flow

preprocessing.prepare(path=Path('data/raw_data.npz')) reads batch-one float64 time/displacement/friction and returns one-dimensional arrays plus scalar b_minus_a, mu0 and integer jump_index. NPZ uses allow_pickle=False. No hidden result enters preparation.

physics_model exposes logcosh, loadpoint(time), loadpoint_velocity(time), regularized_friction(velocity,psi,a,b,mu0), state_rhs(velocity,psi,Dc), initial_conditions(a,b,Dc,mu0,mass=MASS_PER_AREA), derivatives(time,state,a,b,Dc,mu0,loading_offset,mass=MASS_PER_AREA), state_jacobian with that same signature, and trajectory(log_parameters,data,mass=MASS_PER_AREA). State arrays are three active SI variables. trajectory returns batch-one float64 reconstruction(1,3), friction/state/slider_velocity(1,914), with respectively dimensionless a,b and metres Dc, dimensionless friction, seconds theta and m/s velocity. All four outputs are evaluated.

ode_integrator.step(function,jacobian,time_derivative,time,y,h,f0=None) returns proposed state, endpoint derivative and embedded error. integrate(function,jacobian,time_derivative,initial,final_time,abstol=1e-6,reltol=1e-14) returns node times(N,), active states(3,N), and accepted/rejected counts. Pure numeric arrays are used; the fixed source placeholders affect error norms only. Both stages and adaptive controller are explicit local mathematics.

solvers.initial_guess(data) returns two log10 parameters. residual_vector(log_parameters,data) returns914 standardized residuals; chi_square returns their squared norm for diagnostic plots. reconstruct(data) returns the trajectory dictionary and info containing actual evaluation history, nfev, success, termination message, objective, initial log parameters and residual Jacobian(914,2). SciPy provides only general TRF optimization and linear interpolation/LU primitives.

python -m src.main prepares public observations, actively reconstructs and saves output/reconstruction.npz. It selects a plotting backend only in CLI execution. visualization.review_figures(data,fresh,upstream) creates data/residual, latent-state/velocity and parameter comparison figures; it does not run inversion. evaluation/judge.py is independent of solver imports, validates strict shapes/dtypes/finiteness, scores all required fields and returns0/1/2 according to pass/fail/error.

The notebook runs reconstruct directly on public data, independently scores fresh outputs, saves fresh_notebook_result.npz, and loads labeled original arrays only for comparison. Fresh81-point objective geometry, optimizer history, apparatus-mass forward sensitivity and slip-versus-aging vector-field comparison supplement the selected NLS scope. It does not claim Bayesian chains or aging-law inverse fits. Tests consume frozen numeric fixtures only; no original Julia code, private environment or cross-task module is imported.
