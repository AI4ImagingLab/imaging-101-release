# Shipped interface design

`src.preprocessing.load_observations(path)` loads NPZ with pickle disabled and validates three float64 arrays `positions`, `displacement`, `displacement_sigma`, each(1,32,32,2), last axis(x,y), all finite and sigmas positive. Positions are sensor pixels; displacement is already source-convention signed pixels. It returns a plain dictionary without target information.

`src.physics_model.calibrate(Xpix,Ypix,U,V,sU,sV)` accepts equal-shaped two-dimensional float arrays and returns `(x,y,gx,gy,sgx,sgy)` in meters,kg/m⁴. Fixed acquisition constants match the README. `integration_operators(x,y)` returns CSR `(D,B,C)` with shapes(2108,1024),(2108,2048),(2108,124) for the native grid. The function is also exercised on independently known rectangular grids. No domain packages are used.

`src.solvers.integrate_wls(x,y,gx,gy,sgx,sgy,*,uniform_weights=False)` returns density,sigma,diagnostics. Diagnostics include operators, covariance, right-hand side and standard residual. `integrate_poisson(...)` has the same physical inputs/outputs. `reconstruct(observations,method='wls',uniform_weights=False)` calibrates every native observation and returns batch-first `reconstruction` and `density_sigma` plus private diagnostics. The default path uses WLS and full covariance propagation.

`src.main` is the standard CLI, `python -m src.main`; it writes only the two declared numeric arrays to `output/reconstruction.npz`. Library imports do not change Matplotlib backend. Visualization is separate and used by the active notebook. The shipped `src.generate_data` helpers own every newly synthesized diagnostic perturbation; existing bound observations are never regenerated.

`evaluation/judge.py` is standalone, independent of `src`, with actual truth priority if present and otherwise selected-method reference. `evaluate(prediction,evaluation_dir=None)` returns a strict JSON-ready dictionary; an optional evaluation directory supports isolated contract tests. `reference_metrics(x,y)` returns cosine and range-NRMSE, assigning cosine0 for a zero estimate. `forward_rms(density,raw_path)` independently calibrates legitimate public observations and checks all equations. `configuration(path)` rejects invalid numeric thresholds including booleans/strings. `arrays(path)` requires both float64(1,32,32) arrays, finite values and nonnegative standard uncertainty. CLI paths use caller semantics and hidden paths use the evaluator directory. Invalid truth never falls back; metric overflow gives error/empty metrics; report-write failure returns2. Normal tests consume archived numeric fixtures; no upstream imports or cross-task imports.

`src.generate_data.add_displacement_noise(observations,multiplier=1.,seed=123)` returns copied public arrays with independent Gaussian MC-displacement noise in pixels. `conditional_density_samples(diagnostics,gradient_sigma,n_draw=2048,seed=731)` returns(1024,n_draw) density deviations in kg/m³ using fresh independent nodal-gradient and boundary draws and the same fixed WLS system. It verifies covariance algebra, not physical coverage. The bound data are never replaced.

`src.visualization` provides six figure constructors accepting already-computed arrays: `observations(pos,disp,sigma,extent)`, `calibration(cal,extent)`, `results(wls,poisson,extent)`, `comparisons(wls,poisson,upstream,extent,cal)`, `uncertainty(wls,poisson,mc_sigma,uncorrected,extent)`, and `sensitivity(wls,uniform,mc_only,noise_results,noise_levels,extent)`. `save_group(fig,folder,name)` writes PNG,SVG,PDF under an explicit external directory. Constructors neither load inverse references nor run reconstruction. Extents are in millimeters; quantitative arrays remain in SI units.

The notebook reconstructs both integration methods actively and compares qualified upstream results separately. Six chapters cover problem, native data/calibration, WLS/Poisson equations, full-field results, covariance draws, and weighting/noise sensitivity. Every code cell is executed, six PNGs are embedded, and all figure sources are privately exported. The actual research executable/kernel/backend is printed and archived. The standard CLI does not plot or change a backend. Signature and mathematical semantics were reviewed against actual source before final provenance capture.
