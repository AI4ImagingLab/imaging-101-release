# Shipped execution flow

`python -m src.main` calls preprocessing.load_data(path), then solvers.reconstruct(observed,weights,initial=(2.7,.8)), saves output/reconstruction.npz and prints diagnostics. No hidden arrays are read by reconstruction. The input has frequencies and analysis_weights of shape (1,70), float64; frequencies are MHz, weights dimensionless. load_data returns two length70 vectors. The standard output keys are reconstruction (1,2) float64 GPa, component order c11,c44, and resonances (1,76) float64 MHz, ascending order.

physics_model.moment_table(order,dimensions=DIMENSIONS_CM) returns float64 volume moments indexed by three powers, units cm^(p+q+r+3). basis_blocks(order) returns eight int64 arrays with columns component,l,m,n. assemble_block(basis,table) returns mass and two linear stiffness coefficient matrices. operators(order=14) caches only geometry-dependent whitened coefficient matrices, up to three orders. resonances(moduli_mbar,order=14,count=76) evaluates every symmetry block and returns a length-count float64 MHz spectrum, removing six rigid modes.

solvers.match_modes(measured,calculated) returns int64 calculated indices with no stored association table. objective(observed,calculated,weights) returns the source dimensionless percent-squared objective. paired_lm(observed,weights,indices,initial) returns fitted Mbar coefficients and iteration dictionaries. reconstruct returns (output_dictionary,diagnostics_dictionary), including the actually inferred associations, original LM history and RMS percent. Geometry, acquisition constants and standard settings are explicit in source and README/plans.

evaluation/judge.py has no solver imports. It validates both declared arrays and evaluates the hidden method reference, preferring actual ground truth if supplied in a future evaluator. A separately implemented monotone path algorithm supports the public observation-consistency metric. CLI prediction/report paths resolve against caller CWD, references against the evaluator file. Native exit codes are0 pass,1 valid quality failure,2 malformed prediction/evaluator/report error.

The notebook actively calls the cleaned reconstruction on raw observations, independently evaluates it, compares to the original method measurements, examines missing modes and residuals, tests several initial priors, and computes polynomial-order convergence and fresh objective contours. Reference arrays are exclusively for labeled comparison. visualization.review_figures returns scientific figures without selecting a global plotting backend. Tests consume archived numerical fixtures, never original libraries. Maintainer capture scripts and native source/binaries remain outside the task.
