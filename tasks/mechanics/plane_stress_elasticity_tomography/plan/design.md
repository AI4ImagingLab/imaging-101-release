# Shipped interfaces and execution

The standard command is `python -m src.main`; it reads `data/raw_data.npz`, prepares the inverse context, runs complete TV reconstruction, and writes only float64 `reconstruction` with shape `(1,800)` to `output/reconstruction.npz`. Optional CLI arguments select the data/output paths, `tv`, `smooth` or `tikhonov`, and verbose progress. No hidden assets are read by source reconstruction modules.

`preprocessing.load_data(path)` strictly validates the five batch-first public arrays and returns an `Acquisition` containing unbatched nodes `(441,2)`, triangles `(800,3)`, displacement and nodal force `(441,2)`, and fixed degree flags `(441,2)`. Float arrays are float64; connectivity is integer and flags boolean. Coordinates/displacements use L0, force F0, and numerical moduli E/E0, with E0=F0/L0². `element_incenters(nodes,triangles)` returns `(800,2)`. `observation_weights(displacement)` returns 882 diagonal weights using noisy public measurements alone.

`physics_model.PlaneStressModel(acquisition)` precomputes affine element gradients, unit-modulus element stiffnesses and assembly indices. `forward(modulus)` assembles the stiffness, replaces constrained diagonals using the current maximum diagonal, and returns interleaved displacement `(882,)`. `jacobian(modulus)` performs all central current-state perturbations and returns `(882,800)`. `strain(displacement)` returns physical symmetric affine strain tensors `(800,2,2)`. These functions do not perform file I/O.

`solvers.prepare_inverse(acquisition)` returns an `InverseContext` containing the model, measured-data weights, initial field, dual gradient matrices, dual triangles, Gaussian precision, and TV coefficients. `homogeneous_initializer(model,measured)` returns `(800,)`. `gradient_operators(centers)` returns two sparse `(1521,800)` matrices and integer dual connectivity. `gaussian_prior_precision(centers,mean)` explicitly builds and inverts the source covariance. `prior_terms` and `Objective` implement the documented cost/gradient/Hessian and fixed barriers. `gauss_newton_direction` performs the weighted linear update. `uniform_line_search` performs the complete projected 100+100 search, optionally returning both numeric grids for verification.

`reconstruct(context, prior='tv', alpha_multiplier=1., maximum_iteration_index=100, verbose=False)` returns `ReconstructionResult`: final field `(800,)`, modulus history `(N,800)`, objective history `(N,)`, step sizes `(N-1,)`, directions `(N-1,800)`, predicted displacement `(882,)`, actual runtime, prior and stop reason. Default cap allows 99 updates; actual relative-cost/increase stopping may terminate earlier. Truncated iteration settings exist for stage verification only; the CLI and active review notebook use the complete cap. The last increase-triggered update is retained, matching the qualified source.

`generate_data.generate_observations(geometry, standard_normals=None, seed=43)` is maintainer-only. It constructs the author's rectangular element field, explicitly solves the local FEM, and applies two sequential noise terms. It ignores the supplied displacement when simulating. Optional `(2,882)` archived Octave standard-normal draws reproduce the bound realization within independent FEM rounding; NumPy's default generator instead gives another draw under the same model. It returns a new Acquisition, actual field, noiseless displacement and draws; it writes no files and cannot overwrite the bound input.

`visualization.quality_metrics` implements cosine NCC and dynamic-range NRMSE. `comparison_metrics` adds a local forward residual and strain metric for plotting. `make_figures` requires all three original, qualified and fresh methods, plus three actually computed TV multipliers. It returns six Matplotlib figure groups. `export_figures` writes PNG/SVG/PDF, numeric sources and hashes to the caller's chosen private directory. Library imports do not select a Matplotlib backend.

The notebook actively calls the local full reconstruction five times (three priors and two additional TV multipliers), independently evaluates the fresh standard submission, and plots separately labeled original source, qualified source and fresh results. Frozen source arrays are used only for comparisons. It also recomputes simulation from FEM and frozen normal draws. It never imports the upstream implementation.

`evaluation/judge.py` is a standalone hidden evaluator with no solver imports. Assets resolve beside that file; command arguments resolve in the caller's working directory. Actual truth takes priority over baseline fallback. Prediction and references use strict float64 positive `(1,800)` arrays. Independently assembled FEM and analytic affine strain support observation and applicability metrics. Every declared threshold is consumed; status codes are 0 pass, 1 valid-but-failing, 2 malformed input/evaluator failure. JSON reports contain measured metrics, comparisons/boundaries and descriptive errors.

Tests under `test/unit_test` verify schema, independent physical identities, derivative cases, generation and Judge contracts; `test/comparing_test` consumes independently frozen original fixtures and performs fresh full-TV reconstruction. `test/validation.md` identifies every numeric consumer and records source qualification, provenance and actual execution evidence.
