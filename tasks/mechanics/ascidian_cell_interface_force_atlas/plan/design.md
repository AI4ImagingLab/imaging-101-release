# Shipped interfaces and actual execution flow

The standard command is `python -m src.main` from this task directory. It reads only the public observation NPZ and writes the two declared batch-first arrays in `output/reconstruction.npz`. The implementation uses standard library, NumPy and SciPy. Matplotlib is used only by review visualization. No foambryo, dw3d, trimesh, networkx, other task or private oracle is imported by source, tests, Judge or notebook.

## Geometry preprocessing

- `preprocessing.Mesh(vertices,triangles,region_labels,original_vertex_indices)` is a dataclass with unbatched arrays. Used vertices are float64(N,3), zero-based triangles int64(F,3), labels int64(F,2), and original indices int64(N,). Coordinates are author mesh units, not micrometres. No domain mesh object or opaque graph is retained.
- `load_observations(path)` loads NPZ with `allow_pickle=False`, requires exactly `vertices`, `triangles`, `region_labels`, each batch-first rank3 with batch1 and finite values, copies arrays and removes only the leading batch axis. The subsequent preparation validates detailed geometry shapes and index types. It reads no hidden file and writes nothing.
- `prepare_mesh(vertices,triangles,region_labels)` validates dimensions, integer labels/indices, range and distinct region pairs. It converts coordinates to float64 and indices/labels to int64, sorts each region pair with matching winding reversal, removes unreferenced vertices and returns Mesh. Triangle order is preserved, with no cropping, smoothing or face deletion. There are67303 used vertices and144312 faces in the bound observations.

## Explicit physical operators

- `triangle_geometry(mesh)` returns triangle-coordinate float64(F,3,3), unit normals(F,3), and areas(F,), in mesh units and mesh-unit squared. It rejects zero-area triangles rather than assigning a fabricated normal.
- `junction_geometry(mesh)` constructs unordered geometric edge groups from triangle half edges, reads explicitly oriented chord wedges, and returns a dictionary. `angles` maps integer triples(min outer label,interior label,max outer label) to mean radians. `lengths` maps the same keys to six-times line arclength in mesh units, preserving the historical source accounting. `valid_edges` and `malformed_edges` are int64(E,2) endpoint arrays in the used-vertex numbering. `junction_vertices` includes vertices on every edge of valence>2, including higher junctions, as required by curvature comparisons. It does not alter mesh triangles. The128 malformed three-region edges are observable topology diagnostics, not a force-dependent mask.
- `_scatter(triangles,rows,slots,nrows,nvertices)` is the internal numeric COO scatter-add into CSR; slots are three arrays(F,3) of vertex-gradient contributions. It provides no inverse operation.
- `area_volume_operators(mesh)` returns `(D,V,interfaces,cells,areas)`. D is CSR(357,201909) area gradient, V is CSR(65,201909) signed-volume gradient including exterior, interfaces int64(357,2), cells int64(65,), areas float64(357,). Columns are vertex-major x,y,z. Rows follow sorted observed labels, not an assumed consecutive cell numbering. Area derivatives have length units, volume derivatives length squared.
- `tension_system(geometry,interfaces,weighted=True,method='young_dupre')` returns dense float64(Mrows,357) and RHS(Mrows,), with a final normalization row. Default has1708 rows. Methods are `young_dupre`,`projection`,`lami`,`inverse_lami`,`log_lami`. Projection has two rows per line; others three. `weighted=False` is the explicit ablation. The final RHS is357 except for Log Lami's zero log-gauge. Singularity exclusions for the two singular formulas follow the fixed source arithmetic rule; no threshold is selected from a hidden target.
- `interface_curvatures(mesh,geometry,weighted=False,return_diagnostics=False)` returns float64(357,) inverse-length curvatures, with NaN only when an interface has no off-junction measurement. `weighted` selects incident-area versus equal-vertex averaging. With `return_diagnostics=True`, returns `(curvatures,diagnostics)`; diagnostic arrays are `laplacian`(N,3), `normals`(N,3), `inverse_area`(N,), and `vertex_curvature`(N,). These are for the documented numerical-sign investigation and scientific review, not cached solver inputs.
- `cell_volumes(mesh)` returns sorted cell labels and float64(65,) signed volume, in mesh-unit cubed. Exterior volume is negative. This is an independent physical/plot diagnostic; default pressure reconstruction uses analytic volume derivatives, not these scalar volumes as calibration.

## Solvers and comparisons

- `solve_tensions(matrix,rhs,mean_tension=1.,logarithmic=False)` accepts a force system with final gauge row and returns a float64 vector of interface tensions. It derives a power-of-two gauge-row weight from nonzero physics row norms, calls general `scipy.linalg.lstsq`, and rescales the homogeneous solution to the exact arithmetic gauge. `logarithmic=True` instead shifts the solution's log mean then exponentiates, preserving Log Lami's geometric gauge. The method does not solve a positivity-constrained substitute.
- `solve_pressures(D,V,tensions)` uses the full V including exterior, excludes row0 internally, evaluates explicit Gram/cross products and dense inverse, and returns float64(65,) with exterior0. It neither estimates geometry nor fits a pressure scale.
- `reconstruct(observations,weighted=True)` accepts the unbatched observation dictionary from `load_observations`. It calls mesh preparation, junction measurement, analytic operators, default scalar tension system, tension solve and variational pressure solve. Returns a dictionary containing `tensions`(357,),`pressures`(65,),`interfaces`(357,2),`cells`(65,),`mesh`,`geometry`,`D`,`V`,`areas`,`M`,`b`. Array units/conventions are those above. Every value is freshly computed; there is no input checkpoint or file access in this function.
- `solve_variational_tensions(D,V,route='gram')` computes an alternative tension vector. Gram explicitly forms/row-normalizes the finite Gram system, eliminates cell pressure blocks and solves the exact-gauge Schur system. `route='operator'` implements the source's later full vertex-force operator, Householder gauge elimination and dense least squares. It uses temporary dense arrays of shape(201909,421) and(201909,420); they are released on return. Both are comparison-only, explicitly distinguished, and source-validated separately. No GPU is required; numerical threads are pinned externally.
- `solve_laplace_pressures(mesh,geometry,tensions,interfaces,cells,areas,weighted_curvature=False)` returns float64(65,) from the actual cotangent-curvature pressure law. It weights equations by interface area, eliminates exterior pressure0 and solves only cells connected to exterior through measurable interfaces; other cells stay NaN. Both complete bound comparison outputs are finite. `weighted_curvature=True` changes only vertex averaging within each interface, not equation weights.
- `compare_formulations(result,include_operator=True)` reuses already computed geometry/operators from a fresh `reconstruct` result. Returns named dictionaries for five chord-angle formulations, historical variational Gram, optional later Operator, two curvature pressure routes and no-length-weight Young–Dupré. Each has actually computed `tensions` and/or `pressures`. It does not load an original result or replace a missing computation with zeros. Log Lami keeps its native geometric gauge in these returned arrays.
- `generate_data.perturb_geometry(observations,sigma,seed)` copies observed arrays and adds independent Gaussian coordinate displacement in mesh units. It is used only by fresh notebook robustness experiments, with fixed explicitly reported sigma/seeds. No benchmark observations or truths are generated, and the standard CLI never calls it. Its docstring distinguishes diagnostic new perturbations from the existing real binding.

## Main and standalone evaluation

`main.main(argv=None)` parses `--data` default `data/raw_data.npz` and `--output` default `output/reconstruction.npz`, both caller-relative. It runs the complete selected reconstruction, creates the output parent, writes float64(1,357) tensions and(1,65) pressures, and prints runtime, interface/region counts, malformed-edge count and output path. It returns that summary dictionary. Importing main does not import plotting utilities or change the Matplotlib backend.

The independent `evaluation/judge.py` imports only standard library and NumPy. `load_field(path,role)` checks exact keys, batch-one shapes, real float32/64, finite values and NPZ safety. `reference_metrics(x,r)` implements uncentered cosine NCC and range-normalized RMS error, rejects a constant/zero reference and assigns zero NCC to a zero estimate. `observation_physics(tensions,pressures,raw_path)` re-derives triangle gradients directly from public geometry, maps nonconsecutive region labels to sorted output indices, scatter-adds area/pressure forces and evaluates all64 pressure moments plus both gauges. It imports no solver function.

`evaluate(prediction,asset_dir=HERE)` resolves hidden assets relative to the Judge file by default, reads the explicit finite metric definitions, prefers actual truth if present and otherwise uses `baseline_reference.npz`. This task has no force truth. It validates all required quantities before scoring. Pass/fail return0/1; malformed inputs or evaluator failures return2 with empty metrics. CLI paths for prediction/report are caller-relative, nested report parents are created, and report-write failures emit stderr and return2. No submitted code is imported or executed. Both quantities and every declared physics/gauge metric must pass.

## Notebook and visualizations

The active notebook has six story chapters: problem, data, physics, method, results and conclusion. It first builds the observation geometry for acquisition review, then actively runs the full selected `reconstruct` path, writes its fresh NPZ, independently evaluates it, and computes every comparison, jitter, coordinate-scale, gauge and arithmetic experiment. Loaded original arrays are separately labeled. Historical simulated-truth results are context and are never reported as this specimen's force accuracy.

`visualization.style()` configures presentation only and never selects a backend. `centers(result)` returns geometric interface and region centroids for display/graph placement; these are observed-geometry summaries rather than force-dependent calibration. `surface(ax,result,values,cut=False,norm=None,cmap='viridis',explode=False)` renders actual triangle values: exterior only by default, a y-half-space for a labeled display cutaway, or complete per-cell surfaces displaced by75% of centroid offset for an explicitly exploded display. Reconstruction and metrics never use these display selections. Dense triangle artists are rasterized inside SVG/PDF; labels and axes remain vector.

The six plotting functions return `(MatplotlibFigure,numeric_dict)`: `plot_observations(result)`, `plot_atlas(result)`, `plot_parity(result,original)`, `plot_comparisons(result,methods)`, `plot_sensitivity(result,perturbed,sigmas)` and `plot_scaling(result,scaled,scales,gauged,precision,thresholds)`. Plotting receives computed results; it never reconstructs or substitutes references. Native Log Lami arrays remain in numeric sources while its plotted atlas is rescaled to arithmetic mean1. Signed difference maps have symmetric zero-centered color limits. All force metrics use complete arrays. Scale-error/precision bar displays have an explicit1e−18 plotting floor, while numeric sources retain exact zeros/full precision.

`export_figure(fig,figure_id,directory,numeric)` creates the supplied maintainer-only directory, exports paired PNG/SVG/PDF with tight bounding boxes, and saves `<figure_id>_numeric.npz`. The notebook takes the external export path from `IMAGING_FIGURE_DIR`; with no path it still reconstructs and displays every figure, without exporting temporary PDFs into the task. It saves fresh scientific diagnostics and full-precision environment/metric provenance in `notebooks/reference_outputs/` and prints its actual Python/backend/thread environment. No library module changes the backend.
