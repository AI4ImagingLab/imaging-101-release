# Shipped interfaces and actual data flow

The standard entry is `python -m src.main`. `run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads public observations, calls the balanced reconstruction, creates the output parent and writes/returns a dictionary: reconstruction float64(1,181,181)N/m, forces float64(1,4)N and contact_directions float64(1,4)rad. No hidden reference, cache or original package is imported.

`preprocessing.load_data(path)` uses allow_pickle=False, unwraps the batch axis and returns rgb uint8(181,181,3) and contact_angles float64(4)rad. `prepare(rgb)` returns normalized float64(181,181) intensity. `disk_mask(shape=(181,181),center=CENTER,radius=RADIUS)` returns a boolean circular support. Exact observation-fitted constants are CENTER,RADIUS; NOMINAL_PIXELS_PER_METRE=160/.007 and EFFECTIVE_PIXELS_PER_METRE is equal to it; FSIGMA=140N/m. This final correction preserves floating calibration, unlike the archived original optimizer's integer truncation.

`physics_model.stress_basis(beta,shape=(181,181),pixels_per_metre=EFFECTIVE_PIXELS_PER_METRE,alpha=None,center=CENTER,radius=RADIUS)` returns float64(contact,3,row,column), tensor components Txx,Tyy,Txy per unit force. alpha=None means radial directions. `principal_difference(forces,basis)` returns float64(row,column)N/m. `intensity_from_stress(stress_difference,fsigma=FSIGMA)` evaluates the dark-field sin-squared law; `forward(forces,basis,fsigma=FSIGMA)` combines these operations. Outside support is zero; no plotting/backend/file side effects occur.

`solvers.constraint_matrix(beta)` returns the explicit static3x(2*contacts) matrix. `decode(q)` returns(force magnitudes,angular departures). `objective(q,intensity,beta,fsigma=FSIGMA,center=CENTER,radius=RADIUS)` returns the scalar inner0.96-radius pixel SSE. `objective_gradient` has the same signature and returns central finite-difference derivatives in force-component coordinates. `normbound(q)` returns1-n^2-t^2; `normjac(q)` returns its analytic Jacobian.

`fit_forces(intensity,beta,fsigma=FSIGMA,initial=.04,balanced=True,center=CENTER,radius=RADIUS)` runs the explicitly documented SLSQP inverse and returns(forces,alpha,info). info contains objective,iterations,cartesian and constraint_residual arrays. Non-success raises. balanced=False removes only static equality constraints for the notebook ablation; angular/force bounds and optical objective remain. `reconstruct(data,fsigma=FSIGMA,initial=.04,balanced=True,center=CENTER,radius=RADIUS)` returns(output dictionary,info) and computes the full-disk stress field after fitting. Alternate optical/geometry/initial values are review experiments, not standard entry defaults.

`visualization.agreement(x,r)` returns independently tested NCC/NRMSE. `panel(ax,a,title,cmap='magma',vmin=None,vmax=None)` uses calibrated mm axes. `acquisition_figure(data,result)`, `stress_figure(fresh,upstream)` and `sensitivity_figure(rows,fields)` return Matplotlib figures without saving. The stress plot explicitly labels its99th-percentile display clipping; saved arrays and Judge are unclipped. No library calls matplotlib.use.

The canonical notebook actively calls run and loads `notebooks/reference_outputs/upstream.npz` only for labelled original-forward constrained-oracle comparison. It recomputes balanced/unbalanced/coefficient/initial/geometry experiments and writes fresh_measurements.npz. Consumers are the notebook and private final figure/numeric-source exports. Keys reconstruction,forces,contact_directions,unbalanced_intensity,balanced_intensity,low_fsigma_forces,high_fsigma_forces,runtime_seconds retain fresh provenance.

The standalone Judge has no solver imports. It validates every declared key/shape/dtype/finiteness, uses actual truth if present otherwise the inferred method reference, and independently computes physical static ratios from the declared contact convention. evaluate(prediction,asset_dir=ASSET_DIR) returns(report,code). CLI0=pass,1=valid poor/unbalanced prediction,2=malformed/evaluator/report error. Hidden assets resolve relative to the Judge; user CLI paths follow caller cwd. metrics.json declares all numeric comparison boundaries. No implicit normalization or fitted alignment is performed.

Fixtures balanced_upstream.npz and balanced_stress.npz contain independently captured original forward/constraint-gradient/constrained-solver results and the observed unmodified Python stress intermediate. geometry.npz contains measured red-rim input points and the observation-only fitted circle. Comparing tests check raw/preprocessing fidelity, forward and stress parity, objective/constraint Jacobians, static balance, scalar units, optical homogeneity and exact geometry constants. Unit tests cover all three required quantities separately, missing/corrupt/evaluator failures, truth priority, cwd independence and report-write failure. No original/domain code is imported in normal tests. Existing real observations are reused; no generator is shipped.
