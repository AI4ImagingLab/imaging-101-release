## Elastic and optical forward

For image-relative coordinates x=(column-centre_column)/pixels_per_metre and y=(row-centre_row)/pixels_per_metre, radius R is in metres. For each force with departure a=alpha and position b=beta define b1=pi-b and b2=b1-sign0(a)*pi+2a, where sign0(a) is-1 for a<0 and+1 otherwise. The unit chord d is proportional to R(sin b2-sin b1,cos b2-cos b1). The vector from contact to the image point is v=(x-R sin b1,-y-R cos b1), length r. Define q=(v dot d)/r-1e-10, matching the original numerical arccos convention. Inside the disk this is valid; values outside are masked to zero before angular evaluation.

The integrated radial stress is S=(-2/pi)F*q/r. Its angle in the source Cartesian tensor is theta=sign(v_y*d_x-v_x*d_y)*acos(q)+b-pi/2-a. Accumulate T_xx+=S*sin(theta)^2, T_yy+=S*cos(theta)^2, T_xy+=S*sin(2theta)/2. Each contact is evaluated explicitly in NumPy; no domain stress solver or finite-element wrapper is used. The source removed an erroneous anisotropic uniform subtraction; the remaining hydrostatic ambiguity cannot affect DeltaT=sqrt((T_xx-T_yy)^2+4T_xy^2). This quantity has units N/m, not Pa. The optical response is I_pred=sin(pi*DeltaT/f_sigma)^2. Stress and intensity are exactly zero outside the disk. At an exactly collapsed source chord, the original function returns0 immediately; the local function preserves this guard. The selected angular search bound avoids this degenerate state in valid fitting.

Preprocess RGB to I_obs=clip((G-0.5R_channel)/(255*0.65),0,1), preserving uint8 input and computing float64. This is the author's red-leakage/contrast convention. The fit compares only the inner0.96-radius disk, following PeGS2 diskSolve's published default maskradius0.96; finite contacts and point-source singularities invalidate direct optical matching at the rim. DeltaT output and evaluation still cover the entire declared disk, with no scoring mask.

## Static constraints and nonlinear inverse

Daniels et al.2017 SectionIVC/Eq21 requires both force and torque equilibrium. The original pepe optional penalty passes beta and alpha in reversed order; its unmodified fit yields normalized net force0.0869 and torque0.0964 and is unsuitable as a static final solution. The final branch is explicitly a correction to enforce the published conditions, not unchanged original-optimizer parity. It retains the original point-contact elastic response, stress-optic law and squared pixel mismatch.

Parameterize normal/tangential contact components n=F*cos(alpha),t=F*sin(alpha). The signed source force components are f_row=n*cos(beta)+t*sin(beta), f_column=-n*sin(beta)+t*cos(beta). Set A q=0 for interleaved q=(n0,t0,...), where rows of A give sum(f_row),sum(f_column),sum(t). The third condition is torque/R=0. This3x8 matrix is built explicitly and its Jacobian is constant. F=hypot(n,t),alpha=atan2(t,n).

Minimize E(q)=sum_inner_pixels[(I_pred(q)-I_obs)^2], with no1/N or1/2 factor and no hidden prior. Bounds are1e-6<=n<=1N and-1<=t<=1N, plus n^2+t^2<=1N^2 at each contact. The angular numerical search bound is abs(alpha)<=85degrees, implemented as tan(85deg)*n±t>=0. It excludes the original collapsed-chord pure-tangential singularity; the final solution's largest angle is about69degrees, far from this bound. This bound is an optimizer setting, not a measured friction coefficient. The lower normal bound is likewise a nondegeneracy setting for four declared contacts, far below all fitted normal loads.

Initialize n=.04N,t=0 at every contact (already balanced). scipy.optimize.minimize(method='SLSQP') enforces the explicit linear static/angular inequalities and nonlinear magnitude bound. Objective derivatives are explicit centred finite differences with h=1e-6N; bound Jacobian entries are-2n,-2t. Optimizer ftol=1e-9,maxiter=500, no undocumented change of loss or stopping rule. Any non-success raises RuntimeError. The general optimizer is allowed; task-specific acquisition/stress/optical objective and constraints are all local executable mathematics.

Independent original-forward oracles first fixed validation criteria, then evaluated the exact measured ROI. All three balanced starts.02,.04,.07N converge to E=166.1970563 within about4e-8 absolute, with static residual<9e-18N. Zero-force E=517.0641, so this is not a blank-map equilibrium solution. Earlier full-rim and pure-tangential boundary failures are archived as failed numerical branches, not hidden or accepted by relaxing thresholds. The use of the published0.96 fit mask and nondegenerate angular search resolves those failures while preserving the selected published inverse mathematics.
