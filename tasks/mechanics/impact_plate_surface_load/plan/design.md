# Shipped interfaces and actual flow

The independent task runtime uses standard library, NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1 on CPU. All acquisition/inverse mathematics in its selected boundary is local. No RECOLO/domain library or cross-task module is imported. The complete raw optical preprocessing is a private oracle provenance stage; public data are the resulting optically estimated deflection, without pressure/force target inputs.

`src.preprocessing.load_observations(path: str | Path='data/raw_data.npz') -> ndarray` loads only NPZdeflection with allow_pickle=False, requires finite float64shape(1,250,79,97), and returns m. Constants SHAPE, PIXEL_SIZE=0.0030065919701586503m, SAMPLING_RATE=75000Hz and TIME_SIGMA=6 match README/output conventions. `filter_deflection(deflection: ndarray, sigma: float=6.0) -> ndarray` casts tofloat64 and applies Gaussian filtering on axis-3, mode nearest/truncate4; sigma0returns a copy, negative sigma is rejected. It changes no spatial dimensions.

`src.physics_model.bending_stiffness(modulus: float=190e9, poisson: float=0.3, thickness: float=0.00495) -> tuple[float,float]` returns D11,D12 in N m. DENSITY=7934kg/m^3 and WINDOW_SIZE=20are explicit source defaults. `kinematics(deflection: ndarray, spacing: float=PIXEL_SIZE, sampling_rate: float=SAMPLING_RATE) -> dict[str,ndarray]` accepts(time,row,column)float64m and returns deflection, slope_x/y(rad),curv_xx/yy/xy(1/m),acceleration(m/s^2), each same shape, plus time(s)of shape(time,). At least two samples per dimension are required. It preserves original row=x, column=y convention and source edge differences.

`hermite_virtual_fields(window: int=20, spacing: float=PIXEL_SIZE) -> dict[str,ndarray]` requires an even window>=4 and returns deflection(dimensionless),curv_xx/yy/xy(1/m^2), eachshape(window,window), evaluated directly with cubic polynomials and tensor products. `virtual_work_terms(fields: dict, virtual: dict, density: float=7934.0, thickness: float=0.00495) -> tuple[ndarray,ndarray,ndarray]` accepts one frame of measured curvatures and acceleration; returns A11,A12and inertial term over valid sliding windows, preserving convolve2dindex reversal. `pressure_virtual_work(pressure: ndarray, virtual_deflection: ndarray) -> ndarray` implements the external-pressure linear operator as valid convolution, without fitting to a solver result.

`src.solvers.pressure_from_fields(fields: dict, virtual: dict) -> tuple[ndarray,dict[str,ndarray]]` combines virtual-work terms with source stiffness and normalizes bysum(v). Its first result is pressurePa; its dict returns bending and inertial pressure contributionsPa. `reconstruct(deflection: ndarray, time_sigma: float=6.0, window: int=20) -> dict[str,ndarray]` requires batch1(time,row,column), filters time, computes kinematics/virtual patch and loops over the entire observed time sequence. Canonical resultkey reconstruction has shape(1,250,60,78), float64Pa. Optional parameter arguments are used only for explicitly labeled notebook sensitivity, not the standard entrypoint.

`src.main.run(input_path: str | Path='data/raw_data.npz', output_path: str | Path='output/reconstruction.npz') -> dict[str,ndarray]` calls loader and reconstruction, creates output parents and writes one compressed NPZ. CLI `python -m src.main` uses those defaults; --input/--outputare caller-relative unless absolute. Imports do not select a plotting backend. It reads no hidden fixture/reference or independent hammer data.

`src.visualization.make_figures(observations,result,upstream,hammer_time,hammer_force) -> tuple[list,dict,dict]` accepts arrays provided by its caller, actively computes kinematics, pressure decomposition and sensitivity variants, and returns five figures, exact numeric sources and metric dict. It reads/writes no files. `export_figures(figures,numeric,metrics,directory)` writes PNG/SVG/PDFgroups, exact numeric_sources.npz, metrics.jsonand SHA256manifest to caller-selected directory. Notebook independently loads hidden upstream/hammer measurements and runs fresh cleaned canonical reconstruction before plotting and standalone evaluation. Private export tooling additionally writes to the archive figure directory. Standard solver CLI writes no plots.

The standalone `evaluation/judge.py::evaluate(prediction: str | Path) -> tuple[dict,int]` has no solver imports. It checks exact outputshape,float64real dtype,finiteness and key; reads actual truth if available otherwise baseline relative toJudge; independently checks hidden reference; reads the original measured load-cell time/force entries from baseline_reference.npzfor the independent force criterion. These extra entries are independent measurements, not a pressure reference or exposed calibration. Their native1Dlayout is private instrument data, not an output array contract. It then computes cosineNCC,dynamic-rangeNRMSEand fixed subregion forceNRMSE. It does not run reconstruction, fit a pressure scale, align clocks or crop reference/prediction. CLI requires --predictionand --reportwith caller-relative paths; returns0pass,1valid below quality boundary,2malformed/evaluator/write failure. UTF8JSONcontainsstatus,passed,metrics,thresholds,errors; input/evaluator errors have empty metrics.

Tests use only local source, independently frozen numeric fixtures and analytic fields. No upstream module is imported by tests/notebook/Judge. `test/fixtures/upstream_stages.npz` provides complete corrected-acquisition deflection and filtered deflection for temporal-stage checks, original virtual arrays, selected-frame kinematic arrays and pressure outputs; its consumers are explicit parity tests. Complete original pressure baseline and independently measured force trace are in evaluation/baseline_reference.npz, consumed by full parity test, notebook and Judge. `notebooks/reference_outputs/measurements.json` identifies historical/upstream/fresh categories and hashes, read in the notebook. No duplicate pressure/force arrays are kept in reference_outputs. Full original source, images, papers, original logs, capture scripts, environment packages and temporary executed notebook remain outside the task.


Acquisition correction: the original sparse slope integrator placed both coefficients of the first row-direction derivative at the same unknown, canceling that derivative row. A minimal private preprocessing correction changes its second column from the current row to the next row. A linear-ramp analytic test independently validates the correction. The actual bound deflection uses this corrected optical observation estimate; all subsequent original kinematics/Hermite/VFM mechanics functions are unchanged. The unmodified complete original pipeline is separately archived and compared in the notebook. No hammer-force or pressure target determined the correction.
