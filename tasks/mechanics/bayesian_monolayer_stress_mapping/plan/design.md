# Shipped interfaces and actual execution

python -m src.main is the standard entry point from the task directory. It loads data/raw_data.npz, actively calls reconstruct, writes output/reconstruction.npz and prints elapsed time, traction residual RMS and normal-equation gradient norm. It returns(stress,state). Importing main has no execution or backend side effects. No domain solver, private archive or other task is imported.

preprocessing.load_data(path='data/raw_data.npz') checks real float64 finite shape(1,2,50,50) and returns a copied(2,50,50) traction kPa array. coordinates() returns two float64(50,) center-coordinate arrays in micrometres. Only unchanged author observations enter this public asset.

physics_model.operators(rows=50,columns=50,spacing=2.,alpha_shear=1000.,alpha_boundary=1000.) returns CSR A(2RC,2nx+2ny), B(2nx+2ny,2nx+2ny), D(RC,2nx+2ny), E(4(R+C),2nx+2ny). The default dimensions are5000×10200,10200×10200,2500×10200,400×10200. All coefficients and boundary indices are explicitly assembled locally. unpack_faces(vector,rows,columns) returns vertical[xx,yx](2,R,C+1) and horizontal[yy,xy](2,R+1,C). center_stress returns(3,R,C) orderedxx,yy,xy kPa micrometres; interpolation returns the corresponding CSR L(3RC,2nx+2ny). force_balance independently computes raw finite-volume flux differences and returns(2,R,C) kPa.

solvers.objective_gradient returns unhalved objective scalar and face-vector gradient. reconstruct(traction,lam=1e-6,alpha_shear=1000.,alpha_boundary=1000.) returns(stress,state); stress is(3,R,C) float64. State contains a,b,d,e,h sparse operators, general sparse LU factor, fullface vector, data traction vector, prediction(2,R,C), objective,initial_objective,gradient,lambda_value,spacing,rows,columns. It mutates no input and writes no files. All comparisons and CLI call this same active path. The factor object is in-memory computation only, never stored as an object NPZ.

posterior_diagnostics(state,indices=None,noise=.001,batch_size=32) returns exact_variance(3,R,C), diagonal_only_variance(3,R,C), covariance_samples(M,M), face_covariance_diagonal(2nx+2ny,). It solves small RHS batches with the already factored H; it does not allocate a dense10200² matrix. Defaults indices[0,1,n//2,n-1]; the source-parity notebook supplies16original capture indices. Proper variance uses L*C*L-transpose, approximate variance uses squared L entries and diagonal C, explicitly distinct. It is an optional maintainer notebook diagnostic; standard CLI only computes the physical mean.

visualization uses Matplotlib solely for scientific plotting, with no backend selection. The notebook actively reconstructs the standard full tensor, labeled parameter/constraint comparisons, and uncertainty diagnostics, then calls the standalone evaluator for the fresh submission. Figure exports, numeric sources and hashes go to the private maintainer folder; reference outputs remain identified source/fresh subsets.

evaluation/judge.py uses NumPy and stdlib only. It resolves ground_truth.npz and metrics.json from its own directory, never runs/imports prediction code, uses allow_pickle=False, validates required key/exact shape/float64/finiteness, computes all6component metrics without alignment, and writes required finite UTF-8 JSON status/pass/metrics/thresholds/errors. Return codes0pass,1valid poor,2malformed/evaluator/report-write failure. A zero result is valid poor (NCC0), not an undefined metric. Oversized finite values that overflow arithmetic yield descriptive error rather than NaN JSON. Prediction/report paths are relative to caller cwd. Actual truth takes precedence and no baseline_reference.npz is manufactured.

test/fixtures/upstream.npz contains original operators, fullface mean, center stress, traction prediction, complete-covariance samples/diagonal/proper center variance, independent truth-divergence diagnostics and source observations. Comparing tests consume those numeric cases only, not original source. notebooks/reference_outputs/upstream.npz contains compact independently rerun original stress/error bars and covariance diagnostics; fresh.npz is generated by the active cleaned notebook. evaluation/ground_truth.npz is the author exact FEM center tensor; no target values are publicly visible. All original MAT/PDF/checkouts/logs stay outside the task.
