# Implemented Gaussian stress inverse

## Bound physical problem and source choice

The existing author Traction_field.mat is a single50×50 simulated traction frame, two components in kPa, with5% relative added white noise. The accompanying Stress_field.mat is explicitly identified as exact stress from the same finite-element simulation in BISM_manual.pdf. It is legitimate hidden simulation truth, not a source reconstruction. Both files are distributed under the original repository GPL3. We reuse them unchanged as NPZ; no new simulation is generated.

The forward problem is force balance div sigma=t, with traction exerted by monolayer on substrate and height-integrated stress kPa micrometres. It differs from displacement-to-traction microscopy. No rheological inverse or monolayer-height inference is performed. Coordinates have2micrometre spacing: centers1..99, outer faces0..100, x along columns rightward, increasing row index is positive Cartesian y and is plotted upward. The original script comment says rows run top to bottom, but its actual quiver and principal-stress plots use y=1:2:99 with default Cartesian y increasing upward and no reversed axis. The numerical arrays and all tensor signs are preserved; only the display interpretation follows the actual source coordinate plots. The original script calls xmin/xmax center extrema; the manual calls0/100 domain boundaries. These are consistent after distinguishing center and face grids.

The selected published Gaussian fixed-lambda branch is the original default meth_Lambda=3,lambda1e-6,BC1,alpha_xy=alpha_BC1000. The paper also describes hierarchical noise/lambda estimation, and the script offers MAP/L-curve parameter selection; neither is the selected fixed branch and neither is claimed implemented as the standard run. Notebook lambda and boundary sensitivities are explicit comparisons of this same formula, not inferred acquisition parameters.

## Staggered discretization and explicit acquisition

Let R=C=50,N=2500,nx=R(C+1)=2550,ny=(R+1)C=2550. The flattened unknown has order[xx vertical faces,yy horizontal faces,xy horizontal faces,yx vertical faces], each block row-major. Total size10200. The data vector is[tx flattened row-major,ty flattened row-major], length5000. Ax differences adjacent vertical faces, Ay adjacent horizontal faces, with coefficients-1,+1. A has blocks[Ax,0,Ay,0;0,Ay,0,Ax]/l, l2micrometres. Its output is kPa.

D has blocks[0,0,sumY,-sumX], where sumY adds the two neighboring horizontal face values and sumX adds the two neighboring vertical face values. D*sigma is twice the interpolated shear difference. Preserve that factor2: it is not replaced by an average while keeping the same weight. E selects the first/last vertical faces of xx,yx and first/last horizontal faces of yy,xy. It has400rows. The explicit prior precision is B=I+1000² D-transpose-D+1000² E-transpose-E. B is precision, not covariance: the original script's comment says covariance but immediately states S0^-1=B/s0²; the paper names its corresponding reduced covariance B, so its B^-1 is the script's B. The local names and derivation follow the executed script.

## Objective, posterior mean and evaluation

The unhalved objective is J(sigma)=l²||A*sigma-T||²+lambda*sigma-transpose-B-sigma. Its gradient is2[l² A-transpose(A*sigma-T)+lambda B*sigma]. H=lambda B+l² A-transpose-A is positive definite because lambda>0 and B contains I. The unique Gaussian posterior mean is sigma=H^-1 l² A-transpose T. Source sparse backslash is locally evaluated using general SciPy sparse LU factorization/solve. There is no iterative inverse update, arbitrary initialization or artificial convergence path for this closed-form branch. A zero-field objective is recorded for context; a direct-solve endpoint is not called a sequence of converging iterations. Residual, gradient and normal-equation accuracy are explicitly checked.

Cell-center xx and yy are neighboring-face averages with weights1/2. Cell-center xy is the average of both interpolated shear estimates, four face weights1/4. No post-smoothing, clipping, sign change or scale alignment occurs. The original source final physical tensor is preserved; complete auxiliary face arrays remain in state and frozen parity fixtures.

Actual truth is the author exact finite-element center tensor. The Judge independently evaluates each of the three components using cosine NCC and RMS error divided by that component's full truth dynamic range. No mean subtraction, mask, crop, orientation alignment or fitted multiplicative factor. Boundaries are0.9times the independently rerun original NCC and1.1times its dynamic-range NRMSE; no zero-error self-reference threshold is used. All six metrics must pass. No mixed face reference or invented face truth is used.

## Complete covariance and original approximation

The source assumes noise_value=.001kPa for its posterior diagnostic. This is the source-selected uncertainty scale, not the true5% simulated noise standard deviation, and it does not change the fixed-lambda mean. The complete posterior face covariance is Cpost=noise²*l²*H^-1, units(kPa micrometres)². Original full10200² Cpost is privately archived. The cleaned helper computes diagonal elements by batched linear solves and proper central variance diag(L Cpost L-transpose), where L is the explicit interpolation matrix. It also computes the original approximation (L elementwise-squared)*diag(Cpost), which omits cross covariance. Both are returned and distinctly labeled. No corrected uncertainty is silently substituted into the original oracle.

At the bound observations, neighboring/cross-shear covariance is nonzero and the exact/approximate central variance ratio ranges about1.000006 to1.999949. An independent original H*Cpost identity check and source covariance submatrix fixtures establish the covariance is complete. Small-grid dense inversion independently validates the local batched formulas. These conditional Gaussian uncertainties do not explain finite-element sampling errors or true simulation error, so coverage against truth is diagnostic rather than a calibrated frequentist guarantee.

## Notebook experiments and limits

Active reconstruction uses the complete raw observation tensor and local formulas. Comparisons preserve the original traction arrows, principal stress directions and componentwise true-versus-inferred stress logic. New groups additionally show source/local difference, exact finite-volume traction residual, lambda dependence, symmetry/boundary ablations and proper-versus-original uncertainty. Every displayed fresh fit is actually computed.

Independent central finite differences of the supplied true tensor correlate.95975/.97228 with traction components with best unit scale1.0608/1.0764. Residual RMS.03548/.03616kPa reflects differing FEM sampling, finite differences and added noise; it is not an exact inversion-grid generative closure. The source lacks the original FEM mesh, generator and noise realization. Units are taken from the explicit manual kPa/kPa micrometres; an additional source plot labels Pa micrometres inconsistently, and is not used to silently multiply data by1000. Stress near boundaries, unresolved divergence-free components and prior dependence remain limits even when traction fit is excellent.
