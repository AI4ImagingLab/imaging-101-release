# Implemented thin-plate inverse

The unknown q(t,y,x) is incident radiative flux on a real heated steel sheet, in kW/m². It includes ambient incoming infrared radiation and differs from net absorbed heat flux. The observed field T(t,y,x) is absolute temperature in Kelvin on a square grid with spacing a=.0127m,25 one-second frames100…124 after ignition,66 rows and50 columns. The target is the64-by48 interior at all25 times; the observed one-pixel collar supplies measured neighbors to every target pixel. The interior is specified in the public contract and is never an implicit evaluator crop.

The selected original HFITS option is constant convection with the existing `steel (Engineering Toolbox)` material law, and NumPy-gradient time derivative. Preserve epsilon=.94, thickness d=.000793m, density rho=8050kg/m³, ambient Ta=293.15K, convection hf=hb=10W/(m²K), sigma=5.67e-8W/(m²K^4). Conductivity k(T)=8.1119ln(T/1K)-30.377 W/(mK); cp(T)=1000(.1414ln(T/1K)-.3534) J/(kgK). These are selected nominal material/boundary assumptions, not calibrated true fire flux. The alternative source FSRI steel option is not part of this selected run; no term from that option is silently substituted.

For an interior pixel, let Dtt be a temporal first derivative, Lh the spatial Laplacian, and T the local absolute temperature. Define storage S=rho cp(T) d Dtt, convection C=(hf+hb)(T-Ta), radiative loss R=2epsilon sigma(T^4-.5Ta^4), and in-plane conduction K=k(T)d Lh, each W/m². The inverse is q=(S+C+R-K)/(1000epsilon). The factor1000 converts W/m² to kW/m². Both sides emit, ambient radiation enters on the back, and incoming exposed-face radiation is the unknown. Thus at uniform equilibriumT=Ta, S=C=K=0 and q=sigmaTa^4/1000. This analytic condition is independently tested.

For times1…23 use Dtt=(T(t+1)-T(t-1))/(2dt). First frame uses(-3T(0)+4T(1)-T(2))/(2dt), final frame uses(3T(24)-4T(23)+T(22))/(2dt). These are the original NumPy `gradient(...,edge_order=2)` conventions. Lh is the five-point square-grid expression [T(y+1,x)+T(y-1,x)+T(y,x+1)+T(y,x-1)-4T(y,x)]/a², evaluated as sums of neighbor differences to retain source arithmetic. No target pixel requires an imposed lateral boundary value or extrapolated neighbor.

The original source uses central-cell k(T) multiplying this Laplacian. It does not evaluate div(k gradT), which would contain another gradient(k) dot gradient(T) contribution. Preserve this stated approximation and analyze its sensitivity rather than silently changing equations. Through-thickness uniformity is a thin-skin approximation: the unknown is surface exposure, not a reconstructed thickness profile. The supplied processed real temperatures are used directly without newly synthesized observations or extra smoothing. Derivative noise remains visible and is assessed through component and omission comparisons.

The inverse is closed-form. There is no training, optimizer, iteration, initialization, step size, line search, regularizer, or convergence stopping rule to invent. A forward balance check predicts S=1000epsilon q-C-R+K for a trial flux. Standard execution always uses all25 frames and every64-by48 target pixel. Notebook diagnostics compute genuinely fresh spatially independent/no-conduction and no-storage approximations and h=5/10/20 W/(m²K) sensitivity runs. These are labeled ablations/model sensitivity, not substituted standard outputs.

Actual incident-flux truth is unavailable. The hidden baseline is an independently captured unmodified HFITS run on these exact bound temperature values and selected options. Historical author irradiance estimates from the dataset are separately identified, have different fitted convection and processing, and are neither truth nor fresh reference values. Standard NCC is cosine similarity; standard NRMSE divides RMS flux difference by the baseline dynamic range. The standalone evaluator also computes an independent energy-balance residual normalized by RMS balance RHS, with no alignment/cropping/scaling. Independent original reruns are identical; NumPy1.26→2.4 local parity is at roughly7.1e-15 kW/m². Nonzero tolerance1e-7 is therefore justified for baseline NRMSE and balance residual. Physical fidelity and model limitations are checked separately from numerical agreement.
