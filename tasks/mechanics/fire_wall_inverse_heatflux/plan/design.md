# Shipped interfaces and flow

Run `python -m src.main` from the task workspace. `main(argv=None)` accepts optional `--data` (default data/raw_data.npz) and `--output` (default output/reconstruction.npz), loads observations, calls the local inverse, creates output parents, saves reconstruction float64(1,25,64,48), prints its kW/m² range, and returns0. Importing the module performs no reconstruction and does not change a plotting backend.

`preprocessing.load_data(path='data/raw_data.npz') -> dict` loads with pickle disabled, removes the batch dimension and copies finite float64 arrays. It validates temperature(25,66,50) Kelvin, time(25,) seconds, x(50,) and y(66,) metres, with fixed positive temperature and prescribed grid spacings. No hidden asset is read.

`physics_model.thermal_properties(temperature)` returns same-shape conductivity and heat-capacity arrays plus scalar8050 density, in W/(mK), J/(kgK), kg/m³. `time_derivative(temperature,time_step=1.)` returns same-shape K/s, using second-order endpoints along time axis0. `laplacian(temperature,spacing=.0127)` returns interior(time,y-2,x-2) K/m² from measured spatial neighbors only. Input order throughout is(time,y,x).

`energy_terms(temperature,time_step=1.,spacing=.0127,thickness=.000793,emissivity=.94,ambient=293.15,h_exposed=10.,h_unexposed=10.) -> dict` returns storage/convection/radiation/conduction as interior arrays in W/m². It uses original central-cell variable-conductivity approximation. `predicted_storage(temperature,incident_radiation,**parameters)` returns the forward balance's storage term in W/m² from a trial interior incident field in kW/m². It is a diagnostic, not part of the inverse's computation.

`solvers.reconstruct(data,**parameters) -> (q,terms)` receives the dictionary and optional energy-model parameter overrides, calls energy_terms, and directly evaluates the four-term balance. q has shape(25,64,48), float64, kW/m²; terms are as above. There is no iteration or hidden calibration lookup. Standard CLI passes no overrides. The notebook explicitly uses overrides only for sensitivity analyses, with separate method labels.

`visualization.similarity(estimate,reference)` returns cosine NCC and dynamic-range NRMSE. `make_figures(data,q,terms,upstream,historical,sensitivity)` creates three multi-panel groups from provided computed arrays, with raw temperature/fresh flux snapshots, local energy/omission comparisons, and model/reference/sensitivity analysis. `export_figures(figures,sources,destination)` writes PNG/SVG/PDF plus exact numeric NPZ and a SHA256 manifest into an explicit private destination. There is no backend selection in any importable module.

The active notebook reconstructs the entire selected window from raw_data using local src, computes genuine ablations and boundary-model sensitivities, loads the correctedly labeled independent original HFITS output and historical author estimate, evaluates fresh output with the standalone Judge, renders three scientific figure groups, and privately exports all plot sources. The original GUI module is not imported. The canonical notebook contains successful execution outputs after nbconvert; the temporary executed copy is removed from output.

`evaluation/judge.py` is standalone and contains independent metric and thin-plate arithmetic. It validates real float64(1,25,64,48), required key, finite values, nondegenerate reference and finite numeric thresholds; loads NPZ with pickle disabled; and never imports submitted/solver code. Hidden paths are relative to its own directory; prediction/report CLI paths are relative to caller cwd. Actual truth would take precedence if explicitly present; otherwise baseline_reference.npz is used. `evaluate(prediction,asset_dir=HERE)` returns(report,code) with0 pass,1 valid poor output,2 malformed/evaluator errors. JSON fields are status,passed,metrics,thresholds,errors. Report parent creation and write-failure behavior are tested, including foreign cwd.

`test/fixtures/upstream_hfits.npz` contains independently frozen input temperature, spacing/time step, material-law outputs, a conductive-gradient stage, and original full interior reconstruction. `test/comparing_test/` consumes it for exact data/stage/pipeline parity; `test/unit_test/` provides analytic temporal/spatial/equilibrium cases and complete Judge contracts. `evaluation/baseline_reference.npz` and `notebooks/reference_outputs/upstream_hfits.npz` identify the original method output as a method reference. `historical_author_estimate.npz` is used only for explicitly labeled historical comparison. No actual flux truth is invented. All external source, MAT files, acquisition archive/index, capture scripts and logs are private and indexed by test/validation.md.
