# Shipped interfaces and data flow

The standard command `python -m src.main` calls run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz'). It loads the full native uint8 observation array via preprocessing.load_observations(path), reconstructs both recordings, creates output parent directory and writes real float64 keys reconstruction(1,2,39,4),speed(1,2). run returns parameters,speed,elapsed_seconds; importing main has no plotting-backend side effect.

## Preprocessing

load_observations(path) returns copied uint8(1,2,2000,128,128), rejects other native shapes/dtypes. image_structure(movie,chunk_size=256) accepts(T,H,W), casts internallyfloat64 and returns float64(T+1,H,W//2+1), axes lag-or-statistic,yshiftedfrequency,xhalfplane. FirstT-1 planes correspond lags1..T-1; final2 are meanpower/complexvariance, allADU². Chunking changes neither spatial samples nor time sums. radial_average(packed,pixel_size=75.59/128) returns averages,spatialSD float64(90,T+1),q float64(90)rad/µm for native128²; empty binsNaN. It implements cross removal/multiplicity/finite weighted dispersion explicitly. logspace_int(stop,num=200,endpoint=False) returns unique increasing integerlags. resample_loglog(averages,errors,frame_rate=100.,num=200) returns data,error float64(90,200),tau float64(200)seconds. Uses general scipy.interpolate.interp1d for explicitly chosen quadratic log-log interpolation.

No sourcefunction imports upstream/domain libraries or another task. All runtime requirements are shared NumPy/SciPy/Matplotlib.
