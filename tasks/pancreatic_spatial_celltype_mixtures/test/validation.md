# Provenance and validation

This task reconstructs all428 native measured positions and all20 cell-type mixture weights/fractions from real pancreatic spatial transcriptomics counts and a physically separate matched-patient single-cell reference. It is a **qualified published-method reference**, not cell-composition truth. Parent-independent acceptance is separate from worker validation.

## Fixed scientific binding and semantic novelty

Observations are the complete author-distributed PDAC-A spatial_counts(25753,428), reference counts(19736,1926), reference type/sample labels and native x,y positions. The unknowns are V(428,20), source-scaled nonnegative RNA mixing weights, and P(428,20), their row-normalized conditional composition estimates. Every type and position is scored. The calibrated mixture is X=B V^T, regularized with a Gaussian CAR field prior. This acquisition/unknown pair is absent from the frozen179-task prebatch inventory; changing an existing optical modality or sample is not the novelty argument.

The selected configuration uses the original CARDref API with uniform1/20 initialization and all seven published phi candidates. The original wrapper's missing cross-phi determinant normalization is explicitly corrected below, yielding phi0.7. The original uncorrected phi0.99 fields remain identified comparisons. No fitted calibration or initializer is placed in public observations.
