# Shipped interfaces and execution flow

## Modules and public data

`src/preprocessing.py` defines C=299792458.0 m/s. `load_observations(path='data/raw_data.npz')` reads NPZ with allow_pickle=False, requires frequency float64[1,288], polarization complex128[1,288], and noise float64[1,288], and returns a dictionary of copied unbatched arrays. It performs no scene synthesis, resampling, target loading or upstream import. `prepare(frequency,polarization,noise)` requires matching1D arrays, finite entries, positive noise and strictly increasing positive frequency. Its returned dictionary contains frequencyHz, polarizationJy/beam, noiseJy/beam, lambda2m², inverse variance weights, scalar lambda0m², and scalar sigma_fdfJy/beam. Input observations are not mutated.

`src/physics_model.py` provides `forward(components,lambda2,phi,lambda0)` -> complex vector[nchannel] and `adjoint(polarization,lambda2,phi,lambda0)` -> complex vector[ndepth]. Forward uses an explicit positive-sign complex exponential matrix, adjoint its Hermitian transpose. `dirty_spectrum(polarization,lambda2,phi,weights,lambda0)` returns the inverse-variance normalized complex depth vector. `rotation_measure_response(lambda2,phi,weights,lambda0)` returns `(response,phi2,width)`: complex128[803], float64[803]rad/m², and scalar Gaussian FWHMrad/m² for the standard401-bin grid. All functions use general NumPy primitives and have no file side effects.

`src/solvers.py` defines PHI=float64 arange(-600,603,3). `hogbom_clean(dirty,phi,response,phi2,width,cutoff,gain=.1,max_iterations=1000)` returns restored complex vector, sparse complex component vector, complex residual vector and integer update count. It copies dirty input and explicitly performs each source-prescribed global-peak update. The selected single-threshold path has no optional masked second loop. `reconstruct(frequency,polarization,noise)` calls prepare, the weighted inverse sum, response construction and complete CLEAN. It returns `(submission,details)`, where submission contains reconstruction and components as complex128[1,401]. The details dictionary includes all prepare keys plus dirty[401], response[803], phi2[803], width scalar, residual[401], model[288], iterations integer, cutoff scalarJy/beam and runtime_seconds float. These are freshly computed arrays, never hidden references.

`src/main.py`: `run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads only public observations, calls reconstruct, creates the output parent, writes the two submission arrays with np.savez_compressed, and returns `(submission,details)`. `main(argv=None)` parses optional --data/--output, runs the full pipeline and prints JSON for iterations, cutoff and runtime_seconds; exit0 on success. The standard command is `python -m src.main` from task workspace. There is no root wrapper. It does not read evaluation assets, figures or reference outputs, and does not select a Matplotlib backend.

`src/visualization.py` imports pyplot without selecting a backend. `relative_l2(estimate,reference)` calculates the complex Euclidean relative error; the metric has independent known-number coverage alongside the Judge metric. `plot_spectra(submission,details,reference)` returns a2x2 Matplotlib figure containing dirty/original/fresh amplitude, fresh real/imaginary FDF, sparse components and complex error. `plot_observation(details)` returns a2x2 figure of all measuredQ/U/model spectra, normalized channel residuals and the full response. `plot_metrics(report)` returns a1x2 figure comparing measured errors/forward consistency with frozen boundaries. All return figures for caller display and do not write files.

## Standalone evaluation

`evaluation/judge.py` imports only standard library and NumPy. HIDDEN and METRICS resolve relative to this file. PUBLIC resolves to task data/raw_data.npz solely for independent observation consistency. `load_arrays(path,label)` validates exact keys, complex128 dtype, shape[1,401] and finite values. `relative_l2` rejects zero or undefined reference norm. `observation_chi2(components)` independently reconstructs squared wavelengths, reference wavelength and explicit positive-sign forward matrix from public acquisition; it imports no solver. `evaluate(prediction)` returns `(report,exitcode)`. Truth takes precedence if a ground_truth.npz exists; this task only supplies baseline_reference.npz because the target is a selected method-restored spectrum rather than a unique unsmoothed physical distribution.

The boundary JSON contains flat task-specific *_boundary fields, definitions and original measurements. Boolean, nonfinite and nonpositive bounds are rejected. Input/evaluator errors yield empty metrics, errors list and code2; valid poor predictions yield statusfail/code1; all required metrics passing yields code0. Overflow is an error, never JSON infinity. `main(argv=None)` implements required --prediction/--report; CLI paths are relative to caller cwd and report parents are created. Report-write failure prints a diagnostic and returns2.

## Notebook and hidden references

The notebook has Problem/Data/Physics/Method/Results/Conclusion sections. It prints the actual kernel and data identity, loads observations, calls the shipped `run` to actively reconstruct all288channels and write output, then invokes the standalone Judge in a separate process. Only after fresh reconstruction does it load baseline_reference.npz for explicitly labeled independent-original comparisons. `notebooks/reference_outputs/upstream_measurements.npz` contains independently captured original runtime/iteration/noise information; `fresh_measurements.npz` contains the identified active execution measurements. Neither replaces a fresh calculation. Three scientific figures cover full response/spectra/complex components, the observational model and residuals, and metric boundaries. Notebook display uses inline backend; importing any library module does not change it.

Frozen `test/fixtures/upstream_stages.npz` supplies independent original input and output arrays to preprocessing/transform/response/completeCLEAN parity tests. `test/unit_test/` covers physical identities, metric cases, Judge contracts and metadata; `test/comparing_test/` also starts a fresh CLI subprocess and evaluates its new NPZ from a foreign working directory. All archive scripts, logs, complete upstream source and paper remain outside the task. Only the required MIT license text is separately retained in LICENSE. No cleaned source/notebook/test imports that private archive or any reconstruction domain library.
