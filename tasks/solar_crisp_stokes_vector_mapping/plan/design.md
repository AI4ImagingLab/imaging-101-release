# Shipped interfaces and data flow

All paths are relative to this task; there are no cross-task or private-archive imports. Runtime dependencies are NumPy, SciPy and Matplotlib from the shared pinned environment. Upstream C++/Eigen/FFTW and FITS readers are confined to private oracle capture.

`preprocessing.regular_grid(wave, step, extra=5)` takes a float64 vector of wavelength offsets in angstrom and scalar spacing; returns a fine float64 vector and int32 nearest observation indices. `load_data(path=None)` loads public NPZ with pickle disabled, default `data/raw_data.npz`. It returns a dict: raw(64,96,4,30), observations(64,96,4,158), sigma(4,158), indices(30), regions[list of lengths123,35], psfs[lengths75,25], cavity(64,96). Spectra/scales are normalized intensity, regions absolute angstrom, cavity km/s. Returned arrays are owned copies.

`physics_model.Dual(value, derivative=None)` stores floating values and optional trailing9-component derivatives. Arithmetic methods and local sin/cos implement forward differentiation. `as_dual` wraps a scalar/array. `humlicek(a,v)` broadcasts dimensionless damping/frequency and returns complex Voigt values. `profile(damping,frequency)` takes Dual objects and returns Dual absorption/dispersion. `zeeman_components(j1,j2,g1,g2,wavelength)` returns tuples(polarization index,strength,wavelength split per G). `LINES` stores the two native atomic patterns and relative strengths. `degrade(array,psf)` correlates along the final spectral axis with constant endpoint extension; shape preserved, no file side effects. `synthesize_response(parameters,regions,psfs,mu=0.93,with_response=True)` takes physical parameters(N,9), returns spectra(N,4,158), response(N,9,4,158), float64. With response disabled, response has zero parameter length and the value path avoids derivative storage. Values use the explicit analytic transfer solution.

`solvers.pivoted_qr_step(a,b)` solves the small damped normal system by explicit column-pivoted QR/nonzero-pivot convention; a(9,9), b(9) -> delta(9). `clip_parameters(model,cyclic=True)` returns a physical bounded copy(N,9), preserving the source's wrap constants. `lm_block(initial,observed,sigma,regions,psfs,max_iterations=25,mu=0.93)` returns parameters(N,9), spectra(N,4,158), chi-square(N), dict with accepted(N) and history(mean objective after each active batch update). Each pixel tracks its own damping and stop state. `fit_image(initial,data,batch_size=32,max_iterations=25)` flattens spatial pixels and calls independent blocks; returns physical maps(64,96,9), spectra(64,96,4,158), chi-square(64,96), accepted counts(64,96).

`smooth_model(model,size=45,fwhm=15.)` returns the reflected-boundary Gaussian initialization with unchanged shape/units. `reconstruct(data,batch_size=32)` actively runs both full fitting cycles and applies velocity calibration. It returns calibrated parameters(64,96,9), diagnostics dict: cycle1,smoothed,cycle2 uncalibrated maps; spectra full second-cycle fine-grid spectra; chi2_cycle1,chi2_cycle2 maps; accepted_cycle1,accepted_cycle2 integer maps. It never loads references or oracle fixtures.

`python -m src.main` calls load_data then reconstruct, creates output if needed and writes only `output/reconstruction.npz` with batch-first reconstruction(1,64,96,9). It prints the actual mean weighted chi-square and returns the output Path from `main()`. Importing it does not change a Matplotlib backend.

`visualization.make_figures(data,parameters,diagnostics,references,export_dir=None)` is the notebook review path. It receives the freshly computed maps and diagnostic arrays, plus explicitly labeled historical original, FFT-only corrected and doubly corrected source comparisons. It returns six Matplotlib figures and numeric source arrays. When export_dir is supplied, it writes PNG/SVG/PDF figure groups and numeric_sources.npz to that maintainer location. The canonical notebook reconstructs the public observations afresh through the local modules, writes the declared submission, invokes the standalone Judge, prints a metric table and displays all six groups. No cache stands in for the active fitting call.

`evaluation/judge.py` is a separate executable with --prediction and --report. Paths for evaluator assets resolve from its own file; caller paths remain caller-relative. It validates every required finite numeric threshold, exact shape/float64/real/finite output, then evaluates eight maps with NCC/NRMSE, azimuth with its pi-periodic RMS and cosine2 agreement, and four Stokes consistency checks. It selects ground_truth.npz when present, otherwise baseline_reference.npz. It imports no src module, upstream package, checkpoint or submitted code. Its independent forward calculation uses SciPy complex Voigt values, explicit Zeeman sublevels and propagation matrix, batched4x4 linear solves and direct spectral correlation. Report JSON has status,passed,metrics,thresholds,errors, with exits0/1/2 for pass/valid fail/error. Malformed configuration or nonfinite arithmetic returns empty metrics. Report failure emits stderr and exit2.

All test assets have explicit consumers: `test/fixtures/upstream_stages.npz` is read by upstream parity tests; `notebooks/reference_outputs/` is read only by the review notebook/visualization; `evaluation/baseline_reference.npz` is read by the Judge and evaluator tests. Existing real observations require no synthetic generator. The validation document indexes paper/source, separate original/corrected oracle executions, fixture and figure hashes, resource/backend evidence and semantic review.
