# Shipped interfaces and execution flow

`src.preprocessing.prepare(raw)` accepts public wavelength/spectrum float64 arrays(1,28,2048) and orbital_phase(1,28). It returns unquantized continuum-subtracted line spectra(28,477), native-quantized line_spectra, velocity_cm_s(477), phase_radians/phase_width_radians(28). Native float32 phase parsing, text precision, systemic convention and fixed optical constants are explicit local math. No source library import is permitted.

`src.physics_model.DopplerModel(prepared,nv=144)` computes geometry/support/CSR forward and unsorted-CSC adjoint locally from public phases/velocity. It exposes ix,iy as0-based support indices, va,dv,denu in source physical units, and explicit forward/backward/smear functions. `initialize_data(spectra)` returns positive_data,baseline_data,baseline_field,weights and initialization/total flux. Core operators are derived, never loaded from frozen fixtures.

`src.solvers.reconstruct(raw,alpha=.002,ns=7,accuracy=8e-4,max_iterations=150,model=None,current_direction_only=False)` is the selected complete method. It returns full reconstruction(1,144,144), iteration count/trace, first_iterations, positive_field, model, state and prepared diagnostics. Optional model reuse avoids duplicated operators; width variants are explicitly labeled. Standard main writes only reconstruction to output/reconstruction.npz. `solve(model,state,alpha=.002,ns=7,accuracy=8e-4,max_iterations=150,current_direction_only=False)` returns positive field, per-iteration trace and first-two-update dictionaries. `objective_derivatives(model,x,data,weights,ns=7)` returns H,S,raw gradients, prediction, default, logratio and exp(log(default)). `newton_coefficients(model,x,old,new,data,weights,predicted,q,logratio,ex,alpha,ns=7)` returns the two analytic direction coefficients. Arrays remain float64 after explicit source quantization.

Tests consume numeric arrays from an independent unchanged source run on these exact observations. Frozen projection fixture contains64 distributed original columns; complete private original geometry remains outside the package. First-two-update arrays retain pre/post-state labels. Public data contain no target, entropy default, hidden seed or inverse-derived calibration. `evaluation.judge.evaluate(prediction,evaluation_dir=None)` validates the complete signed field and independently constructs whole-observation consistency without src imports. Actual truth takes priority and invalid truth never falls back to baseline. Configuration errors, malformed files and overflow return error with empty metrics. Paths resolve from the evaluator, not its caller. The CLI returns0/1/2 for pass/fail/error and writes strict UTF-8 JSON.

The active notebook computes the full inversion through local modules and retains original field/convergence comparisons. It computes a current-direction-only ablation, alpha sensitivity, raw-noise sensitivity and common-exposure-width variants, exporting six scientific figure groups with actual numeric sources. `src.generate_data.add_spectral_noise(raw,relative_sigma=.01,seed=123)` copies arrays, adds Gaussian noise in observed flux units, and leaves phases/wavelengths unchanged. It is used only for explicit diagnostic perturbations. `src.visualization.image_panel(ax,image,title,extent=None,signed=False,limit=None)` returns an image artist with symmetric signed limits. `export_figure(fig,directory,name,numeric,caption)` writes PNG/SVG/PDF/NPZ/JSON to the supplied directory and returns its PNG path. No library module changes the backend. Notebook export uses IMAGING_FIGURE_DIR provided by the private supervisor; the research kernelspec is independent of default system Python.
