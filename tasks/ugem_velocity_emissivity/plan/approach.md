# Implemented mathematics

## Analytic direction coefficients and execution conventions

For a positive field x, let p=Px, q=Gx, y be positive data, w its likelihood weights, and T the target total flux. Raw likelihood gradient h=Pᵀ[w(y/p−1)] and entropy gradient s=−log(x/q)+G[(x−exp(log(q)))/q]. Subtract their x-weighted means; add T/sum(x)−1 to h. Set d=x(h+alpha s); the initial old direction u equals d.

For directions a,b define pa=Pa, qa=Ga and similarly pb,qb. First derivatives are Ha=sum[w pa(y/p−1)] and Sa=sum[−a log(x/q)+(x−exp(log(q)))qa/q]. Mixed second derivatives are Hab=−sum[w y pa pb/p²] and Sab=−sum[x(a/x−qa/q)(b/x−qb/q)]. The two-vector objective gradient is g=(Hu+alpha Su,Hd+alpha Sd); Hessian entries are Kab=Hab+alpha Sab. Solve Kc=−g by its explicit determinant formula. If abs(det(K))/(K11²+K22²)<1e−3, use c1=0,c2=−g2/K22. This is the source analytic Newton fallback, not a generic inverse solver.

Normalize c by its Euclidean amplitude and form z=c1 u+c2 d with those normalized coefficients. Limit the scalar step by the original amplitude,1e5, and .9/max(−zi/xi) over negative zi; omit the last bound when none are negative. Save z as the next old direction. Stop before updating if the last20 steps are all below .01. Otherwise update and normalize x to total T. The convergence statistic is the RMS over pixels of (h+alpha s)/(|h|+alpha|s|), assigning zero to zero denominators. It uses pre-update gradients and stops at8e−4 or150 iterations. Objective trace rows refer to pre-update states, while returned fields are post-update.

The Gaussian default weights are exp(−j²/49), j=−10,...,10, evaluated float32 then normalized float64. Extend the circular support by zero, convolve along both axes using half-sample reflection, and restrict. This G is symmetric, verified independently by inner products and entropy finite differences. The notebook's current-direction-only flag retains only d in the same analytic Newton step and is explicitly an ablation.

The bound inverse reconstructs all144×144 background-subtracted velocity-plane H-alpha emissivity samples from all28 native UGem spectra. The public target axis order is(batch,vy,vx), explicitly transposed from the source writer's(vx,vy) order, without resampling. Original common phase width.03930 is an author-supplied approximation selected before inverse quality, not individually verified exact exposure. Both the real spectra and unchanged source-domain fullrun/repeat, passive stage captures and independent derivative/adjoint proofs precede this extraction. Source-only thresholds are frozen privately.

Spectral preprocessing interpolates every raw spectrum onto the first spectrum's wavelength grid, fits a cubic continuum in(6500,6537) and(6591,6620)Angstrom intervals after the legacy systemic correction, subtracts that continuum within6562.8±35Angstrom, and linearly interpolates onto477 uniform relativistic-form velocity samples using the author's nominal299700km/s. Let va=max(abs(vfirst),vlast), grid spacing dv=2va/143 and support vx²+vy²<(va+dv/10)². All16124 selected physical support pixels are represented, with the full144² output zero outside this known circular support. At phaseθ and widthΔθ, endpoint radial velocities are vx sin(θ±Δθ/2)−vy cos(θ±Δθ/2). Their minimum minusdv/2 and maximum plusdv/2 define an interval[a,b]. This is the source endpoint-linearized finite-exposure approximation. Raw weights are stored float32, normalized per reconstruction pixel using float64 sums, then rounded to float32 again. Forward accumulation uses source row order; adjoint uses original unsorted phase-then-velocity order.

A flat circular background is inferred only from observations. Its forward response determines a baseline whose central selected response is.1 times the mean input spectrum. Add baseline, replace values below one-third its scalar level by1e−5 times that level, exactly normalize the integrated flux of each nonblank spectrum to the unblanked mean, and retain all data. The local method preserves that behavior rather than silently enabling a different.3-offset normalization. Source likelihood weights are zero for the fixed eclipse phase interval(.95,1.05)mod1 and where background response vanishes; their sum is28. The .1 and1e−5 source real32 literals are promoted to float64 exactly as in Fortran.

The positive latent field x starts uniform with total observed flux. The objective maximized is weighted Poisson loglikelihood H=sum w(y log(Px)−Px) plus alpha=.002 times floating-default entropy S=−sum[x(log x−log q−1)+q], with q=Gx. G folds the circle into a zero-padded144² image, applies separable Gaussian smearing with source ns7 and half-sample reflection, then restricts to the circle. The Gaussian weights preserve the source float32 exponential convention before float64 normalization. G is self-adjoint, independently checked. The raw entropy derivative is−log(x/q)+G((x−exp(log q))/q).

Project the likelihood and entropy derivatives to remove their x-weighted mean; the likelihood projection also restores the target total flux. The new scaled direction is x*(projectedH+alpha*projectedS). Combine it with the previous saved direction by the source analytic2×2 Newton system using first/second derivatives of H and S; if abs(det)/(diagonal² sum)<1e−3, use only the new direction. Normalize those two coefficients, restrict the step to preserve positivity by.9 safety, and cap at1e5. Update x, save the unscaled combined direction, compute Lucy's convergence measure from the pre-update projected gradients, and renormalize total flux. Stop at convergence≤8e−4 or150steps. The chosen native config runs one alpha; it does not execute a decreasing alpha sequence. Source objective logs are pre-update while the returned field is post-update. Original run stops after27steps; reproduce this convention explicitly.
