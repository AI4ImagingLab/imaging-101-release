# Shipped spectral-imaging interfaces and execution

## Runtime and array contracts

The standard command is `python -m src.main` from the task workspace. `src/main.py::main()` loads complete public observations, calls the local direct inverse, creates output if needed, writes `output/reconstruction.npz`, prints JSON with runtime/shape/dtype, and returns the same result dictionary. It has no plotting import or backend mutation. No download, original library import, reference read, trained model, cross-task import or hidden calibration occurs in the solver path.

`preprocessing.load_observations(path=ROOT/'data/raw_data.npz')` loads with allow_pickle=False, validates exact public shapes/dtypes/finiteness, checks complementary even/odd pairs and a complete identifier permutation, and requires increasing wavelengths. It returns copied unbatched arrays: measurements float64(8192,2048) in detector counts; pattern_id int64(8192) dimensionless; wavelength_nm float64(2048) in nm. ROOT is resolved from the module's task directory. Constants SIDE64, SPECTRAL_CHANNELS2048, INTEGRATION_MS1.0, PATTERN_PERIOD_US1400 and NOMINAL_PIXEL_UM182.4 match the public contract. Nominal pitch does not enter the discrete inverse, only its spatial interpretation.

`preprocessing.differential_coefficients(measurements,pattern_id)` returns float64(4096,channels) by subtracting adjacent detector spectra and placing them at their Walsh row identifiers. Full input validation occurs in load_observations; this lower-level routine also supports the notebook's spectrally summed observations and omitted pairs. `spectral_bins(measurements,wavelength_nm,edges_nm)` preserves leading axes and replaces the last channel axis with len(edges)-1 summed bands. Bounds are left-closed/right-open, empty bands and non-increasing edges raise ValueError. No normalization or file write occurs.

`physics_model.sequency_order(n)` validates a power-of-two side and returns int64(n) natural-row indices. `walsh_matrix(n)` returns float64(n,n) signs from the explicit bit-parity formula. `_natural_transform(a,axis)` evaluates private-copy butterfly arithmetic. `forward(cube)` takes real(y,x,channel) with equal power-of-two spatial sides and returns matching-shaped unnormalized Walsh coefficients; `inverse(coefficients)` returns matching-shaped real detector-equivalent intensities and divides by total spatial pixels. Both operate solely on passed arrays; neither loads a fixture or caches an answer.

`solvers.reconstruct(data,pair_count=4096,ordering='acquisition',seed=20261020)` returns `{'reconstruction': array}` with shape(1,64,64,channels), float64, in counts/pixel. It computes local differential coefficients, optionally retains actual pair subsets, and applies the explicit inverse. pair_count must be an integer1..4096; ordering accepts acquisition, sequency, random or random_dc. The last option explicitly retains the actually measured DC pair as a sampling control. The seed affects only optional retrospective pair selection. The default uses every observation, so its result is deterministic without random state. Input data are not modified; there are no filesystem side effects.

## Visualization, notebook and additional experiments

`visualization.metric_values(estimate,reference)` returns uncentred ncc and dynamic-range nrmse and rejects degenerate references; independent known metric cases also test the Judge. `compute_experiments(data,fresh)` sums the actual raw channels into8bands, actively calls reconstruct for4orderings×5counts, calculates method-reference errors against the fresh full-data band sums, and returns images(4,5,64,64,8), nrmse(4,5), counts(5), band_sum(64,64,8), edges_nm(9), centre_nm(8), and binned_measurements(8192,8). These are analysis results, not additional public solver inputs.

The four plotting functions `spectral_plate(experiments)`, `parity_plate(fresh_bands,upstream_bands)`, `sampling_plate(experiments)`, and `diagnostics_plate(data,fresh,experiments)` each return one Matplotlib Figure, without file writes, show calls or backend changes. Spectral plates share physical count scales; residuals use symmetric limits and explicitly annotate exact equality. Sampling figures identify the full measured inverse as a method reference. Diagnostics use native spectra, actual complement sums and negative-value fractions, never substitute a physical truth. Display functions retain exact arrays and only adjust visible color limits.

The active notebook loads public observations, computes and saves a fresh full2048-channel result, loads the independent standalone Judge by filename, writes its report, and requires exit0. It loads reduced identified original measurements from notebooks/reference_outputs/upstream_views.npz solely for original/fresh comparisons. It then actively computes all20local sampling cases and renders four scientific figures with quantitative tables and explicit physical limitations. Cached upstream results never substitute for a fresh inverse. Complete original stage and sampling fixtures remain under test/fixtures, consumed by their named comparison tests. A temporary executed notebook is archived outside the task after successful nbconvert; its executed outputs are retained in the canonical notebook.

## Independent evaluator and tests

`evaluation/judge.py::evaluate(prediction,asset_dir=HERE)` returns (report,exit_code). HERE resolves relative to the Judge file. Prediction is the caller-relative NPZ path. The evaluator chooses an existing ground_truth.npz before baseline_reference.npz and rejects invalid existing truth rather than falling back. It validates the exact reconstruction key/shape/real float64/finiteness, nondegenerate reference, finite meaningful boundaries and forward metric. All error cases return status error, passed false, empty metrics, descriptive errors and exit2. A valid poor cube returns fail/1, and a passing cube pass/0. `reference_metrics(x,ref)` and `observation_residual(cube,data_path=HERE.parent/'data/raw_data.npz')` implement independent scoring; the latter uses explicit small Sylvester blocks and sign-change sorting, with128-channel chunks. No solver import or submitted code execution occurs. CLI main(argv=None) creates report parents, writes strict UTF-8 JSON, and returns2with stderr on report-write failure.

Unit tests cover per-function invariants, independently known metrics, zero output, missing inputs/keys, malformed shapes/dtypes/complex arrays, NaN/Inf/finite overflow, missing evaluator assets, actual-truth precedence, report failure, foreign working directory, declared metadata and import backend stability. Comparison tests consume original frozen stage outputs and full baseline, enforce bitwise equality, verify every sampling case's selected bands, and add independent DC/impulse/orthogonality/adjoint/full-forward physics checks. Fixtures are never generated by the cleaned function under test. Shared pytest/Jupyter are development tools; the runtime subset is only NumPy and Matplotlib.
