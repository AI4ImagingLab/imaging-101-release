# Implemented spectral single-pixel inverse

## Bound physical unknown and observations

The unknown is a signed detector-equivalent cube F[y,x,l],64×64×2048, in detector counts per spatial pixel. It retains the LED spectrum and spectrometer throughput. It is not a calibrated transmission, radiance or material concentration. All8192 acquired binary-pattern spectra and all2048 measured wavelengths are reused without spatial/spectral resampling, downcast or synthetic generation. Pixel indices y,x increase down/right; row-major flattening is p=64y+x. The published nominal x1 object-plane pitch is182.4micrometres, distinct from a newly measured calibration. Spectral wavelengths are the supplied float64 array, not a uniform interpolation.

Let n=64, N=n²=4096, and L=2048. W is the n×n unnormalized sequency Walsh matrix. The Sylvester sign at natural row i, column j is (-1)^popcount(i AND j), where AND is the bitwise binary conjunction and popcount counts set bits. For sequency row k, first compute Gray code g=k XOR floor(k/2), where XOR is bitwise exclusive-or, then reverse its log2(n) binary digits to get natural row i. This is exactly the upstream Gray-code/bit-reversal ordering, independently checked against the original W. The2D operator is H=W tensor W in C-order flattening. W W^T=nI and H H^T=NI.

For acquired pair a, j(a)=pattern_id[2a]/2. Physical positive/negative masks are (1±H[j(a),p])/2. The expected detector observations equal their spatial sums against F plus a stable wavelength-dependent offset. The instrument gain is absorbed into the unknown detector-equivalent F. The original paper's Poisson-Gaussian model motivates differencing, but independent gain/dark-noise variances are unavailable, so no fitted noise likelihood or calibrated chi-square is used.

## Exact preprocessing and objective

For every pair and wavelength compute D[a,l]=raw[2a,l]-raw[2a+1,l] in float64. Place D into C[j(a),l], undoing the recorded acquisition permutation. Every j occurs once in the standard case. No background target, hidden answer, contrast normalization, positivity clipping, wavelength fitting or learned covariance is loaded. The acquisition-order list is an actually recorded calibration, originally ordered using an independent image database; its generating covariance is neither needed nor shipped.

The selected published reconstruction minimizes J(F)=0.5 sum(j,l)([H F][j,l]-C[j,l])², using the unnormalized detector-count operator. There is no per-channel weighting, sample-count normalization, regularizer or positivity constraint. With full orthogonal measurements the unique least-squares inverse is F=H^T C/N. For each wavelength, reshape C into n×n and evaluate F=W^T C W/n². The original code forms the full4096×4096 matrix and uses its symmetry; the local code evaluates the identical transform with separable binary butterflies. Original W/H symmetry and the full result are independently checked.

## Explicit binary transform and numerical convention

The natural unnormalized Sylvester transform uses stages of width h=1,2,4,...,n/2. For each adjacent pair of length-h blocks a,b, replace the two blocks with a+b and a-b, using private copies to prevent aliasing. This arithmetic is performed along both spatial axes; the last spectral axis is untouched. For forward sensing, natural transforms precede Gray/bit-reversal row permutation. For the inverse, undo that permutation, perform natural transforms along both axes, then divide by N exactly once. The inverse returns real float64 without clipping. Butterflies are a direct factorization of a closed-form inverse, not an iterative optimizer: initialization, line search, regularization strength, stopping criterion and iteration convergence do not apply.

Original recorded values are integers stored in float64. All relevant sums stay below2^53 and division by4096 is binary power-of-two scaling; both the dense original and local full inverse are bitwise identical on this dataset. An independently generated constant image tests DC amplitude; a known-position impulse tests signs and2D pixel order; random complex-free arrays test the forward/adjoint dot product. The original run and its exact repeat were captured before local implementation. Frozen upstream41-channel stage arrays and15 retrospective cases are independent expected values, not values generated by cleaned functions.

## Evaluation and interpretation

No independent actual cube truth exists. The hidden method baseline comes from this task's original-source run, never from a reconstruction relabelled as truth. NCC is the uncentred cosine similarity over all flattened signed samples. NRMSE is RMS error divided by the full reference dynamic range, without crop, scale fitting, shift, magnitude conversion or spectral selection. Zero prediction norm gives NCC0, which fails; a zero-norm or zero-range reference is an evaluator error.

The independent Judge also reconstructs W by sorting Sylvester rows by sign-change count, rather than importing the solver's Gray-code helper. It computes the full forward image coefficients in spectral chunks and compares them to actual positive-minus-negative spectra, using L2 error divided by L2 observed differences. Thresholds were frozen before local extraction: NCC>=1-1e-12; NRMSE<=1e-11; relative measurement residual<=1e-11. Original repeats have zero discrepancy. Nonzero thresholds allow alternative binary64 implementations while exact parity/physics tests and strict metric cases remain separate gates. Full measurement consistency in a square invertible system does not prove specimen accuracy or remove measurement noise.

The notebook distinguishes full physical band data, independently reproduced original outputs, fresh local outputs, and retrospectively subselected actual measurements. It retains small negative values and diagnoses complement-sum temporal variation and wavelength-dependent negative-pixel fractions. Display limits may clip color only, never stored values. The paper's additional DC-Net training and128×128 learned outputs are explicitly outside this selected direct-inverse task; no cached neural result is displayed as fresh. The benchmark therefore evaluates the native published linear inverse with richer acquisition/spectral diagnostics, not reproduction of all the paper's learned-method experiments.
