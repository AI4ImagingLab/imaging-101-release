# Shipped interfaces and data flow

The task is self-contained. NumPy supplies array mathematics and polynomial least squares; SciPy supplies general MINPACK leastsq; Matplotlib serves notebook visualization. No LMfit, xlrd, ProteinUnfolding2D or CheMelt package enters cleaned runtime, tests, Judge or notebook. Full original source, XLSX, paper-access evidence and capture code remain outside this package.

## Standard execution

src.main.run(data_path=None,output_path=None) resolves default input/output relative to the task module, loads all public arrays, normalizes observations, fits all18 free parameters and writes exactly the three public-contract arrays to output/reconstruction.npz. Explicit path arguments are caller-relative. It returns the solver diagnostics plus arrays and runtime_seconds. Importing src.main does not select or change a plotting backend. `python -m src.main` executes this same path and prints objective/runtime; no root wrapper exists.

preprocessing.load_observations(path) loads NPZ with allow_pickle=False, returns float64 temperature(15,3181)°C, concentration(15,)mol/L and original intensity(2,15,3181)instrument units. normalize_intensity(temperature,intensity) returns the same intensity shape divided per sample/channel by its nearest70°C observation; it raises on a zero divisor. flatten_observations(temperature,denaturant,intensity) returns four length95430 arrays: t in °C, D in mol/L, channel integer0/1, and normalized intensity; channel/sample/frame order matches original author source.

physics_model.free_energy(temperature,denaturant,thermodynamic_parameters) broadcasts temperature/concentration arrays and evaluates the explicit thermodynamic equation, returns kJ/mol with broadcast shape. thermodynamic_parameters is ordered(t_m,H,C,m). unfolded_fraction uses the same arguments, source negative-energy guard and dimensionless population0..1. baseline_planes(temperature,denaturant,coefficients) takes a7-vector and returns folded/unfolded dimensionless baseline arrays. fluorescence(parameters,temperature,denaturant,channel) takes an18-vector, shared-shaped flat arrays and channel indices, returns modeled dimensionless normalized intensity. parameter_jacobian(parameters,temperature,denaturant,channel,relative_step=1e-5) returns length(observations)×18 centered finite-difference columns in intensity per respective parameter unit. These functions read no files and have no side effects.

solvers.initial_parameters(temperature,denaturant,intensity) consumes normalized observations and returns the18-vector computed from native empirical physical guesses, observed corner slopes and full highest-denaturant quadratic baselines. reconstruct(temperature,denaturant,normalized_intensity,initial=None) creates those observed-data starts unless an explicit comparison start is supplied; runs the complete global unconstrained LM fit and returns parameters(18,), initial_parameters(18,), prediction(95430,), residual(95430,), objective scalar, evaluations integer and status integer. Residual signs are prediction−observation. Source higher m-coefficients are fixed zero and absent as free variables. The standard run never supplies an oracle initial vector or fitted cache.

visualization.denaturant_midpoint(temperature,parameters) takes a4-vector and returns G(t,0)/m in mol/L. relative_l2(prediction,observation) returns the full observed-array L2 ratio. No plotting backend is selected in any library module.

## Evaluation and review

evaluation/judge.py is a standalone implementation, importing no src modules. It independently checks exact NPZ keys/shapes/float64/finite arrays, physical orientation and Kelvin domain, recomputes optical normalization, thermodynamics and complete fluorescence, and scores all three required arrays and both physical consistency criteria. Reference and metrics paths resolve relative to its own file; CLI prediction/report paths resolve relative to caller. Missing or malformed predictions/evaluator assets are errors with exit2/empty metrics. Valid below-threshold results exit1; passes exit0. Report writing uses finite UTF8 JSON and creates parent directories; report failure exits2. It prefers independently available ground_truth over baseline_reference, but this task has no actual truth.

evaluation/baseline_reference.npz and notebooks/reference_outputs/upstream_standard.npz contain independently captured original-source global thermodynamics/baselines and the corresponding full energy surface, explicitly method references. test/fixtures/upstream_stages.npz records source normalization, all initial and converged physical parameters, flattened input ordering, forward predictions and independently captured numerical Jacobian. Tests consume these fixed numerical arrays without upstream imports. Notebook actively calls cleaned main.run, records distinct fresh_cleaned_standard.npz and fresh_review_measurements.json, and computes all labeled comparisons from observations with cleaned modules. Source original figures are comparison context, not fabricated newly measured results.

All public metadata and output units appear in README; the public NPZ contains only observed processed intensity, measured temperature and chemical concentration. It contains no optimizer start, fitted calibration, hidden free energy or reference parameters. Plans document actual code signatures/defaults and the selected entire2020 method; archival2026 CheMelt analysis is not shipped or counted as this implementation.
