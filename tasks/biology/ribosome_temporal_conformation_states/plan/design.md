# Actual modules and execution flow

The standard command is python -m src.main. No domain package, NumPycheckpoint, other task or private oracle is imported. The local runtime subset is NumPy,SciPy(specialdigamma/logsumexp in solver/evaluator) and Matplotlib for review. Original HDF5 parsing and Numba are isolated upstream-only. No generator exists because the original author observations are reused.

preprocessing.load_observations(path) returns intensity(590,500,2)float64, interval_start(590)int64 and interval_stop(590)int64 from the publicbatch. observation_sequences(intensity,interval_start,interval_stop) returns590one-dimensional apparent-ratio arrays, preserving each half-open nativeinterval, and rejects zero denominators/nonfinite values. pack_sequences(sequences) returns paddedfloat64(N,Tmax), validbool(N,Tmax), lengthsint64(N). Padding is computational only and never contributes state/transitioncounts.

physics_model.gaussian_probability(observations,means,variance) broadcasts a finalstateaxis and returns positive Gaussian densities with the original10^-300floor. variational_emissions(observations,a,b,beta,means) returns the expected-log-Gaussian emissionfactors. forward_backward_batch(emission,transition,initial,lengths) takes(N,T,K),(K,K),(K),(N) and returns posterior(N,T,K), summedtransitionresponsibility(K,K), and summedlognormalizer(float). variational_step(...) constructs all sourceexpectedlogfactors and calls that boundary-aware operator. viterbi_sequence(observations,means,variance,transition,initial) returns int64(T)jointMAPstates under the stated normalizedplug-inparameters. model_log_likelihood(sequences,means,variance,transition,initial) computes actual summedGaussianHMMloglikelihood across independentsequences, not the unusedhistoricalELBO.

solvers.normal_gamma_update(observations,responsibility,a0,b0,m0,beta0) returns a,b,means,beta,count from a fullsoftassignment matrix. initialize(sequences,states=2,seed=20261026) implements the original observedquantile/conjugate/Viterbiheuristic and returns its state plus declaredpriors. reconstruct(sequences,states=2,updates=200,seed=20261026) executes explicitvariationalupdates, then jointly sorts stateaxes. It returns state_mean(K),state_variance(K),transition_probability(K,K),initial_probability(K),population_fraction(K),posterior(totalframes,K),a,b,beta,transition_posterior,pi,updates,normalizer_history(updates). The history is the expected-factor normalizer, **not** a valid evidencebound or actual normalizedobservationlikelihood. Otherstatecounts/updatebudgets/seeds are explicit notebookcomparisons, not unexecuted standardpaths.

main.run(data_path=None,output_path=None) resolves defaultpaths relative to the taskmodule, reads allpublicobservations, fits the two-state200-updateensemble, allocates an int64(590,500)pathfilled−1 and invokes localViterbi on every nativeinterval with inferredposteriorA/pi. It writes exactly the six READMEarrays with leadingbatchdimension and returns fulldiagnostics plus runtime_seconds. Explicit patharguments are caller-relative. No reference is read. Importing main changes no Matplotlibbackend.

visualization.path_agreement(estimate,reference,valid) computes fixedvalidframe agreement; transition_dwell_frames(transition) returns geometricmeanstate durations in frames; model_comparison(log_likelihood,frames,states) returns normalizedloglikelihood, explicitpointparametercount and the labeledheuristicBIC-style score. No score is presented as a Bayesfactor.

The standalone evaluation/judge.py imports no src code. It independently validates NPZkeys,shapes,dtypes,finitevalues,probabilitynormalization,positivevariances and fixedsupport/sentinel rules. It performs a singlejointcanonicalization of all submittedstate-indexedoutputs, then scores allphysicalparameters and activepathlabels. Its independently implemented log-domainGaussianforward and Viterbirecursions calculate actualobservationlikelihood anddecoderconsistency. Hiddenreferencepaths are evaluator-relative; CLI--prediction/--report are caller-relative. StrictUTF8finiteJSON uses status/pass/metrics/thresholds/errors and exit0/1/2. Actualtruth would takeprecedence only if independently supplied; thisbinding has only baseline_reference.

test/fixtures/upstream_stage.npz contains an originalfullsequence variationalforward–backward case; upstream_posterior.npz contains the originaltwo-statewholeensemble posterior parameters/responsibilities. They support independentstage/fullpipeline tests. evaluation/baseline_reference.npz is the separately recaptured originalcoherentdecoder plus physicalparameters. notebooks/reference_outputs/upstream_1/2/3_states.npz provide originaldifferent-state-count comparisons; upstream_gui_population_decoder.npz records the actual alternativeGUIinitializationpaths. The active notebook writes a distinct fresh_cleaned_2_states.npz. OriginalHDF5,Papers,checkout,Numbaoutputs,capturecode and logs remain private and are indexed in validation.md.
