# Shipped interfaces and flow

`python -m src.main` calls `run(data_path='data/raw_data.npz', output_path='output/reconstruction.npz')`. Paths are caller-relative. It loads the visible arrays, runs the complete SLPRU reconstruction, creates the output parent, saves one batch-first `reconstruction` array and returns `(image, diagnostics)`. Importing main does not change any plotting backend. No generator is shipped because instrument observations are reused.

## Modules

- `preprocessing.load_data(path='data/raw_data.npz')`: validates storage shape/dtype, returns uint8(30,30,24) observations and float64(24,13) spectra. No files are modified. `detector_units(image)` implements uint8/255 and otherwise float64 conversion. `window(image,row,col)` returns C×9 in column-major neighborhood order. `PIXEL_PITCH_M` and `FLUOROPHORES` specify acquisition coordinates and channel labels.
- `physics_model.forward(abundances,spectra)`: (...,13)×(24,13)→(...,24), with linear amplitude units preserved. `adjoint(spectral_values,spectra)` reverses the channel map using the Euclidean transpose. `poisson_loss(predicted,measured)` returns a summed scalar and infinity for nonpositive predictions. `poisson_prox(value,measured,mu)` evaluates the positive quadratic root. `relative_observation_error(abundances,measured,spectra)` returns `(relative_error,gain)` on the fixed interior, using the explicitly declared global alignment; it never modifies inputs.
- `solvers.group_shrink(x,tau)`: two-dimensional rowwise reweighted shrinkage. `solve_window(y,m,lambda_rank=0.1,lambda_group=0.1,poisson=True,capture=False)`: C×N and C×R float64 inputs, returns R×N nonnegative U, central R-vector, and dictionary containing iterations, final residuals and optional snapshots. Zero windows return a zero result. Snapshot copies at1,11,101,501 are used by independent upstream tests; no external files are opened.
- `solvers.reconstruct(image,spectra,method='SLPRU',lambda_rank=0.1,lambda_group=0.1)`: complete y/x/channel image→y/x/label relative abundance, plus per-pixel iteration counts and the discarded brightness maximum. Supports only SLPRU,NLS,SNLS,SLNLS. It runs all nonzero interior centers, fixes borders to zero and normalizes once over the whole image.
- `visualization.agreement(estimate,reference)`: returns cosine NCC and dynamic-range NRMSE. `acquisition_figure(image,m)`, `abundance_figure(methods)`, `residual_figure(image,m,methods)` return Matplotlib figures. They neither save nor close figures and do not choose a backend.

## Independent evaluator

`evaluation/judge.py --prediction PATH --report PATH` uses only standard library and NumPy. Hidden assets resolve relative to the evaluator, CLI paths relative to the caller. It validates prediction key, shape, real floating dtype and finiteness before scoring. Truth would take precedence if present; this task has only `baseline_reference.npz`. It computes every declared metric, fixed border/max-one physical checks, writes UTF-8 JSON and returns0/1/2 for pass/fail/error. Errors produce empty metrics; report-write failures print to stderr and return2. It does not load or run solver code. Public calibration is read for the observation-consistency diagnostic.
