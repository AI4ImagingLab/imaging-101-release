# Shipped implementation and execution flow

`python -m src.main` reads `data/raw_data.npz`, invokes `src.solvers.reconstruct`, and writes only the two declared float64 arrays to `output/reconstruction.npz`. It prints diffusivity, adjustedR² and function-evaluation count. Paths are relative to the task workspace. Importing main does not select a Matplotlib backend. It supplies one-thread defaults for numerical backends before importing NumPy; the validated commands also set these variables explicitly.

## Modules and callable interfaces

* `preprocessing.sample_line(movie, coordinates)`: uint16(time,y,x) movie and float32(position,2) x/y centerline → float32(time,position) camera intensity. It uses explicit bilinear interpolation, float32 strip samples and original triangular9-to-1 reduction. Raises ValueError if a strip exceeds the observed image. Does not infer or alter ROI geometry.
* `preprocessing.prepare(data)`: NPZ-like mapping containing batch-first movie and two coordinate arrays → dictionary with profile(42,89), control(42,75), normalized(41,89), scalar background/stationary/epsilon, norm(2), and control_fit(42). It processes every frame. Constants PIXEL_SIZE and TIME_STEP preserve float32 source values. No disk writes.
* `physics_model.compression_matrix(nx,nq=9)`: integers → float64(nq,nx) real Fourier matrix. Standard nx=89,nq=9.
* `physics_model.heat_gram(diffusion,epsilon,nt=41,nx=89,nq=9,beta=0.)`: scalar diffusion in pixel²/frame and loss factors per frame → float64(nt*nq,nt*nq) compressed infinite-line heat Gram matrix. The general small dimensions support independent numerical tests.
* `physics_model.profile_residual(diffusion,compressed,epsilon,background,stationary=0.,model='diffusion',beta=0.,return_all=False)`: float64(time,mode) observations and normalized nuisance terms → flattened normalized residual. Standard spatial length is89. With return_all=True returns residual(time,mode), cost scalar and effective residual trace scalar. Constructs the original ridge projector via explicit LAPACK operations. Cholesky/inverse errors raise ValueError. A fixed ARPACK initialization is an explicit reproducibility convention.
* `solvers.reconstruct(data,model='diffusion',nq=9,ignore_bleaching=False)`: NPZ mapping → dictionary containing reconstruction(1,41,89), diffusivity(1,1), loss_rate, epsilon, cost, trace, adjusted r2, covariance, compressed observations, residual, preprocessing diagnostics, nfev and success. All computations are fresh. Optional model values are reaction and reaction-diffusion; they are maintainer comparisons, not separate released tasks. ignore_bleaching is an ablation only.
* `visualization.agreement(a,b)`: finite real comparable arrays → standard cosine NCC and reference-range NRMSE; rejects a degenerate reference. Independent known-number tests match the Judge.
* `visualization.acquisition_figure(data,result)`, `recovery_figure(result,upstream)`, `model_figure(results)`: construct Matplotlib figures from actual supplied measurements and results; return Figure objects; no backend changes or file writes. They show acquisition ROIs/control, full kymographs with residuals, and fresh model-comparison costs/R²/recovery curves.

## Evaluator separation

`evaluation/judge.py` uses only standard library and NumPy. It never imports src, checkpoints or prediction code. `load_arrays(path)` validates both required keys, exact batch-first shapes, float64 real dtype and finiteness. Hidden references resolve beside the Judge, choosing actual truth if present, otherwise the baseline reference. CLI prediction/report paths remain relative to the caller's working directory. `metrics(prediction,reference)` computes NCC/NRMSE/relativeD independently; `evaluate(prediction_path)` returns JSON-ready report and exitcode; `main(argv=None)` handles arguments and UTF8 report writing, including report-parent creation and write-failure exit2.

## Notebook flow and provenance boundaries

The canonical notebook has Problem, Data, Physics, Method, Results and Conclusion sections. It loads the complete public observations, actively calls reconstruct, evaluates a fresh temporary submission through the standalone Judge, and loads the explicitly labeled reproduced upstream result only for comparison. It actively fits reaction-only, reaction-diffusion and no-bleaching variants and plots their actual results; no archived output masquerades as a fresh calculation. It retains the author’s scientific distinction between pure diffusion and physically suspect negative exchange. Additional residual, objective-profile and bandwidth checks expose uncertainty.

`test/fixtures/upstream.npz` is consumed by stage/pipeline tests. `notebooks/reference_outputs/upstream.npz` supplies the notebook's labeled oracle comparison. `notebooks/reference_outputs/cleaned_measurements.npz` records a fresh measured local run for provenance only; the notebook does not substitute it for active reconstruction. Independent oracle source, original TIFFs, ImageJ JAR, capture scripts, PDFs and logs remain in the external maintainer archive. No source-tree or oracle imports occur in the cleaned package.
