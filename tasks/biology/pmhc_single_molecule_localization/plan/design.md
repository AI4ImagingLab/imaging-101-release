# Shipped interfaces and caller flow

Dependencies: NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1 only; no sdt/trackpy or other imaging package is imported by source, tests, Judge or notebook. Original package is used only in an external private oracle environment. No cross-task imports or raw-format readers are shipped.

`preprocessing.load_observations(path)` loads allow_pickle=False and returns a copy of frames(1,10,128,128)uint16ADU; rejects wrong native shape/dtype. `bandpass_filter(image,feature_radius=3,noise_radius=1,nonneg=True)` takes one2D frame, returns same-sized float64ADU with valid-convolution zero border. FEATURE_RADIUS3,NOISE_RADIUS1,SIGNAL_THRESHOLD300,MASS_THRESHOLD5000 document canonical defaults. No file effects.

`solvers.find_peaks_yx(image,search_radius,threshold)` returns integer(N,2)y/x candidates after circular grayscale dilation, boundary exclusion and original tie resolution. `solvers._get_crop(img,start_idx,end_idx)` returns a view of a valid2D ROI or None if out of bounds. `solvers.locate(raw_image,radius,signal_thresh,mass_thresh,bandpass=True,noise_radius=1)` performs local bandpass/detection/two-pass moment inversion and returns float64(N,5), columns x/y pixel,massADU,sizepixel,eccdimensionless. `solvers.reconstruct(frames,radius=3,signal_thresh=300.,mass_thresh=5000.,bandpass=True,noise_radius=1)` takes batch-first frames and returns float64(1,N,6), prepending frame index. It infers N; input arrays are not mutated.

`physics_model.gaussian_image(shape,centers,masses,sigmas,background=0.)` takes height/width, centers(N,2)x/y pixels, masses(N,)ADU,sigmas(N,)pixels and scalar backgroundADU; returns float64(H,W)ADU. It explicitly evaluates the normalized Gaussian analytic model for tests. `moment_preview(table,shape=(128,128),n_frames=10)` returns illustrative isotropic filtered-feature images(1,T,H,W),ADU. It is not a raw forward prediction or scored output.

`main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` validates complete movie, localizes all frames, creates output parent and writes reconstruction table. Returns(table,runtime_seconds). `python -m src.main` prints actual count/timing JSON. Importing main does not change any plotting backend.

`visualization.experiments(frames,original)` actively reconstructs canonical and controlled variants and returns arrays/measurements in a dict; no cached variant is relabeled fresh. `visualization.table_metrics(estimate,reference)` is a local independent implementation of same-frame matching and full-reference losses; unit tests check against independent known values and standalone Judge. `visualization.figures(frames,result)` returns a dict of Matplotlib figures for full native images, subpixel zoom/coordinate and moment comparisons, and sensitivity studies. No display/save/backend mutation is performed by this module. Notebook owns explicit single display and close.

Flow: public frames -> valid bandpass -> dilation/tie-resolved candidates -> circular initial mass/centroid -> bilinear shift -> second moments/centroid -> concatenated table -> canonical NPZ. Notebook repeats complete fresh reconstruction using local modules, reads only identified original baseline for comparison, computes full-movie variants, evaluates strict standalone Judge and displays each resulting figure once. Scientific display zooms do not change benchmark input size. Synthetic Gaussian checks and additive-noise stresses are separately labeled and do not generate benchmark observations, so generate_data.py is omitted.

Independent `evaluation/judge.py` resolves hidden assets relative to its own directory, takes caller-relative --prediction/--report paths, uses ground_truth if present otherwise baseline_reference, validates all required columns, scores every feature moment and detects extras/missing rows; returns0pass/1validpoor/2malformed-or-evaluatorerror. Report is strictUTF8JSON with status/passed/metrics/thresholds/errors; report parent is created, report-write failures produce stderr and exit2. No solver imports occur.

Consumers: test/fixtures/upstream_stages.npz contains independently captured output_filtered_i/output_peaks_i/output_localizations_i for each of10frames; comparing tests consume every array. evaluation/baseline_reference.npz contains original table and supplies Judge/notebook reference. notebooks/reference_outputs/upstream_measurements.json identifies original run; fresh_measurements.json identifies fresh reconstruction/variants. Original raw movie and source remain private archives; source/data notices are preserved in LICENSE/NOTICE. All tests/fixtures/validation live under test; no duplicate reports or root wrappers.
