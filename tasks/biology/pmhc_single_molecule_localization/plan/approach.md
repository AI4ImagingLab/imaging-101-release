# Implemented mathematics and conventions

Unknowns are visible feature count and per-feature x/y subpixel center, bandpass intensity mass M in ADU, effective original-estimator size R in pixels, and second-angular eccentricity e. All ten native128x128 uint16 images are retained. Coordinates are integer pixel centers, x right/y down. Absolute physical pixel scale, gain, frame interval and instrument PSF are absent; neither photon counts, molecular copy numbers, true PSF widths nor nanometer precision is inferred. The selected method is the actual sdt-python Crocker–Grier moment estimator used on this movie. Its feature moments, not a deconvolved fluorophore truth, are the reference estimands.

## Bandpass

Let feature radius r=3 and noise radius lambda=1 pixels. Set w=max(r,2lambda)=3 and grid i=-w,...,w. g(i)=exp[-(i/(2lambda))^2], B=(sum g)^2 and K0=(sum g^2)^2/B-B/(2w+1)^2. Kernel K(i,j)=[g(i)g(j)/B-1/(2w+1)^2]/K0. Evaluate finite valid FFT convolution of raw ADU image with K; embed into an otherwise zero full-size array, with w-pixel zero boundary. Clip negative filtered intensities to0. This nonlinear clipping is part of the selected method. The kernel has zero DC response up to floating roundoff; filtered mass is not conserved raw photon flux. Formula/sign/normalization are retained exactly from sdt.image.filters.cg.

## Detection and boundary conventions

Create integer circular dilation footprint i^2+j^2<=r^2. Candidate maxima satisfy np.isclose(dilated,J) and J>=300ADU; default NumPy isclose conventions are preserved. Remove candidates within r pixels of each detector edge. Flat peaks use the original deterministic column-wise sorting/argmax convention and progressively remove rejected candidates from the maxima image, rather than silently replacing this rule with a different maximum finder. Returned coordinates are x/y; ndimage indices are y/x. Candidates are retained only if an entire refinement aperture is available. The initial aperture mass must be strictly greater than5000ADU.

## Two-pass moment inversion

Offsets i,j=-r,...,r define S=i^2+j^2 and W=1[S<=(r+0.5)^2]. In a(2r+1)^2 filtered ROI, M=sum J W. First centroid shift dx=sum J uW/M-r and dy=sum J vW/M-r, where u,v=0,...,2r are ROI pixel-center coordinates. Provisional global center is (x0+dx,y0+dy). Let integer shifts be floor(dx),floor(dy), and fractions be modulo1. Extract one extra right/bottom row/column at those shifted bounds. Use ndimage.shift by the negative fractions, order1 (bilinear), cvalNaN, then discard the extra final row/column. This sign and boundary convention is preserved; if the required crop is out of bounds, exclude the feature.

Compute refined M=sum Jshift W. Radius R=sqrt(sum Jshift*(S W+1/6)/M): the original +1/6 term applies to all ROI entries and is not silently changed to W/6. Theta=atan2(i,j) is clockwise under image coordinates. Set C=cos(2theta)W and Q=sin(2theta)W, with center entries set0. Eccentricity e=sqrt[(sum Jshift C)^2+(sum Jshift Q)^2]/[M-Jshift(center)+1e-6]. The1e-6 denominator stabilization is retained. Final centroid adds a second dx/dy moment correction from the shifted ROI to the provisional global center. Mass, radius, eccentricity and final coordinates are all retained.

This is direct local moment inversion after feature detection, not a loss-minimization iteration. There is no global objective, regularizer, gradient descent, initialization schedule, line search or convergence tolerance. Exactly two centroid passes are used. The standard entry point fixes all defaults above and concatenates every frame's valid rows as float64(1,N,6), columns frame,x,y,mass,size,ecc. A zero-detection result has shape(1,0,6).

## Image formation and independent checks

The physical fluorescence model is background plus optical spot images plus camera/fluorescence noise. For independent mathematical checks, physics_model.gaussian_image explicitly evaluates normalized point-sampled isotropic Gaussian spots m/(2pi sigma^2) exp[-((u-x)^2+(v-y)^2)/(2sigma^2)] on integer-centered pixel grid. Continuous infinite-plane flux equals m; finite discrete sums differ. This analytic model tests known centers, integer translations, flux and positive widths. It is not substituted for the real movie or claimed as calibrated true PSF. moment_preview uses inferred mass and sigma=R/sqrt2 for an explicitly labeled isotropic visualization; eccentricity has no orientation output, so no anisotropic orientation is invented. That preview is not scored as a physical raw-image prediction.
