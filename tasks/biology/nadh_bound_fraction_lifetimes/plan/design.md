# Shipped interfaces and execution

- `preprocessing.load_data(path='data/raw_data.npz') -> (signal,reference)`: NPZ allow_pickle=False, removes only leading batch axis, returns copies of full (512,512,97) uint8 observations in row,column,delay order. No write or filtering.
- `physics_model.calibrated_phasors(signal,reference) -> (mean,z)`: mean (512,512) float64 stored intensity/bin; z (2,512,512) complex128 dimensionless normalized calibrated harmonic moments; zero-total background NaN. Constants FREQUENCY=80MHz, REFERENCE_LIFETIME=3.05ns, OMEGA=2*pi*.08/ns.
- `physics_model.mixture_phasors(lifetimes,fractions)`: component-first broadcast arrays, lifetimes ns and integrated fractions dimensionless; returns first-two-harmonic complex model with leading harmonic axis. No state or IO.
- `solvers.graphical_search(z,lifetime_range=(.2,.8,.01)) -> (tau,fractions)`: harmonic-first z, returns two component-first float64 arrays, ns and dimensionless. Explicit semicircle/grid equations; no external solver.
- `solvers.single_harmonic(z,mean,free_lifetime=.4) -> (fraction,bound_lifetime)`: one harmonic and intensity image; output clipped fraction image and one inferred bound lifetime ns, no calibration state change.
- `solvers.reconstruct(signal,reference,lifetime_range=(.2,.8,.01)) -> (output,details)`: output dictionary reconstruction (1,2,512,512) and bound_fraction (1,512,512), float64, background zero; details contain mean, phasors, both fractions, single_fraction and single_bound_lifetime for comparison. No file writes.
- `main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz') -> seconds`: complete load/reconstruct/save compressed NPZ, creates output directory. CLI `python -m src.main` invokes run. Import does not change Matplotlib backend.
- `visualization.forward_residual(output,phasors,support) -> image`: two-harmonic complex RMS per pixel, background NaN. `image_grid(images,titles,limits=None,cmaps=None) -> figure`: labeled colorbar per panel; no implicit save or show.
- `evaluation/judge.py`: independent NumPy/standard-library evaluator, validates both output keys, finite real floating dtype, exact shapes, observed support, ordering and fraction range; hidden reference paths relative to evaluator; prediction/report relative to caller. `evaluate(prediction,assets=ROOT) -> (report,code)`. Actual truth filename takes priority if ever legitimately supplied; current task has only method reference. No solver/domain imports, no reconstruction fallback.

Flow: public observations -> preprocessing -> independently calibrated Fourier moments -> local exhaustive graphical inverse -> both output quantities -> strict independent Judge. The active notebook calls the same modules freshly for the complete bound observations, imports Judge through importlib for fresh evaluation, loads identified original arrays only for comparisons, and runs fresh sensitivity variants. Frozen fixtures supply tests only; neither runtime nor inverse method reads them. Plans, evaluation, notebook and tests are hidden from benchmark solvers. Dependencies are only shared NumPy and Matplotlib; pytest/nbconvert are shared development tools.


Version2: lifetime_range denotes inclusive start and stop endpoints at the given positive spacing; default candidates are 0.20+0.01k ns for k=0,...,60. The standalone Judge independently evaluates public phasors and geometric constraints, accepting equivalent near-degenerate minima rather than requiring lifetime agreement to an implementation-specific tie.
