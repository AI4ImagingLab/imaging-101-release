Let qx=2pi*fftfreq(n)/dx, qy=qx, qz=2pi*rfftfreq(n)/dx for n64. Compute Cartesian radius r=sqrt(qx^2+qy^2+qz^2), shell width deltaq=min(r>0)-1e-8 and nb=int(max(r)/deltaq). Boundaries linspace(0,nb*deltaq,nb+1), labels searchsorted(right)-1 exactly preserve upstream convention. A real Fourier transform stores half the z frequencies. A qualified correction supplies multiplicity w=1 on qz0/Nyquist and2 on interior qz. Shell means sum(w*a)/sum(w) are used both for shell-coordinate mean radius and intensity. This is independently equal to averaging full complex FFT samples, invariant under90degree Cartesian rotations. The unmodified upstream implementation omitted multiplicity, introducing half-space/axis dependence; unmodified runs are preserved as comparisons and never represented as corrected parity evidence.

Interpolate the GNOM fit linearly onto shell coordinates lying within the supplied q range. Let qL be the final such coordinate, IL its fitted intensity. For every higher shell extend IL*(q/qL)^(-4). Divide all target intensity and interpolated sigma values by fitted I(0), preserving unit mass. This is a prior beyond the data, not new measurements. All selected shells form one target T. Each iteration computes F=rfftn(rho). Exact zero Fourier entries become1e-16 as in source. J is the correctly weighted shell average |F|^2.
