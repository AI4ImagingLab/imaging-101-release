# Shipped interfaces and execution flow

`preprocessing.load_data(path)` loads intensities uint16(1,4,512,512) with allow_pickle=False and returns copied unbatched intensities(4,512,512) ADU. `normalize(intensities)` returns float32 contrast using a reflect-boundary uniform filter and original in-place float32 divisions/DC subtraction.

`physics_model.transfer_functions(shape=(512,512))` returns Hu/Hp complex128(4,Y,X), source float32(4,Y,X), pupil bool(Y,X), and fx/fy complex64 coordinate vectors in cycles/µm. Constants are WAVELENGTH=.514 µm, NA=.4, PIXEL_SIZE=.1625 µm and ROTATIONS=(0,180,90,270). `forward(absorption,phase,hu,hp)` returns real contrast(4,Y,X). `adjoint(images,hu,hp)` returns the real absorption/phase adjoint pair(Y,X). All task-specific pupil/source/WOTF mathematics is local.

`solvers.normal_matrix(hu,hp,reg_u=.1,reg_p=.005)` returns the four complex normal-matrix entries. `invert(a,b)` evaluates the explicit determinant inverse and returns real spatial absorption/phase. `third_difference(x,axis)` and `shrink(x,threshold)` implement periodic third derivatives and the isotropic vector proximal operator. `tv_solve(images,model,iterations=10)` returns the actual third-order-TV comparison plus its residual history. `reconstruct(data,method='Tikhonov',reg_u=.1,reg_p=.005)` returns(outputs,stages); outputs contains reconstruction phase delay and absorption log amplitude, each float64(1,Y,X). Stages contains all model arrays, float32 normalized images and history(empty for Tikhonov). TV comparison uses original rho=tau=1 and10 updates. The regularization sensitivity sweep changes only explicit Tikhonov arguments.

`main.main()` resolves task root, loads data, runs nominal Tikhonov and writes both required arrays into output/reconstruction.npz. Library imports never set a Matplotlib backend. `visualization.run_experiments(data,upstream)` actively computes nominal, TV and five quadratic sensitivity conditions. `make_figures(data,e)` returns five groups retaining the original notebook scientific panels; `export(figures,e,directory)` writes private PNG/SVG/PDF and numeric NPZ/JSON only when explicitly called.

The notebook actively computes both methods from raw data and loads separately identified upstream results for comparison. upstream.npz and upstream_tv.npz are standard-method outputs, consumed by nominal/TV parity and notebook comparisons. test/fixtures/oracle_stages.npz contains original normalized images, sources, pupil, both WOTFs and frequency grids; every key is tested. The standalone Judge evaluates both entire required quantities and cannot pass when only phase or only absorption is correct. Exact shape/dtype/finite checks, malformed files, overflow, evaluator failure, report-write failure and foreign cwd are covered. No upstream library, cross-task import or simulated benchmark observation is shipped.
