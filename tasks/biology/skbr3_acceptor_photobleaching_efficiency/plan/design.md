# Shipped interfaces and flow

Runtime dependencies are NumPy2.4.6 and Matplotlib3.11.1, with Python3.11.11. ImageJ, Java, TIFF readers and the upstream plugin are private oracle tools only. No source module imports or invokes an upstream implementation. The shared environment is not changed.

`src.preprocessing.subtract_background(image,roi=(0,64,448,512))` accepts a2D intensity array, returns float32 background-subtracted/clamped image and a float32 measured offset, in ADU. `gaussian_half_kernel(sigma=1.0,accuracy=.01,max_radius=512)` returns float32 half-kernel and tail vectors. `_convolve_axis(image,kernel,tail,axis)` performs explicit nearest-edge line mathematics. `gaussian_blur(image,sigma=1.0)` returns full-frame float32 horizontal/vertical filtering; sigma0 is a comparison-only identity. `registration_shift(before,after)` returns signed integer(row,column) correlation shift. `translate_zero(image,shift)` preserves the image dtype and leading axes, translating its final two spatial axes with zero-filled exposed pixels, as in the original ShiftDialog. `preprocess_sample(observations,sigma=1.0)` accepts TCYX(2,2,Y,X), validates finite intensities, and returns dictionary keys `background`, `smooth` (float32 TCYX ADU) and `offsets` (float32 TC ADU). Library imports do not select a plotting backend.

`src.physics_model.donor_acquisition(efficiency,donor_brightness,acceptor_brightness,factors)` evaluates the explicit forward model and returns four float64 arrays Dpre,Dpost,Apre,Apost in ADU. Factors have order gamma,delta,epsilon,alpha. `corrected_efficiency(donor_before,donor_after,acceptor_before,factors)` evaluates the source mixed-precision inverse and returns float32 dimensionless E; it does not clamp signed results or set support.

`src.solvers.estimate_corrections(donor_control,acceptor_control,target,threshold=100.0)` accepts three float32 TCYX arrays, returns a float32 factor vector(4,) and tuple of donor-before, acceptor-before and target masks, each boolean YX. The donor-after mask is independently used for its control mean. `_display_factor(value)` preserves the original float32/3decimal/float32 factor convention. `reconstruct(observations,sigma=1.0)` accepts STCYX(3,2,2,Y,X), checks acquisition layout, aligns the observed target's post channels using integer correlation, reconstructs the complete original method and returns `reconstruction`(1,Y,X), `correction_factors`(1,4), the three preprocessing `stages`, three `masks`, and `registration_shift`. It rejects nonfinite supported results. No side effect writes files.

`src.main.load_observations(path)` loads `allow_pickle=False`, requires exactly public keys `observations` and `observation_mask`, native uint16 shape(1,3,2,2,512,512) and bool(1,512,512), returns sample array without the batch dimension and mask with batch retained. `run(task_dir=None)` resolves task root relative to its own source by default, calls the fresh pipeline, verifies the computed support equals the public fixed support, writes exactly the two declared arrays to `output/reconstruction.npz`, and returns the detailed fresh result. `python -m src.main` is the standard entry point. No root entry-point wrapper exists.

`evaluation/judge.py` is standalone and imports no solver code. `evaluate(prediction)` validates finite thresholds and all hidden reference fields first; `ground_truth.npz`, if present, takes unconditional priority over `baseline_reference.npz`. It loads the fixed mask from public data. Required exact shapes/keys, real float32/64, finite arrays and zero exterior are checked without coercing complex data. Valid zero and otherwise poor fields fail metrics rather than causing undefined cosine values. `main(argv=None)` implements `--prediction` and `--report`, resolves hidden paths relative to the evaluator file, preserves caller-relative CLI paths, creates report parents and emits UTF8 strict JSON. Exit0=pass,1=valid below thresholds,2=malformed prediction/evaluator/report error.

`src.visualization` supplies actual figure composition to the active notebook; its numerical display metrics use the same public definitions and independently tested known cases. It never changes a Matplotlib backend. The notebook actively loads raw data, calls fresh reconstruction and Judge, loads identified frozen upstream arrays only for comparison, and runs scientifically distinct observed-data sensitivity checks. It exports actual PNG/SVG/PDF figures and numeric sources to a maintainer archive through a notebook environment argument. Comparison observations and any independent analytic fixtures remain explicitly distinguished from the real benchmark. The canonical executed notebook is the sole notebook shipped.

`test/fixtures/original_stages.npz` contains40 source-captured arrays: 12 each background, Gaussian and selected TCYX images, three input masks and the complete E field. `original_known_physics.npz` contains independently generated forward observations and known E plus original-plugin inversion; it is not benchmark truth. Stage tests consume every captured array, independent physics tests consume the latter case. `notebooks/reference_outputs/upstream_complete.npz` identifies the complete unchanged original result for notebook comparison, while `cleaned_complete.npz` is a separately identified fresh local measurement. `evaluation/baseline_reference.npz` is the standard-method result for scoring, never renamed as true biology.
