# Implemented mathematics

The selected published method is the fully corrected acceptor-photobleaching FRET estimator, applied to the full author-supplied real SK-BR-3 doubly labelled frame and its matched donor-only and acceptor-only preparations. This is a conditional method-reference problem, not a molecular ground-truth measurement. All three native LSM observations have TCYX=(2,2,512,512) uint16, transformed losslessly to float32 ADU for arithmetic. Lateral sampling is0.0558035713935203 micrometre. Time is before/after and channels donor/acceptor. All calculations use the full frame, with output support fixed by observed pre-bleaching signals.

For each frame I, take the float64 sum of observed values in rows0:64, columns448:512, divide by4096, cast its mean to float32 b, and calculate max(I-b,0) in float32. This is the upstream clamped background convention and is distinct from clipping the inferred efficiency, which is forbidden. The rectangle is observed background in all three preparations.

Use ImageJ1.54p's separable Gaussian discretization with sigma1pixel, accuracy.01, radius5 (offsets0..4). Kernel entries start as float32 exp(-i²/(2sigma²)); the finite-edge quadratic rule applies only if its derived condition changes a tail entry. Normalize by the float64 sum of the stored symmetric float32 entries, cast each normalized entry to float32, and retain its float32 uncomputed tail mass. Nearest-edge continuation is evaluated explicitly with the tail, preserving source operation order. For interior pixels, start with k0 I(i), then add k(j)[I(i-j)+I(i+j)] for increasing j in float32. Process x then y, with float32 storage between axes. No implicit library default, FFT convolution, wrap boundary or reflected boundary substitutes for this convention.

The native registration operation is an integer peak of the unnormalized circular correlation between donor pre/post frames. The local implementation evaluates inverseFFT(FFT(before)conj(FFT(after))) with float64 FFT primitives and scans x before y for tied maxima. The bound pair has shift(0,0), independently observed in the original and local runs. The source GUI's nonzero integer translation uses zero-filled exposed rows and columns, not circular wrap; the local translation helper follows that boundary when needed. Registration applies the same observed displacement to both post channels. Control means are shift invariant and the selected original driver does not register the donor-only control.

Write d and a for smoothed donor-only and acceptor-only arrays, and t for the doubly labelled sample. Donor-before mask Md1=(d10>100), donor-after mask Md2=(d20>100), acceptor-control mask Ma=(a11>100), and target mask M=(t10>100 and t11>100). The supplied public mask is exactly M. Indices here denote time and channel explicitly; source code uses zero-based arrays [time,channel].

The donor-only ratio gamma is mean(d-before donor on Md1)/mean(d-after donor on Md2). Delta is mean(acceptor-only before donor on Ma)/mean(acceptor-only before acceptor on Ma). Epsilon replaces the numerator with acceptor-only after donor, retaining the same Ma. Means use float64 accumulation of float32 intensities. Alpha is the mean over M of float32 target A-after/A-before ratios. Each factor is cast to float32, formatted to3decimals with round-to-nearest-even, and parsed into float32. The actual factors are observed control estimates, not independently known truths. Gamma below1 is retained with the upstream warning; no clipping or refitting is introduced.

Let E be dimensionless transfer efficiency, D0 unquenched donor brightness in ADU, and A the pre-bleaching acceptor signal in ADU. The conditional forward model is

```math
D_1=D_0(1-E)+\delta A,\quad
D_2=D_0(1-\alpha E)/\gamma+[\alpha\delta+(1-\alpha)\epsilon]A,\quad
A_2=\alpha A.
```

Detailed unknown brightness cancels algebraically. With x=D1-delta A and y=gamma[D2-(alpha delta+(1-alpha)epsilon)A]-alpha x, the closed inverse is E=1-(1-alpha)x/y. Source mixed arithmetic is retained: x is evaluated in float32; the bracket coefficient and y are evaluated in float64 using the parsed float32 factors, then y is stored in float32. The final division is float64 followed by float32 output. No iterative objective, initialization, line search, regularizer or stopping rule is needed for this closed inverse. Gaussian smoothing is the selected spatial regularization, not an estimated optical PSF or target calibration.

Evaluate E on all29261 fixed supported pixels, retain all4446 negative values in the standard result, and pad the rest of the full512² field with exactly zero. Require all outputs finite; no denominator threshold, postfit mask, percentile trim, efficiency range clip or output-dependent support is allowed. Four correction factors are also required and scored. A deliberately broad molecular interpretation is not supported: the field assumes an effective donor/acceptor environment and represents conditional noisy ensemble efficiency.

Reference comparison uses uncentered cosine NCC, RMS error divided by reference dynamic range, and maximum absolute error. Boundaries were frozen before local extraction: NCC>=.999999999, DR-NRMSE<=5e-7, maximum efficiency absolute error<=1e-6, factor maxabs<=1e-7. These are numerical-method criteria, supported by original bitwise repeats, independent double evaluation error1.6364e-7 and known-E source error2.1336e-7; they are not biological accuracy confidence bounds. Actual truth takes priority if present, and malformed truth is an evaluator error rather than permission to fall back to a method reference.
