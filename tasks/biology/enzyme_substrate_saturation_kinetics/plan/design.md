# Shipped interfaces and execution flow

Runtime uses Python standard library, NumPy2.4.6 and Matplotlib3.11.1. No R, SciPy, renz, domain package or cross-task imports. CLI and numerical routines need only NumPy; visualization uses Matplotlib. Input is the visible README and `data/raw_data.npz`. All arrays load with allow_pickle=False.

`preprocessing.load_data(path='data/raw_data.npz')` validates real float64 substrate(1,10), rates(1,8,10), finite positive values and strictly increasing concentrations; returns copied s(10) in mM and rates(8,10) in micromolar/min. Data are already unit-converted; it does not infer calibration from hidden reference values.

`physics_model.rate(substrate,parameters)` evaluates V*s/(K+s), preserving NumPy broadcasting over a scalar/array substrate; parameters length2 is (K,V). `jacobian(substrate,parameters)` returns (n,2) analytic derivatives with corresponding rate-per-parameter units. `profile(substrate,observed,km_grid)` returns V(grid) and RSS(grid) by exact conditional least squares.

`solvers.intersections(s,v,corrected=False)` returns all n(n-1)/2 pairwise (K,V) intersections; default deliberately reproduces the original erroneous V intercept. `ecb(s,v,corrected=False)` takes coordinate medians and rounds three decimals. `line_fit(x,y,weights=None)` returns intercept,slope from explicit least-squares design; optional weights multiply both rows and observations by their square roots after common rescaling. `linear_fit(s,v,method)` supports lb,weighted_lb,hw,eh and returns the original rounded two-parameter result.

`direct(s,v,initial=None,return_history=False)` selects original ECB initialization unless an explicit length2 diagnostic initial state is supplied. It implements Gauss-Newton with QR, relative-offset convergence tolerance1e-5, max50 updates and backtracking minimum1/1024. Returns rounded parameters(2). With return_history=True returns (parameters,history), history(iterations+1,4) columns unrounded K,V,RSS,convergence criterion. Nonconvergence raises RuntimeError; no silent cached fallback.

`compare(s,rates,author_removal=False)` returns all six method outputs(6,groups,2), ordered by METHODS=('direct','lb','weighted_lb','ecb','hw','eh'). With author_removal=True only group index1, concentration index7 is omitted. The default keeps every datum. `reconstruct(s,rates)` invokes direct independently on every group and returns a dict with reconstruction(1,8), maximum_rate(1,8), fitted_rate(1,8,10). `sensitivity(s,rates)` actively fits each leave-one-point-out dataset; returns(groups,concentrations,2). A failed diagnostic fit is explicitly NaN, counted/reported in Notebook, and never used as a solver output.

`main.main()` calls load_data, reconstruct, creates output/ if necessary and saves output/reconstruction.npz; returns the same result dict. Standard execution is `python -m src.main`, relative to the task workspace. It reads no hidden arrays and does not import visualization. Importing it never changes a Matplotlib backend.

`visualization` contains observation, comparison, metric, profile, sensitivity and original-error diagnostic plotting functions. They return Matplotlib Figure objects, compute no replacement reconstructions and never set a backend. The notebook loads raw observations through load_data, actively runs reconstruct plus both complete comparison scenarios, evaluates the fresh result using the standalone Judge, then passes computed arrays to the plotting functions. Independent original arrays are loaded only for comparison; fresh arrays and metrics are separately saved in notebooks/reference_outputs/fresh.npz. No cache-preview path is used.

Plot signatures are `observations(s,v,fresh,original)`, with the last two arrays(groups,2); `parameters(comparison)`; `errors(s,v,comparison)`, returning (Figure,RMSE(6,8)); `paper_comparison(s,v,comparison)`; `deletion(s,v,full,removed)`; `profiles(s,v,primary)`; `sensitivity_plot(s,v,primary,loo)`, returning (Figure,approximate_SE(8,2),scaled_Jacobian_condition(8)); and `ecb_diagnostic(s,v,comparison,corrected)`. Unless specified otherwise, each returns only a Figure. Comparison arrays are(6,8,2), primary/corrected arrays(8,2), leave-one-out(8,10,2). Units are the same as numerical solver interfaces. The ECB pair scatter explicitly reports parallel/infinite intersections and plots only finite coordinates; no observations are removed from reconstruction.

`evaluation/judge.py` is independent of solver imports. CLI requires --prediction and --report. It validates every key/shape/exact float64 dtype/finite entry, physical positive K,V and evaluator configuration. Hidden reference resolves relative to its own file, actual truth takes precedence if present; otherwise baseline_reference.npz. Public substrate is independently loaded for forward consistency. Return codes are0 pass,1 valid but below limits,2 malformed input/evaluator/report error. UTF8 JSON contains status,passed,metrics,thresholds,errors, with finite numeric values only. Relative prediction/report paths remain caller-relative.

`test/fixtures/original.npz` is consumed by original-parity tests; `test/fixtures/original_stages.npz` by independent R nlsModel stage tests; `notebooks/reference_outputs/original.npz` by notebook comparisons; baseline_reference.npz by Judge. These are independent original results. `notebooks/reference_outputs/fresh.npz` records the actively executed cleaned comparison outputs and is a measurement record, never solver input. Complete upstream source, R capture/logs and paper stay in the external maintainer archive indexed in test/validation.md.
