# Shipped interfaces

preprocessing.load_data(path=None) returns values(63,86), lengths(63), processed dictionary with separate1byLength traces, observed means/maxima and unique lengths. Default input is module-relative data/raw_data.npz; no hidden arrays are read.

solvers.PromoterModel(K,W,t_MS2,deltaT,kappa,compound_states,processed_signals) stores physical/model parameters. initialise_parameters() derives randomized starts from public observations. EM_fixed(initialised_parameters,n_steps,n_traces,PERMITTED_MEMORY,eps,seed_setter) returns warmup parameters; EM_with_priors with the same interface jointly estimates parameters. get_promoter_traces(final,n_steps,n_traces,PERMITTED_MEMORY,eps,seed_setter) returns trace-indexed2byLength log posterior arrays. forward_backward exposes explicit retained-graph recursion and sufficient statistics. physics_model provides elongation weights, state-weight decomposition, Gaussian observation log likelihood, signed-log arithmetic and emission-system solve; no upstream framework is imported.

main.reconstruct(path=None) executes all63traces with the fixed reference configuration and returns all five batch-first output arrays. python -m src.main writes output/reconstruction.npz. Intermediate numerical warnings from log(0) encode exact zero-probability terms as negative infinity and are distinct from invalid saved outputs. No plotting backend is modified by library imports. The standalone Judge imports NumPy only, anchors references/config to its own location, validates all keys/shapes/dtypes/finite and physical contracts, and scores every declared unknown with truth precedence if a valid ground_truth file exists.

## Numerical helper interfaces

physics_model.ms2_loading_coeff(kappa,W) returns a float64(1,W)response, explicitly restricted to0<kappa<2,W>=2 because the selected original axis-index implementation is not a general ramp generator. get_adjusted(state,K,W,ms2_coeff) returns(ONweight,OFFweight) in dimensionless response units, summing bits newest first. calcObservationLikelihood(lambda_logF,noise_tempF,dataF,veef,INPUT_STATE,K,W,ms2_coeff_flipped) evaluates the Gaussian log density with scalar observation,2by1loadings, log precision lambda and positive noise SD. compute_dynamic_F(state,length,W,K,ms2_coeff_flipped,count_reduction_manual) returns two read-only(1,length)log basis arrays ordered OFF then ON; corrected basis no longer uses early count_reduction_manual subtraction. Internal bounded memoization returns exact deterministic operator arrays, not inferred data.

logsumexp_numba(X) retains the original direct exponential sum despite its historical function name; no Numba dependency remains. log_sum_exp(arr,signs) returns(logabs sum,sign sum). v_log_solve(m_lg,m_sgn,b_lg,b_sgn) takes2by2log magnitudes/signs and length2right-hand side log magnitudes/signs, and returns(2,2): first row is solution log magnitudes, second row the original sign diagnostic. Only first row is consumed by the selected positive-emission inference; the sign diagnostic is not a validated general signed-system solver. The original determinant routine reports sign(logabsdet) rather than determinant sign; this unused sign-row defect is preserved and explicitly not used as an inferred physical sign. The bound positive normal equation is independently checked against an ordinary linear solve.

forward_backward(pi0_log,lambda_log,data,noise_temp,v,K,W,ms2_coeff_flipped,states_container,off_off,off_on,on_off,on_on,PERMITTED_MEMORY,trace_length,log_likelihoods,logL_tot,baum_welch,i_tr) accepts(2,1)initial log probabilities, scalar log precision/noise, data(1,L), loading(2,1), four transition logs and a fresh list for the retained graph. It returns a dictionary of per-frame state-to-log-posterior maps and four expected-transition log-statistic collections. It mutates its supplied likelihood work arrays/list as in the reference. Solvers.v_m_function is a retained original optional helper, not called by the shipped main/EM path; its numerical role is redundant explicit emission-statistic accumulation. None of these functions performs file I/O.
