# Shipped interfaces and actual data flow

`python -m src.main` calls `src.main.run(task_dir=None)`. With no argument the task root is resolved from the source file; an explicit task_dir accepts a pathlike workspace. It loads raw inputs through `load_observations(path)`, invokes `reconstruct`, creates output/ if necessary, writes exactly three arrays to output/reconstruction.npz and returns the dictionary. It does not import plotting, change a notebook backend, read hidden assets or produce metric reports. There is no wrapper entry point outside src.

`src.preprocessing.load_observations(path)` uses NPZ allow_pickle=False, checks exactly intensities and angles, exact shapes `(1,32,23,26)` and `(1,32)`, uint16/float64 and finite calibration. It returns these two arrays without normalization. Public images encode ADU and angles radians.

`src.physics_model.optical_constants(angles,n_buffer=1.33,oxide_nm=1924.9,wavelength_nm=642.0,n_oxide=1.4719,n_silicon=3.8660+0.017933j)` flattens angles and returns real float64 `(32,3)` columns Re(r),Im(r),phase/nm. Keyword overrides exist only for explicit notebook calibration-sensitivity experiments. `forward(constants,parameters)` maps `(32,3)` and `(3,)` A/B/H to `(32,)` predictedADU. `jacobian` has the same inputs and returns `(32,3)` derivatives. `predict_stack(result,angles,**optics)` evaluates every output pixel and returns `(1,32,23,26)` float64; it neither fits nor accesses references.

`src.solvers.fit_pixel(constants,signal,initial=INITIAL,max_iter=1000)` returns `(parameters,iteration_count,converged,sse)` using explicit bounded LM. INITIAL=[.5,1,75] and fixed LOWER/UPPER define the source benchmark. Inputs have shapes `(32,3)`, `(32,)`, `(3,)`; invalid initial bounds raise ValueError. `reconstruct(observations,angles,initial=INITIAL,return_diagnostics=False,**optics)` requires one batch and matching number of angles. Standard output dictionary contains reconstruction/amplitude/background `(1,row,column)` float64. With return_diagnostics=True it instead returns `(dictionary,diagnostics)` where diagnostics has per-pixel iterations(int64),converged(bool),sse(float64), all `(1,row,column)`. This helper has no file side effect. Every pixel is processed, including dim/background pixels.

`src.visualization.metrics(estimate,reference)` implements standard real cosine NCC and dynamic-range NRMSE, rejecting constant reference. `panel(images,titles,units,columns=3,cmap='viridis',shared=False)` imports pyplot only when called, creates and returns a Matplotlib figure, preserves row-down camera coordinates and attaches unit-labelled colourbars. Shared=True fixes the common full-data colour range. Neither function writes files or changes backend.

The active notebook resolves its own task root from execution cwd, imports only local cleaned modules, loads public data, computes all598fresh fits and diagnostics, and separately reads `notebooks/reference_outputs/upstream.npz` for labelled source-method comparisons. Its additional calibration, noise and initialization reconstructions are actual calls to the same local inverse. It creates actual plots and fresh metrics, writes output/reconstruction.npz and runs the standalone Judge. Optional maintainer figure export uses an explicitly external path from environment, not extra task-level report folders. The conclusion distinguishes measured intensity, conditional height and absent independent GT.

`evaluation/judge.py --prediction PATH --report PATH` runs independently of src. The reference and metrics paths are relative to its own file; public data needed for consistency is read at task/data/raw_data.npz. CLI prediction/report resolve relative to caller cwd. Exact keys/shapes/float64/finite values are validated before any scoring. Malformed input/evaluator failure yields empty metrics,status error,exit2; valid below-threshold output yields fail/exit1; every metric passing yields pass/exit0. Report parent directories are created; report-write error produces stderr andexit2. The evaluator never imports submitted code and evaluates all three fields plus forward RMS without alignment/rescaling.

`test/fixtures/upstream.npz` contains the full independently frozen Julia outputs, public input copies and probe forward/Jacobian values; `test/comparing_test/test_upstream.py` consumes it for operator and full-pipeline comparisons. It is not generated by cleaned code. `evaluation/baseline_reference.npz` contains the original A/B/H fields. `notebooks/reference_outputs/upstream.npz` additionally includes original prediction and conditional standard errors for review. No ground_truth.npz is invented. Test, Judge and figure metrics have independent known-value tests. Private complete source checkout, TIFF, Julia environment, capture scripts/logs and oracle CSVs live outside this task and are indexed in test/validation.md. No src/generate_data.py is shipped because no new synthetic acquisition is bundled.
