# Implemented joint spectral inverse

The method is the complete published self-consistent SELCON3 pipeline as implemented by SSCalcPy, not a least-squares substitute. Public A is the24independent calibration spectra, F their4fractions, and Q the4target spectra. All four target columns and annotations were excluded before original execution. Source text is loaded float32 as in the original loader. The full267bins preserve66CD wavelengths240to175nm followed by201IR wavenumbers1600to1800cm^-1. Joint analysis retains IR1600to1720step2 and multiplies its61values by15 in float32; the selected127-bin spectra equal the source reduced file exactly. The multiplier is an algorithmic block weight, not an acquisition constant. CD-only uses the66CD bins and IR-only uses all201IR bins from the same public observations.

The physical interpretation is q≈Bf,A≈BF, where q is a target spectrum, f its4fractions, B an unknown effective structural basis and A,F paired independent calibration spectra/fractions. The subspace representation q≈Ac,f≈Fc supplies an empirical inverse, with signed coefficients c. It does not recover unique atomic coordinates or claim dry-film and solution structures identical. CD uses differential molar extinction per residue; IR is baseline-corrected and maximum-normalized absorbance. Fractions are dimensionless, not percent.

For each query q, compute full SVD A=USV^T with NumPy's full_matrices=True. S is a float64 rectangular matrix populated by the returned singular values; U,V inherit the original input dtype. HJ5 is F V[:,0:5] pinv(S[0:5,0:5]) U[:,0:5]^T q, preserving multiplication grouping and NumPy pinv defaults. The initial HJ5 SVD operates on float32 input. Sort calibration spectra by unweighted spectral RMSD sqrt(mean((q-Acolumn)^2)); default argsort determines ties. Original sorting allocates float64 A and F. Augment A with q in column0 and F with the closest calibration fraction as its initial unknown column. This does not insert target truth.

SELCON1: for every prefix length n=3…25 and every rank r=1…min(7,n), compute f(n,r)=Fprefix V_r pinv(S_r) U_r^T q. Accept if abs(1-sum(f))<=.05 and min(f)>=−.025. For each n retain the candidate with the smallest sum error; ties select the later rank. Preserve the original zero-based best_basis>0 convention: a rank-one winner is not retained. If no valid candidate exists, decrease lower bound by.005 and increase sum tolerance by.01 until a candidate exists. The local function raises a descriptive error for the upstream degenerate valid-rank-one-only case rather than propagating NaNs; no bound datum takes this exceptional branch. Average selected candidates to obtain sel1 and replace Fcolumn0. Stop if RMSD(oldguess,sel1)<.0025 or after50updates. This is a self-consistency criterion, not a gradient optimization objective. No step size, line search, generic optimizer, extra regularizer or post-hoc normalization is used.

SELCON2: for each retained (n,r), reconstruct the query as column0 of U_r S_r V_r^T from the augmented spectral prefix. Retain those with spectral RMSD<=.25 (joint and CD-only) or.025(IR-only); if none pass increase this threshold by.01 until nonempty. Average retained fractions to obtain sel2. These adaptive thresholds are published algorithm rules, not evaluation-threshold relaxation. Bound comparisons use their original defaults without relaxation.

SELCON3: use HJ5 helix fraction h to select SELCON2 candidates by helix content. If h>.65 retain helix>.65. If .25<=h<=.65 select within±.03 of(h+maximum retained helix)/2. If .15<=h<.25 use the mean helix instead of maximum; if h<.15 use the minimum. If no SELCON3 candidate remains, the original method falls back to SELCON2; record the fallback flag. Compute the mean fractions and population standard deviation(ddof0) across retained solutions. These spreads describe solution-selection variability, not calibrated posterior uncertainty. Refit every retained prefix/rank and average their query spectra. Unscale the IR block before output. Do not clip small negative fractions or force their sum to1.

Both original and local runs execute all28comparisons: four targets, weights0/1/5/10/15/20 plus IR-only. Default is15. Default iteration counts2,3,5,6 and original reference arrays freeze HJ5, sorting, SELCON1/2/3, selected prefix/rank pairs, refit thresholds and spectra. Deterministic stage tolerance is rtol=atol1e-9 fixed before extraction; observed differences0. Judge requires maximum fraction error1e-6, CD-refit RMS1e-6, unscaledIR-refit RMS1e-7, fraction sum deviation<=.06, minimum>=−.025. These nonzero numerical tolerances follow repeatable original runs; no actual truth is invented.

Independent checks verify known spectral mixtures, SVD reconstruction, projector symmetry/idempotence, helix selection and metric examples. Atomic/crystal fractions of the withheld proteins are only a private independent structural proxy in notebook comparisons: the spectral samples are measured under different conditions. No claim of physical accuracy follows just from original parity or a good refit. Missing raw instrument settings are disclosed; only normalized processed spectra are bound.
