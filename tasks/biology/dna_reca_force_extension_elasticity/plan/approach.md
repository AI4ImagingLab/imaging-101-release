# Actual selected mathematics and numerical flow

The selected model is extensible Marko–Siggia WLC, not the initially investigated Odijk approximation. README defines F,d,Lp,Lc,S,kT and the full implicit force relation. All native observations are retained. The public selection Fobserved≤30pN is evaluated once, producing884/1030samples. Extension is independent variable, force dependent; there is no unit conversion hidden in the ratio d/Lc and kT/(F*Lp). Fixed kT=4.11pN nm follows source convention despite26°C calibration metadata. No target-derived calibration or random generator is used.

For explicit inversion, multiplying the relation by4(1−d/Lc+F/S)^2and collecting powers yields F^3+aF^2+bF+c=0. physics_model.ewlc_marko_siggia_force computes the coefficient expressions directly and calc_cubic_root evaluates the same depressed-cubic branch as upstream: p=b−a²/3,q=2a³/27−ab/3+c,discriminant=q²/4+p³/27. Use real cube roots when discriminant≥0; otherwise use the selected trigonometric root2and subtract a/3. The physical branch is independently checked against the unsquared implicit equation, zero extension and positive stiffness. Analytic coefficient/root derivatives retain upstream near-degeneracy floor1e-5in intermediate derivative denominators. These are numerical conventions, not new physics.

Parameters are p=(Lp,Lc_control,S,Lc_RecA). Minimize half the unweighted sum of(measured force−predicted force)^2over both complete selected curves. No regularizer or prior. Initial point(50,2.7,1500,3),lower(39,.00034,1,.00034),upper(80,infinity,infinity,infinity),fixed kT4.11. Use scipy least_squares TRF,analytic Jacobian,ftol=xtol=gtol1e-8,default x_scale1,linear loss,default max_nfev100times4. Author’s free-column Jacobian selection is Fortran contiguous; the local joint Jacobian explicitly retains this arithmetic/LAPACK convention. Without it, identical numeric input arrays at the initial point led to small optimizer endpoint changes; the actual controlled diagnostic is archived rather than attributed vaguely to the environment. No parity tolerance was loosened.
