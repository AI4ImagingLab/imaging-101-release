# Shipped interfaces and execution flow

All source modules depend only on NumPy except visualization, which additionally imports Matplotlib and the standard library. No source module reads a hidden reference or upstream code. The final runtime accepts `README.md`, `data/raw_data.npz` and requirements; none of the maintainer modules is a solver input.

`src.preprocessing.load_observations(path: str | Path='data/raw_data.npz') -> ndarray` opens NPZ with allow_pickle=False, reads intensity, requires shape (1,116,298,298) and uint16, and returns ADU without altering pixels. `RAW_SHAPE`, `POLARIZER_ORDER` and `OFFSET_ADU` match README. `split_channels(raw: ndarray, offset: float=0.0) -> ndarray` accepts arbitrary leading axes and even final row/column axes, casts to float64 before subtracting the scalar ADU offset, rejects nonfinite values, and returns (...,4,H/2,W/2) in analyzer order 0,45,90,135. It never crops odd input dimensions.

`src.physics_model.analyzer_matrix() -> ndarray` returns the float64 four-by-three dimensionless analyzer matrix. `forward(stokes: ndarray) -> ndarray` maps (...,3,H,W) Stokes ADU to (...,4,H,W) analyzer ADU. `adjoint(channels: ndarray) -> ndarray` returns the corresponding real transpose, not the inverse. `polarization(stokes: ndarray) -> tuple[ndarray,ndarray]` removes the component axis and returns angle in radians and dimensionless degree, handling isotropic/zero cases as described in approach. `relative_residual(channels: ndarray, stokes: ndarray) -> float` returns a dimensionless Frobenius ratio; the all-zero case returns 0. No physical constraints are imposed by these primitive operators.

`src.solvers.estimate_stokes(channels: ndarray) -> ndarray` directly evaluates the exact float64 least-squares inverse, changing the component axis from four to three. `reconstruct(raw: ndarray, offset: float=0.0) -> dict[str,ndarray]` calls split_channels, estimate_stokes and polarization, returning reconstruction, orientation and degree; it has no file effects. Canonical input leads to reconstruction (1,116,3,149,149) and the two derived maps (1,116,149,149), all float64.

`src.main.run(input_path: str | Path='data/raw_data.npz', output_path: str | Path='output/reconstruction.npz') -> dict[str,ndarray]` loads public data and calls reconstruct, creates the output parent directory and writes the three keys into one compressed NPZ. Both paths are relative to the caller unless absolute. CLI `python -m src.main` uses those defaults; optional --input and --output override them. Importing src.main does not load Matplotlib or change its backend.

`src.visualization.make_figures(raw, result, upstream) -> tuple[list,dict,dict]` builds five Matplotlib figures, exact numeric source arrays and a numeric metric dictionary. All argument arrays are already loaded by its caller. It actively computes the comparison/sensitivity arrays from the public observations. It neither loads references itself nor saves files. `export_figures(figures, numeric, metrics, directory)` writes PNG, SVG, PDF, numeric_sources.npz, metrics.json and hash_manifest.json to a caller-selected directory. It creates that directory; library imports never select a Matplotlib backend. The active notebook calls run, standalone Judge, make_figures and inline display; a private maintainer runner additionally calls export_figures. The standard CLI deliberately does not generate plots.

`evaluation/judge.py` is standalone and imports no src code. `evaluate(prediction: str | Path) -> tuple[dict,int]` validates every required key, exact shape, real float64 dtype and finiteness, then validates hidden reference arrays, prefers ground_truth.npz if present and otherwise baseline_reference.npz, loads metrics relative to its own file, independently recomputes every metric and its raw observation-consistency operator. Canonical reference is an upstream baseline, with no truth file. CLI requires --prediction and --report. Prediction/report paths are caller-relative; reference paths are Judge-relative. A valid pass/fail returns 0/1; malformed input, invalid hidden assets and report write failure return 2. UTF-8 JSON has status, passed, metrics, thresholds and errors. Error reports have empty metrics.

`test/unit_test/` covers local operators and Judge metric/CLI behavior. `test/comparing_test/` consumes frozen source-stage fixture and full hidden upstream baseline, never importing the oracle. `test/fixtures/upstream_stages.npz` contains three original planes restricted to an upper-left 12x14 detector region and corresponding stage arrays; consumers and hashes are recorded in validation. No standalone duplicated full upstream NPZ is retained in notebook references: its full-baseline consumer is the notebook and pipeline parity test. `notebooks/reference_outputs/measurements.json` identifies upstream and fresh measurement records, without duplicating full arrays.
