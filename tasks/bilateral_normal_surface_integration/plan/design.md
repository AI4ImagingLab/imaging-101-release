# Actual shipped modules and caller flow

Cleaned execution uses standard library, NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1, CPU float64. PyVista and OpenCV are limited to the private original capture/decoding role; no domain solver or rendering package is imported by this task. Existing normal observations are reused, so no generate_data.py is needed.

- `preprocessing.load_data(path='data/raw_data.npz')`: validates exact batch-first array shapes/dtypes, finite normal values and nonempty masks; returns `{'vase':(normal,mask),'tent':(normal,mask)}` with unbatched float64(H,W,3) and bool(H,W) copies. No smoothing, unit renormalization or file output.
- `physics_model.move_left/right/up/down(mask)`: zero-filled bool shifts for neighbor identification; no image wrap.
- `physics_model.derivative_matrices(mask,nz_horizontal,nz_vertical,step_size=1)`: accepts bool(H,W), compact float64(n,) z-normal components and positive scalar pitch. Returns right,left,up,down CSR(n,n) matrices. Matrix entries have inverse-height-unit factors. Missing-neighbor rows are zero.
- `physics_model.system(normal,mask,step_size=1)`: maps declared RGB conventions, returns A(4n,n), b(4n,), and the four matrices. No side effects.
- `physics_model.weights(depth,operators,k)`: compact depth(n,) and four matrices -> stacked w(4n,), horizontal(n,), vertical(n,). Gradient contrasts are squared after multiplication by normal components; complementary pairs sum1.
- `solvers.integrate(normal,mask,k=2.,step_size=1.,max_iter=100,tol=1e-4,cg_max_iter=5000,cg_tol=1e-3)`: returns `(height,diagnostics)`. Height is float64(H,W), zero-mean in mask and zero outside, in pitch units. Diagnostics: `energy` float64(iterations,), `horizontal_weights`/`vertical_weights` float64(H,W), iteration count, `cg_info` int(iterations,), original pre-gauge scalar mean and weighted-residual RMS sqrt(E/(2n)). It raises on failed inner CG and on zero allowed outer iterations.
- `solvers.reconstruct(data)`: executes integrate with k4 for vase and k1 for tent, both full native grids. Returns output dict with reconstruction(1,168,168) and tent_reconstruction(1,128,128), plus dict of each field's diagnostics. No file side effect.
- `main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')`: loads, reconstructs, creates output parent, writes the one NPZ, returns output/diagnostics. `python -m src.main` invokes it and prints actual iteration counts. Import does not choose a plotting backend.
- `visualization.quality(height,reference)`: returns NCC and dynamic-range NRMSE, independently checked against Judge's metric cases. `experiments(data,fresh)`: actually computes all noncanonical variants, returns dict of height maps, sharpness table and CG table. Each numeric row stores field(0=vase,1=tent), parameter value, NCC, NRMSE, weighted residual RMS, iterations and measured seconds. Canonical sharpness rows reuse the current fresh result; no archived result is substituted.
- `visualization.figures(data,fresh,upstream,variants,rows,sensitivity)`: returns four named Matplotlib Figure objects. The caller provides upstream keys vase/tent_depth and vase/tent_energy from identified independent arrays. It creates no files, displays nothing and does not select a backend. Surface rendering strides2 only for plotting, not reconstruction or metric evaluation.

CLI flow is public NPZ -> load/validate -> explicit derivatives -> Jacobi-CG/bilateral iteration -> gauge -> output NPZ. The maintainer notebook repeats that active path, independently invokes Judge, loads frozen original comparisons, computes the full experiment suite, explicitly displays each figure once and closes it. `IMAGING_REPORT_DIR`, when supplied, exports PNG/SVG/PDF and full-precision numeric sources to a maintainer-selected directory. No private path is hardcoded into the notebook.

`evaluation/judge.py` imports no solver. `evaluate(prediction,asset_dir=ASSETS)` returns report/exit; paths to hidden metrics and truth/reference resolve from the Judge file. Actual truth would take precedence if present; the bound task has no truth. Prediction/report CLI paths are caller-relative. It checks both exact shapes, float64, finite arrays and valid nondegenerate references before scoring, emits strict UTF-8 JSON with status/passed/metrics/thresholds/errors, and uses0/1/2 for pass/quality-fail/input-or-evaluator-error. Report-write error returns2 with stderr. Missing or invalid input never runs a solver or emits partial metrics.

Only test/ houses unit, physics, metric/Judge, original-stage and pipeline tests. Frozen original encoded normals, sparse operators and inverse traces are read by comparing tests, not by the solver. Original full source/PDF/downloads/capture scripts/logs and raw PNGs are privately archived; `test/validation.md` identifies revisions, hashes, consumers and evidence. GPL notices remain in LICENSE and extracted source. There are no cross-task imports, duplicated entry wrappers or unused capture scripts in the task package.
