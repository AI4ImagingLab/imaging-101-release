# Shipped interfaces and data flow

All modules import only standard library, NumPy, SciPy and Matplotlib; there is no ObsPy/rf runtime requirement. CPU execution is the validated path. `src/__init__.py` has no import side effects. No library selects a Matplotlib backend, and importing `src.main` does not import plotting code.

## Runtime

`python -m src.main` calls `main()`. It calls `reconstruct(data_path='data/raw_data.npz')`, which returns a new real float64 (1,2,4801) R/T array. The function calls `load_data`, `preprocess`, `rotate_zne`, then `waterlevel`. `main()` creates `output/` if needed and overwrites only `output/reconstruction.npz`, key `reconstruction`. Paths default relative to caller working directory. There is no reference, fixture, checkpoint, notebook, other task or original source import.

`preprocessing.load_data(path='data/raw_data.npz')` opens NPZ with pickle disabled, requires finite float64 waveforms (1,3,4801), and returns an independent (3,4801) copy in m/s, ordered ZNE. Constants SAMPLING_RATE=20.0 Hz and BACK_AZIMUTH=33.06338963947741 degrees match README. `preprocess(waveforms,low=.05,high=1.0)` accepts a real (3,N) array, promotes to float64, performs linear detrend,5%-per-side Hann taper, causal fourth-order Butterworth bandpass, and returns a new array of equal shape/velocity units. It does not mutate inputs.

`physics_model.rotate_zne(waveforms,back_azimuth=BACK_AZIMUTH)` returns new ZRT(3,N) velocities. `filters(nfft,gauss=.5,shift=30.)` returns (complex128 filter(nfft),float64 signed frequencies(nfft)) using the20Hz benchmark rate. `convolve(source,response,nfft=None)` and `adjoint(source,residual,nfft=None)` return real circular FFT convolution/adjoint vectors on the selectedFFT grid; default fftpack next-fast length of source. They are verification/helper operators, not calls in standard reconstruction. `reconvolution(zrt,receiver,norm,gauss=.5)` accepts (3,N),(2,N),scalar source normalization, and returns predicted/observed Gaussian-smoothed R/T velocities (2,N), preserving full trace. It uses fixed native sampling and30s delay, so it is a native-record diagnostic, not a general arbitrary-rate API.

`solvers.waterlevel(zrt,waterlevel=.05,gauss=.5,shift=30.)` returns `(rf,diagnostics)`. rf is float64(3,N), source-self,R,T, common normalized amplitude. Diagnostics maps norm→float, power→stabilized float64(L), source_conj→complex128(L), filter→complex128(L), freq→float64(L). FFT length is from fftpack's5-smooth rule. `time_domain(zrt,spiking=.1,shift=30.)` returns common-normalized float64(3,N). `_cross(a,b,n,shift=0)` is its private full-lag correlation/padding helper. `iterative(zrt,gauss=.5,shift=30.,itmax=400,minderr=.001)` returns `(float64(3,N),diagnostics)`; diagnostics contains integer iteration counts and per-component lists of normalized residual squared error. These comparison methods have no filesystem side effects.

## Review notebook and visuals

The canonical notebook resolves the task root from its own working directory, loads the one public acquisition, actively calls standard reconstruction, and recomputes time-domain, iterative, water-level/bandwidth/reduced-sampling experiments from local equations. It loads hidden independent original arrays only for parity and explicitly labels those original measurements. All reported fresh metrics are computed from the new arrays. Original comparison values are independent frozen outputs, not substituted fresh methods.

`visualization.metrics(estimate,reference)` returns a dict with numeric ncc,nrmse using standard definitions on flattened nondegenerate arrays. Tests cover its definitions against known independent cases and Judge. `make_figures(raw,zrt,methods,sweep,norm)` returns a dict of three Matplotlib Figures: observations, receiver_comparisons, forward_consistency. It does not save files or change backend. `methods` maps method labels to (2,N) arrays; `sweep` maps scalar waterlevels to (2,N) arrays. Plot lag display−15..90s is explicitly a view of full arrays, not evaluation cropping. Forward plots show the whole acquisition.

Notebook produces active inline figures and numeric tables, with explicit display and close to avoid duplicate automatic figures. A private export runner stores final PNG/SVG/PDF and exact numeric trace outside the task. Runtime output directory contains only reconstruction.npz and judge_report.json. Fixtures are loaded only by test/comparing_test; independent original measurements JSON is read by the review notebook. No synthetic data generator is shipped because actual observations are reused.

## Independent evaluator

`evaluation/judge.py` imports no solver. `load(path)` strictly validates NPZ key/shape/real32-or64 dtype/finite values. `score(prediction,reference)` implements standard metrics; zero estimates get NCC0. `evaluate(prediction)` returns report dict and exit0/1/2. Hidden paths resolve relative to the Judge itself; caller prediction/report paths keep caller semantics. Ground truth takes precedence if available; current package contains only a valid original-method baseline. Degenerate references and missing/invalid assets produce evaluator errors. `main()` writes finite UTF-8 JSON, creates parent directories, and handles report-write failures with stderr plus exit2. Each R/T metric must meet its threshold. Contract tests cover foreign cwd, missing arrays/files, integer/complex/nonfinite/wrong shapes, poor quality, truth priority, invalid thresholds, missing evaluator assets and report-write failure.
