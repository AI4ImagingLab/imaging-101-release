# Shipped interfaces and execution flow

`preprocessing.load_data(path)` loads uint8 batch-first hologram and empty_hologram with allow_pickle=False and returns copied(200,210) ADU arrays. `padded_spectrum(image,padding=2)` converts to float64, subtracts its mean, places the complete region at the top left of512×512 zeros, and returns a centered complex128 spectrum.

`physics_model.intensity(object_wave,reference_wave)` evaluates |O+R|². `sideband_peak(spectrum)` returns observed carrier(fy,fx) in cycles/pixel after excluding central/lower bands. `aperture(shape,carrier,size_fraction=.5,kind='smooth disk')` returns a float64 window; optional kind='disk' is a diagnostic helper. `recover_field(spectrum,window,carrier,shape)` returns the native complex128 field and full filtered spectrum. `unwrap_axis(phase,axis)` implements explicit cumulative neighboring-phase corrections; `unwrap_for_review(phase)` applies columns then rows. Unwrapping is review-only.

`solvers.reconstruct(data,size_fraction=.5,kind='smooth disk')` returns(outputs,stages). Outputs contains reconstruction complex128(1,200,210), dimensionless relative field. Stages contains object_field/background_field complex128(200,210), fft_origin/fft_filtered complex128(512,512), window float64(512,512), carrier tuple, and phase_difference/unwrapped float64(200,210). The empty observation always uses the exact cell-selected carrier and aperture. No qpretrieve, skimage or other domain solver is imported by cleaned code.

`main.main()` resolves task root, reads raw data, runs the nominal inverse and writes output/reconstruction.npz. It does not import plotting or alter a backend. `visualization.run_experiments(data,upstream)` actively computes nominal plus five aperture settings. `make_figures(data,e)` returns three figure groups retaining the original example observation/spectrum/phase/unwrap comparisons, augmented with relative amplitude and sensitivity. `export(figures,e,directory)` explicitly writes private PNG/SVG/PDF and numeric NPZ/JSON.

The notebook actively reconstructs the measured inputs and compares independently saved upstream.npz. test/fixtures/oracle_stages.npz supplies original object/empty fields, spectra, phase difference and reliability-based unwrap; every array has a parity-test consumer. evaluation/baseline_reference.npz contains a standard-method relative complex field, not a cell refractive-index truth. The independent Judge validates exact complex128 shape and finite values, scores all pixels with no phase fitting, and emits0/1/2 status codes. Tests cover malformed/overflow inputs, zero-field quality failure, evaluator errors, report-write failure and foreign-cwd operation, as well as analytic interference, conjugate sideband selection, unity relative transmission and known continuous-phase unwrapping.
