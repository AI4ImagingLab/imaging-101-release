# Shipped interfaces and execution flow

The standard invocation is `python -m src.main` from the task directory. It reads only `data/raw_data.npz`, computes the full19-frame native reconstruction and writes `output/reconstruction.npz`. Source, references, plans, tests and this review notebook are maintainer-only. No source checkout, upstream package, fixture, target, saved polynomial operator or checkpoint is read by the runtime. Existing author observations are reused; no synthetic-data generator is shipped.

## Preprocessing module

- `load_observations(path=None) -> ndarray`: defaults to task-local `data/raw_data.npz`, regardless of caller cwd. Loads with `allow_pickle=False`, requires exactly the public key `observations`, shape(1,19,1080,1920,3), dtype uint8. Returns(19,1080,1920,3) in frame,row,column,BGR order, digital-number units. Performs no new image decoding, filtering, registration or normalization.
- `fused_multiply_add(a,b,c) -> ndarray`: broadcasts binary32 operands through binary64 products/sums and one binary32 cast. Products are exact in binary64; sums need not be. A rare double-rounding tie can differ by one binary32 ULP from true CUDA FMA, demonstrated by an exact-rational independent test. This is an approximation validated on actual source stages and the complete native reconstruction under predeclared tolerance, not a universal bit-identity guarantee. It is general scalar arithmetic, not a domain reconstruction API, used for coefficient and box-filter accumulation.
- `modified_laplacian(observations) -> ndarray`: accepts uint8(F,H,W,3); rejects other dtype/shape conventions. Returns binary32(F,H,W), sum of absolute second differences in normalized digital intensity per unit-pixel squared. Uses BGR order, binary32 reciprocal1/255 and replicate boundaries. Does not subtract a mean or estimate an optical PSF.
- `box_replicate_cuda(image,width) -> ndarray`: accepts a two-dimensional binary32 image and odd positive box width used here as15or21; returns same shape/dtype. Explicit column-first then row-tap convolution with replicate boundary preserves the source shared-memory kernel's accumulation order, with the approximate FMA caveat above. It does not use a separable surrogate for the main initializer.
- `initial_focal_coordinate(sharpness,index_offset=1) -> ndarray`: accepts binary32(F,H,W) unnormalized MLAP. Smooths each frame15×15, selects the first strict maximum, smooths indices21×21 and maps20((mean_index−index_offset)/(F−1)−1/2). Returns binary32(H,W) relative focal coordinates. The default retains the explicitly documented source index discrepancy and can initially fall below−10. `index_offset=0` is an optional named diagnostic; it is not the selected runtime's initialization. The iterative output is clipped separately.
- `lu_inverse_float32(matrix) -> ndarray`: copies a small square matrix, performs partial-pivoted binary32 Gaussian elimination with identity right-hand-side and scalar back substitution, returns binary32 inverse. Rejects a pivot below10times binary32 epsilon. Its order follows the source's generic OpenCV LU implementation, with legal attribution in NOTICE. No OpenCV import or domain solver exists locally.
- `polynomial_operator(frames=19,degree=8) -> (X,P)`: returns binary32 arrays(frames,degree+1) and(degree+1,frames). Nodes are20(k/(F−1)−1/2). Builds descending powers and the source normal equations explicitly. General matrix products accumulate in binary64 before binary32 serialization; small LU remains binary32. No file access, hardcoded captured inverse or physical calibration is used.
- `fit_focus_polynomials(sharpness,degree=8,denominator_regularizer=.3) -> (coefficients,derivative)`: input binary32(F,H,W). Normalizes by reciprocal of per-pixel maximum+.3, computes frame-order FMA coefficient sums. Returns binary32(degree+1,H,W) positive contrast coefficients and binary32(degree,H,W) **negative** derivative coefficients, both descending powers. The scalar .3 is a fixed numerical parameter, not read from README or interpreted as measured noise.

## Physics and finite-grid model

- `gradient(u) -> (x,y)`: same-shaped two-dimensional real arrays, forward unit-pixel differences with zero last-column/last-row component. Returns differences in relative focal coordinate per pixel, preserving input dtype.
- `adjoint(x,y) -> ndarray`: equal-shaped gradient components to the exact Euclidean transpose of `gradient`, ignoring unused terminal entries. It works even for arbitrary terminal inputs; the source's negative backward-zero implementation is equivalent on the actual split/dual subspace. No hidden boundary crop is used.
- `neumann_eigenvalues(shape,dtype=np.float64) -> ndarray`: shape is(H,W); returns4sin²(pi p/(2H))+4sin²(pi q/(2W)), cast to requested float dtype. Eigenvalues are dimensionless for the unit-pixel difference convention. The standard iterative path requests binary32; independent analytic tests use binary64.
- `solve_neumann(rhs,penalty,eigenvalues=None) -> ndarray`: computes the explicit spectral inverse of I+penalty K-transpose K. Uses general SciPy orthonormal DCT-II/inverse, workers1. If no eigenvalues supplied, derives them for rhs shape/dtype. Returns same-shaped transform result, without clipping or file access. A supplied eigenvalue array is computed once by the solver, not loaded from a reference.
- `polynomial_value(coefficients,x) -> ndarray`: descending coefficients(d+1,H,W), coordinate field(H,W). Uses add-before-multiply Horner order, preserving x dtype. This is a local contrast surrogate, not an assertion of a calibrated optical blur operator.
- `objective(coefficients,u,data_fidelity=6.) -> dict`: converts to binary64 for identified reporting, computes negative contrast sum, isotropic TV sum and their weighted objective. Keys are `negative_contrast`, `tv`, `objective`. The reporting sum is unnormalized over the full grid; it neither modifies the inverse nor fits gains.

## Selected inverse and independent comparisons

- `shrink(x,y,threshold) -> (gx,gy)`: explicit pointwise isotropic vector soft threshold; zero vector remains zero. Inputs have equal two-dimensional shape. Returns same-shaped arrays with input numerical dtype, without a generic optimizer or proximal-library call.
- `linearized_admm(derivative,initial,iterations=400,data_fidelity=6.,descent_step=None,penalty=1.,capture_steps=(1,2,10,100,400),callback=None) -> (u,snapshots)`: negative-contrast derivative coefficients(d,H,W), initial field(H,W). State is copied to binary32. `descent_step=None` gives binary32(8/data_fidelity). Each iteration explicitly evaluates the data derivative, original backward-zero split divergence on its valid subspace, Neumann inverse, clipping to[−10,10], spatial forward differences, vector shrink and scaled-dual update. All these operations are in local source. Penalty growth/scaled-dual rescaling follows the source after zero-based iteration>0. Returns binary32(H,W), plus a dictionary of actually captured iteration states. At each requested completed step, keys `u,gx,gy,bx,by,ux,uy` contain full native arrays **before** the subsequent optional penalty/dual rescaling. Optional callback receives(completed_step,u) after that bookkeeping; it is for logging/measurement and returns nothing used by the solve. No convergence tolerance is imposed or inferred.
- `reconstruct(observations,iterations=400,data_fidelity=6.,index_offset=1,callback=None) -> (u,details)`: calls MLAP, local polynomial fit, original-convention initializer and the complete local inverse. Input(F,H,W,3) uint8; standard caller supplies all19 native frames. Details contain `initial`(H,W), `coefficients`(9,H,W), `derivative`(8,H,W), `steps`(actual captured dictionaries), `sharpness`(19,H,W) and `objective`(numeric report dictionary). All arrays are fresh. It reads no files and writes none.
- `classical_focus(sharpness,window=9,median_width=1) -> ndarray`: fresh independent comparison from all19 sharpness frames. Uses a general separable replicate box, first maximum and unshifted relative-coordinate mapping, then optional replicate median filter. Source tap-by-tap initializer parity is not claimed for these distinct classical estimators. Returns binary32(H,W). Notebook groups use window1,9,41/median11,and21/median5.
- `tv_denoise_only(observation,weight,iterations=250) -> ndarray`: explicit Chambolle–Pock/ROF comparison minimizing .5||u−z||²+weightTV(u), with constant z equal to the already estimated classical map. Initializes u=z, dual zero, tau=sigma=.35, extrapolation1. Each iteration applies a dual Euclidean-ball projection and quadratic primal proximal step. Product tau*sigma*||K||²≤.98<1. Returns binary32(H,W), no reference reads. Fixed250steps do not claim an exact optimum. Notebook weights are6and26in this relative-coordinate scale.

## Standard main, measurements and evaluation

`main.main()` parses optional `--diagnostics PATH`, loads native observations, calls the complete standard inverse, creates task-local output directory, writes the single batch-first `reconstruction` key and prints actual runtime/400steps/conditional objective. Default output is `output/reconstruction.npz`, binary32(1,1080,1920), relative focal-coordinate units. Optional diagnostics is write-only and never resumes an inverse.

`main.save_stage_measurements(details,path)` serializes fresh stage measurements at nine fixed pixel coordinates, including four actual grid corners. It saves focus, polynomial, initializer and the captured iteration arrays for independent comparison tests. These measurements are not an operator, target, initializer or solver input. Their consumer is `test/comparing_test/test_complete_execution.py`; their provenance is the actual timed CLI run in validation. No library module mutates the Matplotlib backend; importing `src.main` is safe within a notebook.

The standalone `evaluation/judge.py` imports only standard library and NumPy. Prediction/report CLI paths are caller-relative, hidden assets Judge-file-relative. It loads NPZ without pickle, validates reconstruction key, complete native shape, real float32/64, finite values and[−10,10]range. It uses actual truth if one exists, otherwise the explicitly method-defined baseline. This task has only the latter. Independently implemented full-grid cosine NCC/dynamic-range NRMSE require both declared boundaries. No crop, rescale, sign flip, offset or alignment is performed. Invalid predictions/evaluator failures have empty metrics and error status, exit2; valid poor estimates exit1; pass exits0. Report-parent creation and write errors are tested. Every JSON number is finite.

## Notebook and figure caller flow

`notebooks/nexus_relative_focal_depth.ipynb` tells the complete problem,data,physics,method,results,conclusion story. It loads public images and separately identified original-source comparison arrays, actively runs the full selected400-step path, writes the fresh submission, then actually computes all four classical estimates, three additional400-step contrast-weight conditions and two250-step ROF comparisons. It evaluates that fresh output with the standalone Judge. Historical paper results do not enter these metrics; the different later smartphone acquisition is explicit.

`visualization.image_metrics(estimate,reference) -> dict` uses full-grid binary64 cosine NCC/dynamic-range NRMSE, rejects nonfinite/mismatched arrays and degenerate references. A known independent vector case checks it and the separately implemented Judge.

`visualization.relative_surface_figure(images,result,sharpness) -> Figure` draws the actual relative focal surface and top-two focus-score margin. It uses plot-only stride12, original frame9colours, pixel x/y axes and an explicitly labeled relative vertical coordinate. It computes no reconstruction and writes no file. The caller supplies native images and already computed full field/sharpness; this helper permits visual layout QA without rerunning the inverse.

`visualization.make_figures(images,result,details,upstream,source_diagnostics,classical,variants,tv_only,directory=None) -> (figures,measurements,captions)` receives only caller-computed arrays. It creates eight actual scientific groups: all19 observations, selected-source agreement/diagnostics, classical conditions, four joint weights, two-stage ROF comparison, actual trajectory states, explicitly relative surface/ambiguity map, and fitted contrast/regularity evidence. It does not perform or substitute reconstruction. `variants` contains full a4/12/28 arrays; `tv_only` contains full weights6/26 arrays; `source_diagnostics` contains the independently executed original compiler/qualified-initializer comparisons, clearly labeled as such. Every main field shares[−10,10]colour bounds; initial fields and signed difference limits are explicitly different and documented. Plot-only stride4image atlas and stride12surface never affect metrics or reconstruction.

When directory is provided, it exports each figure as PNG/SVG/PDF, numeric full fields to `figure_numeric_sources.npz`, full-precision metrics JSON and figure caption/provenance JSON. The notebook passes a maintainer-only external directory via `IMAGING_REVIEW_EXPORT`; final task directories retain no temporary figures/PDFs. Returned Matplotlib figures are displayed and closed by the notebook. The optional export changes no computed arrays.
