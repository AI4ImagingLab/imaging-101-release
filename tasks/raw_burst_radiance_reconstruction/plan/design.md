# Shipped interfaces and data flow

`python -m src.main` is the standard entry point. `main.main()` sets PyTorch CPU threads to1, resolves the task root relative to source, loads data/raw_data.npz, calls reconstruct with defaults and writes only output/reconstruction.npz. No module changes a Matplotlib backend. Notebook plotting explicitly uses inline mode.

`preprocessing.load_data(path)` reads NPZ with allow_pickle=False and returns unbatched copied uint16 frames(10,1024,1024) in ADU. `getTiles(image,window,steps=1)` returns a sliding-window view of shape(tile row,tile column,window,window). `downsample(image,kernel='gaussian',factor=2)` supports native integer Bayer averaging, reflected Gaussian filtering and optional generic kernel convolution; factor1 returns the input. `getAlignedTiles(image,tileSize,motionVectors)` returns a copied tile grid from rounded/clipped starts. isTypeInt/umean4_/fmean4_ are local dtype/averaging helpers, not imported domain operations.

`physics_model.computeDistance(refPatch,searchArea,distance='L2')` takes float32(h,w,t,t) and float32(h,w,t+2r,t+2r), returning float32(h*w,(2r+1)²) distance costs with explicitly preserved accumulation. `computeTilesDistanceL1_(refTiles,altTiles,offsets)` evaluates propagated candidate distances with source rounding/clipping and returns float32(h,w). `subPixelMinimum(arrDst,arrIdx)` takes flattened float32 search costs and uint16 minimum indices, returning float32(n,2) corrected row/column offsets. `sample_forward(image,row_offsets,column_offsets)` implements a finite clipped integer pullback; `sample_adjoint` implements its scatter-add adjoint. These independent physical operators are tested directly and do not supply hidden motion to the solver.

`solvers.hdrplusPyramid(image,factors=[1,2,4,4],kernel='gaussian')`, `upsampleAlignments(referencePyramidLevel,alternatePyramidLevel,previousAlignments,upsamplingFactor,tileSize,previousTileSize,method='hdrplus')`, and `alignOnALevel(referencePyramidLevel,alternatePyramidLevel,options,upsamplingFactor=1,tileSize=16,previousTileSize=None,searchRadius=4,distance='L2',subpixel=True,previousAlignments=None)` implement explicit local multiscale search. The propagation function intentionally mutates its private previous displacement array when scaling, preserving source arithmetic. `alignHdrplus(referenceImage,alternateImages,params,options)` returns integer(9,65,65,2) native motion, uint16(10,65,65,32,32) aligned tiles and36 copied float32 scale displacement arrays. No file I/O occurs in these functions.

`patchesRMS(patches)` safely computes a float64 per-tile RMS in ADU. `mergeWienerDFTPatches(referenceImagePatchesFFT,alternateImagePatchesFFT,noiseVariance,temporalFactor=8)` calls the explicit pair shrinkage formula; the nominal caller passes75. `temporalDenoisePairPatches(referenceImagePatches,alternateImagePatches,noiseVariance,temporalFactor=8,method='DFTWiener')` transforms the alternate patch and applies the selected pair filter; simple passthrough/paired-average helpers retained from source are optional diagnostics, not standard runtime replacements. `spatialDenoisePatches(patchesFFT,noiseVariance,spatialFactor)` applies explicit radial spectral attenuation. `cosineWindow2Dpatches`, `cat2DPatches`, and `depatchifyOverlap` implement weighting and reassembly. Their callable names retain author spelling to make equation traceability direct; every numerical step remains visible local code.

`mergeChannelHdrplus(referenceChannel,alignedChannelTiles,lambdaS,lambdaR,params,options)` merges one Bayer site and truncates its reassembled image to the reference dtype. `getNoiseParams(tags,blackLevel,whiteLevel,params,options)` returns the fixed public noise-curve tuple already derived from documented acquisition ISO; no metadata fitting or exif library is hidden. `mergeHdrplus(referenceImage,alignedTiles,padding,tags,blackLevel,whiteLevel,params,options)` calls all four site merges, interleaves and removes padding. getTime is a local optional logging helper; default options suppress those messages.

`reconstruct(data,temporal=75.,spatial=.1,frame_count=10,align=True)` returns `(outputs,stages)`. Outputs has reconstruction uint16(1,1024,1024). Stages has native motion,36 scale arrays, full aligned_tiles for maintainer diagnostics, aligned_sample(first3×3 tile grid), unpadded Bayer average and four padded reference pyramid arrays. Full tile storage is transient and approximately86MB, not public input or output. Nondefault arguments are used only in actual notebook sensitivity runs; defaults reconstruct every bound exposure. All core mathematics uses NumPy/SciPy/general PyTorch FFT, no original package, rawpy, numba, cv2, ready-made motion estimator or domain inverse.

`visualization.relative_l2(x,y)` casts before subtraction and computes Euclidean relative error. `preview(x)` produces a half-resolution2×2 site mean above black solely for labeled review. `alternate_dc_weights(tiles,index)` explicitly evaluates the alternate contribution weight from exact DC tile sums and the same reference variance/scaling, averaged over four Bayer sites. `run_experiments(data,references)` actively reconstructs every comparison, returning spatial solutions, motion, frame-count measurements, two DC weight maps and full-precision metric dictionary. References contains corrected and unmodified independent original arrays; neither replaces any fresh reconstruction. `make_figures(data,e)` creates five actual multi-panel figure groups. `export(figures,e,directory)` writes private PNG/SVG/PDF and numeric NPZ/JSON only when explicitly called; it is not used by CLI.

The active notebook loads raw measurements, computes all comparisons through src, evaluates fresh outputs and displays five inline figure groups. It separately loads corrected_upstream.npz and unmodified_upstream.npz for labeled numeric/visual comparison. Final cleaned scalar measurements are separately stored/read as provenance, never substituted for solving. Frozen oracle_stages.npz is consumed by test/comparing_test, and baseline_reference.npz by the standalone Judge. No actual ground truth is available or invented.

`evaluation/judge.py` implements evaluate(prediction), relative_l2(x,y), main(), independent of src. It resolves evaluator assets from its own directory, preserves caller-relative prediction/report paths, validates file/key/exactuint16 shape/finite values, scores every pixel and emits UTF-8 finite JSON with status/passed/metrics/thresholds/errors. Exit0/1/2 distinguish pass/poor prediction/invalid or unavailable evaluator. Unit/contract tests cover known metric values, dtype/NaN/Inf/object/overflow errors, missing assets, write errors, zero-field rejection and foreign-cwd invocation. Comparing tests freeze independently run corrected source stages, while physical tests use analytic fields and no upstream imports. All tests/fixtures/validation stay under test/.
