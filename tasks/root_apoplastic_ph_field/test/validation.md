## Calibration independence, acquisition discrepancies and limits

The low/high reference images are separate roots from the same Figure5 calibration experiment, explicitly labeled by known incubation medium pH in the source data and described as independent calibration samples in the primary paper. Neither calibration uses a hidden target estimate. The in-vitro response coefficients are independently supplied, not fitted using target root labels or reconstructed maps. ImageJ image means ignore NaNs and include finite zeros; each independent reference root is equally weighted. The observed reference levels are lower **0.3933395155239811**, upper **1.875376803966015**, computed from all nine/eight reference images. Individual original ImageJ means are frozen separately.

The paper's generic HPTS labels and plate-reader characterization say465/405nm; confocal Methods say458/405nm. All six original Figure5 LIF XML headers were independently extracted and contain the actual405/458nm laser settings, supporting the microscopy interpretation. `native_lif_metadata_0.xml` through`_5.xml` and `native_lif_settings.json` preserve exact headers/settings and hashes. No wavelength-dependent gain or spectral correction was invented. The input is the author's already processed ratio, calibrated with that experiment's independent roots. Reported 514nm common emission center is retained; an exact confocal emission bandwidth is not inferred from the plate-reader's8nm/10nm descriptions. Exact laser power for the selected series is not needed to invert already calibrated ratios and is not invented from unrelated default XML settings.

Native ImageJ calibration supplies x/y pixel width **0.18037518037518038 micrometre**, with zero image origins; scalar source capture records it. Physical display coordinates use image edges and preserve row-down/column-right order. No spatial registration, interpolation, denoising or altered PSF is introduced. Real NaN and zero input pixels remain unchanged; no Inf exists. `native_nan_exception_evidence.json` independently verifies original TIFF uint32 bit patterns for **every pixel of every packaged image**, missing-pixel counts and zero Inf. Missing data are a deliberate exception to generic all-finite-input audits; the declared output is fully finite with exact-zero padding.

The source uses epsilon0.0001 interior-asymptote clipping to avoid divergent inverse values. The largest bound root has **0.2848758951165671** clipped measured-pixel fraction. Those pixels, negative finite ratios and pH excursions outside5–7 remain in the scores and plots. No outcome-dependent support or clamping-to-display-range is introduced. Chemical reliability outside the calibrated interval is limited, and no independently measured target pH field exists.
