# Shipped interfaces and execution flow

Runtime subset: NumPy 2.4.6 and Matplotlib 3.11.1. Pillow/Java/Jython/ImageJ are private acquisition-conversion/oracle tools only and are not imported by source, tests, Judge or notebook.

`src.preprocessing.load_observations(path)` loads exactly `ratio`, `calibration_low` and `calibration_high` with pickle disabled. Native batch-first float32 shapes are `(1,43,1024,1024)`, `(1,9,1024,1024)` and `(1,8,1024,1024)`. Infinite data and empty images are rejected; native NaNs and zeros are retained. It returns the three arrays without batch axes. `valid_pixels(ratio)` returns a bool array of the same shape, finite and nonzero. `calibration_levels(low,high)` accepts reference-root-first arrays, returns lower and upper scalar levels and the two per-root float64 mean arrays, and rejects nonincreasing levels.

`src.physics_model.normalize_ratio(ratio,lower,upper)` returns a float64 array of normalized dimensionless observations and requires finite ordered levels. `fluorescence_response(ph,top=TOP,bottom=BOTTOM,hill_slope=HILL_SLOPE,log_ic50=LOG_IC50)` directly evaluates the calibrated forward response for pH-valued input. `invert_response(normalized,top=TOP,bottom=BOTTOM,hill_slope=HILL_SLOPE,log_ic50=LOG_IC50,eps=EPS)` returns float64 pH and a same-shape bool asymptote-clipping indicator. All default constants are the exact source values. Neither helper silently replaces the physical nonlinear response with a linear rescaling.

`src.solvers.invert_image(ratio,lower,upper)` returns `(pH,valid_mask,clipping_mask)` for one native image. Output is float32 with exact-zero invalid exterior; mask arrays are bool. `reconstruct(ratios,low_calibration,high_calibration)` computes independent reference levels, loops through all target roots and returns dense float32 `[43,1024,1024]`, lower level, upper level and the per-root clipping fractions. It has no file-writing or plotting side effect.

`src.main.main(input_path=None,output_path=None)` defaults to task-relative `data/raw_data.npz` and `output/reconstruction.npz`. It loads observations, performs fresh reconstruction, adds the batch axis, creates the output parent and writes the sole key `reconstruction`. The returned dictionary identifies runtime, number of roots, calibration levels and maximum clipping fraction. `python -m src.main` is the standard entry point. Importing it changes no backend and writes nothing.

`src.visualization.agreement(estimate,reference,mask)` computes one image's cosine NCC and reference-range NRMSE, rejecting undefined/nonfinite cases. `ph_image(ax,image,mask,title,limits=(5.,7.),cmap='viridis',unit='pH')` draws the full native field on an existing axis in micrometres, increasing row downward, and attaches a colorbar with out-of-display-range indicators. This function changes display limits only, never output values or scoring support.

The active notebook loads public inputs, reconstructs all roots using local modules, loads the independently captured original comparison and computes every reported comparison/sensitivity. It writes primary output and strict Judge report and exports actual numerical plot sources and PNG/SVG/PDF figures to a maintainer archive. The original domain implementation is not imported.

Independent `evaluation/judge.py` resolves hidden assets relative to its file and prediction/report arguments relative to the caller. It validates configuration, native reference, public input-defined masks and prediction contract before scoring. It computes both metrics independently for every root and requires all to pass, reporting per-root values plus minimum NCC and maximum NRMSE. Missing/extra keys, shape/dtype errors, nonfinite submissions or nonzero unavailable-pixel padding are errors, never coerced or cropped. JSON contains status, passed, metrics, thresholds and errors, with native return 0/1/2 for pass/fail/error; report-write failure diagnoses stderr and returns 2.

All stage/physics/metric/Judge tests are under `test/`. Fixtures hold actual original ImageJ means and original Jython normalization/inverse cases frozen before local extraction; the hidden reference contains original 43-map results, not chemical truth. The validation report identifies every consumer and private archive. No generator is shipped because observations are real and reused unchanged.
