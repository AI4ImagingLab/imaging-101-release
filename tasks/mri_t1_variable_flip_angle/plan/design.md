# Shipped modules and execution flow

The standard entry point `python -m src.main` invokes `main()`, resolves data/output relative to the task directory containing source, creates `output/` and writes `output/reconstruction.npz`. Only main writes submission files. Importing any module changes no Matplotlib backend.

`preprocessing.load_data(path)` reads NPZ with `allow_pickle=False`, validates shapes, float64 signal/calibration dtypes and positivity on supplied support, and returns signal `(128,128,2)`, B1 map `(128,128)`, and bool tissue mask `(128,128)`. Signal has arbitrary scanner units; B1 is dimensionless. Native x,y index order is retained. Background B1 values are not used for fitting.

`physics_model.spgr_signal(m0, t1_ms, b1=1.)` returns shape `(...,2)` steady-state signal in scanner units using fixed α=[3,20] degrees and TR=15 ms. Inputs may be scalar or broadcast-compatible arrays; B1 is a multiplicative transmit ratio. `linearized_fit(signal, b1=1.)` consumes final-axis angle samples and returns `(t1_ms,m0)` arrays with that final axis removed. It uses arithmetic centered ordinary least squares and the upstream E clipping convention. Calculation is float64 when supplied bound data.

`solvers.reconstruct(path)` calls load_data, applies linearized_fit only on mask-selected voxels, inserts results into zero-initialized full-grid arrays and returns `reconstruction` and `equilibrium_magnetization`, float64 `(1,128,128)`. It writes nothing. `reconstruct_uncorrected(path)` repeats fitting with B1=1 and returns float64 batch-first T1 for the notebook comparison.

`visualization.metrics(estimate, reference)` returns uncentered cosine NCC and dynamic-range NRMSE. `comparison(fresh, reference, mask=None)` returns a Matplotlib Figure containing reference/fresh/difference panels for every output key; optional mask is accepted for a common plotting interface and does not alter scoring. The notebook uses full active corrected and uncorrected reconstruction, identified upstream comparison arrays, measured runtime, map comparisons, consistent metric tables and paired reference-agreement bars.

`evaluation/judge.py` is a standalone evaluator importing no solver. It validates required keys, exact batch-first shapes, real float64 dtypes and finite values before calculating any metric; both maps must pass. Its `observation_error(pred)` independently evaluates the physical GRE formula from both predicted maps and the public B1 calibration, and returns supported RMS signal mismatch divided by measured signal range; this must also be at most 1e-6. References and metric config are evaluator-relative. Prediction/report CLI paths are caller-relative. UTF-8 report fields and exit codes are 0 pass, 1 poor valid prediction, 2 malformed input, unavailable assets or report write failure.

`test/fixtures/upstream_stages.npz` stores sampled input locations, original signal/B1, scalar upstream parameters and forward signals. Parity tests compare forward and inverse stages and the entire pipeline; notebook references separately identify corrected/uncorrected upstream measurements. Numeric metrics and error/report contracts are independently tested. Original NIfTI files, upstream source, capture scripts and logs remain in the private archive. No generator exists because all benchmark observations are real measurements, without synthetic additions.
