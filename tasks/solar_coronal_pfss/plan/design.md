# Shipped finite-volume interfaces and execution

The standard command is `python -m src.main`, working in the task directory. It reads the single public NPZ and writes exactly `output/reconstruction.npz`, containing radial,polar,azimuthal arrays. No original domain package, SunPy, Astropy, checkpoint, fixture, reference array or other task is imported by the runtime. Only standard library and NumPy are needed for inverse computation; Matplotlib supplies scientific plots. CPUfloat64 execution is validated. No module changes Matplotlib backend.

## Source APIs

`preprocessing.load_data(path='data/raw_data.npz')` requires magnetogram(1,180,360),finite32-bit real storage, and returns an independent native(180,360)copy inGauss. It preserves the FITSbig-endianfloat32 numeric storage. Constants N_LATITUDE180,N_LONGITUDE360,RADIAL_CELLS35,SOURCE_RADIUS2.5,LONGITUDE_EDGE22.0 match README. `balance_flux(magnetogram)` promotes tofloat64 and returns input minus its float64 arithmetic mean; no in-place mutation or hidden calibration.

`physics_model.grid(ns=180,nphi=360,nr=35,rss=2.5)` returns a dict with integer sizes, shellradius,stepsds/dp/dr and one-dimensional coordinates sg,sc,rg,rc,pg. All radius coordinates rg/rc are logarithms; exp converts to physical solar-radius values. `area_factors(g)` returns positive radial(ns bynr+1 transposed asr-first),polar andazimuthal areas: specifically Ar(nr+1,ns),At(nr,ns+1),Ap(nr,ns). Polar endpoint conversion areas use the adjacent-face regular-field convention. flux_divergence explicitly restores zero physical surface area at both poles.

`physics_model.field_from_potential(als,alp,g)` accepts edge-integrated vector potential als(nphi+1,ns,nr+1),alp(nphi,ns+1,nr+1); no radialA is needed. It returns a dict of float64 r-first fields radial(nr+1,ns,nphi),polar(nr,ns+1,nphi),azimuthal(nr,ns,nphi+1), inGauss. It implements localStokes differences,area division and polar opposite-longitude averaging. `flux_divergence(fields,g)` returns net cell flux(nr,ns,nphi),unitsGauss·solar-radius²; it is a verification/diagnostic operator, not an inverse solver.

`solvers.solve(magnetogram,nr=35,rss=2.5,return_diagnostics=False)` accepts balancedfloat64(ns,nphi) and solves all azimuthal modes locally. Standard return is the three-fielddict above. With return_diagnostics=True it returns `(fields,diagnostics)`; diagnostics has A(ns,ns),Fs(ns),Fp(ns+1),mu(nphi),psi_probe sampled `[::7,::15,::30]`,als_probe sampled `[::30,::15,::7]`,alp_probe with the same edge probe strides. They are numerical stages consumed by tests, not input calibration. Probes avoid duplicating full reference arrays in fixtures. The fulloriginal result remains the evaluation baseline and private oracle archive. There is no filesystem side effect.

`main.reconstruct(path='data/raw_data.npz')` calls load→balance→solve and adds exactly one leadingbatch axis to each component. `main.main()` creates outputparent and writes compressedNPZ with those keys. Runtime defaults are task-relative; a caller may provide an absolute input to reconstruct. No root-level wrapper exists.

`visualization.metrics(a,b)` returns standardncc,nrmse on flattened nondegenerate realarrays and is tested with independently known two-element cases. `plot_maps(raw,fields,reference,radii)` returns one MatplotlibFigure with observed,boundary,intermediate,source-surface,original andparity-residual maps. It never saves or modifies scientific arrays. Coordinates use pixel-edge extents and signed zero-centered scales. All99%display limits are explicit. Notebook creates additional component,conservation,boundary-sensitivity andangular-sampling figures from actual fresharrays. Source-radius experiments and coarse sampling call solve locally; historical/cached results are not inserted as fresh.

## Evaluator

The standalone `evaluation/judge.py` imports only standardlibrary andNumPy. SHAPES explicitly declares the three required arrays. `load(path)` requires existence,allkeys,exactshapes,realfloat32/64,finitevalues,allow_pickle=False. `score(a,b)` implements uncenteredcosine and dynamicrangeNRMSE; degenerate reference is an evaluatorerror andzeroestimateNCC=0. `evaluate(prediction)` returns report andexit0/1/2; actualgroundtruth takesprecedence if available, otherwise the explicitly named baseline is used. All hidden paths resolve relative to Judge itself; prediction/report paths retaincallerworkingdirectory semantics. JSON is finiteUTF8 and reportparent is created; reportwriteerrors go tostderr/exit2. Tests cover malformed arrays,missing assets,poor outputs,truthpriority,foreigncwd andreportwritefailure.
