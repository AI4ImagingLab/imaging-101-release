# Provenance and executed validation

## Fixed physical task and original sources

This task reconstructs phase-only apparent conductivity from all 25 real, native 3D MRI transceive-phase observations. It is a new inverse electric-conductivity unknown/acquisition, distinct from existing anatomical MRI, susceptibility, relaxation, perfusion, diffusion and mechanical-wave modulus tasks. The selected published method is the phase-only Helmholtz baseline and quadratic spatial derivative described in Arduino, Pennecchi, Katscher, Zilberti and Cox, ISMRM 2021 Proceedings 29, abstract 3777, https://cds.ismrm.org/protected/21MProceedings/PDFfiles/3777.html . The complete primary proceedings text and native detailed report `A232_Report.tex` were read and archived. The method lineage is Voigt et al., MRM 2011, DOI 10.1002/mrm.22832; only its public abstract was available, and no full-text reading is claimed. No MDPI article is selected as the method paper.

Original author code: https://github.com/EPTlib/eptlib . The exact paper-era **v0.1.1** commit is **c3983045d7d8cb0c41929a88628492201ca9354b**, remotely verified from tag metadata and fetched unchanged. Current v0.4.0 tracking head was separately screened and is not the implementation used. Mathematical source is MIT, copyright 2020 Alessandro Arduino / INRiM, preserved in NOTICE. The source ZIP SHA256 is 796eea1ec2a605f3b36968b0230573acf47d9814a98d9584f6ad88b03e74af31. See the private source download and tag indexes for actual remote URLs and hashes; no remote-freshness claim is inferred from a local tracking branch.

Real dataset: Arduino et al., EMUE-D5-3-EPTTissueCharacterization, 2020 v1.0, DOI https://doi.org/10.5281/zenodo.4248879 , explicitly CC-BY-4.0. Native `emue-sphere.h5` SHA256 **e94c0ccd7ff4cdebaefa83351ab6c4d19f230869c96104cbbb85542619ea99de**. It was obtained with documented HTTP range extraction of this member from the genuine 5,579,324,147-byte author ZIP; no observation was synthesized. Full native H5 is 147503104 bytes. All 25 phase and magnitude datasets retain native float32 `[z,y,x]=(96,96,80)` bit patterns including original NaN exterior. Raw NPZ SHA256 **b9702ebb37735f26f38e9977926421c07f1e40621e54fc3be6b1b576b1d173da**. The original library grid is x-fastest `[80,96,96]`; the NPZ changes only the container and adds batch/repeat axes. The 11513 measured-voxel sphere and the 859-center 11-cuboid support are derived solely from input availability. They are not fitted-value quality masks.

The original phantom was real 3 T Philips Ingenia TX, 32-channel head-coil, low-flip-angle SSFP, 2 mm isotropic, 128 MHz; 25 repeats in five groups, phantom not moved. Original numerical TR/TE/flip angle and scanner-space origin were not supplied and have not been invented. Relative FOV-centered display coordinates are explicitly declared. Magnitude is supplied transmit-sensitivity approximation, not calibrated absolute B1. No extra square root, phase unwrapping, extrapolation or resampling is introduced. The nominal 0.56 S/m bulk preparation has **no independent experimental characterization or associated uncertainty**, explicitly stated in the native report. It is not stored or scored as ground truth. Magnitude-assisted sigma and permittivity are model comparisons, never truth.

The original derivative kernel uses even normal equations, not an arbitrary smoothing substitute. Division by each physical spacing twice and x/y/z summation order are preserved. NaNs are replaced with zero **only during stencil arithmetic**; finite-support checks exclude any stencil using an absent active sample. No physical or numerical upstream error was silently corrected. The local full-complex helper avoids arithmetic on the invalid exterior with masked division; it leaves NaN there and changes no valid equation.
