# Shipped interfaces and data flow

All runtime modules use NumPy and SciPy primitives. Matplotlib is used only for review visualization. There are no domain-library imports, cross-task imports, generated synthetic observations, training checkpoints, or runtime upstream calls.

- `preprocessing.load_data(path=None)` reads the public NPZ with allow_pickle=False; strips its singleton batch axis and returns a dictionary of independent float64 arrays. Default path is task-relative data/raw_data.npz. Image fields are512x512; radial_edges has36elements.
- `preprocessing.image_center(counts,exposure)` returns (x,y) pixel coordinates from the sigma5smoothed count maximum.
- `preprocessing.annular_profile(data,edges,center=None,min_exposure=.05)` returns profile/error[count/s/arcmin²], observed area[arcmin²], mean exposure[s], count totals and center. Arrays have length len(edges)-1. It implements the fixed exposure mask and rounded annulus rules.
- `preprocessing.background_subtraction(data)` extracts the135bin outer background profile and35bin source profile. Returns raw and background-subtracted rates/errors plus scalar background and background_error, and outer centers/profiles/errors. It has no file side effects.
- `physics_model.projection_volumes(inner,outer)` returns N-by-N upper triangular shell/cylinder volumes in the cube of the supplied length unit. Inputs are copied; contiguous outer boundaries are enforced as in upstream.
- `physics_model.count_to_hydrogen_emission_measure()` returns the scalar physical count-rate conversion. Public constants exactly match README acquisition metadata.
- `physics_model.edge_correction(inner,outer,emission)` returns Ndimensionless finite-boundary fractions using the author's formula; lengths may be angular if consistent.
- `physics_model.forward_profile(emissivity,edges)` returns Nsurface rates without exterior contamination, using cm^-6emissivity and arcmin edges. This helper supports review comparisons; the Judge independently implements its physics.
- `solvers.median_smooth(profile)` implements the five-neighbor source filter including endpoint rules; returns an Nvector.
- `solvers.onion_peeling(profile,error,edges,nmc=1000,seed=24713,correct_edge=True,smooth=True)` returns density, density uncertainty, emissivity and stage dictionary. All output profiles have35elements for the bound data. Stages include cm³projection matrix,35xnmcRHS/emissivity samples, integrated emission, exterior fraction and unsmoothed emission statistics. Flags support explicitly labeled notebook ablations.
- `solvers.reconstruct(data,nmc=1000,seed=24713)` performs full observation extraction and deprojection. Returns (output,diagnostics). Output contains exactly reconstruction and emissivity, both float64(1,35); diagnostics include the measured profile and solver stages. No file writes occur.
- `main.main()` is the standard `python -m src.main` path: load public data, reconstruct, create output directory and write output/reconstruction.npz. It returns the written Path and consumes no hidden reference.
- `visualization.make_figures(data,output,stages,upstream,experiments,export_dir=None)` creates scientific comparison figure objects. Optional export_dir writes PNG/SVG/PDF and exact numeric_sources.npz. It never selects a Matplotlib backend. CLI visualization and notebook are distinct callers.

The active notebook imports these modules, computes the complete fresh reconstruction, computes explicitly labeled edge/smoothing/MC comparisons, evaluates the fresh file through the independent Judge, and displays six scientific figure groups. Upstream reference arrays are loaded solely for comparisons, never substituted as fresh results. `notebooks/reference_outputs/upstream_native_run.npz` identifies the exact original native-image run.

The standalone `evaluation/judge.py` imports no solver modules. Its read_output validates every required key, exact float64(1,35)shape and finite real values. evaluate loads metrics relative to its own directory, prioritizes ground_truth.npz if present, otherwise baseline_reference.npz, and computes all six declared metrics. Its independent observation calculation reads only public raw images and geometry. CLI prediction/report arguments are caller-relative; report directories are created. Exit codes0/1/2 mean pass/valid fail/error, and report-write failures are diagnosed on stderr. Tests import the Judge only as evaluator code and consume frozen numerical fixtures; upstream libraries are never imported.

`test/fixtures/upstream_stages.npz` is the frozen original numeric pipeline capture, consumed by stage and full-pipeline parity tests. Raw observations remain only in data/raw_data.npz. Private original source, complete FITS files, paper PDFs, build/install logs and capture scripts are outside this task. Output files are generated artifacts. No notebook backend changes are made by importing main or any library module.
