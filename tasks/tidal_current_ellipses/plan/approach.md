## Objective and direct inverse

Minimize J(m)=sum_i|zi−(Bm)i|², equally weighted actual observations. This objective sums squared east and north residuals in(cm/s)². There is no noise-variance normalization because none is supplied, no regularizer, no hidden target, no trend or node correction. Solve via np.linalg.lstsq(B,z,rcond=None), a generic SVD least-squares primitive. The normal equations are Bᴴ(Bm−z)=0; use them as a verification, not an unstable explicit matrix inverse. No iterative initialization, updates, step size or stopping rule is necessary. Numeric rank/condition and the fixed publicfrequency separations diagnose identifiability.
