# Actual interfaces and execution flow

`preprocessing.load_data(path=None)` loads public NPZ with allow_pickle=False; default path resolves from module location. Returns copied unbatched float64 arrays: observations(1798)Å,entry/exit/direction(1798,2),path_length(1798)m,grid_x/grid_y(40,40)m,traction_points/traction_normals(100,2).

`physics_model.circular_modes(count)` returns flattened circular integer modes in original column-major order. `place_bases(direction,theta=(6.6359,.0223,.0044,182.4,.007,.2918),counts=(15,10),seed=1203)` returns dictionary of density/stress wavenumbers, domain sizes, prior spectra and geometry-only RNG state; no target/observation values enter. `density_basis(points,b)` maps n×2 coordinates to n×158 density basis. `derivative_basis(points,b)` returns n×69×3 Airy derivatives xx,yy,xy. `strain_basis(points,b,nu=.3)` returns interleaved(3n,69), rowsxx,xy,yy per point. `traction_basis(points,normals,b)` returns interleaved(2n,69) normalized traction rows.

`integral_density(entry,exit,direction,b)` returns ray×density-mode line integrals in m times basis units. `integral_products(entry,exit,direction,b)` returns ray×(158*69)×3 product integrals, density mode varying fastest, last axis Airy derivative xx,yy,xy. `acquisition_operators(data,b,chunk=128,nu=.3)` returns linear(1798,158) and bilinear(1798,158,69) line-average operators. Chunking is execution-only; every native ray is retained. `prediction(weights,linear,bilinear)` returns absolute mean lattice spacings(1798)Å; `jacobian` returns1798×227 physical-coefficient derivatives.

`solvers.initialize(basis,grid_points,nominal_spacing=4.056)` returns independent nominal-spacing GP mean227-vector, using stable direct QR and zero initial stress. `objective(weights,mean,prior,linear,bilinear,traction,observations,noise_sd=4.056e-4,traction_sd=1e-6)` returns scalar negative Eq19 objective. `derivatives` has the same arguments and returns negative-gradient g(227), objective Hessian H(227,227), full data-plus-traction Jacobian(1998,227). `newton_direction(gradient,hessian,coordinate_scale,cutoff=1e-12)` returns physical direction, dimensionless singular spectrum and retained integer rank; explicit congruence and truncated pseudoinverse occur here.

`solve_weights(linear,bilinear,traction,observations,mean,prior,max_iterations=15,noise_sd=4.056e-4,traction_sd=1e-6,svd_cutoff=1e-12)` returns weights and diagnostics. Fixed initial column scaling is reused. Diagnostics: weights_path(227,accepted_updates+1),history(rows,4)columnsupdate/objective/acceptedα/physical-stepnorm,firstdict(gradient,hessian,jacobian,direction,coordinate_scale,singular_values,rank),mean and prior. It writes no files. `reconstruct(data,max_iterations=15,noise_sd=4.056e-4,traction_sd=1e-6,counts=(15,10),svd_cutoff=1e-12)` builds local operators, initializes, solves and maps all four fields. Returns resultdict strain(1,3,40,40), lattice_spacing(1,40,40), and diagnostics augmented with finalweights,basis,prediction(1798),elapsed and traction(100,2). All arrays are float64; physical output axes are batch/component/y/x.

`main.run(output=None)` reads public data, calls full reconstruction, writes both required keys to output/reconstruction.npz relative to task root by default, creates parent directory and returns result/diagnostics. `python -m src.main` is the standard CLI. No source module changes a Matplotlib backend or imports upstream code.

`generate_data.ray_geometry()` explicitly clips the native30×100 rays to the rectangle; `physical_fields(x,y)` is hidden author Saint-Venant/Gaussian truth; `clean_measurements(entry,exit,direction,order=64)` integrates the original physical coupling with independent Gauss-Legendre quadrature; `generate(seed=1203)` returns a new sample from the same noise law using NumPy. Bundled observation randomness is the original author's Octave stream and is not claimed bitwise reproducible by NumPy. No new generated sample replaces bundled observations.

`visualization.field_metrics(result,truth)` returns independent per-field NCC/rangeNRMSE. `sensitivity(data)` actively recomputes1e−10 and1e−14 local variants. `figures(data,truth,fresh,diagnostics,original,qualified,cases,histories)` returns six computed multipanel figures. Original includes actual reproduced original heuristic, plus its fixed-d0 GP comparison; qualified contains reproduced selected-source fields and objective history. No missing comparison is zero-filled. Notebook uses cleaned modules for every fresh estimate; fixed upstream arrays are explicitly labeled.

Standalone `evaluation/judge.py` imports no solver, validates both exact float64 shapes and finite values, evaluates all eight metrics against actualtruth and returns strict0/1/2 statuses. Tests consume frozen numeric fixtures only; private qualified MATLAB functions, generic compatibility helpers and archives are not runtime imports. The notebook actively reconstructs and exports private PNG/SVG/PDF/numeric arrays only under an explicit export environment variable.
