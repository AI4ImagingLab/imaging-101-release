# Implemented inverse mathematics

The standard selected method is the L1 sparse-regression alternative in the CVPR2012 paper, implemented by the author's reference IRLS. All4author comparison methods are actively reconstructed in the notebook. The source-SBL comparator has distinct mean/covariance ridge values, so it is explicitly a source heuristic rather than an exact common-posterior implementation. This scope was fixed and criteria frozen after independent original execution and before local source extraction; initial SBL criteria and scope review are preserved privately. No failed local parity result drove this selection.

## Data, coordinates and objective

Let L=50 and P=256×256. The public input is grayscale y of shape(L,H,W), known A of shape(L,3), and Boolean support S of shape(H,W). The original arithmetic RGB mean was applied before packaging; local preprocessing only reshapes to M of shape(P,L), using C-order row,column indexing. No intensity renormalization, lighting normalization or image resize occurs. The native dataset is an author-existing renderer output, not real photography and not newly synthesized here. The support is its observed silhouette, not a hidden-normal threshold. Every light row uses the original Cartesian x,y,z basis. Image pitch is unknown; normal components are dimensionless.

The per-pixel forward model is b=Ax+e where b is the pixel's L×1 intensity column, x=rho n is an unnormalized3×1vector, rho is diffuse albedo and n a signed unit normal. The linear operator is the light dot product; its Euclidean adjoint is multiplication by A. The nuisance e includes specularity/shadows; the diffuse linear component itself is not clamped. The selected objective is sum_i |b_i−(Ax)_i| with no averaging factor, no spatial regularizer, no normal-sign alignment and no post-fit smoothing.

## Standard L1 IRLS

Initialize x_old=(1,1,1)^T, W=I_L. At each of at most1000iterations solve min_x ||WAx−Wb||² using NumPy least squares with rcond=None, with exactly the original multiplication ordering. Record r=b−Ax. If ||x−x_old||₂<1e−8, return x before another weight update. Otherwise set x_old=x and set the diagonal entries W_ii=1/max(sqrt(|r_i|),1e−8). Thus squared weights approximate reciprocal absolute residuals; the floor prevents unbounded numerical weights. No line search, learned weight or warm start is used. The stopping tolerance is in albedo-weighted coefficient units, not relative angular error. The iteration budget is an explicit fallback; bound original and local runs are compared, not presumed globally exact L1 solutions. Trace tests compare every iteration at three independently captured foreground pixels and verify weighted normal stationarity with a dimensionless backward error plus decreasing actual absolute loss.

Reconstruct each known foreground independently. Divide each non-negligible coefficient row by its L2norm; the original normalization leaves rows below10machine-epsilon unscaled. Background rows are zero. The standard submission is float64(1,256,256,3); no albedo, clipping, gamma or display transformation is submitted. The CLI invokes only this method on all50lights.

## Preserved scientific comparisons

L2: solve A X=M^T by least squares with rcond=None, transpose, normalize rows, zero background. This is the ordinary diffuse baseline.

Source-SBL: initialize gamma=ones(L,1), x_old=1000ones(3,1). At each iteration W=diag(1/gamma), C=1e−6 I₃+A^TWA, d=A^TWb, x=solve(C,d). Test the same absolute coefficient-change tolerance1e−8 before gamma update, max1000iterations. If continuing, e=b−Ax, E=I₃+A^TWA, Xi=solve(E,A^T), v_i=sum_j A_ij Xi_ji, gamma=max(e²+v,1e−8). These are exactly the author's executable formulas. The differing diagonal terms in C and E are not one shared Gaussian covariance, and no exact evidence objective or monotonic marginal-likelihood claim is made for this comparator. It remains a real freshly computed comparison, not replaced by cached images or silently corrected math.

RPCA: construct D=M[S,:]^T, shape(50,20317). Minimize nuclear norm of B plus lambda times the entrywise L1norm of E subject to D=B+E, with lambda=1/sqrt(max(D.shape)). Initialize B=E=0, let s be the largest singular value of D, Y=D/max(s,maxabs(D)/lambda), mu=1.25/s, mu_max=1e7mu, multiplier1.5. Each iteration first sets E=soft(D−B+Y/mu,lambda/mu); then computes full economy SVD of D−E+Y/mu and B=U diag(max(sigma−1/mu,0)) Vh. Set Z=D−B−E, Y=Y+mu Z, mu=min(1.5mu,mu_max). Stop when ||Z||F/||D||F<1e−6 or at1000iterations. Preserve the sparse-first update order. Fit A X=B by least squares, then normalize foreground rows. There is no artificial rank3projection or domain solver. Unused upstream SVD-rank bookkeeping does not restrict the economy SVD.

## Truth, metrics and acceptance

Actual independent renderer normals are hidden truth. No reconstruction is relabeled as truth. Compute NCC as uncentered cosine between all foreground Cartesian components, NRMSE as foreground component RMS error divided by max(reference)-min(reference), and angular error as degrees acos(clipped normalized per-pixel dot product), then average only foreground pixels. A zero submitted vector incurs180degrees. Also require maximum foreground |norm−1| and background absolute value≤1e−8. No translation/rotation/sign/scale fit is allowed. Nonzero normal fields and nonconstant component reference are required; undefined metrics/configurations are rejected rather than NaN JSON.
