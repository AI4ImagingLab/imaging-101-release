# Shipped interfaces and execution

All computations are CPU float64 NumPy/SciPy. Dependencies are pinned subsets of the shared environment; no pycpd installation is needed in the cleaned environment.

- `preprocessing.load_data(path='data/raw_data.npz')` opens NPZ with pickle disabled; returns a dictionary of unbatched native `target_points` (40256,3) and `source_points` (40097,3), float64 metres. It validates 2D point tables, finite values and dtype. The batch axis is removed from stored observations.
- `preprocessing.prepare(data,stride=40)` returns selected normalized target/source tables, target-selected mean `origin` shape(3,) metres and scalar coordinate unit metres. It does not mutate inputs. Default selected shapes are (1007,3) and (1003,3).
- `physics_model.transform(points,scale,rotation,translation)` applies row-vector `scale*(points@rotation)+translation`. `initialize_variance(target,source)` returns the average squared pair displacement per spatial dimension. `expectation(target,transformed_source,variance,outlier_fraction=.1)` returns posterior P(M,N), P1(M,), Pt1(N,), PX(M,3), and scalar posterior mass, all normalized-coordinate quantities.
- `solvers.one_step(target,source,transformed_source,variance,previous_objective,outlier_fraction=.1,tolerance=1e-6)` implements one original E/M update. Its dictionary contains R(3,3), t(3,), scalar s, TY(M,3), sigma2, q, diff, A(3,3), YPY. Translation here is normalized; variance is normalized length squared.
- `solvers.reconstruct(data,stride=40,outlier_fraction=.1,max_iterations=400,tolerance=1e-6)` returns `(output,diagnostics)`. Output is the four batch-first public-contract arrays, including every original source point and translation in metres. Diagnostics contains history(iterations,4) columns iteration/Q/normalized-variance/scale, iteration count, final variance, absolute objective change, coordinate unit and origin.
- `main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads, reconstructs and writes the output NPZ, creates its parent directory and returns the output/diagnostics tuple. `python -m src.main` invokes it and prints iteration/scale information. No plotting backend changes occur during import.
- `visualization.nearest_distances(target,points)` returns distances in metres to a SciPy cKDTree of target samples. `icp(data,iterations=100)` returns all rigidly aligned source points and its MSE history. `experiments(data,fresh)` returns a numeric sweep table, ICP points and ICP history; each sweep row stores family(0=w,1=stride), value, RMS metres, median metres, iterations, scale and measured seconds. Default rows reuse the already fresh notebook reconstruction, rather than an archived result.
- `visualization.figures(data,fresh,upstream,sweep,icp_points,icp_history)` returns four named Matplotlib Figure objects. It does not save, close, select a backend or import an upstream solver. Figures use millimetres only for presentation.

The active notebook imports the cleaned modules from the task root, reconstructs the exact public data, evaluates a fresh submission with the standalone Judge, performs the above actual comparisons and explicitly displays each figure once. Archived upstream fixtures are comparisons only. Optional report export is controlled by `IMAGING_REPORT_DIR`; no private absolute path is embedded in the task. Canonical notebook retains actual executed outputs. Maintainer numerical measurements under `notebooks/reference_outputs/` identify their consumer and original/cleaned provenance in validation.

`evaluation/judge.py` imports no solver modules. Its callable `evaluate(prediction,asset_dir=ASSETS,public_path=None)` returns `(report,exit_code)`; default hidden assets resolve against its own file. It independently checks four exact shapes/dtypes/finiteness, actual-truth precedence if supplied, reference metrics and forward transform/nearest-target conditions. CLI prediction/report paths resolve relative to caller cwd. Exit0=pass,1=valid below boundary,2=input/evaluator/report-write error. It never runs solver code. Report JSON forbids NaN/Infinity.

All tests are under `test/`: frozen original numerical stages feed `comparing_test`, independent analytical geometry/posterior tests and Judge contracts feed `unit_test`. Full original source, raw download archive, failed network attempts, capture scripts, original logs and environment evidence live outside the task in the private archive. `LICENSE` preserves pycpd MIT notices and `NOTICE` preserves source-data conditions. No cross-task import or root wrapper exists.
