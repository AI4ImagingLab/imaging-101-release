# Actual implementation and data flow

The standard command is python -m src.main from the task root. main.run(task_root=None) locates the root by its own path unless explicitly supplied, reads data/raw_data.npz, executes the complete automatic selection and final 100-frame reconstruction, and writes output/reconstruction.npz. It returns the fresh fields and diagnostic history, search scores and runtime. It never reads hidden reference arrays or upstream packages.

preprocessing.load_observations(path) validates the original (1,100,1040,1388) uint8 image stack and returns the chronological stack without its batch dimension. antialiased_triangle_matrix(input_size,output_size,center_mode=0) returns a float32 sparse CSR normalized triangle operator. mode 0 gives the antialiased observation downsampling; mode 1 provides the non-antialiased aligned-corner field upsampling. resize_stack(images,shape) returns float32 (T,Hout,Wout), processing one native frame at a time. upsample_field(field,shape=(1040,1388)) returns one float32 native field.

solvers.shrink, dct and idct implement scalar proximal shrinkage and orthonormal spatial DCT-II transforms. step(Im,W,Shat,R,B,Y,mu,max_mu,smoothness) returns the updated field, coefficients, background, residual, temporal factors, multiplier, penalty and constraint residual. fit_coarse(Im,smoothness=5,max_iterations=500,max_reweight_iterations=10) returns mean-one flatfield, physical baseline, residual, all reweighting history and the first update diagnostics. These are computed mathematical states; no archived answer is used.

solvers.fit_baseline(Im,S) performs five full baseline-only reweightings for automatic selection. corrected_quantiles and differential_entropy process preliminary frames individually, so no corrected native stack is allocated. fourier_fraction(field) computes the original automatic frequency criterion. autotune(images) returns selected smoothness, all candidate scores, 128² candidate fields and their primary-fit temporal factors. reconstruct(images) completes that selection and runs the final complete 100-frame fit. The maximum permitted budgets are not reduced for notebook execution.

physics_model.background(flatfield,baseline) broadcasts the rank-one DN background. quality(coarse,flatfield,baseline) computes the explicit fixed unweighted public metrics, independently from the adaptive solver's residual weights. visualization functions operate on observations and computed arrays and never select a Matplotlib backend on import.

The standalone evaluation/judge.py loads only its metrics and visible observation data, validates both required batch-first floating outputs, reconstructs its own resampling matrices, then accumulates full-frame residual metrics without importing src. A positive admissible prediction can be accepted without any comparison to the source's final fields. evaluation/baseline_reference.npz contains the author's full selected-method result only for maintainer comparisons; it is not actual truth. notebooks/reference_outputs/source_selected_views.npz records original corrected examples and their temporal statistics. Original first and late proximal updates and all automatic-search fields/costs are independent frozen numerical fixtures in test/fixtures.

The active notebook calls main.run on raw observations and compares all original automatic-search groups, final fields, baselines, temporal residuals and corrected examples. It loads original fixtures only for labeled comparisons after fresh computation. Native corrected examples and per-frame statistics are computed framewise. The original source's separate final transform uses is_timelapse=False: image/flatfield, without subtracting the fitted temporal baseline. The automatic-selection transform uses image/flatfield−refitted baseline; these are labeled separately.
