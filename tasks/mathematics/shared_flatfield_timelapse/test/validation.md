# Provenance and validation

## Bound problem, publication and source revision

The task recovers a positive mean-one stationary sensor flatfield and all 100 temporal backgrounds from an existing real stem-cell brightfield time series. The additive darkfield is fixed to zero as the author's selected branch/model assumption, not measured instrument calibration. This blind sensor-field problem is distinct from the existing single-scene intrinsic reflectance/illumination inverse. It was semantically reserved with the parent before download and implementation.

Model publication: Peng et al., Nature Communications 8,14836 (2017), “A BaSiC tool for background and shading correction of optical microscopy images”, DOI10.1038/ncomms14836. The selected executable method is the modern **BaSiCPy2.0 approximate Torch implementation**, not the original2017 MATLAB implementation or an unchanged algorithm claim. Exact remotely verified repository https://github.com/peng-lab/BaSiCPy, commit **bbb6d9aa994e3c3233efc5967d7ea5e49b269a29**. The fetched remote Git tree is basic_source_tree.json; basic_verified_source_blobs.json independently matches each used file to its exact Git blob; basic_download_manifest.json records SHA256 values. The full private source subset, original notebook and MIT license are basic_original/. No domain library is imported by the cleaned method, Judge, tests or notebook.

Dataset creator Tingying Peng, Zenodo record6334810 (concept6334809), DOI10.5281/zenodo.6334810, CC BY4.0.
