# Shipped execution and interfaces

`python -m src.main` calls main.run(output=Path('output/reconstruction.npz'), seed=20261029), which reads only data/raw_data.npz, reconstructs the complete bound observations, writes the sole reconstruction key, and returns (result, diagnostics). The script prints measured runtime and selected observed objective. It imports no upstream, cross-task, hidden evaluator or truth module.

preprocessing.load_data(path=Path('data/raw_data.npz')) checks exact keys, shapes, float64, finiteness and positive event intervals, returning a dict with the one batch axis removed. Shapes are (13,10), (9,14), (14,), (13,3) in the README units. It makes no timing correction from hidden geometry.

physics_model.free_indices(microphones=10,events=14) returns C-order free-state indices. pack(state) maps a (24,5) float64 state to (85,); unpack(parameters) restores the fixed zero coordinates and returns (24,5). predict_measurements(state,intervals,speed=340) returns successive, between and displacement arrays in the data shapes and units. This helper supports generic sensor/event counts for analytic physical cases. residual_jacobian(state,data) is the bound-task 295-vector and (295,85) analytic matrix, with columns carrying the physical coordinate, offset and drift units described in approach.md. A coincident source and sensor raises ValueError.

solvers.normal_step(jacobian,residual) returns the explicit weighted normal-equation update, using the fixed 295-entry variance vector. uniform_starts(seed=20261029,count=30) yields target-independent states. gauss_newton(initial,data,max_iterations=100,fit_clocks=True) returns state and a diagnostic dict containing convergence, final objective, history and iteration count. fit_clocks=False restricts updates to geometry columns and is used only for the notebook's wrong-clock ablation. reconstruct(data,seed=20261029,starts=30,fit_clocks=True) returns ({'reconstruction': (1,24,3) float64}, diagnostics). Diagnostics contain full estimated clock nuisance state, selected start, number of successful starts, and every start's finite objective or explicit null. No hidden assets are read by any of these functions.

visualization.review_figures(data,result,diagnostics,truth,upstream,repeat_result,repeat_diagnostics,clock_free_result,clock_free_diagnostics,privileged) returns five Matplotlib Figures. This maintainer-only caller receives explicitly loaded surveyed xyz and identified original outputs after fresh reconstruction. No backend is selected in library imports. The notebook actively reconstructs full inputs for the primary, independent-start repeat, and clock-free ablation before plotting. It evaluates the fresh primary via the independent Judge, prints runtime and metrics, and compares original and fresh results with their roles stated. Archived TDOA-M is only a labeled privileged-frame pairwise-distance comparison.

evaluation/judge.py is standalone, imports no src module, and resolves truth, thresholds and public data relative to itself. Its read_positions, cosine, range_nrmse, observed_residuals, score and evaluate functions implement the declared shape, gauge, metrics and asset checks independently. It profiles clock nuisances from the submitted geometry and public observations. main accepts required --prediction and --report paths relative to caller cwd, writes UTF-8 finite JSON, and returns 0/1/2 for pass/quality fail/error. Missing, malformed or nonfinite input yields empty metrics; report-write failure is a diagnostic stderr error. No baseline fallback replaces actual surveyed truth.

`test/fixtures/upstream_stages.npz` is a frozen independent original computation consumed by comparing_test/test_original.py and unit_test/test_physics.py; no fixture is generated by the cleaned method. `notebooks/reference_outputs/upstream_original.npz` identifies two original joint runs and their restart tables. `upstream_privileged_comparator.npz` identifies original TDOA-M in its surveyed microphone frame, never relabeled fresh or truth. test/validation.md records complete provenance, original warnings, failed alternatives, CPU/backend and command evidence.
