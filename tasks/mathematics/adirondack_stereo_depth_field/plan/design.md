# Shipped interfaces and execution

All clean computations use NumPy2.4.6; Matplotlib3.11.1 is used for notebook figures. Original C++/IIO/WSL, private image decoding and upstream capture tooling are absent from task runtime. No generator is shipped because the original acquired images are reused.

`preprocessing.load_observations(path)` loads NPZ with pickle disabled, requires `left_image,right_image` uint8(1,496,718,3), and returns two HWC arrays without modifying their pixel values. Standard entry point is `python -m src.main`, from task root.

`physics_model.project_points(points)` accepts (...,3) coordinates in left-camera mm, converts to float64 and returns left/right (...,2) pixel coordinates. `depth_from_disparity(disparity)` accepts real pixel disparities and returns float64 depth in mm. Camera constants are explicit module constants matching README. `census_bytes(image)` accepts HWC RGB, converts to float32 only for rank arithmetic and returns uint8(H,W,12) packed descriptor bytes. `cost_volume(left,right,dmin=-127,dmax=0)` returns float32(H,W,dmax-dmin+1) costs, with infinity for unavailable correspondences. It explicitly constructs both descriptors and counts bits; no opaque stereo API is used.

`solvers.minplus_message(values,p1,p2)` accepts float32-compatible (...,D) predecessor costs, returns the explicit truncated-label message of identical shape/dtype. `aggregate(cost,method='mgm',directions=8,p1=24.,p2=96.,capture_points=None)` accepts HWD costs. Supported methods are mgm,sgm,ocsgm,wta and direction counts2,4,8; source only defines eight safe passes. It returns integer winning **label indices**(H,W), not signed labels, and diagnostics. Optional points are integer(K,2) row,column indices. Diagnostics then contain unary_samples(K,D), pass_samples (a list of direction-count arrays), sum_before_correction_samples and aggregate_samples, all independent float32 snapshots. Invalid aggregate entries preserve NaN in snapshots; only selection working storage replaces nonfinite entries with infinity. Peak dense arrays are cost, one recursive pass and summed cost, roughly3x182MB at the bound shape, plus small temporary wavefront arrays. Pass storage is released before selection. No file side effects occur.

`main.reconstruct(raw_path,method='mgm',directions=8,p1=8.,p2=32.,capture_points=None)` loads observations, constructs the unary, multiplies CLI-unit penalties by3, aggregates, converts ascending native label indices to positive left-minus-right disparities, and triangulates depth. It returns `(output,diagnostics)`, with output dict `disparity,reconstruction`, each float32(1,496,718). `main.main()` parses optional `--raw` and `--output` paths, defaults `data/raw_data.npz` and `output/reconstruction.npz` relative to caller workspace, creates output parent and writes the one submission NPZ. Importing main has no plotting/backend or reconstruction side effects.

`visualization.agreement(estimate,reference,mask,bad1_threshold=1.)` returns cosine NCC, range NRMSE and optional exceedance fraction in input units; the notebook passes None for depth to avoid labeling one millimetre as a disparity-pixel error. `image_panel(ax,image,title,*,unit='pixel',limits=None,cmap='viridis')` plots native scalar/RGB data on an existing axis. `point_cloud(ax,depth,rgb,title,stride=5)` projects depth mm into calibrated XYZ for rendering; stride changes display only. `save_review_figure(fig,name,arrays,export_dir=None)` optionally writes PNG/SVG/PDF and numeric NPZ/JSON into a private maintainer export directory. None of these helpers runs a solver or substitutes a reference. The notebook actively calls cleaned reconstruct for the bound primary and comparisons; it loads original precomputed arrays only under their explicit original-method label and actual measurements only for evaluation. Scientific figure numeric sources, native logs and export images are private maintainer artifacts.

The standalone `evaluation/judge.py` imports no solver. `evaluate(prediction)` returns strict JSON-compatible status,passed,metrics,thresholds,errors. It resolves hidden measured assets/config relative to its own file, while CLI prediction/report paths resolve from caller. Required keys,shape,real float32/64,finite values and physical denominator/depth are validated before scoring. Reference sentinel values are excluded solely by the fixed independent availability mask; required predicted arrays remain finite over the complete image. Malformed assets/submissions return error with empty metrics. Valid below-boundary results fail. `main(argv=None)` writes reports creating parent directories, returns0/1/2 for pass/fail/error; report-write errors return2 and stderr. Full precision is retained in JSON.

Tests reside only under test/. Upstream stage fixtures consume private captured numerical stages; whole original disparity in notebooks/reference_outputs/upstream_method.npz is used by pipeline parity and notebook comparisons. Upstream comparison arrays have their own consumers in parity tests and notebook plots. Independent physical tests and metric/Judge contracts do not import upstream code. Details, exact signatures and file inventory are semantically reviewed in test/validation.md after final execution.
