# Shipped interfaces and flow

`python -m src.main` loads `data/raw_data.npz`, calls `reconstruct`, and writes `output/reconstruction.npz`. It does not load truth, fixtures or upstream code. No plotting backend is changed by imports.

`preprocessing.load_data(path=None)` returns an unbatched dictionary of copied arrays; default path is task data. `observations(data,camera)` returns normalized direct RGB, column-by-RGB LED, and fluorescent profiles. `population_basis(population)` takes (44,31,3), returns channel-major eigenvector matrices and a (31,3) population mean.

`physics_model.interpolation_matrix(query,grid)` returns the dense query-by-grid linear interpolation/extrapolation matrix. `fourier_basis(n,degree=7)` returns (n,degree); degree must be positive odd. `wavelength_kernel(mapping,n)` returns pixel-by-n weights. `predicted_observations(sensitivity,attenuation,illumination,kernel,interpolation)` returns direct RGB and dispersed pixel-by-RGB predictions. `spectral_system(direct,dispersed,illumination,kernel,interpolation,bases,attenuation_basis)` returns matrix, rhs, residual, constraint, target and products; shapes depend on the selected basis sizes. All matrices and solver calculations are float64; wavelengths are metres, profiles and sensitivities relative dimensionless quantities.

`solvers.peak_mapping(measured,expected,degree=3,top_k=2)` returns three descending polynomial coefficients; degree denotes coefficient count. `icp_mapping(measured,expected,degree=3,iterations=500)` returns the same mapping representation. `reconstruct_camera(data,camera,basis_size=7,attenuation_size=7,fluorescent=True)` returns a dictionary containing reconstruction (31,3), unnormalized sensitivity, attenuation (321,), mapping, kernel, interpolation, bases, system, solution, predicted observations and measured profiles. `reconstruct(data,**kwargs)` returns `(result,details)`, with result (1,4,31,3) and four diagnostic dictionaries. These functions have no file-writing side effects.

`visualization.metrics(estimate,reference)` returns cosine NCC and range-normalized NRMSE. The observation, response, diagnostic, comparison and parity figure functions return Matplotlib figures from supplied measured or computed arrays. They do not manufacture results or run reconstruction implicitly.

The notebook uses the same local load/reconstruct functions, actively recomputes all four default reconstructions and twenty comparison reconstructions, and loads private actual truth and original measurements only for evaluation. The independent standalone Judge uses only NumPy and its own metric implementation. Tests consume frozen upstream arrays, never import upstream code. Private upstream capture and EXR decoding are outside this task and are not runtime dependencies.
