# Shipped execution flow

`python -m src.main` calls `load_data()` on task-relative `data/raw_data.npz`, calls `reconstruct(data, iterations=20)`, and writes only `output/reconstruction.npz`. Output is batch-first float64 `(1,1228,3)` with metres/metres/radians. The CLI prints initial and final full weighted errors. It creates the output directory and does not use hidden assets or upstream imports.

`src.preprocessing.load_data(path=Path('data/raw_data.npz'))` removes the sole batch axis and returns a dictionary of independent arrays: `edge_indices (1483,2)` int64, `relative_poses (1483,3)` float64, and `information (1483,3,3)` float64. It checks bound shapes and finiteness. `initialize(data)` returns float64 `(1228,3)`, entirely by composing consecutive observations from an identity anchor.

`src.physics_model.wrap(angle)` returns original principal radians in (-pi,pi]. `residual_jacobians(poses,data)` returns residual `(1483,3)` and two world-additive Jacobians `(1483,3,3)` in input edge order. Translation residual components are metres and the third is radians. `weighted_error(poses,data)` returns the dimensionless full weighted sum as a Python float. All physics is executable local mathematics.

`src.solvers.normal_equations(poses,data)` returns a full anchored-before-elimination CSC sparse Hessian `(3684,3684)` and gradient `(3684,)`. It assembles all six-coordinate edge blocks using general NumPy tensor contractions and SciPy COO accumulation. `reconstruct(data,iterations=20)` returns `(poses,history)`: poses `(1228,3)` float64 and full weighted errors `(iterations+1,)`. It fixes node zero by removing the first three linear coordinates, solves with SuperLU COLAMD, updates world coordinates and wraps headings. Nonfinite steps raise an error. It has no file side effects.

`src.visualization.comparison_metrics(poses,reference,data)` independently exposes three physical/evaluation metrics for notebook presentation. `trajectory_figure(initial,fresh,original,data)` creates a three-panel map; `residual_figure(initial,fresh,data)` displays every translation and heading residual; `convergence_figure(history,fresh,original)` displays the actual full cost sequence and separately scaled discrepancies. They return Matplotlib figures and do not change the backend.

The notebook actively loads the public observations, constructs fresh observation-only odometry, executes the complete local 20-step reconstruction, writes the declared output, and invokes the standalone Judge. It loads `notebooks/reference_outputs/original_method.npz` only for separately labeled original GN20/50 comparisons. It displays fresh odometry versus fresh all-edge fitting, preserved upstream original results, all-edge physical residuals, convergence and mixed-unit metrics. No archived array substitutes for a fresh reconstruction.

`evaluation/judge.py` uses only standard library and NumPy, and imports no solver module. Its `score(x,reference,raw)` independently computes fixed-gauge position, circular heading and canonical forward errors. `evaluate(prediction,assets=HERE)` validates assets, exact submission keys/shape/float64/finite values/anchor/principal angle, and uses actual ground truth if present, otherwise method reference. `main(argv=None)` implements caller-relative prediction/report paths and evaluator-relative assets, status pass/fail/error with native 0/1/2, nested report creation, and report-write diagnostics.

Frozen `test/fixtures/original_g2o.npz` supplies original initial poses, original one-step and final/repeat results, and all original edge errors/Jacobians. The ill-conditioned one-step result is retained as evidence but is not treated as an invariant floating-point coordinate target. `original_linear_system.npz` contains original upper-triangle sparse H, original right hand side and original LLT step for independent system and backward-error tests. Normal tests consume frozen numbers, never an upstream executable. `evaluation/baseline_reference.npz` contains original GN20 method reference, not truth. `notebooks/reference_outputs/original_method.npz` contains original initial/GN20/GN50 arrays used in the notebook. All original source, compiler capture clients, logs, full original data including unused VERTEX initial estimates, optical rejection investigations and provenance are maintained outside the task.
