# Implemented mathematics

Each pose is x=(t_x,t_y,theta). A rotation is R(theta)=[[cos,-sin],[sin,cos]]. Observed z=(z_x,z_y,phi) maps the destination pose origin into the source pose frame. Let q=R(theta_i)^T(t_j-t_i), u=q-z_translation, and e_translation=R(phi)^T u. The angular error is wrap(theta_j-theta_i-phi), using the original fmod convention (-pi,pi]. This is the translation/angle coordinate chart of Z^-1 T_i^-1 T_j; it is not the Lie algebra logarithm, and it is not the reversed residual used by some ports.

The objective is one half sum e^T Omega e, with the complete provided symmetric positive definite information Omega. Logs and evaluation report the full sum (twice the minimized objective). Omega has the inverse products of metre/radian coordinate units. No robust kernel, noise fitting, damping, regularizer, edge pruning, or outlier mask is used. There is no independent absolute truth; supplied information is a processed nominal weight, not verified independent noise variance.

The source-pose translational Jacobian is -R(phi)^T R(theta_i)^T, and the destination-pose translational Jacobian is its negative. Write q=(q_x,q_y). The source heading derivative of translation is R(phi)^T(q_y,-q_x); the destination heading derivative is zero. Angular derivatives are -1 and +1. These are derivatives with respect to world-additive coordinates, not body-frame composition increments. Rotation wrapping is locally differentiable away from its branch cut.

Build H=sum J^T Omega J and g=sum J^T Omega e. Remove the first three coordinates, fixing pose zero exactly to identity. Solve H_free delta=-g_free with SciPy SuperLU (`spsolve`, COLAMD ordering). Add delta directly to each free world coordinate, then wrap all headings. The author oracle uses Eigen SimplicialLLT with block AMD ordering; the factorization backend is the only selected numerical backend difference. The update, observations, weights, initialization and schedule are preserved. Run exactly 20 undamped Gauss-Newton iterations; no cost-based termination or line search is added. The first step increases cost, then subsequent steps converge. A 50-step original run independently establishes stability of the final result.

Initialize only from observations: anchor pose zero, then for each consecutive i to i+1, t_next=t_i+R(theta_i) z_translation and theta_next=wrap(theta_i+phi). Exactly one sequential constraint is required for each consecutive pair. Original file VERTEX estimates are neither bundled nor used; no original trajectory acts as calibration.

The original anchored initial system has estimated condition number about 7.45e16 because of extremely unequal supplied weights. A preselected one-step coordinate tolerance failed and is explicitly retained in private evidence. Independent same-original-H different sparse orderings disagree by up to .00283 in a step coordinate despite tiny backward errors. The revised prewritten linear-stage test therefore compares original H and right hand side independently by induced infinity/vector infinity relative norms, and requires the cleaned step's backward error against the ORIGINAL H/b to be at most 1e-14. This does not change the strict full 20-step parity (1e-5 m, 1e-6 rad) or final evaluation boundaries.

Evaluation separates units: maximum Euclidean node position discrepancy and maximum absolute circular heading discrepancy against a method reference. There is no fitted alignment, arbitrary scale, or mixed-unit scalar NRMSE. All 1483 constraints contribute to forward weighted consistency.
