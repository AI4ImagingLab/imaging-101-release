# Actual shipped interfaces and execution

All modules use only Python, NumPy and Matplotlib. No source repository, domain library, video decoder or cross-task module is imported by runtime, tests, evaluator or notebook. Private upstream verification and original video decoding are archive operations, not shipped execution.

- `preprocessing.load_data(path='data/raw_data.npz')` loads with allow_pickle=False, requires exact batch-first (1,84,240,320) uint8 `frames`, returns its unbatched (84,240,320) array. `as_matrix(frames)` accepts (T,H,W) uint8 and returns (H*W,T) float64 normalized ADU; `as_movie(matrix,shape)` returns (1,T,H,W) float64 in original pixel order, normally a view. Subsampling in experiments calls `as_matrix` on explicit temporal slices.
- `physics_model.forward(low,sparse)` returns the elementwise additive image matrix. `shrink(matrix,threshold)` is the entrywise soft proximal map; `singular_threshold(matrix,threshold)` is the exact nuclear proximal map using the smaller Gram eigenproblem. Inputs/outputs are real arrays of matching matrix shape, with no clipping or hidden reshape.
- `solvers.decompose(matrix,mu=None,lmbda=None,relative_tolerance=1e-7,max_iter=3000)` performs explicit fixed-penalty iterations. It returns L,S and a dictionary: history with columns iteration/Frobenius additive residual/fraction(abs(S)>1e-10), iterations, relative_primal, converged, mu and lambda. Defaults infer the paper/source-compatible fixed constants from the complete input matrix. Nonfinite or zero observations and nonpositive algorithm constants are rejected.
- `solvers.reconstruct(frames,lambda_factor=1.,relative_tolerance=1e-7,max_iter=3000)` creates the normalized matrix and scales default lambda by lambda_factor. Returns a dictionary with both declared full batch-first movie arrays and the same diagnostic dictionary. No file side effects.
- `main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads native observations, reconstructs, creates the output parent and writes only the two arrays into a compressed NPZ. It returns (result,diagnostics). The standard entry `python -m src.main` calls run and prints scalar diagnostics. Importing main does not change plotting backend.
- `visualization.summary(result,info)` computes rank/sparse/energy statistics; `experiments(frames,canonical,diag)` runs full-data lambda variants, temporal subsets and rank1/3/5 PCA, returning selected preview arrays, trace arrays and measured records. No variant is loaded from archived reconstruction. `figures(frames,result,diag,upstream,exp)` builds four figures; upstream is an identified independently captured residual trace, not a solver input. `export(figs,exp,directory)` writes private PNG/SVG/PDF, experiment_metrics.json and figure_source.npz only if the notebook receives IMAGING_REPORT_DIR.

## Standard and review paths

The CLI path is raw NPZ -> load_data -> reconstruct -> as_matrix -> decompose -> shrink/singular_threshold -> as_movie -> output NPZ. The evaluator is a separate process and never imports solver modules. `evaluate(prediction,asset_dir=ASSETS)` validates exact float64 keys/shapes/finite values and configured positive boundaries, prioritizes actual truth if ever available, otherwise uses baseline_reference.npz, then checks both components and the public measured additive model. Its reference paths resolve relative to the Judge file; supplied prediction/report CLI paths remain caller-relative. Errors return empty metrics/exit2, valid poor results exit1, passes exit0. UTF8 JSON never contains NaN/Infinity. Report-write errors diagnose stderr/exit2.

The active notebook starts in the task workspace with inline display, reconstructs complete native observations, writes and independently evaluates its fresh output, then runs actual supplementary experiments and renders four figures. It reads only upstream_trace.npz for the visibly labeled original convergence curve and upstream_measurements.json for independent original diagnostics. Fresh measurements and variants are recorded separately in reference_outputs/cleaned_measurements.json and private export sources. A3600-second per-cell timeout accommodates complete full-native repeated reconstructions on the measured CPU backend. There is no cache-preview path replacing reconstruction.

Tests under unit_test/ verify proximal formulas/optimality/equivariance, independently known metrics, all malformed/passed/poor Judge cases, every required component and backend/README constants. comparing_test/ consumes frozen original first-update matrices and full source components from the hidden standard-method file; it compares all full1657-iteration outputs/trace and additive physics without importing original code. Each NPZ under fixtures/reference_outputs has its documented consumer in test/validation.md. There is no generate_data.py because no new synthetic observation is generated.
