# Implemented mathematics and algorithm

The unknown `u` is a real centered Y/Cb/Cr array with shape `(3,432,640)`, in encoded intensity units. All five JPEG padding rows are unknowns constrained by observations and included in the objective. Public integer coefficients `a` have shape `(3,54,80,8,8)`, and positive step tables `q` have shape `(3,8,8)`. The native observation is an existing public-domain SpaceX photograph, not a generated degradation. No uncompressed original camera image is known.

The acquisition is `a=round(D(u)/q)`, where `D` is orthonormal type-II DCT on each 8×8 block. `blocks(u)` reshapes the image without changing spatial order, `transform(u)` computes this DCT, and `inverse(b)` applies its transpose/inverse. Frequencies are stored vertical then horizontal; block axes are row then column. There is no chroma subsampling, inter-block transform, JPEG gamma inversion or data downcast. Feasibility means every transformed coefficient is in `[q(a−0.5),q(a+0.5)]`. Rounding ties are deliberately accepted on either closed endpoint.

For every coded pixel `p`, define forward column and row differences `dx(u),dy(u)` with zero outgoing faces. The vectorial TV is the sum over pixels of `sqrt(sum_c(dx_c²+dy_c²))/sqrt(3)`. Its subgradient is the negative divergence of the normalized joint gradients, with the zero vector chosen where the joint norm vanishes. The implementation forms outgoing zero faces explicitly, so no wrapped difference or hidden boundary contribution enters the adjoint.

The target criterion adds `alpha/2 * sum(((D(u)-a*q)/q)²)`, where `alpha=0.001*2*255*sqrt(2)`. This is the author's native coefficient-probability term, not an added uniqueness device. Division by `q²` occurs in its coefficient gradient; applying `D` transpose gives the spatial gradient. The probability term and TV are both implemented locally. The public criterion fixes the target and permits different converged inverse methods.

The shipped optimizer reproduces the original program's native `w=0` branch. Initialization is the ordinary inverse DCT of `a*q`. Let `x` be the current projected image, `z` its previous projected image, and `t=1` the initial acceleration scalar. For a selected total update count `N=2000`, the radius is `R=sqrt(432*640)/2` and fixed update distance is `R/sqrt(1+N)`. Each update uses `tnew=(1+sqrt(1+4*t²))/2` and extrapolates `x` by `(t−1)/tnew * (x−z)`. It computes the full TV-plus-coefficient subgradient, divides each channel's gradient by that channel's spatial L2 norm when nonzero, and moves by the fixed update distance. It then DCT-transforms the result, clips coefficients to their measured intervals, and inversely transforms back. Previous projected states and `tnew` become the next update's history. The algorithm stops after the requested total number of updates, exactly as the upstream algorithm does; there is no line search or alternate learned prior.

`reconstruct(coeff,q,iterations=2000)` exposes this finite numerical procedure for maintainer reproducibility, but it is not the scoring identity. Evaluation checks the public objective and coefficient feasibility directly. The native original 2000-update objective is 1069561.9791301962; the score allows an upper value 1069668.9353281092, a fixed 0.01% numerical objective allowance. Maximum raw coefficient-interval violation is bounded by 0.001 intensity-coefficient units. Midpoint inversion has objective 1338936.5010448082 and fails the objective criterion; zero also fails feasibility. No true-image NCC/NRMSE, clipping, best-fit rescaling or image alignment is used.

The implementation computes reconstruction in float32 using general SciPy DCT primitives and local array mathematics. The objective and evaluator use float64 diagnostics. The original uses Ooura float32 DCT butterflies; its initialization differs by at most 3.8146973e-5 intensity units from SciPy in exploratory checks. At the exact same spatial input, independent original-C TV-gradient capture agrees with the local gradient within 3.5762787e-7. Full nonlinear trajectory comparisons therefore use scale-aware RMS and objective criteria, recorded in validation. Different arithmetic is not claimed to be bit identical.

An independently confirmed upstream defect prevents selection of its nonzero-TV2 branch: its Hessian norm's spatial boundary stencil is not the derivative of the advertised boundary objective. A nondegenerate finite-difference check has maximum error 2.0168058630 at boundaries and less than 1e-9 at interior points. The notebook retains an actual upstream TV2 reconstruction solely as a labeled diagnostic comparison. It is not a corrected implementation or the selected reference method. Ordinary TV and its boundary adjoint are separately verified.
