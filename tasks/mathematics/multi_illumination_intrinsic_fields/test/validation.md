# Validation and source traceability

## Bound inverse and semantic identity

This task recovers two complete relative intrinsic fields, reflectance and reference-light shading, from ten real measured illuminations. It is not ordinary image denoising, photometric-stereo normal recovery or a single gain fit. The complete600×534 dinosaur image and all70430 independent foreground pixels are bound; first official TAR object was selected before any inverse result. No outcome-based crop, mask or illumination choice is used. Cross-repository semantic searches found no previous intrinsic reflectance/shading task. The primary estimator is parameter-free Weiss; better optional Weiss–Retinex is not substituted after inspecting quality.
