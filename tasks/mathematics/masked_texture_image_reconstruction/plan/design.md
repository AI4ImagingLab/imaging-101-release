# Shipped interfaces and caller flow

python -m src.main is the sole standard entry. main.main() reads visible data through preprocessing.load_observations, runs solvers.reconstruct at order2/8000updates, saves output/reconstruction.npz float64 reconstruction(1,240,320), prints actual elapsed time, and returns the complete solver result dictionary. No module import changes a plotting backend. No upstream library, paper, hidden truth, archive, other task or checkpoint participates in this path.

preprocessing.load_observations(path='data/raw_data.npz') returns observations and boolean mask, unbatched(240,320). It validates exact public keys/shapes/dtypes/finite values and zero missing storage. The CLI input/output relative paths intentionally use the task workspace.

physics_model.acquisition(image,mask) applies fixed binary sampling to equal-shaped arrays. gradient(x) accepts(H,W), returning(H,W,2); gradient_adjoint(p) returns(H,W). symgrad(v) maps(H,W,2) to(H,W,3); symgrad_adjoint(q) reverses those shapes with the weighted tensor metric. symgrad2(w) maps(H,W,3) to(H,W,4); symgrad2_adjoint(r) returns(H,W,3). All derivative computations are float64 with explicit unit-grid finite boundaries, no files or mutation. _negative_backward_adjoint is an internal boundary-aware helper.

solvers.project_ball(p,radius=1.,weights=None) returns an independent projected array of the same shape. solvers.group_norm(p,weights=None) returns the sum of pointwise norms. solvers.reconstruct(observations,mask,order=2,niter=8000,alpha1=sqrt2,alpha2=sqrt2,capture_steps=()) accepts equal(H,W) arrays, returns a dictionary: u(H,W),v(H,W,2),w(H,W,3),objective(niter+1),snapshots keyed by captured update numbers, plus sig,tau,operator_norm scalars. Auxiliary v/w fields unused by lower orders remain zero and are not required solver outputs. Snapshots contain only fields actually active in the selected order. All returned arrays are float64 and no files are written. Exact budget/positive weights and basic array invariants are validated. The standard computation does not retain intermediate image snapshots unless requested.

generate_data.generate_observations(rgb,mask) accepts an existing uint8(H,W,3) photo and independent binary mask(H,W), returns two dictionaries: public observations(1,H,W)float64/mask(1,H,W)bool, and private reconstruction(1,H,W)float64 actual photograph. This hidden acquisition-preparation helper neither loads source files nor exposes truth to the standard run. Existing photographic mask is reused; no random source or added noise is generated.

The active notebook imports cleaned modules, reconstructs complete bound observations under all three orders, writes a fresh standard submission and invokes the standalone Judge. It reads actual hidden photographic truth for maintainer-only review and notebooks/reference_outputs/upstream_methods.npz solely for independently identified original comparisons. That file contains order1/2/3 complete original images and corresponding objective histories; original image agreement and objective traces are explicit consumers. Original full-resolution auxiliary fields stay only in the private complete capture. measurements.json distinguishes historical paper reports from this task's original runs. Neither an archived source estimate nor hidden truth is substituted for a fresh reconstruction.

visualization.metric_pair(x,truth,mask) accepts equal-shaped unbatched images and a boolean mask and returns NCC, full and missing-only NRMSE and known_error scalar values. visualization.make_figures(y,mask,truth,fresh,upstream) takes native(240,320) observations, boolean mask and truth; fresh maps each order1/2/3 to a solver result dictionary, and upstream maps named order/objective arrays to independent original values. It returns(figures,numeric,table): five Figure objects, exact plotted arrays and full-precision metric dictionaries. It actively runs three alpha1 sensitivities at2000updates and does not read files. visualization.export_figures(figures,numeric,metrics,directory) creates the supplied private directory and writes PNG/SVG/PDF plus numeric_sources.npz/metrics.json/hash_manifest.json. Neither plotting helper selects a backend. Plotting does not run during the standard CLI. The notebook owns inline backend selection and a justified1800s execution timeout; three full8000-update original runs took about591s combined before plotting. It actively runs its selected complete benchmark path rather than a cache preview.

evaluation/judge.py imports only standard library and NumPy. ASSETS resolves to its own directory; hidden actual truth has precedence over the reserved baseline filename. evaluate(prediction) returns(report,code), validating key, exact shape and realfloat64, finite values, public mask, nondegenerate reference and finite/legal mandatory thresholds. score(a,b,mask) independently computes documented metrics. No src imports, implicit rescaling/cropping or submitted-code execution. main(argv=None) implements mandatory --prediction/--report, writes UTF8 finite JSON and creates report parents. Codes0/1/2 distinguish pass/validpoor/error, including report-write failure.

All tests use test/unit_test and test/comparing_test. Frozen test/fixtures/upstream_stages.npz is captured by unmodified original code before local extraction. Consumers cover acquisition, exact differences, weighted adjoints, constrained primal/dual updates, projected geometry, complete native source parity, independent numeric metrics, bad submissions/configurations/evaluator errors and fresh pipeline behavior. test/validation.md records actual source/data hashes, source equation/function/test mapping, original/local/notebook commands and all gate states.
