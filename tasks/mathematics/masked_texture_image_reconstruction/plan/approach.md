# Implemented weighted TGV inverse

The unknown u is the complete240x320 dimensionless encoded-luminance image on the author native row/column grid. Public observations y=M*u retain30.16536458333333% of its pixels. The fixed author mask is not generated from intensities. The private generator converts the existing normalized RGB photograph as .3R+.59G+.11B and applies that mask, without additional noise. Missing zeros are not black measurements. Actual complete photographic pixels supply hidden truth; they are not an estimator. There is no physical scene-length or radiance calibration.

Let D denote a forward finite difference: D0u[r,c]=u[r+1,c]-u[r,c] except zero on the final row; D1 similarly along columns with final-column zero. Unit spacing is one pixel; no continuous pixel area factors enter this discrete objective. The vector gradient G=(D0,D1) uses Euclidean norm. Its adjoint is negative backward divergence with zero-flux boundary: top row -p[0,:,0], bottom row +p[-2,:,0], and analogous columns; the final p row/column does not couple across the boundary.

The symmetric derivative E uses backward differences B0v[r,c]=v[r,c]-v[r-1,c], with first row zero, and B1 with first column zero. E(v)=(B0v0,B1v1,(B0v1+B1v0)/2). Its tensor norm uses weights(1,1,2), so sqrt(q0²+q1²+2q2²) is the true Frobenius norm, not an unweighted3-vector norm. The adjoint E* is defined with respect to that tensor inner product and the vector Euclidean inner product. It is computed explicitly as (B0* q0+B1* q2,B0* q2+B1* q1); no extra factor of two appears because the off-diagonal tensor multiplicity cancels the half in E. B0* has row0=-q[1], rowlast=q[last], and interior q[row]-q[row+1]; B1* is analogous.

For order three, H(w)=(B0w0,B1w1,(2B0w2+B1w0)/3,(B0w1+2B1w2)/3). The third-order tensor metric has weights(1,1,3,3); the input second-order metric has weights(1,1,2). Consequently H*(r)=(B0*r0+B1*r2,B1*r1+B0*r3,B0*r2+B1*r3). The local code exposes all these operators and independently tests their weighted adjoint identities and captured original probes.

Define L(z;weights)=sum_pixels sqrt(sum_components weights*z²). With constraint C={u: u[M]=y[M]}, the selected second-order objective is indicator_C(u)+L(G u-v;(1,1))+alpha1*L(E v;(1,1,2)). alpha1=sqrt2. First-order comparison is indicator_C(u)+L(G u); third-order comparison adds w and uses indicator_C(u)+L(G u-v)+alpha1*L(E v-w;(1,1,2))+alpha2*L(H w;(1,1,3,3)), alpha2=sqrt2. There is no data averaging, Gaussian likelihood, intensity clipping or extra smoothing. At all feasible iterations the recorded original objective equals this regularizer. Upstream uses an L1 acquired-pixel deviation as a diagnostic instead of infinity at infeasible initialization; the local diagnostic preserves this. Its finite iteration-zero value is not a feasible objective or a duality gap.

All primal fields u,v,w and extrapolated fields are initialized to zero; all dual fields p,q,r to zero. Let n be the largest singular value of the order-by-order nonnegative upper-bidiagonal matrix with diagonal sqrt8 and superdiagonal1. This is the original conservative product-operator bound, not a fitted norm. For orders1/2/3 it is2.8284271247461903,3.372281323269015,3.5756483139187023. Set sigma=100/n, tau=1/(100*n), so sigma*tau*n²=1, preserving the original step-size ratio and its non-strict-boundary convention.

For order2, update p by projection of p+sigma*(G ubar-vbar) onto the pointwise Euclidean unit ball; update q by projection of q+sigma*E(vbar) onto the tensor-metric ball of radius alpha1. In order3, replace E(vbar) by E(vbar)-wbar and additionally project r+sigma*H(wbar) onto the third-order-metric ball of radius alpha2. In order1, omit v,q,w,r and use p+sigma*G ubar. Each projection explicitly divides each vector/tensor by max(norm/radius,1); all Hilbert metric conventions are retained.

Primal updates are u_new=projection_C(u-tau*G*p), v_new=v-tau*(-p+E*q), and for order3 w_new=w-tau*(-q+H*r). After each update set the corresponding extrapolate to2*new-old. The observation projection overwrites acquired pixels exactly, without changing missing ones. The dual updates all use old extrapolates. There is no line search, adaptive step, trainable network or general optimizer. Stop after exactly8000 updates, as fixed before capturing the original oracle. This is a finite-budget reference, not a claim of mathematical convergence. All objective values0..8000 are computed, not interpolated.

Native frozen original operator tolerance is absolute1e-12,30-step primal/dual stage tolerance1e-11, and native complete image tolerance1e-10, selected before extraction. The local implementation agrees bit-for-bit with complete original TV and TGV2 runs and their objective histories; TGV3 is separately measured. No original domain package, OpenCL framework or cross-task implementation is imported.

Standard truth metrics are uncentered cosine NCC and RMS error divided by complete truth dynamic range. Missing-only NRMSE uses exactly the author mask complement with the same full-image dynamic range; no data-driven ROI is chosen. Known-pixel maximum error checks observation consistency. Boundaries are respectively.9*baseline NCC,1.1*each baseline NRMSE and1e-8 known-pixel numerical tolerance. All four must pass, without alignment/scale/crop. Poor zero or constant fills fail. Hidden truth is actual complete photographic data before synthetic masking.
