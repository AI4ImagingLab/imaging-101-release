# Interfaces and actual flow

`python -m src.main` calls `preprocessing.load_data(path=None)`, then `solvers.reconstruct(image,**kwargs)` and writes only the required array to output/reconstruction.npz. Loading returns an unbatched(1585,886,3)float64 measured image. The path default is resolved from the module location. No reference arrays are consulted.

physics_model.positions(shape,size,step) returns ordered(row,column) patch origins. patch_columns(image,size,step) returns(size squared,number of patches), column-major patch vectors. overlap(columns,shape,size,step) is its unweighted adjoint. gradient(image) returns two same-shaped float arrays with replicated-edge forward differences. window(size) returns a separable square Hamming window; weights(shape,size,step) returns that window and the image-sized overlap denominator. psf_prior(size,alpha,beta) returns the spectral regularizer; estimate_psf(sharp,blur,prior) returns a complex(size,size) Fourier kernel. features(image,gx,gy,i,j,size) returns(size squared,4) ordered features.

solvers.reconstruct_channel(base,blur,psf_size=500,transfer_size=60,alpha=.3,beta=.3,iterations=3,capture=False) returns reconstructed scalar image,49by49byPatchCount cropped diagnostic kernels, and a dictionary. The dictionary always includes the initialization; capture=True additionally stores per-iteration first Fourier kernel, full blurred guide, first normal matrix/rhs, all4byPatchCount transfer coefficients and full reconstructed image. These are real/complex float64 arrays as appropriate. All coordinates and kernel offsets are pixels, intensity is relative digital signal. The routine has no filesystem side effects. reconstruct(image,**kwargs) returns(batch-first RGB,details), preserving green; details keys0and2 identify red/blue channel diagnostics. The default full pipeline uses three iterations.

The active notebook calls the same local routines with capture=True, reads original output only for comparisons, and freshly runs supplementary parameter variants. visualization.image_comparison, zoom_comparison, psf_figure and diagnostics return Matplotlib figures. Display clipping occurs only in visualization. visualization.metrics calculates the same independently tested NCC/range-NRMSE as the standalone Judge. The Judge never imports reconstruction code. Test fixtures are numeric captures from the private original run; no upstream module is imported by any task file. No library module selects a Matplotlib backend.
