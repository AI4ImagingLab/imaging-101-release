# Shipped runtime and interfaces

The standard entry point is `python -m src.main` from the task directory. It reads only `data/raw_data.npz`, reconstructs with local modules and writes `output/reconstruction.npz`. It never opens evaluator references, frozen fixtures, notebooks or upstream source. Paths are relative to the caller's workspace. `src.main.run(input_path='data/raw_data.npz', output_path='output/reconstruction.npz')` returns `(height, diagnostics, elapsed_seconds)`, creates the output parent and writes one NPZ key `reconstruction` of real float64 shape (1,457,235). Importing main does not select or change a Matplotlib backend.

## Modules and signatures

`src.preprocessing.load_observations(path)` loads with `allow_pickle=False`, removes exactly the declared batch axis and returns four copied arrays: `images[457,235,36]` float64 dimensionless, `angles[36]` float64 radians, `mask[457,235]` bool and `specular_mask[457,235]` bool. It checks compatible shapes and finite observations. `decompose(images, angles, mask)` performs per-pixel trigonometric least squares and returns `(rho, phase, intensity)`, each float64[457,235], units dimensionless, radians and dimensionless, respectively. Background is zero.

`src.physics_model.diffuse_zenith(rho, refractive_index=1.5)` returns a same-shape real zenith-angle array in radians from the explicit Fresnel inverse. `specular_zenith(rho, refractive_index=1.5)` returns same-shape angles using the fixed 0.01-radian lookup table; values outside its range become NaN. The bound sample has none in foreground. `angular_fields(rho, phase, specular_mask)` returns `(theta, adjusted_phase)` as image-shaped float64 arrays in radians, with the specular corrections applied locally.

`fit_light(theta, phase, intensity, diffuse_mask, direction=LIGHT_DIRECTION)` returns `(light, chosen_basis, update_count)`. `light[3]` is float64 in intensity/albedo units along right/up/view axes. `chosen_basis[Ndiffuse,3]` is the selected normal basis; `update_count` is an integer. It uses a copied direction argument, not mutable global state. `LIGHT_DIRECTION` is the unnormalised float64 vector (2,0,7). `REFRACTIVE_INDEX=1.5` and `SMOOTHING=0.1` are explicit constants matching the public calibration and hidden solver plan.

`assemble_height_system(theta, intensity, phase, light, mask, specular_mask, smoothing=SMOOTHING)` returns `(C,d)`. C is float64 CSR[222682,74331] and d is float64[222682] on the standard full sample. The derivative part has inverse-pixel units; the unknown height is in pixels. C and d combine heterogeneous physical equations without statistical whitening, as in the source. The function accepts image-shaped arrays and a three-component light vector, enumerates foreground row-major and has no file side effects. Padding, boundary choices, smoothing and gauge are implemented in this module; they are not delegated to a surface-reconstruction library.

`src.solvers.reconstruct(images, angles, mask, specular_mask, smoothing=0.1)` returns `(height, diagnostics)`. Height is float64[457,235] in pixels, zero outside mask. It calls decomposition, diffuse-angle inversion for illumination, scalar alternating illumination fitting, mixed-angle conversion, sparse assembly and the direct linear solve. Diagnostics include image-shaped `rho`, `phase`, `intensity`, `theta`, `adjusted_phase`; `light[3]`; integer `light_iterations`; equation residual `residual[C.shape[0]]`; stationarity residual `normal_residual[C.shape[1]]`; CSR `C`; and `rhs[C.shape[0]]`. These are returned for tests/notebook review; the CLI does not write a redundant intermediate archive.

`src.visualization.metrics(estimate, reference, mask)` accepts matching real image arrays and a boolean mask; it returns Python floats `ncc`, `nrmse`. Zero-norm or constant references raise ValueError. `image_panel(arrays, titles, mask=None, cmap='viridis')` returns a Matplotlib Figure with one row of independently scaled images and colorbars. It does not save or choose a backend. Callers own figure display and closure.

## Notebook flow and comparisons

`notebooks/glossy_polarisation_surface_height.ipynb` locates the task root, imports these modules and actively reconstructs raw data. Its six scientific sections show acquisition and observation roles; explicitly identified upstream reference/no-ground-truth status; fresh reconstruction; upstream/fresh metrics and residuals; the computed zero-smoothing ablation; and computed robustness under calibrated-in-code artificial intensity perturbations. The notebook loads `notebooks/reference_outputs/upstream_measurements.npz` solely for its identified historical comparison, never as the fresh solution. The λ=0 and noisy-data runs use the same full mask and 36-image dimensions. Notebook execution figures and temporary executed notebooks are archived privately and omitted from final task output.

## Evaluator and tests

`evaluation/judge.py --prediction ... --report ...` imports only standard-library modules and NumPy. Hidden assets resolve relative to its own directory; supplied CLI paths remain caller-relative. A present ground_truth.npz takes precedence over baseline_reference.npz, including failure on malformed truth rather than fallback. The shipped task has only a baseline because independently measured truth is unavailable. The Judge loads the public mask for declared masked metrics. It strictly validates exact key set, shape, floating real dtype, finite values and zero background. It creates the report parent and returns 0/1/2 for pass/quality failure/input or evaluator error. A report-write failure is diagnosed on stderr and returns 2.

`test/fixtures/upstream_stages.npz` stores independently captured original preprocessing, angular fields, illumination, full sparse COO triplets/RHS and output height. Comparing tests consume these without importing original code. Function tests use analytic modulation, the independently written forward Fresnel law, flat geometry, adjoint and objective-gradient cases. Judge tests cover valid float32/64, poor outputs, missing/corrupt/wrong-key/wrong-shape/wrong-dtype/object/NaN/Inf/background cases, asset failures, truth precedence, foreign cwd and report-write failure. `test/validation.md` is the sole provenance and completion record. Complete upstream source, capture scripts, original logs and MAT captures stay outside this task in the maintainer archive.
