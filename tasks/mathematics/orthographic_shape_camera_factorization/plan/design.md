# Shipped interfaces and execution flow

Each task is independent. NumPy handles explicit metric equations/SVD/pseudoinverses/linear algebra; SciPy only provides a generic principal matrix square root; Matplotlib is review-only. Source/GitHub checkouts and Octave are maintainer archive assets, never runtime imports. No domain solver, cross-task import or pretrained object appears.

* `preprocessing.load_observations(path)` checks finite float64 tracks[1,51,491,2] and returns a copy [51,491,2]pixels. `centre_and_scale(tracks)` returns normalized W[2F,P], centroids[2F,1]pixels and scalar image scale pixels. It rejects degenerate zero scale.
* `physics_model.symmetric_products(a,b)` returns six terms for symmetric3x3 metric equations. `metric_system(motion)` accepts affine motion[2F,3], returns A[3F,6],b[3F]. `metric_upgrade(motion,shape)` accepts motion[2F,3],shape[3,P], returns M[2F,3],S[3,P] and dict A,b,C,G,num,den,correction,Q with shapes as in approach. `forward(shape,cameras,translations)` takes [P,3]pixels,[F,2,3]dimensionless,[F,2]pixels, returns tracks[F,P,2]pixels. `joint_alignment(shape,cameras,reference_shape)` returns jointly aligned row shape/cameras and one orthogonal3x3gauge, including reflection. It never translates or rescales.
* `solvers.reconstruct(tracks)` returns shape[P,3]pixel-equivalent,cameras[F,2,3],translations[F,2],diagnostics. Diagnostics include metric_upgrade outputs plus normalized,translation,scale,singular_values,motion_affine,shape_affine. It performs no I/O. Generic SVD signs may differ across backends; the physical factor pair shares one unobservable orientation.
* `main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz')` loads the complete public observations, reconstructs all three quantities, creates output parent, saves batched NPZ, returns shape,cameras,translations,diagnostics,elapsed_seconds. `python -m src.main` exposes optional --input/--output and calls this full path. No plotting/backend operation occurs during import or standard reconstruction.
* `visualization.metrics(a,b)` reports cosine NCC and dynamic-range NRMSE on already aligned arrays. `plot_shape(ax,shape,title)` scatters all3Dlandmarks with pixel labels. `evaluation/judge.py` is independent of src: it validates exact keys/shapes/dtypes/finiteness; resolves truth then baseline relative to itself; fits one global orthogonal gauge and applies it jointly to shape/cameras; computes all required metrics and complete reprojection RMS using public tracks. Scaled arithmetic keeps extreme finite submissions as finite quality failures. CLI prediction/report paths follow caller cwd; report directory is created. Exit0/1/2 means pass/quality-fail/error; invalid inputs have empty metrics. Write failure returns2 with stderr.

The active notebook resolves task root, imports local source, calls main.run on raw observations, and invokes independent Judge. Original measurements are loaded only for labelled comparisons. Affine ablation reads fresh diagnostics, not reference coefficients; noise experiments reconstruct every point/frame anew. All arrays in test/fixtures/upstream_stages.npz are frozen native Octave outputs before extraction, consumed by test/comparing_test/test_upstream.py. The original rigid helper has no supplied scientific notebook; this notebook builds the six required review stages without claiming unrun historical algorithms. No observations are newly generated, so generate_data.py is omitted. Truth is absent; baseline_reference feeds Judge and upstream_measurements feeds notebook. All tests live in test; no duplicate tests/report tree or root wrapper exists.
