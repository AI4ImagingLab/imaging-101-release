# Shipped interfaces and actual data flow

Standard entry point `python -m src.main` calls run(output=Path('output/reconstruction.npz')), which loads only the two public arrays, reconstructs all15bursts with GAP-TV100, saves the sole reconstruction key, and returns (result,diagnostics,runtime_s). Parent directories are created; a JSON timing/shape/residual summary is printed by main. Importing src.main does not change a plotting backend. No CLI path loads hidden assets or upstream libraries.

preprocessing.load_data(path=Path('data/raw_data.npz')) checks exact keys, native batch-first shapes, float64/finiteness, calibrated mask range and positive per-pixel energy; it returns mask(14,256,256) and observations(15,256,256) without batch. The units and physical interpretation are stated in README. It does not estimate normalization from a hidden target.

physics_model.forward(cube,mask) maps time-first(T,H,W) to integrated(H,W) with an explicit increasing-index sum; adjoint(image,mask) returns (T,H,W). difference(cube,axis) accepts spatial axes1/2 and returns corresponding interior differences. difference_adjoint(dual,axis) restores the spatial dimension using zero-flux boundaries. chronological_cube(cube,burst_index) reverses temporal order on odd zero-based bursts, leaving even bursts unchanged. observed_residuals(movie,observations,mask) returns one relative L2 consistency value per burst, applying the same declared acquisition order. These helpers also support independent small physical tests.

solvers.tv_denoise(image,weight=.07,iterations=5) is the explicit finite two-direction dual clipping operator. reconstruct_burst(measurement,mask,method='gap',iterations=None,weight=.07,tv_iterations=5) returns mask-order(T,H,W) and diagnostic dict; None chooses100GAP or200ADMMiterations. It always starts independently from the acquisition adjoint, records actual per-iteration forward residuals and returns the prescribed native primal. reconstruct(data,method='gap',iterations=None,weight=.07) runs every exposure, converts each to chronology and concatenates into {'reconstruction':float64(1,210,256,256)}, with fifteen diagnostic records. There is no domain solver, hidden cache, source import or cross-task dependency.

visualization.review_figures(data,fresh_gap,fresh_admm,original_gap,original_admm,gap_diagnostics,admm_diagnostics) returns six Figures. All arrays are explicitly passed by the notebook after fresh full reconstructions. Figures show every measured exposure, all14effective masks, every210freshframe, selected original/fresh GAP/ADMM full-frame comparisons, temporal space-time slices and radiance/forward-fit tradeoffs, and actual convergence/parity. Display-only0..1grayscale bounds do not alter arrays or scoring. Library imports do not call matplotlib.use or save files.

The active notebook separates problem/data/physics/method/results/conclusion. It reconstructs all15GAP100and all15ADMM200paths in separate active cells, records actual runtimes and metrics, checks both against their separately identified original runs, evaluates the fresh main output through standalone Judge, and plots both complete comparisons. Its identified fresh measurement summary is stored in notebooks/reference_outputs/fresh_notebook_measurements.npz; it contains measured numerical comparisons/runtimes and no substitute video cache. Original GAP is kept only in evaluation/baseline_reference.npz, consumed explicitly as a method reference by parity and notebook; original ADMM is kept only in notebooks/reference_outputs/upstream_admm200.npz for full scientific comparison. test/fixtures/upstream_stages.npz stores original first-burst operators/TV/GAP1/2/5/ADMM1/2/5 plus independent three-burst repeats, consumed by comparing_test. No redundant full-array copies are shipped.

evaluation/judge.py imports no src. load_movie enforces the sole key, float64(1,210,256,256), finiteness and actual file existence. frame_metrics implements uncentered cosine and reference-range NRMSE without image alignment; score aggregates worst frame and all15physical residuals. evaluate validates finite positive thresholds/acquisition assets and uses actual ground_truth.npz if present, otherwise the explicitly reserved baseline_reference.npz. No filename guessing occurs. Reference/metric/raw paths are __file__-relative; CLI --prediction/--report paths are caller-relative. main writes finite UTF8JSON with status/pass/metrics/thresholds/errors and returns0/1/2. Input/evaluator errors have empty metrics, and report-write failure yields stderr/exit2.

Tests cover exact independently frozen original operators and complete pipeline; known coded summation and adjoint identity; finite-boundary gradient adjoints; TV constant and pre-dual return; alternating-order involution; known metric cases; all valid/poor/missing/key/shape/dtype/complex/nonfinite/corrupt/error/report-write contracts. All source/archive/paper/download/log materials remain outside the task. Runtime requirements are the validated pinned shared NumPy and Matplotlib subset; SciPy is only a private original MATLAB-file capture aid, not cleaned runtime.
