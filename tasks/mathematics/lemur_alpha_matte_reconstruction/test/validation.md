# Provenance and validation

## Bound scope and independent sources

This task reconstructs the complete 440 by 680 spatial opacity field from a real encoded RGB photograph and its independently authored manual trimap. Foreground and background colors are nuisance variables analytically eliminated by the selected closed-form color-line method. It is not foreground-color estimation, semantic segmentation or recovery of a known photographic alpha channel. No actual opacity truth is available.

Original modern reference repository: https://github.com/pymatting/pymatting . The GitHub commit API was actually queried during this batch; the exact downloaded revision is 6d5c4a6bed0e5672abac0bad078e594423ffe4fd. This is a verified remote revision, not a local tracking assertion. Private codeload archive source.zip SHA256 418c09488bd6427b2b41f8d70977490da0cd1f8c8aca85b476a19647f0d1dec5. The original source is MIT licensed; LICENSE retains its notice.

Selected mathematical paper: Levin, Lischinski and Weiss, A Closed-Form Solution to Natural Image Matting, CVPR 2006, author eight-page version https://www.ee.technion.ac.il/people/anat.levin/papers/Matting-Levin-Lischinski-Weiss-CVPR06.pdf . The separately archived paper is not bundled. The later 2008 journal publication is not silently substituted for this version. Modern reference-code paper: Germer et al., PyMatting: A Python Library for Alpha Matting, JOSS 5(54),2481,2020, https://doi.org/10.21105/joss.02481 . PyMatting is the original code of that software paper and a reference implementation of the earlier mathematical method; it is not claimed to be the 2006 authors' original release.

The real lemur photograph is by Mathias Appel, https://www.flickr.com/photos/mathiasappel/25419442300/ , released under CC0-1.0. The author-released crop and manual trimap are used at full resolution. The stored source RGBA alpha is uniformly 255 and is not opacity truth. The source's example lemur_alpha.png is neither ground truth nor public input. The manual trimap has values 0,0.4,1; its 38,666 unknown pixels are retained. RGB is decoded uint8 divided by 255 into float64, preserving encoded image intensity, without claiming absolute linear radiometry. No new synthetic observations are generated.

Public data/raw_data.npz SHA256 0916ac23b8584a784f28ed263889fa0f563c4950aa9cd1a4ed65b7add19791d9. It contains only image (1,440,680,3) and trimap (1,440,680), both float64. The private archive index records all source-image, paper, fixture and result hashes. It is outside the solver-visible release.
