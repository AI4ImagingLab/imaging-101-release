# Actual interfaces and execution

Standard entry point is python -m src.main from the task directory. It reads only data/raw_data.npz and writes output/reconstruction.npz. No hidden reference, upstream package or another task is loaded by the reconstruction. Runtime dependencies are the shared pinned NumPy/SciPy/Matplotlib subset; plotting is only used by the notebook, not the CLI solve.

preprocessing.load_data(path='data/raw_data.npz') returns image(440,680,3),trimap(440,680),both float64 in dimensionless original encoded RGB/label units. It requires exact NPZ keys and declared native shapes/dtypes/finiteness/ranges and the authored trimap categories0,.4,1. Constants IMAGE_SHAPE and TRIMAP_SHAPE include the batch axis for contract checking. partition_trimap(trimap) returns flattened foreground,background,known,unknown Boolean masks; classification is>=1 and<=0, with all other values unknown. The public loader additionally restricts the canonical manual label values.

physics_model.mixing_model(alpha,foreground,background) computes encoded RGB composite values using broadcast alpha[...,None]; it is an independent physical-model primitive, not called as a synthetic data generator. matting_laplacian(image,known=None,epsilon=1e-7,radius=1) returns native-pixel CSR L of shape(299200,299200), float64 values, after explicitly computing complete3x3window color statistics and cofactor inverses. It supports only the selected radius1 method and rejects invalid image types/finiteness, epsilon, radius and mask shapes. known=None means no skipped windows. It has no file effects. The fixed25slot-per-row storage and original insertion/row order are deliberate numerical conventions; it is not an opaque domain operator or loaded hidden matrix.

solvers.conjugate_gradient(matrix,rhs,rtol=1e-7,maxiter=10000,capture_steps=()) returns unknown-vector x,history(N,3),and an integer-key dictionary of requested iterate snapshots. History columns are one-based update index, recursive residual norm and ratio to||rhs||. The zero right-hand side returns zero immediately; exhausted budget raises an error. Jacobi action and all CG arithmetic/stopping are local. reconstruct(image,trimap,epsilon=1e-7,capture_steps=()) returns alpha(440,680),float64, and diagnostics with history,captured,laplacian,rhs,unclipped_unknown,known,unknown,explicit_relative_residual. It has no file side effects; opacity is clipped only after solving and the independent labels are retained.

main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz') calls load_data and reconstruct, creates output parents and writes reconstruction with shape(1,440,680),float64. It returns alpha and diagnostics and prints actual time,CG count and explicit residual. CLI --input/--output can override defaults. Paths are caller-relative unless absolute. Importing main does not import plotting or select a backend.

visualization.make_figures(image,trimap,alpha,diagnostics,reference,default_reference,default_history) returns scientific figures,numeric source arrays,measurements. It actively computes two epsilon sensitivity reconstructions and uses passed original arrays only as explicitly labeled comparisons. export_figures(figures,numeric,measurements,directory) exports PNG/SVG/PDF and numeric_sources.npz/metrics.json/hash_manifest.json to a caller-selected private archive, with no backend mutation. The active notebook calls the standard run, standalone Judge and these local plotting functions, shows every group inline, and chooses a private figure export destination through an explicit maintainer environment variable. No cache preview substitutes for reconstruction.

evaluation/judge.py is independent of all src modules. read_array enforces exactly one finite real float64 reconstruction with native batch-first shape. image_metrics independently computes standard cosine NCC and dynamic-range RMS error, returns NCC0 for a zero estimate, and rejects a degenerate reference. evaluate(prediction) resolves reference/configuration relative to its own file, prefers actual ground_truth if available otherwise baseline_reference, reads public trimap only for independent known-label consistency, and returns report/exit code0,1,2. Predictions/reports are caller-relative. CLI requires --prediction/--report, creates report parents and reports write failures on stderr. Every named boundary is validated and actually consumed.

test/fixtures/upstream_stages.npz is an original numeric capture consumed by stage tests for masks,L,rhs,probe actions,CG iterates and history. evaluation/baseline_reference.npz is the independently captured selected standard result, consumed by Judge,notebook and full parity tests; it is not truth. notebooks/reference_outputs/default_ichol_measurements.npz contains only the independently reproduced alternative-preconditioner opacity/history and is consumed by the notebook. measurements.json identifies both source runs,source revision,runtimes and measured numerical tolerance controls. Fresh reconstruction is computed actively and only saved to declared output; private figure numeric exports identify fresh arrays without adding redundant task-level caches. Original full checkouts,paper PDFs,capture scripts,source-environment files,logs and executed temporary notebooks remain outside the task.
