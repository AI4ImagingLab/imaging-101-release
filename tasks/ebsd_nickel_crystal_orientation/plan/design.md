# Actual modules and interfaces

`python -m src.main` sets torch CPU threads1, reads data/raw_data.npz from current workspace, calls local reconstruct and saves output/reconstruction.npz reconstruction float32(1,40,50,4). There is no upstream/domain import or hidden reference access in runtime. Libraries never set a Matplotlib backend. Public inputs are native detector data and independent master calibration; all fixed scalar geometry is declared in README.

preprocessing.load_data(path) validates allow_pickle=False patterns uint8(1,40,50,60,60), master_pattern uint8(1,2,401,401), returns raw uint8(40,50,60,60) and combined torchfloat32master(401,802). prepare_patterns(raw,return_stages=False) returns torchfloat32(2000,30,30), optionally (patterns,stage_dictionary) with detector downsample/background/normalization/CLAHE states. Background uses only these2000public samples. prepare_master(master,return_stages=False) returns processed float32(401,802), optionally (processed,pre-CLAHEminmax). minmax(patterns) preserves its input dtype. clahe_grayscale(x,clip_limit=40,n_bins=64,grid_shape=(4,4)) explicitly computes tile histograms/CDFs and trilinear CDF interpolation, input(B,1,H,W), same-shape float32output. Experimental initialfloat16 and laterfloat32 precision are retained from source.

physics_model.detector_rays(projection_center=(.4221,.2179,.4954)) returns torchfloat32(900,3), row-major, source-qualified corrected integer pixel centers in detector-length units. bruker_geometry_to_SE3(pattern_centers,primary_tilt_deg,secondary_tilt_deg,detector_shape) returns R(...,3,3),t(...,3) and is the explicit geometry kernel. get_radial_mask(shape,radius=None,center=(.5,.5)) returns boolean(H,W); default radiushalf smallerdimension. rosca_lambert_side_by_side(pts) returns(...,2) normalized north-left/south-right coordinates. interpolate_master(master,rays,align_corners=False,normalize_coords=True) returns intensities with rays'leading shape. It uses border padding. simulate_patterns(master,quaternions,rays=None,align_corners=False) is a forward helper, returning(...,900) if default rays. No file side effects.

orientations.py contains only required explicit quaternion/cubochoric/cubic math kernels extracted from the original MIT source. All quaternion components(w,x,y,z), floats; qu_apply(q,point) broadcasts and rotates3-vectors. sample_cubic_grid(resolution_deg=2,permute=True) returns float32(102448,4) for bound resolution. cubic_elements() returns float64(24,4) proper cube rotations; runtime converts to float32, matching source exactly. Source TorchScript's nominalfloat64sqrt(.5) coefficients retain a1.21e-8FP32promotion error; localfloat64coefficients are mathematically normalized, while all originalfloat32runtime coefficients/decisions are unchanged. cubic_reduce(q) is the source right-action candidate map, not a physical-forward invariance helper. get_local_orientation_grid(semi_edge_in_degrees,kernel_radius_in_steps,axial_grid_dimension=3) returns cubochoric offsets(27,3) at the bound radius1.

solvers.update_covariance(aggregate,count,mean,x) explicitly mutates accumulator/count/mean and returns them. learn_components(master,rays,mask,n_components=100,resolution_deg=2,chunk=256) returns (torchfloat32basis(716,k),eigenvalues(716,),statsdictionary). index_patterns(master,patterns,rays,mask,components,resolution_deg=2,dictionary_chunk=256,query_chunk=256) returns coarse float32(2000,4) and unnormalized top dot scores(2000,). refine(master,patterns,rays,initial,iterations=4,batch_size=64,semi_edge_deg=2) returns refined float32(2000,4) and actual per-round winning dot scores(2000,iterations). The selected q is exactly the scored proposal; no post-selection symmetry remapping occurs.

reconstruct(raw,master,n_components=512,resolution_deg=2,refinement_iterations=4,return_diagnostics=False,projection_center=(.4221,.2179,.4954)) seeds the dictionary permutation, preprocesses only public arrays, learns basis, indexes and refines. Default return NumPyfloat32(40,50,4); with diagnostics returns(q,dict) containing components,eigenvalues,coarse,dot_scores,refinement_dots,cleaned_patterns,master,rays,mask,seconds,stage_seconds,dictionary_count. No file side effect. Alternative component counts and explicitly known alternative PC are notebook sensitivity paths, not hidden fitter parameters.

visualization.review(task_dir,figure_dir) actively reconstructs bound data, computes lower-dimensional matching/refinement and the paper-provided alternative PC inverse, then independently evaluates fresh output and exports six scientific multi-panel groups with exact numeric_sources.npz,metrics.json,PNG/SVG/PDFandSHA256manifest. IMAGING_FIGURE_DIR directs notebook exports to the private maintainer folder. Original unmodified/corrected captures load only from notebooks/reference_outputs/upstream_methods.npz and are labeled.

evaluation/judge.py is independent NumPy, no src/upstream imports. It loads exact float32(1,40,50,4), requires unitnormwithin1e-5and finite, then float64normalizes. Actual ground_truth.npz has priority if present; baseline_reference.npz is used because measured truth is unavailable. It computes24left-cubic sign-invariant angular errors and independent public-only pattern cosine. All2000pixels are scored with no scan mask/registration. Reference paths anchor to __file__, while CLI prediction/report paths belong to caller. JSON contains status/passed/metrics/thresholds/errors, exits0/1/2for pass/validfail/error; malformed input yields empty metrics. Config boundaries must be finite, numeric nonbool and valid ranges; report-parent creation/write errors are handled. The independent NumPy CLAHE agrees with original preprocessing within3e-7; its physical geometry is derived directly rather than invoking source kernels.

index_direct(master,patterns,rays,mask,resolution_deg=2.,dictionary_chunk=256,query_chunk=256) returns coarse float32(2000,4),scores(2000,). It performs original uncompressed716-pixel dot matching, without any PCA surrogate, and is used only in the active scientific comparison before common four-round refine. This source branch normalizes detector rays before rotation, projects all900pixels with align_corners=False and no post-rotation renormalization, and selects the mask afterwards. reconstruct diagnostics stage_seconds records actual preprocessing,pca_learning,indexing,refinement wall times; review separately measures direct indexing and refinement. The sixth group preserves original/fresh direct DI versus PCA-DI and actual matching-only CPU timings.

The final selected method uses512PC after independent original runs improved public-only forward cosine from100PC0.3831627455 to512PC0.4512641989 (direct DI0.4512924226). Actual100PC and25PC matching/refinement are retained as negative comparisons using freshly learned columns; neither is a hidden reference or truth. Original100PC fixtures remain consumed by explicit100PC pipeline tests. Main selected512PC has separate original fixtures and full parity. The same2degree dictionary and acquisition model are unchanged. All total learning/matching/refinement costs remain shown; no complete-pipeline acceleration or ground-truth accuracy is claimed.
