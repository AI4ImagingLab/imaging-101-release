# Runtime modules and data flow

`python -m src.main` loads only data/raw_data.npz through preprocessing.load_data(path='data/raw_data.npz'),calls solvers.reconstruct(data,beta_sync=-3.,beta_dust=1.54,dust_temperature=20.),and writes output/reconstruction.npz with reconstruction,synchrotron,dust keys. Each output is real float64(1,48,64),microkelvin. Importing main changes no backend. CLI paths resolve relative to caller task workspace.

load_data returns unbatched copied arrays: measurements(5,48,64),frequencies(5,),galactic_longitude(48,64),galactic_latitude(48,64). Physics rj_to_cmb(frequency) accepts GHz scalars/arrays and returns dimensionless factors. mixing_matrix(frequencies,beta_sync=-3.,beta_dust=1.54,dust_temperature=20.) returns(5,3),columns CMB,synchrotron,dust. forward(components,mixing) maps(C,Y,X) to(F,Y,X) in microkelvin;adjoint(measurements,mixing) uses its transpose and returns(C,Y,X).

solvers.separate(measurements,mixing) accepts general compatible channel/component counts and returns maps(C,Y,X),unit-noise response covariance(C,C),weights(C,F). reconstruct returns maps(3,48,64),prediction(5,48,64),covariance(3,3). No task-specific pretrained weights,upstream imports,evaluation assets or cached results enter runtime. The reference method is closed form, so an artificial iterative loop is absent.

visualization is notebook-only and provides named figures plus numeric-source arrays; comparison computations call local operators. The active notebook freshly separates the observed map,loads the separately identified upstream measurements,computes ablations and spectral sensitivities,runs the standalone Judge and displays diagnostic residuals. The Judge imports no src module,loads reference/config relative to its own file,and scores every required quantity. Tests consume frozen oracle stages,analytic spectral reference cases,adjoint identities and metric/Judge contracts. No forward generator is shipped because the task reuses real observations.
