# Wind-Tunnel Acoustic Source-Power Imaging

> Recover a planar aeroacoustic source-power map from a full measured 56-microphone wind-tunnel recording despite finite-aperture smearing and incoherent sensor contamination.
> Domain: mechanics | Keywords: acoustic imaging, array sensing, inverse source mapping | Difficulty: Hard

## Background

Sound generated by turbulent flow and vibrating surfaces propagates to microphones with distance-dependent phase and amplitude. A synchronized array combines these differences to form an acoustic image of where the measured sound originates.

Source maps help characterize aerodynamic noise, machine noise and vibration-induced radiation. Conventional array images spread each source over a finite-aperture response and contain sidelobes. Inverse source mapping attempts to separate source power from this point-spread response, while sensor noise and the assumption of mutually incoherent sources limit physical interpretation.

## Problem Description

For frequency f, let C=E[ppᴴ] be the cross-spectral microphone matrix in Pa², with p the complex microphone spectrum and H denoting conjugate transpose. A monopole at position g has transfer h[m,g]=(r0[g]/r[m,g]) exp[-i k(r[m,g]-r0[g])], where r is source-to-microphone distance (m), r0 is source-to-array-origin distance (m), and k=2πf/c (rad/m) for sound speed c. Assume mutually incoherent source powers q[g]>=0, giving C approximately sum_g q[g] h[:,g] h[:,g]ᴴ plus noise.

The true-level steering vector v[g]=h[:,g]/sum_m abs(h[m,g])² yields a dirty power image b[g]=v[g]ᴴ C v[g], with sensor diagonal removed and correction M/(M-1) for M valid channels. Its point-spread matrix is A[g,j]=abs(v[g]ᴴh[:,j])². Recover q from b approximately A q and sum the per-bin q over the declared third-octave band. The stated A is the full coherent point-spread approximation retained by the standard method. Removing the sensor diagonal changes the exact single-source response; the scalar correction does not restore that entire response at every image point. Finite aperture makes nearby source columns similar and the inverse nonunique.

Use the complete 25600-sample measured record and all 56 stored channels, excluding only the two documented invalid channels. The source plane is fixed at z=-0.68 m. This free-field incoherent-power model does not reconstruct source phase, account for flow refraction or claim calibrated physical source truth.

Save `output/reconstruction.npz` relative to your task workspace. Required arrays:

| Key | Shape | Dtype | Description |
| --- | --- | --- | --- |
| `reconstruction` | `(1, 13, 13)` | `float64` | Real nonnegative third-octave source mean-square pressure at array origin in Pa²; axes (batch, x, y) on the declared 13×13 source plane. Sum per-bin source powers; do not submit dB, magnitude, transposed image or normalized values. |

Evaluation compares every required physical quantity with a validated standard-method result using relative Euclidean error, norm(estimate-reference)/norm(reference). Complex arrays retain both quadratures under the Hermitian norm. Mixed-unit parameter components are scored separately; every declared error must be at most 1e-5. No cropping, scale fitting, phase rotation or translation is performed. This is reproducibility against a standard method, not a claim of directly measured object truth.

## Method Hints

Use conventional true-level beamforming to form the dirty map, then deconvolve its modeled point-spread matrix using nonnegative sequential Gauss–Seidel updates (DAMAS). Recomputing the point spread at each included frequency preserves frequency-dependent aperture resolution.
