# Shipped interfaces and execution flow

All library functions use NumPy arrays and have no import-time file writes or Matplotlib backend selection. The standard entry point is `python -m src.main` from the task folder. `main()` resolves the task root from its own source path, calls `load_data`, calls `reconstruct`, creates output/, writes output/reconstruction.npz and returns the unbatched response. Notebook comparisons call the same cleaned functions directly and explicitly evaluate fresh results.

`preprocessing.load_data(path)` loads public NPZ with allow_pickle=False, validates exact batch-first shapes/dtypes and a binary mask, then returns uint32(256,256) energy inkeV and float32(124,124) dimensionless mask. `preprocess(raw,sigma=1.,reject_outliers=True)` returns float32(H,W) energy, using strict percentile replacement and reflected Gaussian boundaries. sigma=0 disables only the Gaussian; reject_outliers=False disables only percentile replacement. These optional parameters support documented ablations; they are not alternate CLI defaults.

`physics_model.central_crop(image,fraction)` returns a2D NumPy view using int-truncated centred bounds after constraining the fraction to[0,1]. `decoding_pattern(mask)` returns a copied float32(62,62) signed NTHT decoder. `projected_size(distance=50.)` returns an integer projected central period,126 at50mm, and rejects nonpositive distance. `nearest_resize(a,size)` returns an array of the input dtype with shape(size,size), using centre-based nearest indices. `cyclic_convolve(source,shadow)` and `cyclic_adjoint(detector,shadow)` return real arrays on the shared2D grid and preserve NumPy FFT computation precision; the adjoint conjugates the shadow transfer function. `source_coordinates(size=126,distance=50.)` returns float64(size,) nominal source-plane coordinates inmm. Geometry constants declare256 pixels,14.08mm detector,9.92mm mask,20mm camera gap,50mm plane and.055mm detector pitch.

`solvers.reconstruct(raw,mask,distance=50.,sigma=1.,reject_outliers=True)` returns float32(N,N) signed response in summedkeV units. It preprocesses, generates the signed mask, projects it, checks that it fits the detector, crops, directly convolves and casts. There is no optimized state or iterative stopping. `accorsi(raw,mask,distance=50.,sigma=1.,reject_outliers=True)` returns float32(K,K) sparse-decoder comparison; K124 at50mm. Its interpolation conventions match the archived author's function. It is called in the notebook only and never changes the standard output.

`visualization.metrics(x,reference)` returns a dict with float64-accumulated ncc and nrmse, defining zero submitted NCC as zero and rejecting degenerate references. `contrast_to_noise(a)` returns the3x3 peak-neighbourhood mean minus background mean divided by background standard deviation. Background excludes the11x11 peak square; this is an explicitly named notebook diagnostic, not the paper's ROI localization score or a Judge threshold. `image_panels(arrays,titles,cmap='magma',symmetric=False)` returns a labelled Matplotlib figure; the caller owns save/close. No plotting function reads archived references implicitly.

The independent `evaluation/judge.py` imports only standard library and NumPy. `load_prediction(path)` validates key/reconstruction, exact float32(1,126,126), finite real values. `score(x,r)` computes cosine NCC and dynamic-range NRMSE. `evaluate(prediction)` resolves hidden assets relative to evaluation/, gives actual truth precedence if present, validates metric boundaries and returns(report,exitcode). The actual shipped reference is baseline_reference.npz; no ground_truth.npz exists. Malformed inputs/evaluator failure yield error, empty metrics and exit2; quality failure yields fail/1; success pass/0. CLI paths are caller-relative, and report parents are created. JSON is strict finite UTF-8 and report-write failure produces stderr and exit2. No submitted or reference-solver code is imported by Judge.

Fixtures are frozen stage outputs from the independently run unchanged author's module on the same observation. Test consumers cover preprocessing, mask conversion, MURA and Accorsi outputs, independent convolution/adjoint physics, metric numerical cases, malformed and poor submissions, evaluator asset/configuration failure, report-write errors, entry point and README constants. The maintainer notebook actively reconstructs and measures both methods, performs geometry and preprocessing sensitivities, and renders six chapters. Only canonical executed notebook outputs remain in notebooks/; diagnostic exports and numeric source arrays belong to the external archive. No source imports the private oracle, cross-task code or domain reconstruction software.
