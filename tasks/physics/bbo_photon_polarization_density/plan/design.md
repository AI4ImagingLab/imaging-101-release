# Shipped execution flow

`python -m src.main` calls preprocessing.load_data(path="data/raw_data.npz"), which uses allow_pickle=False and returns counts(36,)float64 and projectors(36,4,4)complex128. It validates shape, finiteness and count nonnegativity. main calls solvers.reconstruct(counts,projectors), then creates output/ and writes reconstruction(1,4,4)complex128 and intensity(1,1)float64 to output/reconstruction.npz. Paths are relative to the caller's task workspace. No plotting or backend mutation occurs on import or in main.

physics_model.triangular(t) accepts16 real dimensionless count-square-root coordinates and returns complex(4,4)T. density(t,normalize=True) returns normalized dimensionless rho or unnormalized count-valued R. predict(rho,projectors,intensity=1.) returns a real vector of Born probabilities (default scale) or counts. residual(t,counts,projectors) returns the Pearson-like residual vector. No file side effects in these functions.

solvers.initial_coordinates(counts) returns16float64 initial values. reconstruct(counts,projectors) accepts any supplied analyzer-row count with shapes(M,),(M,4,4); returns density(4,4), positive Python float intensity, and diagnostics dict(objective,evaluations,status). linear_reconstruct(counts,projectors) returns unconstrained Hermitian density and scalar scale for notebook diagnosis; it is not the standard solver. It uses NumPy least squares in an explicit Hermitian design. visualization.comparison_figure(counts,projectors,solutions) returns a Matplotlib Figure; solutions maps labels to(rho,scale). This renders observation counts, real/imaginary density, count predictions/residuals and eigenvalues. state_metrics(rho) additionally returns tangle, base2 entropy, normalized linear entropy and ideal Bell overlap; independent analytic Bell/maximally-mixed tests validate these. It never selects a backend.

The notebook locates the task root from cwd, imports cleaned modules and actively solves the complete acquisition,16-outcome comparison, linear comparison, circular-removal sensitivity and synthetic perturbations. It reads notebooks/reference_outputs/upstream.npz only for explicitly labeled original-run comparisons. Its panels are actual fresh computations. No archived density appears as fresh. Results are displayed in canonical executed notebook outputs, with a private PNG exported solely for maintainer figure inspection.

The standalone evaluation/judge.py imports only standard library and NumPy. validate(path) returns unbatched density and scale after exact key/shape/dtype/finite checks. evaluate(path) returns(report,exit_code). main parses required --prediction and --report, creates the report parent and writes UTF8 finite JSON. Hidden paths are anchored to the evaluator's own directory; public Born calibration is data/raw_data.npz. Invalid inputs/assets yield error2 with empty metrics, below-threshold valid predictions fail1, accepted predictions pass0. Report-write failures yield2 and stderr diagnostics.

test/fixtures/upstream.npz is consumed only by independent parity tests. notebooks/reference_outputs/upstream.npz is consumed only by notebook comparisons. These separate roles are documented; they are not solver inputs. No upstream library is imported by any shipped module or notebook. Test tooling belongs to shared development environment and is not a runtime dependency.

Reference selection: ground_truth.npz takes precedence when present; otherwise baseline_reference.npz. Hidden references must satisfy physicality, finite and positive-scale validation before scoring.
