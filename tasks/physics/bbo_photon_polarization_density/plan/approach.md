# Implemented mathematics

The bound dataset is the complete 36-outcome real BBO polarization acquisition in Altepeter/James/Kwiat Fig7b. Counts have already been corrected for accidentals and detection efficiencies. They are not hidden ground truth and cannot be used to infer an exact Poisson variance. There is no independent measured density matrix. The oracle supplies a numerical method reference only.

Let c[j] be corrected counts, P[j] the known analyzer projector, and t a real vector of length16. The lower triangular T is filled by diagonals: t[0:4] main real diagonal; t[4:7]+i*t[7:10] first subdiagonal; t[10:12]+i*t[12:14] second; t[14]+i*t[15] third. Set R=T T-dagger, s=real(trace R), rho=R/s. This is exactly the current original code's coordinate ordering, a permutation of paper Eq75's t labels with the same matrix family. The forward model is mu[j]=real(trace(P[j] R)), in corrected counts. No conjugation of rho is allowed. H,V,D,A,R,L follow README Eq definitions; projectors use the standard outer product v v-dagger.

The minimized objective is sum_j ((max(mu[j],.01)-c[j])/sqrt(max(mu[j],.01)))^2. There is no 1/M or 1/2 factor, regularizer, additional positivity penalty or prior. The floor .01 is the original numerical count safeguard. This is the original implementation's Pearson-like Gaussian approximation, not the exact Poisson likelihood. It retains a common unknown scale across settings. Its residual may be systematically larger than Poisson expectations because the published counts are processed and no full correction covariance is supplied.

Initialize rho=I/4. Its Cholesky coordinates have main diagonal .5 and other coordinates0. Add .0001 to all16 coordinates, then multiply by sqrt(4*mean(c)), precisely as original tomography_MLE. This initialization is independent of the target and avoids the original high-level linear initializer's documented transpose correction. scipy.optimize.leastsq performs unconstrained Levenberg–Marquardt in these positive-matrix coordinates, ftol=xtol=1.49012e-8, gtol=0, maxfev=0 (MINPACK automatic budget). It chooses its internal trust-region step, scales and finite-difference derivatives; no custom line search is claimed. Stop on MINPACK status1–4; otherwise raise. Return rho,s and actual objective/evaluation count.

Linear diagnostic: construct a16-dimensional Hermitian matrix basis (four diagonals and six real/six imaginary coherences), solve real least squares for R against all counts, then normalize by trace without PSD projection. Sixteen-outcome comparison selects H,V,D,R on each arm and actively runs the same MLE. Circular-removal comparison selects H,V,D,A and has deficient design rank; it is a diagnostic, never an accepted substitute. Supplementary Poisson resamples illustrate count perturbation sensitivity, not a calibrated confidence interval for the processed experiment.

Metrics: complex Frobenius distance to independent original result<=2e-5; scale relative difference<=1e-6; maximum trace/Hermitian/negative-eigenvalue error<=1e-7; normalized observation RMSE<=.02. The conservative proposals were frozen before extraction; density/scale bounds were subsequently tightened from .001 using independent native reruns and float32 quantization measurements recorded in validation. Original proposals are at archive/quantum_preimplementation_protocol.md. The fresh baseline RMSE is .006664358465880508. Reference agreement bounds evaluate numerical recovery; they do not assert the reference is truth. No crop, magnitude conversion or phase alignment. Independent checks cover exact basis probabilities, projector completeness, rank and imaginary-phase sensitivity.
