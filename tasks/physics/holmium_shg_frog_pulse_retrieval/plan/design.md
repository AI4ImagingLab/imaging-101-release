# Shipped interfaces and execution flow

The standard entry is `python -m src.main`. It loads `data/raw_data.npz`, actively reconstructs the complete experimental trace with the local COPRA implementation and writes `output/reconstruction.npz`. It does not import pypret, other tasks or private archives. Source mathematics uses NumPy and SciPy FFT primitives; Matplotlib is used only for scientific visualizations. Importing the package or `src.main` does not select a plotting backend.

## Data and preprocessing

`src.preprocessing.load_observations(path)` takes a string/Path NPZ path and returns `(measured, model)`. `measured` is float64(512,512), ordered delay/frequency, dimensionless. The `SHGFrog` model owns the SI-coordinate `FourierGrid` and actual float64 delay(512). The loader uses `allow_pickle=False`, validates finite values and shape, and checks the supplied `time` and signal-frequency coordinates exactly against the declared constants. `FREQUENCY_STEP` and `CARRIER_ANGULAR_FREQUENCY` match the README acquisition table.

`gaussian_initialization(grid,width_fs=50.)` returns complex128 spectrum(512), computed from an independent zero-phase Gaussian intensity FWHM in femtoseconds. `unit_energy_field(grid,spectrum)` returns complex128 temporal envelope(512), in s^-1/2. `regrid_for_pcgpa(measured,model)` returns `(comparison_measured, comparison_model)` on the exact Fourier time grid, with float64(512,512) and a new model. This function is a diagnostic notebook path; it is not called by the standard reconstruction.

## Forward and derivative operators

`src.physics_model.abs2(x)` returns elementwise real squared complex magnitude; `norm2(x)` returns its scalar sum. `FourierGrid(n=512,dw=407474458795.6243)` stores `n`, `dw`[rad/s], `dt`[s], increasing arrays `t,w` and four phase/scale factor arrays. `forward(x)` and `backward(x)` return newly allocated complex arrays matching the input shape, operating on the last axis. All leading axes are batch dimensions for the transform; the public batch is stripped by the loader.

`SHGFrog(grid,delays)` stores the float64 delay vector and complex phase-mask matrix(M,N). `signal(spectrum,indices=None)` returns `(signal, delayed, field, mask)`. For no indices, signal/delayed/mask are complex128(M,N), while the shared undelayed field is complex128(N). A scalar integer selects one delay and returns one-dimensional arrays. `trace(spectrum)` returns float64(M,N). `gradient(target,signal,delayed,field,mask)` returns complex128 shaped like the signal, one spectrum gradient per selected delay. `project(measured,signal)` takes the gain-adjusted measured intensity matching the signal shape and returns the projected complex temporal signal. `scaled_residual(measured,predicted)` returns `(R,gain,residual_sum_squares)`, three Python floats. All calls are explicit local mathematical operations and have no file side effects.

## Inverse updates

`src.solvers.Retriever(model,measured,initial,method='copra',alpha=.25,seed=1234)` takes the local model, measured float64(M,N) and complex128 initial spectrum(N). It creates a private NumPy RandomState, evaluates the initial complete residual and, for COPRA, the initialization gradient maximum. It stores current and best spectra separately, gain, local/global mode, approximate-selection flag and stagnation counter. Supported methods are `copra`, `pie` and comparison-only `pcgpa`; the latter rejects delays different from `grid.t`.

`step(mode=None,capture=False)` mutates the current spectrum and selection state and returns `(R,diagnostics)`. Optional explicit mode is used by frozen one-step parity tests. With `capture=True`, diagnostics include actual intermediate arrays and step scalars, not opaque source objects. This testing path is not required by the solver CLI. `run(iterations=1000)` repeatedly calls `step` and returns a dictionary containing `spectrum` complex128(N), `trace_error` float64(iterations), `mode` int array(iterations), `actual_error` float and `runtime_seconds` float. The spectrum is the source-convention best old input. The trace-error history preserves the source logging convention; its final entry need not equal the complete returned-field error.

## Entry point and notebook

`src.main.reconstruct(data_path,iterations=1000,seed=1234,alpha=.25,width_fs=50.)` returns `(unit_energy_envelope,result,model)`. `main()` resolves task paths from its own file, creates `output`, serializes only `reconstruction` with shape(1,512) and prints the actual trace error and elapsed retrieval time. It does not read hidden references or evaluation thresholds.

The active notebook imports these cleaned modules, reconstructs the primary data, computes independent PIE and explicitly regridded PCGPA comparisons, and evaluates the fresh normalized field. Identified upstream spectra/histories in `notebooks/reference_outputs/` serve only comparison and independent sensitivity roles; they do not substitute for the active primary run. `src.visualization` provides scientific figure functions and numeric source exports; it neither selects a Matplotlib backend nor performs hidden reconstruction. Figures cover the acquisition, forward model, convergence, full complex pulse, measured/predicted residuals, comparison methods and sensitivity. The alpha comparison explicitly starts from the shared fresh primary best field, forces global mode and saves each200-step mode array and exact local/global counts.

Visualization callables are `aligned_field(field,reference,alignment,grid)` returning a complex128(N) field in the reference gauge; `style()` updating Matplotlib rcParams only when called; and `save(fig,directory,name)` writing PNG/SVG/PDF and returning the figure. Figure builders `acquisition(measured,model,directory)`, `pulse(field,reference,model,alignment,directory)`, `residuals(measured,model,spectrum,directory)`, `convergence(fresh,upstream,directory)`, `comparisons(rows,profiles,model,directory)` and `uncertainty(stability,controls,sensitivity,directory,field_boundary,trace_boundary)` each return a Matplotlib figure and export its three formats. Inputs are the computed arrays/dictionaries described above; they never fill missing methods or run an inverse solver. Heatmap cells are rasterized within SVG/PDF; axes and text remain vector. Exactly-zero log-intensity pixels are white and explicitly identified in the notebook caption.

## Evaluation and tests

`evaluation/judge.py` is a standalone executable with `--prediction` and `--report`. It imports neither the solver nor submitted code. Hidden paths resolve from its own directory. It validates required complex128(1,512) finite data and unit-energy quality, performs independently implemented continuous ambiguity alignment, recomputes the nonlinear trace using public calibration, and writes the standard status/passed/metrics/thresholds/errors JSON with exit0/1/2 semantics. A missing hidden asset is an evaluator error; a finite poor field is a quality failure. The method result is `baseline_reference.npz`; there is no invented `ground_truth.npz`.

`test/fixtures/original_stages.npz` is consumed by stage parity tests and contains original FT/SHG/projection/gradient and local/global/PIE step captures from the exact Regen observations. `test/unit_test` covers transform/physics invariants, alignment and Judge contracts; `test/comparing_test` compares independent frozen upstream stages and the complete standard path. `test/validation.md` indexes paper/source/data/environment hashes, actual commands/logs, measured tolerances, equation mappings, all gates and the semantic review of these plans. Complete author repositories, papers, capture scripts and original failures remain in the maintainer archive outside the task.
