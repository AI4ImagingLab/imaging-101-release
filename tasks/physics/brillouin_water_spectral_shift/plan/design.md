# Shipped interfaces and execution flow

All modules are task-local; the runtime imports only Python, NumPy, SciPy and Matplotlib primitives. bmlab, Shapely, scikit-image and HDF5 readers are unnecessary in the cleaned runtime. HDF5 conversion and original package execution are private provenance operations. Numerical functions adapted from the GPL-3.0 source retain the task LICENSE.

## Standard path

`python -m src.main` calls `run(data_path=None, output_path=None)`. Defaults resolve against the task directory to `data/raw_data.npz` and `output/reconstruction.npz`. Explicit path arguments resolve in the caller's context. The function loads all visible arrays, calls `reconstruct`, creates the output parent, saves compressed NPZ and returns the output dictionary. It does not plot, read hidden references or change Matplotlib backends.

`preprocessing.load_data(path)` reads NPZ with allow_pickle=False into an array dictionary. Camera uint16 observations remain native until float64 frame averaging/interpolation. `find_points(images,min_height=10,min_area=20,max_distance=50)` consumes one calibration's `(10,400,400)` images and returns `(6,2)` integer row/column points for this data. It performs median filtering, explicit threshold construction, general-purpose grayscale closing and connected-component labeling. `interpolate_time(times,values,query)` interpolates along values' leading calibration dimension and holds nearest endpoint outside the calibration interval. `extract_spectrum(image,arc)` consumes `(400,400)` ADU and `(500,2*width+1,2)` pixel strip coordinates and returns `(500,)` float64 ADU. It has no disk side effects.

`physics_model.setup()` returns a small `SimpleNamespace` containing explicit geometry, laser frequency, nominal FSR and known independent reference shifts/order vector. It contains no specimen target. `lorentz(x,w0,fwhm,intensity)` returns the zero-background line. `spectral_model(x,parameters)` adds the fourth background parameter. `fit_lorentz(x,y)` returns four scalars `(center,FWHM,height,offset)` and preserves the source quartic residual/default bounded optimizer. `fit_double_lorentz(x,y,bounds_w0=None,bounds_fwhm=None)` returns two center/width/height tuples and one offset; runtime calls it without optional bounds. Only this supported two-line calibration path is used; no quadruple-peak framework is shipped.

`calculate_exact_circle(points)`, `are_points_on_line(points)`, `_circle_opt(c,x_coord,y_coord)` and `fit_circle(points)` implement source circumcircle initialization and algebraic circle fitting. `fit_circle` returns `((center_row,center_column),radius)` in pixels. `arc_coordinates(points,shape=(400,400),width=2,num_points=500)` explicitly clips a 64-edge circle polygon against the detector rectangle and returns `(arc,circle_parameters)` with shapes `(500,5,2)` and `(3,)` at defaults. It preserves the polygon approximation used upstream; no Shapely import or precomputed trace is used.

`VIPA(x,vipa_params)` computes absolute frequency in Hz from the first three coefficients. `fit_vipa(peaks,setup)` consumes six ordered pixel centers and the local instrument object, returns four coefficients including FSR, and preserves source Nelder–Mead objective/defaults. It may print optimization progress and emit a max-evaluation warning; neither changes the data contract. `vipa_objective(params,peaks,instrument=None)` exposes the identical task-specific calibration objective for independent mathematical review.

`solvers.calibration_regions(spectra)` consumes `(10,500)` calibration ADU and returns `(4,2)` integer windows, ordered Rayleigh 1, Rayleigh 2, Brillouin doublet 1, Brillouin doublet 2. `fit_region(region,x,y,double=False,power=4)` maps physical endpoints to nearest sample indices, slices right-exclusively, removes nonfinite pairs, and dispatches local single/double equations. Single-peak return is `(4,)`; double return contains two centers, widths, heights and shared offset. `power=2` is an optional specimen-only L2 diagnostic initialized from the L4 result.

`solvers.reconstruct(raw,arc_width=2,calibration_mode='interpolate',power=4)` consumes exactly the public input dictionary and returns `(outputs,details)`. It infers both calibration traces, extracts every calibrator spectrum, estimates every calibrator's six peaks and four dispersion coefficients, constructs all frequency axes, interpolates trace/time-specific axes, extracts every water spectrum, fits all four specimen regions and calculates both frequency shifts. All seven output arrays are float64 with the README's exact batch-first shapes. `details` contains points `(2,6,2)`, fitted circles `(2,3)`, calibration spectra `(2,10,500)`, calibration windows `(2,4,2)`, fitted calibration centers `(2,10,6)` and measurement traces `(10,500,5,2)`. `arc_width=1/3` and `calibration_mode='first'` support explicitly labeled sensitivity experiments. No hidden reference or upstream import occurs in this flow.

## Evaluation, tests and notebook

`evaluation/judge.py` independently loads `metrics.json`, validates every required key/shape/exact dtype/finiteness, loads actual truth if present or the independent standard-method baseline otherwise, and computes every configured relative-error metric. It imports no solver. CLI prediction/report paths belong to caller; hidden assets resolve against Judge location. Reports use finite UTF-8 JSON, status/pass/metrics/thresholds/errors and exit codes 0/1/2. Missing/undefined metrics, incomplete output coverage and invalid boundaries are errors. Report parents are created; write failure produces stderr and exit 2.

Frozen `test/fixtures/upstream_stages.npz` is consumed by comparison tests only; it contains original numeric measurements, never local-generated expectations. `test/comparing_test/test_upstream.py` checks preprocessing/geometry/windows/calibration centers/frequencies/every final peak/shift plus original diagnostic intensity/time/drift. `test/unit_test/test_physics.py` checks independent analytic cases. Judge tests exercise quality failure for every output, malformed predictions, missing assets, truth priority, foreign cwd, report failure, metric values/configuration and backend-safe imports. Public metadata and visualization metrics have independent tests.

The active notebook loads public observations through `preprocessing`, calls `reconstruct`, evaluates fresh saved arrays through the standalone Judge, reads the original baseline solely for comparison, then actively calls `visualization.experiments` and `make_figures`. `experiments(raw,result,details)` returns `(variants,source,measurements)` and independently recomputes four sensitivity conditions. `make_figures(raw,result,details,reference,variants,source)` returns three named Matplotlib figures and adds numerical residual arrays to `source`; no plotting occurs during imports. Each is explicitly displayed once after closing automatic pyplot displays. All PNG/SVG/PDF exports and complete plot-source NPZ stay in a maintainer-only archive. Canonical notebook retains executed outputs; temporary executed copies stay outside the task. `reference_outputs` stores only identified upstream/fresh measurement JSON with recorded consumers; baseline arrays are not redundantly duplicated there.
