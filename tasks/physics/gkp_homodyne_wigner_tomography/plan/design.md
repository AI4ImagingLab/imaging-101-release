# Shipped interfaces and data flow

The standard command is `python -m src.main`. Its complete path is public NPZ loading →per-block variance/phase calibration →strict three-detector selection →full list-mode positive ML inverse →explicit Wigner transform →`output/reconstruction.npz`. It neither reads hidden assets nor imports an upstream/quantum reconstruction package. Existing observations are reused, so no `generate_data.py` is present.

## Observation module

`preprocessing.load_observations(path=None) -> dict` defaults to task-local data/raw_data.npz. It loads with allow_pickle=False, validates exactly nine declared keys, batch-first shapes and finite values, checks positive vacuum variance and calibration index range, removes the single batch dimension and returns copied arrays. ADC/phase/file indices retain int16, distances uint16 and calibration float64. Shapes after batch removal are(N,), (N,3), (100,), or(100,64), with N=3756232. Units match README.

`phase_distortion(x,offset,amplitude,phase) -> ndarray` returns x-offset+amplitude*sin(x-phase), all phase arguments in radians. `variance_model(x,offset,amplitude,phase,squeezed,antisqueezed) -> ndarray` computes the canonical variance curve. `calibrate(data) -> dict` applies the source's default unbounded curve_fit per block and original float64 arithmetic/order. It returns full `q`, `phi`, `uncorrected_phi` shape(N,), `phase_fit_param`(100,5), float64 `pnr_distance`(N,3), `cutoff`(3,), integer `accepted_indices`(1881028,), and `q_accepted`, `phi_accepted`, `uncorrected_phi_accepted` shape(1881028,). Canonical q is dimensionless; phi is radians. Functions write no files and use no target state.

## Physical mathematics

`physics_model.hermite_amplitudes(q,theta,cutoff=30,hbar=1) -> complex128(cutoff+1,N)` evaluates normalized oscillator wavefunctions with phase factors. It requires equal one-dimensional q/theta shapes, cutoff>=1 and positive hbar. `born_probabilities(density,amplitudes) -> complex128(N,)` preserves the source numerical form of the real continuous Born density. `log_likelihood(density,amplitudes) -> float` returns the real sum of log Born densities.

`density_update(density,amplitudes) -> (new_density,R,p)` performs the explicit Hermitian R-rho-R normalization. Matrices have shape(cutoff+1,cutoff+1); p has shape(N,). It preserves the source operation ordering, symmetrizations and old-probability convention. `step_fidelity(density,previous) -> scalar` uses general SciPy matrix square roots and the exact source normalization diagnostic; it does not alter the inverse update.

`wigner_function(density,q,p,hbar=1) -> real ndarray(len(p),len(q))` implements the explicit recurrence. Canonical q/p coordinates and Wigner density use hbar1 in the benchmark. Constants Q_GRID/P_GRID contain201 float64 entries from−7 to7. No finite-window renormalization occurs.

`quadrature_probability(density,q,theta) -> ndarray(len(q),)` implements the original finite-grid normalized probability mass for review plots. It is separate from `born_probabilities`; no histogram or finite-window mass enters ML. `displacement(shape,alpha) -> complex128(shape)` evaluates closed generalized-Laguerre matrix elements; shape is the desired output/input photon dimensions. The alpha0 identity is an explicit mathematical limit. Both helpers have no file side effects.

## Inverse and standard entry point

`solvers.maximum_likelihood(q,theta,cutoff=30,iterations=100,snapshot_steps=(1,2,7,25,50,100)) -> dict` uses every supplied sample in every update. It creates the full complex amplitude array, initializes identity/(cutoff+1), executes the fixed loop and returns `density_matrix`, `likelihood` and `step_fidelity`, `snapshots` keyed by one-based completed update count, `iterations` and actual `runtime_seconds`. Likelihood/fidelity vectors have length iterations; matrices have the corresponding photon dimension. Default complete execution is CPU and needs memory for the31×1881028 amplitude array and temporary products. CPU threads are constrained in recorded commands, not by changing global shared configuration.

`main.main(diagnostics=None) -> dict` loads/calibrates public observations, calls the full default inverse and computes the full Wigner field. It creates task-local output and writes exactly two batch-first arrays, complex128 density_matrix and float64 wigner. It returns the fresh inverse dictionary extended with wigner and prints accepted-shot count, update count and measured total runtime. No plotting backend is changed on import or execution.

The optional `--diagnostics PATH` serializes fresh numeric density/field/history/snapshots plus actual phase parameters, cutoffs, accepted indices and calibrated accepted q/phi. It is a write-only capture option; no checkpoint or cache is loaded. The output is outside the task for CLI validation. The active Notebook reconstructs independently with the same local functions and separately identifies upstream references and historical cached context.

## Review visualization interfaces

`visualization.state_statistics(density,W) -> dict` computes purity, signed-field finite-window integral/negative volume, both native displacement stabilizer magnitudes and the smallest density eigenvalue. Density is a complex square matrix; W is the real201-by201 field. Stabilizers use the original displacement scales1.86/sqrt(2) and i*sqrt(2)*pi/1.86. These diagnostics neither initialize nor constrain reconstruction.

`visualization.comparison_metrics(result,reference) -> dict` pads a smaller photon-support result with zeros only for the explicitly labeled support-comparison metric, then measures density relative L2 and Wigner dynamic-range NRMSE against the native method reference. It also collects state statistics and the negative last recorded total likelihood. The internal likelihood dictionary entry is normalized by accepted-shot count in `make_figures` before any table/plot/JSON export; all exported values with the per-shot name are normalized. This comparison helper is never the Judge or a solver operation.

`visualization.make_figures(data,calibration,upstream,fresh,comparisons,historical,directory=None) -> (figures,metrics)` consumes already actually computed arrays. It returns six Matplotlib figures and full-precision measured metrics. The active Notebook supplies newly reconstructed primary/support/phase-control results; the separate upstream and historical dictionaries retain their provenance labels. Optional directory export writes figure1 through figure6 in PNG/SVG/PDF, figure_numeric_source.npz, figure_metrics.json and figure_provenance.json. No inverse is silently replaced by a loaded result. Plot rc settings are scoped to a context and no backend is changed. The complete primary inverse and all three controls execute before plotting.

## Evaluation and test flow

`evaluation/judge.py --prediction PATH --report PATH` imports no src module. Hidden metrics and references resolve from the Judge file's directory. If ground_truth.npz exists, it has priority; otherwise baseline_reference.npz is selected. Invalid truth is an evaluator error, without silent fallback. This actual experimental task supplies only the independently reproduced method reference. Prediction/report paths follow the caller's cwd. NPZ loading forbids pickles, requires exactly the two output keys, declared shapes, supported real/complex dtypes and finite values. Evaluator reference and thresholds are checked independently. The Judge's closed-Laguerre transform is independent of the runtime recurrence. All required quality and physical metrics must pass. It writes UTF-8 finite JSON with status/passed/metrics/thresholds/errors and returns0/1/2 for pass/valid poor output/error. Report write failure returns2 with stderr.

Tests consume frozen independent original outputs; none imports original code or a private capture driver. Original small real-data stages cover Hermite factors, Born probabilities, full R operators and seven complex density updates/history. Analytic state fixtures and independent likelihood finite differences check physics. Complete preprocessing tests verify all selected indices and broad calibrated samples. Judge tests exercise both supported precisions, foreign cwd, bad states/fields, missing/corrupt inputs, dtype/shape/finite errors, unavailable evaluator assets, invalid thresholds and report failure. Full default CLI and active Notebook executions are separate mandatory captures rather than repeated needlessly by every unit test.

Historical context NPZ is a maintainer Notebook comparison only, produced by actual execution of the original release's cached-context cells. Its matrices are not ground truth, raw observations or a solver initialization. Complete source/PDF/raw download archives and original logs remain outside the task.
