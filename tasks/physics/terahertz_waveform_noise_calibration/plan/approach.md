# Implemented joint waveform/noise inverse

## Observation binding, coordinates and physical model

The public input is all fifty measured author air scans from 2017-03-20, all 267 native samples. Convert author voltage to pA by multiplying by 1e12/(5e7 V/A); no other baseline subtraction, window crop, normalization, padding, synthetic noise or filtering occurs. Sampling dt=0.05003462406015038 ps is the mean native time-coordinate interval. Only the relative time origin is set to zero. Runtime arrays are row-oriented `(M,N)` after removing the leading batch axis; here M=50,N=267. All arithmetic is float64/complex128 on one CPU FFT worker.

Let mu in R^N be a latent photocurrent waveform; a in R^M and eta in R^M are per-scan amplitude and delay. Fix a[0]=1,eta[0]=0, so there are N+2(M-1)+3=368 free parameters. The scan mean is zeta[j]=a[j] S(eta[j])mu. The source Fourier convention is scipy real forward FFT followed by irfft of exp(-i omega eta) times Fourier coefficients; positive eta delays the feature. The operator is periodic over N native samples. N is odd, avoiding real-Nyquist shift ambiguity. A spectral derivative multiplies coefficients by i omega. Distinguish a derivative per sample, d zeta, from its physical derivative D zeta=d zeta/dt in pA/ps.

Given uncorrected noise amplitudes alpha pA, beta dimensionless and tau ps, v[j,k]=alpha²+beta² zeta[j,k]²+tau² D zeta[j,k]². This matches the published 2021 paper's secondary-waveform variance (Eq. 34–37). The archived historical MATLAB calcnoise implementation instead approximates variance with a common waveform; the selected later Python implementation explicitly uses each scaled/shifted secondary waveform. It also uses all 267 samples here, whereas historical MATLAB scripts selected 256. No historical numerical table is relabeled a result of this benchmark.

## Objective and scaled parameterization

The minimized negative log likelihood is L=1/2 sum[log v+(x-zeta)²/v], omitting the constant MN log(2 pi)/2. No division by sample count or regularization is applied. For internal time coordinates measured in samples, set V=(alpha²,beta²,(tau/dt)²) and use d zeta per sample, so v=V0+V1 zeta²+V2(d zeta)².

Write the optimization vector theta as three scaled log variances l, N waveform deviations delta, M-1 amplitude deviations epsilon and M-1 scaled delays q. Scales are s_l,s_mu,s_a,s_eta. Decode V=exp(l*s_l), mu=x[0]-delta*s_mu, a=1+insert(epsilon*s_a,0,0), eta_samples=insert(q*s_eta,0,0). The physical delay is dt eta_samples. Elementwise scale multiplication is intended. The minus sign in mu's deviation coordinate matters in its gradient; its initial estimate is the sample mean, not the first measured trace.

The acquisition operator is computed explicitly: w=2 pi rfftfreq(N) in radians per sample; E[j,l]=exp(i eta_samples[j] w[l]); mu_f=rfft(mu); zeta_f[j]=a[j] conjugate(E[j]) mu_f. Then zeta=irfft(zeta_f), d zeta=irfft(i w zeta_f), and d² zeta=irfft(-w² zeta_f).

## Initialization and scales

Set mu0=mean(x,axis=scans), a0=ones(M), eta0=zeros(M). Compute sample variance v_t with ddof=1 across scans at each time. Let sigma_min=sqrt(min(v_t)). Regress v_t against columns [1,mu0²,(D mu0)²] using general least squares. Take masked square roots of the three coefficients, replacing a negative-root result by sigma_min exactly as source. This gives alpha0,beta0,tau0. The physical derivative used in this regression is irfft(i 2 pi rfftfreq(N,dt) rfft(mu0)).

Use s_mu=sqrt(alpha0²+(beta0 mu0)²+(tau0 D mu0)²); replace isclose-to-zero entries by sqrt(machine epsilon). Here D is evaluated in the source NoiseModel convention, the per-sample derivative divided by dt. Set s_a to a constant max(sigma_min/max|x|,beta0), repeated M-1 times. Set s_eta to max(sigma_min/max|diff_time x|,tau0/dt), repeated M-1 times; diff_time x means the first difference between neighboring native time samples, without dividing by dt. All log-variance scales s_l are 1/M.

Initial log variances are log([alpha0,beta0,tau0/dt]²)/s_l, with masked-log fill -100 before division. Initial waveform deviations are (x[0]-mu0)/s_mu. The other free coordinates are zero. All these arrays are compared independently with original parser fixtures before optimization.

## Analytic gradient and BFGS update

Let r=x-zeta, qv=(v-r²)/v² and rw=r/v. Define p=V1 qv zeta-rw and h=V2 qv d zeta. Derivatives of L with respect to the unshifted physical waveform are the sum over scans of a S* [p-d h], because the periodic derivative's adjoint is -d. The scaled delta coordinate therefore has the additional factor -s_mu. Local code evaluates this adjoint through FFTs: transform p minus i w times transform h, multiply by E, invert, multiply by a and sum.

The log-variance derivatives are 1/2 s_l[i] V[i] times sums of qv, qv zeta² and qv(d zeta)² for i=0,1,2. For each free amplitude, derivative is s_a/a times sum[(v-V0)qv-rw zeta]. For each free sample delay, derivative is -s_eta times sum[qv(V1 zeta d zeta+V2 d zeta d² zeta)-rw d zeta]. The first scan's amplitude/delay components are excluded, preserving the fixed gauge. These derivatives include variance changes; freezing the variance would be a different objective. Independent unit tests check directional finite differences, shift signs, integer delays, Fourier adjoints and derivative units.

Minimize L with SciPy BFGS and the explicit analytic gradient. This is the permitted general optimizer used by the selected source. Initial theta is fixed as above; method='BFGS', maxiter=10000, gtol=1e-6. The source passes tol=1e-5*x.size, but the explicit gtol option overrides its gradient tolerance. Other source defaults remain unchanged: inverse-Hessian initialization identity, no variable bounds, default Wolfe line search and default finite-difference fallback unused because the gradient is supplied. The reference callback only records objective values; it does not alter the iterate. The source BFGS inverse update and line search are delegated to this general-purpose primitive, while task-specific acquisition, cost, scales and gradient are local.

**Actual canonical stop:** the source and cleaned algorithm return success=False, precision loss, after 169 iterations. The scaled maximum gradient is about 1.997e-5, above the requested gtol. This is not silently relabeled convergence or cured by relaxing gtol. An independent original-function Hessian is positive definite (eigenvalues 0.07012…250.8449); gradient per observation is 1.496e-9. Directional finite differences agree within 3.83e-8 absolute. A private diagnostic Newton step reduces NLL by only 2.46e-11 and reduces maximum gradient to 5.57e-12; its Newton decrement is 5.41e-11. This supports floating-point line-search stagnation near the local minimum. The probe does not replace the selected BFGS reconstruction, original baseline, initialization or thresholds. The unmet gtol and actual flag remain visible in CLI, notebook, measurements and validation.

## Physical output and finite-sample correction

Decode mu,a,eta from the returned canonical theta. Convert tau from samples to ps. All three fitted noise amplitudes are multiplied by sqrt(M/(M-1)), matching source finite-sample correction. This is an approximate nuisance-bias correction and does not remove all incidental-parameter effects. The final likelihood and gradients continue to describe the uncorrected MLE parameters; do not substitute corrected noise into the optimization cost and claim the same NLL.

Return all latent samples, every amplitude/delay (including exact gauge entries), and corrected alpha/beta/tau. Additionally compute expected_waveforms directly from the returned mu,a,eta and compute noise_std from the corrected noise and each expected waveform/physical derivative. These six arrays have the exact README batch-first shapes and units. The full standard method uses no mask or alignment.

## Diagnostic curvature and real experiments

`curvature` differentiates the analytic gradient locally with a five-point centered formula at absolute scaled-coordinate step h=1e-3: H[:,j]=[-g(theta+2h ej)+8g(theta+h ej)-8g(theta-h ej)+g(theta-2h ej)]/(12h). This is a general numerical derivative implemented with NumPy; numdifftools is confined to the private original oracle. Curvature never updates the submitted theta. Invert H and apply the source coordinate scales: corrected-noise*s_l/2, s_mu, s_a, dt*s_eta. The source uses a positive s_mu coordinate scale for its returned inverse-Hessian convention; the actual physical mu map has a minus sign. Marginal variances are unaffected by the sign, but off-diagonal source-coordinate covariance is not silently called physical covariance. Uncertainty plots use marginal standard errors only. For the three noise marginal errors, source additionally multiplies by sqrt(M/(M-1)); this convention is retained and documented. Full Hessian and all displayed marginal errors are compared against independent original numerical-derivative fixtures. They are joint observed-curvature approximations conditional on the assumed likelihood/model/data, including nuisance coupling, not physical truth or validated coverage intervals.

Actively refit the complete selected joint inverse using the first 10 and first 25 of the real acquired scans; retain all 267 time samples. Compare corrected noise amplitudes and their fresh curvature marginal errors with the complete 50-scan fit. Prefixes are acquisition subsets, not random independent trials; variability should not be interpreted as Monte Carlo coverage. Independently compute an additive-only sensitivity model by fixing the other two log variances at -100 (amplitudes effectively zero) and fitting the same latent waveform/drifts/additive noise with BFGS. This model ablation is explicitly labeled and does not remove unknowns from the standard benchmark. Plot full-model versus additive-only standardized residual RMS across time, signal-dependent variance contributions, all normalized residual traces, a normal QQ comparison and actual BFGS likelihood history. QQ is a qualitative conditional residual diagnostic, without an invalid iid goodness-of-fit p-value after fitting nuisance parameters.

## Evaluation

Actual latent truth is unavailable. The hidden baseline is the independently executed selected original method on the exact fifty native traces, with its precision-loss stop honestly retained. Each required array must meet relative Euclidean error ≤1e-6; noise components are scored separately because their units differ. No alignment, cropping, scale fitting or nominal noise replacement is allowed. Original stage acceptance was fixed before local extraction at rtol=1e-6,atol=1e-7 and stricter parser/operator checks are also run. Nonzero reference tolerance accommodates floating-point endpoint differences and does not establish physical accuracy. Independent gradient/physics/nearstationarity evidence complements original parity and the standalone Judge.
