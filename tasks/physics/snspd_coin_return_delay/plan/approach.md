# Implemented full-histogram inverse

The selected published method is the CVPR2022 **Full-Resolution Histogram matched-filter baseline**, implemented by original IdentityCoding.max_peak_decoding(rec_algo_id='matchfilt'). It is applied to independently licensed Glasgow real SNSPD measurements. This is an explicit cross-source binding, not a compressed CVPR acquisition or a depth script authored by the Glasgow group. The Glasgow paper independently also describes IRF cross-correlation, but its unavailable depth-rendering code is not claimed as reproduced.

Input native scan50x50,10000bins,1ps/bin,20s/pixel; independent raw3500nm IRF has maximum at6873. Roll this raw response by-6873 and normalize to unit sum h; it is an acquisition calibration, never estimated from the target. No smooth approximation of h is substituted. Counts remain integer. For each histogram y and template h, form z(a)=(a-mean(a))/(||a-mean(a)||2+1e-8). Compute C[s]=real(IFFT(conj(FFT(z(h)))*FFT(z(y))))[s]. Thus C[s]=sum_i z(h)[i] z(y)[(i+s)modN]. Return s=argmax C (first-index tie behavior), all10000lags. No sign reversal or padding to a different linear-correlation model.

The original matchfilt_reconstruction creates roll(h,s), then max_peak_decoding finds that reconstructed pulse's maximum. Since the provided unit-sum h peaks at0, this equals s. The local inverse evaluates this mathematical result directly rather than allocating unused10000x10000 coding matrices or an unnecessary pulse array for every pixel. This equivalence was independently proved on small complete constructors, and the actual complete10000-bin original constructor plus all2500 original decodes were subsequently run and compared exactly. No iterative optimization, artificial iteration, gradient, stopping criterion or learned checkpoint is needed for this closed-form discrete shift search. Fifty-row batching changes only memory usage.

The single-return diagnostic forward model is independent Poisson counts with mean A*h[(i-s)modN]+b. A is integrated signal photons and b counts/bin. Because h integrates to1 across bins, no extra bin-width factor enters its discrete photon count model. Multiple optical returns and noise violate this simple model; they are exposed in the notebook rather than removed by object-dependent gates. An optional explicit nonnegative two-column least-squares diagnostic fits A,b at the chosen s: with hy=dot(roll(h,s),y), hh=dot(h,h), sy=sum(y), D=N*hh-1, the interior A=(N*hy-sy)/D,b=(hh*sy-hy)/D is compared with both nonnegative-axis solutions; choose smallest squared residual. This diagnostic does not alter s and is not the original depth estimator.
