# Shipped interfaces and execution

`python -m src.main` calls main()->load_data(task/data/raw_data.npz)->amplitude_stack->reconstruct and writes task/output/reconstruction.npz (complex128 array (1,512,512)); stdout reports actual runtime and residual. Paths resolve from the installed task directory. Importing src.main never changes a plotting backend or runs reconstruction.

- preprocessing.load_data(path): requires NPZ measurements uint16 (1,8,512,512), returns unbatched (8,512,512) uint16. amplitude_stack(measurements): returns zero-phase complex64 (planes,y,x), preserving per-plane normalization. Constants SHAPE=(512,512), NPLANES=8, PIXEL_SIZE=1.12μm, WAVELENGTH=.532μm, DISTANCES positive float64 eight-vector.
- physics_model.wave_grid(shape,pixel_size=1.12): float32 angular-frequency squared grid (rad/μm)^2. transfer(shape,distance,pixel_size=1.12,wavenumber=K): complex kernel, dtype follows scalar promotion. propagate(field,distance,pixel_size=1.12,wavenumber=K): periodic spatial field of same shape; no mutation. predicted_amplitudes(field,distances): float stack of propagated magnitudes. amplitude_residual(field,amplitudes,distances): scalar normalized L2 amplitude mismatch.
- solvers.reconstruct(amplitudes,iterations=100,distances=DISTANCES,record_every=5): returns (object field complex128, history float64 (checkpoints,2)). Input zero-phase amplitudes shape(planes,y,x), distances μm; private copy of first plane; exact traversals, transfer kernels cached locally. History columns sweep and residual. record_every=0 suppresses diagnostics. No file side effects.
- visualization.figure_groups(amplitudes,fresh,upstream,single,two,history,export=None): constructs four actual scientific multi-panel comparisons and returns [(name,figure),...]. Optional export folder receives PNG/SVG/PDF, exact numeric sources.npz and structured manifest.json with SHA256 hashes. Plotting imports do not choose backend.
- evaluation/judge.py: independent of src, uses fixed acquisition and shape constants, standalone CLI --prediction PATH --report PATH. Paths relative to caller except hidden reference/assets resolved relative to judge. Exit0 pass,1 valid poor prediction,2 malformed input/evaluator/report error. Report JSON fields status,passed,metrics,thresholds,errors. Required key complex64/complex128 reconstruction, shape(1,512,512), finite; no cropping/coercion. Constant phase alignment only. Complex error formula explicit in metrics.json. Independent forward check loads legitimate public observations.

The active notebook reconstructs all8 bound planes afresh and compares with frozen upstream arrays under notebooks/reference_outputs/upstream_reconstruction.npz; it also computes single-plane and two-plane methods afresh. These helpers are notebook comparisons, not default CLI variants. Figure export is controlled by PRIVATE_FIGURES environment variable and remains outside task package. Unit tests and independent upstream parity fixtures live only in test/. No upstream import, TensorFlow, domain library or TIFF reader is needed at cleaned runtime. No data generator exists because all observations pre-exist upstream.


Validated grid support is restricted to positive even two-dimensional shapes. The original odd-size fftshift convention is not physically validated and is rejected. Public prediction and independent Judge propagation use NumPy float64 distances, matching the solver kernel precision; literal-distance stage fixtures retain their original argument dtype.
