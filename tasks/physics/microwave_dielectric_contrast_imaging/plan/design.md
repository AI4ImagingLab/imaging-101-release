# Shipped module and execution contract

`python -m src.main` is the standard entry. `main.main()` resolves task root from source, loads data/raw_data.npz, runs reconstruct with alpha0.001 and15 updates, creates output/ and saves float64(1,30,30) reconstruction to output/reconstruction.npz. It does not load truth/reference assets, import a domain library or change a plotting backend. Shared CPU thread variables are set by the validated execution environment.

`preprocessing.load_data(path)` uses allow_pickle=False and returns unbatched copied arrays: measurements complex128(9,10), illumination_angles float64(10)rad and receiver_angles float64(9)rad. It does not fit calibration or alter values.

`physics_model.coordinates(n=30)` returns x,y float64(n,n)m using original half-cell np.arange coordinates. `green_matrices(receiver_angles,n=30)` returns GS complex128(receiver,n²) and GD complex128(n²,n²), dimensionless integrated interactions. `incident_field(illumination_angles,n=30)` returns complex128(n²,source), normalized field. Constants are GRID30,LENGTH0.8m,BACKGROUND_EPSILON4,WAVENUMBER12.575070131717595+0j/m,RADIUS1m. The shipped benchmark is square30; smaller square6 is used only for analytic tests. No unverified arbitrary rectangular geometry is claimed.

`extended_kernel(n=30)` builds the original Hankel-first-kind59² circulant embedding. `prepare_fft(n=30,sources=10)` returns a dictionary G,fft,adjoint_fft,n; transforms are complex128(59,59,10) for default geometry. `fft_A(field,contrast,cache)` and `fft_AH` accept field complex128(n²,source) and contrast(n,n) or flat n², returning the same field shape. They explicitly perform finite zero-extended convolution and its adjoint. `physical_contrast(contrast)` maps the real part through the original relative-permittivity roundtrip, returning complex storage with zero imaginary part. It does not clamp signed values.

`cg_fft(rhs,contrast,cache,maximum_iterations=500,tolerance=1e−8)` returns internal conjugate-system field complex128(n²,source) and actual one-dimensional residual history. Initialization, common denominator, per-source alpha/beta, stopping and zero guards are local executable steps. `total_field(contrast,incident,cache=None)` creates a cache when absent, solves the equivalent conjugated physical system and returns public total field plus inner errors. `scattered_field(contrast,field,gs)` evaluates GS@(contrast[:,None]*field). `forward(contrast,illumination_angles,receiver_angles)` builds geometry and returns prediction,total field,inner history. It is a standalone local forward wrapper for diagnostics; the standard inverse reuses its operators/cache instead of rebuilding geometry each step.

`solvers.linear_kernel(gs,field)` returns receiver-major/source-minor complex128 matrix(90,900). `tikhonov(kernel,measurements,alpha=0.001)` evaluates the original complex normal equation using general NumPy linear solve. `reconstruct(data,alpha=0.001,iterations=15)` returns(outputs,stages), with output reconstruction float64(1,30,30). Stages has GS/GD, incident, complex_contrasts complex128(iteration,900), total_field_inputs complex128(iteration,900,10), final_total_field complex128(900,10), legacy_objective squared field mismatch, physical_residual and state_residual dimensionless vectors, and a list inner_history of actual per-outer inner residual arrays. No function writes files except CLI and explicit review/export paths. Data and hidden truth are never passed interchangeably.

`visualization.ncc/nrmse` implement the same public metric definitions and reject undefined reference cases. `run_experiments(data,truth,upstream,historical)` calls the local solver for alpha0.001/0.01/0.1 and returns fresh images/stages, metrics/table, first-Born image, physical prediction and separately labeled historical summaries. Truth/upstream/historical are used after reconstruction only, never to construct inverse inputs, tune operators or replace fresh solutions. `make_figures(data,e)` creates five multi-panel groups. `export(figures,experiments,directory)` explicitly saves PNG/SVG/PDF plus numeric_sources.npz and metrics.json to a caller-selected private directory.

The notebook’s first code cell explicitly selects inline plotting. It actively reconstructs all three alphas, saves/evaluates the fresh nominal prediction, writes separately identified cleaned_metrics.npz, displays five computed groups and optionally exports them when the maintainer sets IMAGING_REVIEW_EXPORT. The default notebook does not depend on a private path; the variable merely selects an export destination. No library calls matplotlib.use(). Cached author DE/PSO/GA arrays are read only for labeled historical plots. No training or stochastic reexecution is claimed.

`evaluation/judge.py` defines ncc,nrmse,physical_prediction,score_arrays,evaluate,main independently of src. Actual ground_truth.npz takes precedence if both reserved reference files exist. The Judge validates exact real float64(1,30,30), required key, file existence and finite values before scoring, then uses public raw geometry/measurements for an independent dense physical forward. All metrics must meet their fixed directions/boundaries. CLI paths remain caller-relative; evaluator assets resolve relative to __file__. Reports contain status,passed,metrics,thresholds,errors as finite UTF-8 JSON. Exit0 means pass,1 valid poor quality,2 malformed input/evaluator/report failure. Submitted code is never imported or executed.

Fixtures are independent original runs: oracle_stages.npz contains all geometry/Green/incident/measurement/15-update arrays consumed by comparing tests; extra_oracle_stages.npz contains original extended kernel, A/AH action, three inner updates and first linear kernel; truth_averaging_case.npz contains author native60 truth solely to verify exact2×2 physical cell averaging. Ground truth is not a reconstruction. notebooks/reference_outputs/upstream.npz is the original native30 real contrast; historical_author_results.npz contains the deposited three30-run context; cleaned_metrics.npz is an actual fresh notebook measurement archive. Each has a documented test/notebook consumer, with no public solver-input leakage. Tests also cover dense/FFT adjointness, zero/weak scattering, phase sign, regularized stationarity, metric cases and full NPZ/Judge contracts including foreign cwd and truth precedence.
