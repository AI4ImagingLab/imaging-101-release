## Acquisition and physical forward map

For homogeneous parallel faces at normal incidence in nonabsorbing ambient na=1, the isolated primary-pulse ratio has amplitude A=4nna/(n+na)² exp(−αSI d/2). Propagation delay phase is φ=2πf(n−na)d/c, nonnegative for these dielectric pellets n>na. Here fHz,dmetres,c299792458m/s,αSI in m⁻¹. Under negative-exponential FFT, the delayed physical pulse has spectral factor exp(−iφ); the published complex-index convention n+iκ uses physical exp(−iωt) time convention and κ=cαSI/(4πf). These sign statements refer to distinct representation conventions and are explicit. The model neglects absorption in Fresnel interface factors, multiple internal reflections in the isolated primary pulse, scattering and differences in beam coupling. These limitations remain part of interpretation.

## Published common primary-pulse window

For each channel q, take integer peak index jq=argmax|Eq| and actual peak time tq. Let Δtq be mean successive time difference inps; h=round(15/Δtq). The local window length is2h and its support indices jq−h throughjq+h−1, padded with zeros when necessary. Multiply the field by Hann weights w(j)=.5[1−cos(2πj/(2h−1))],j0..2h−1. The regularized per-channel time coordinates are tq+Δtq*arange(−h,h). A distinct optional boxcar experiment uses weights1; it is not the benchmark default.

Choose latest absolute-peak channel q*. Its window time defines the common Δt and unpadded lengthN. Set P=round[(max tq−min tq)/Δt]+1. Extend that channel's time axis byP samples before its first window sample. For each channel use right padding Rq=round[(tq*−tq)/Δt] and left paddingP−Rq. If a channel window has a different number of samples, interpolate by original sample index onto the selected length, exactly preserving the original implementation's convention rather than inventing a new continuous-time interpolation. These steps preserve relative pulse arrival times while suppressing separated etalons.

Let M be the smallest power of two at least the common length, times2³; hereM16384. Use standard unnormalized forward FFT and np.fft.fftfreq(M,Δt), with Δt inps, so numerical frequencies areTHz. For phase reference only, define positive-maximum times ts=time[argmax(fieldslab)] and tb analogously, distinct from absolute-peak window centering. Let ks=2πts fTHz,kb=2πtb fTHz. Compute u=unwrap(angle(S exp(−iks))−angle(B exp(−ikb))). The unwrap uses NumPy's default2π period andπ discontinuity. Find nearest FFT indices to0.2and0.4THz and use the half-open slice[left,right).
