# Shipped implementation and interfaces

`python -m src.main` is the standard complete CPU entry point. `src.main.run(root=None)` locates the task root by its own path unless supplied, loads only `data/raw_data.npz`, actively estimates resolution and runs all three selected optimization stages. It writes `output/reconstruction.npz`, fresh identified measurements under `notebooks/reference_outputs/fresh_measurements.npz`, and an execution record. It returns `(prediction, diagnostics, elapsed_seconds)`. Importing main does not alter the plotting backend. The CLI sets numerical thread variables; callers should set them before Python starts for consistent backend scheduling. No upstream library, hidden baseline or fixture is read by the runtime.

## Data and preprocessing

`preprocessing.load_data(path=None) -> dict` opens NPZ with allow_pickle=False, removes exactly the leading singleton batch axis and copies each public array. Energy/intensity/error arrays become float64 (3,180); temperature float64 (3,); mask bool (3,180); ab fields/moments float64 (215,), c fields/moments float64 (272,). All units are defined in README. No source-specific file reader is required at runtime.

`preliminary_profile(x,*p) -> float64(N,)` implements the explicit five-Voigt profile with the exact 17-variable convention in approach. `estimate_resolution(data) -> (width,diagnostics)` actively fits all 180 low-temperature points, then the four-point linear width regression. Width is float64 (2,), ordered slope/intercept, dimensionless/meV. Diagnostics contains `voigt_parameters` (17,), `voigt_covariance` (17,17) and `width_covariance` (2,2). No fit parameter is loaded from a hidden file.

## Forward and magnetic physics

`physics_model.power(a,n)` computes sequential dense matrix powers. `angular_momentum()` returns five (16,16) float64 matrices `(Jx,Jy_imag,Jz,Jplus,Jminus)`, where physical Jy is `1j*Jy_imag`. `stevens_operators()` returns the six float64 matrices in parameter order. Module constants `OPERATORS,JX,JY_IMAG,JZ,J` are generated from known ion metadata and explicit formulas when imported, not read as opaque calibration.

`diagonalize(coefficients)` accepts six float64 meV values and returns `(H,eigenvalues,eigenvectors)`: real H (16,16), relative energies (16,), and complex eigenvectors (16,16), **rows** are states. Eigenvectors are real-valued for this selected Hamiltonian but the primitive may return complex dtype. `transition(v,w)` takes real row-state components and returns the scalar nonnegative powder angular-momentum strength. `voigt(x,center,alpha,gamma)` evaluates the normalized source signed-width profile with meV arguments and inverse-meV output. Its validated domain restriction is explicit in approach.

`neutron_spectrum(energy,temperature,width,gamma,eigenvalues,eigenvectors)` returns float64 intensity shape (N,) before prefactor/background. `predict(parameters,energy,temperature,width)` takes a float64 (15,) vector, energy (3,N), temperatures (3,), width (2,), and returns float64 (3,N) processed intensity. It applies each model's own expansion coefficient consistently. `magnetization(coefficients,temperature,field)` accepts a 3-vector field in tesla and returns float64 (3,) source-convention g<J> in Bohr magnetons per Er. The physical along-field moment used in the notebook and branch selection has the opposite sign.

## Inverse solver

`solvers.initial_hypotheses()` returns float64 (2,15) runtime initial guesses. `objective(parameters,data,width)` returns the scalar masked weighted residual sum of squares; the data dictionary comes from preprocessing. `select_model(parameters,data)` accepts both branch parameter rows and returns `(index,diagnostics)` after evaluating their positive physical longitudinal magnetic contrasts against the independently measured sign. It raises if contrast fails to identify one branch. Diagnostics labels observed moments and predicted contrasts.

`physics_model.gtensor(coefficients)` returns a dimensionless (3,3) ground-doublet tensor using the original component rounding and doublet basis convention. It is a review diagnostic, not a new solver output. Tensor row norms describe positive physical effective g along x,y,z and are independently checked against full-Hamiltonian small-field Zeeman splitting. The notebook prints fresh and original tensors and physical axis row norms. This preserves original cell14 without claiming a historical paper g value is a known truth target.

`reconstruct(data,maxfev=30000)` returns `(prediction,diagnostics)` after active width estimation and three native Nelder–Mead stages. The default budget is the independently validated converged protocol; no reduced-preview or cached reconstruction mode is used. Prediction contains exactly the four required arrays in README, each with the batch dimension. Diagnostics additionally stores initial parameters, the seven-variable warmup result, all three optimization status/nfev/loss records, first 40 objective inputs/losses per stage, resolution diagnostics and branch selection evidence. A nonconverged stage raises a RuntimeError. Diagnostics are maintainer review measurements, not solver input.

## Notebook and visualization flow

The notebook follows problem, data, physics, method, results and conclusion. Its active reconstruction cell calls `src.main.run` and evaluates those fresh arrays. Upstream comparisons come from identified numerical arrays in reference_outputs and never substitute for fresh predictions. Visualization consumes the returned fresh results plus public observations and separately labeled upstream measurements. Figures retain the two original branches, all three temperatures, active peak-width estimation, initialization comparison, independent magnetic curves, observed low-energy levels and residuals. Runtime and native optimizer statuses are printed. The mathematical renderer and complete nbconvert execution are separate validation gates.

## Evaluation and tests

The standalone Judge consumes only the declared submission, public observations where needed for forward/physical checks, and hidden evaluation assets. It does not import src. All required arrays are validated before scoring. The canonical gauge rule and every threshold are frozen independently of local results.

Tests under `test/comparing_test` consume the frozen original-domain implementation's numeric stages, with documented archive provenance. They compare operators, full preliminary fit/covariance, width regression, eigensystems, transition strengths, full spectra, first 40 objective evaluations for each of three native stages and directional magnetization. Independent checks cover angular-momentum algebra, sum rules, Kramers pairs, transverse gauge invariance and finite-domain Faddeeva reflection. The full-pipeline artifact test checks the independently executed complete CLI, its successful stage counts, first-step histories and final parameters; it does not claim to resample or rerun inside pytest. The notebook supplies another genuinely active complete fit. Judge and malformed-input tests are independent of solver execution.
