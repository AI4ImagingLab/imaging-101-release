# Shipped interfaces and execution

`python -m src.main` is the standard entry point. Its `main(argv=None)` parses `--input` (default task-relative data/raw_data.npz), `--output` (default caller-relative output/reconstruction.npz) and `--iterations` (30). It loads observations, reconstructs the complete sky, prints per-update likelihood and timing JSON, creates the output parent, and writes one float32 `(1,3072)` intensity array. The CLI sets OMP/BLAS thread counts to one before numerical imports. Importing src.main has no plotting/backend side effect.

## Preprocessing and array contracts

`load_observations(path) -> ObservationData` validates the bound public NPZ using allow_pickle=False. `ObservationData.events` and `.background` are uint8 `(278,184320)` photon-count views. `.operator` is a ComptonOperator. Coordinates are `(3,3416064)` int32 zero-based physical indices after subtracting original underflow-slot offsets; weights are float32 seconds. Exposure is float32 `(3072,)` in cm2 s sr. The private `_read_response(path)` streams the standard NPZ member without allocating an extra full response; return is uint16 `(3072,184320)` exact simulation tallies. The public float32 area multiplier converts each tally to cm2. Loading reads no truth, reference, checkpoint, external file or upstream library.

## Acquisition operator

`ComptonOperator(response,coordinates,weights,exposure=None,pixel_area=4*pi/3072,response_area=1.)` constructs sparse CSR rotation of shape `(278*3072,3072)`; supplied bound calibration sets actual dimensions. Forward/transpose arithmetic uses float32. `forward(intensity,add_floor=True)` accepts `(3072,)` or `(1,3072)` intensity in photons cm^-2 s^-1 sr^-1 and returns `(278,184320)` source photon expectations. Rotation multiplies intensity by dwell seconds; calibrated detector response then contracts incoming direction, followed by solid angle. Add-floor default adds1e-12 counts; disable it for linear adjoint tests. `adjoint(data)` takes the same count-space shape and returns `(3072,)`, implementing the transpose without floor. `compute_exposure()` returns `(3072,)` in cm2 s sr using response-row sums and summed attitude weights. Forward output columns tile8192 and transpose output directions tile32; reduction dimensions are complete. No output trimming/cropping is performed.

`ring_pixel_angles(nside=16)` returns two float64 `(12*nside**2,)` arrays, colatitude and longitude radians in HEALPix RING order. It implements the ring formulas locally and is used only to label/render sky maps. No healpy dependency is used.

## Inverse and objective

`poisson_log_likelihood(events,expectation)` returns a Python float of the float32 full-array sum d*log(mu)-mu, with no factorial constants or normalization. `reconstruct(data,iterations=30,initial_intensity=1e-4,stopping_increment=.01,callback=None) -> ReconstructionResult` follows approach.md, including additive float32 delta, fixed background, nonnegative clipping, step1 and no optional advanced flags. It validates positive finite initialization and exposure. Callback is `(iteration,model,delta,likelihood)` and is invoked after the fresh update/objective. Its arrays are ephemeral internal views; callbacks that retain arrays must copy them. Result contains `.reconstruction` float32 `(1,3072)`, `.maps` float32 `(number_updates,3072)`, `.log_likelihood` float64 `(number_updates,)` storing actual source-precision scalar values, `.delta` float32 `(3072,)` final additive update, and `.seconds` wall time. At most30 updates are used by default; the bound acquisition executes30. No solver function writes files.

## Independent evaluator and tests

`evaluation/judge.py` imports no solver module. `evaluate(prediction,evaluation_dir=None,public_data_path=None)` returns `(report,code)` with caller-relative prediction/report CLI paths. Shape/dtype/nonnegative/finiteness and metric domains are validated before full scoring. Unexpected future truth assets require a separate explicit truth-quality certification and cannot silently replace the current scalar attainable-quality protocol. Missing metric/public assets or finite-arithmetic overflow return error2/empty metrics. Current pass0/fail1 is determined by complete normalized Poisson deviance, unchanged source closure and zero unsupported positive-count bins.

`public_context(path)` independently constructs a float64 CSR attitude factor and loads exact uint8 observations/background, float32 area and public exposure. `factorized_blocks(fields,public_path,context,block_columns=2048)` streams exact uint16 response into a temporary read-only memmap; each yielded tuple is `(start,stop,predictions,available_host_bytes)` with predictions `(number_fields,278,stop-start)` float64. Every reduction includes all3072 incoming directions. No full float response or full51M-bin float64 prediction is allocated. `forward_statistics(fields,public_path,context=None,callback=None)` sums every measurement and reports normalized deviance, unsupported bins, source count, total bin count and host-memory low-water mark; callback receives `(start,stop,predictions)` for independent maintainer controls only. `deviance_sum(observed,mean)` uses stable log differences; positive observations at zero mean receive a finite rejecting report penalty, not physical mean clipping. A6GiB free-host guard prevents unsafe tiled work. These routines never read solver caches or import inverse mathematics.
