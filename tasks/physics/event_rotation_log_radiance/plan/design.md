# Shipped interfaces and actual execution flow

`python -m src.main` reads `data/raw_data.npz` relative to the caller's workspace, calls the local TV method and writes only `output/reconstruction.npz`, creating output if necessary. Its required reconstruction key is float64(1,180,240). It prints actual CPU runtime. Importing the CLI does not import plotting utilities or mutate a Matplotlib backend. There are no root entry-point wrappers and no cross-task imports.

`preprocessing.load_observations(path='data/raw_data.npz')` returns copied events(27643,4),angular_velocity(3,),intrinsics(3,3),allfloat64, using allow_pickle=False. `normalize_clock(events)` returns a float64 event copy with unit-interval timestamps and scalar duration in seconds; it rejects a nonpositive interval. `rotational_displacement(angular_velocity,intrinsics,duration)` returns float64(2,180,240), component order rightward-x/downward-y in pixels per whole window, from independent gyro and pinhole calibration.

`physics_model.accumulate_events(events,displacement)` accepts normalized-time events(N,4)and a(2,H,W)window displacement, returning float64(H,W)bilinear signed event counts. The flow sample uses separate axis floors. `normalized_motion(displacement)` returns unit_flowx,unit_flowy,safe magnitude,border mask,each(H,W),dimensionless except magnitude in pixel/window. `directional_matrix(flow_y,flow_x)` returns CSR(HW,HW),dimensionless one-pixel directional differences. `derivative_matrices(shape)` returns CSR Gy,Gx,Lap,each(HW,HW),with explicit centered and edge stencils.

`solvers.normalize_log_image(x)` maps a2Dlog image to the stated percentile gauge. `reconstruct(events,angular_velocity,intrinsics,method='TV',weight=None,outer_iterations=20,warp_fraction=1.0)` returns(image,state). Method TV defaults to source parameter.1and Laplacian to.3; the outer cap applies only to TV. Image is float64(H,W),dimensionless relative log radiance. State contains raw_log_image(H,W)in unit-contrast log units,iwe andniwe(H,W),displacement(2,H,W),unit_flowx/y andflow_magnitude(H,W),history(K,3)of[data cost,anisotropic TV,outer-update norm],andCSR A. For Laplacian,history is an empty array. `warp_fraction` is a dimensionless diagnostic multiplier on trajectory displacement only; it leaves inverse-model displacement unchanged. Default1is the physically corrected model. Setting it to the acquisition duration expressed numerically in seconds reproduces the earlier seconds-clock convention for a controlled notebook comparison. It is never used by the standard CLI.

`visualization.metrics(x,reference)` computes the same cosine NCC and dynamic-range NRMSE as the independent evaluator. `run_experiments(events,angular_velocity,intrinsics)` actively computes standard TV,Laplacian,the seconds-clock control,TVweights.03/.1/.3/1,andindependent gyro multipliers.8/1/1.2; it also computes uncompensated signed event accumulation. Its dictionary contains fresh arrays,states,parameters and actual elapsed time. `make_figures(result,references,export_dir=None)` takes those fresh arrays and explicitly identified original references, returns five(name,Figure)pairs and a parity metric table. If export_dir is provided it writes each actual figure as PNG/SVG/PDF plus numeric_sources.npz,metrics.json and figure_manifest.json withSHA256. No output method is invented or loaded as fresh.

The active canonical notebook reads the raw observations, calls run_experiments, independently loads original measurements from notebooks/reference_outputs/upstream_methods.npz,checks TV/Laplacian/seconds-control parity,writes the fresh TV submission,then invokes the standalone Judge as a subprocess. It loads no upstream package or checkpoint. Inline plotting belongs to the notebook. The private runner sets IMAGING_FIGURE_DIR to the group archive and JUPYTER_PATH to its private shared-Python kernel; timeout240seconds. After successful nbconvert, actual execution counts and all five inline plots are preserved in the canonical file. Private executed temporary copies remain outside the task.

`evaluation/judge.py` independently implements input validation,metrics,public-physics voting and directional comparison, with no imports from src. Required CLI arguments are --prediction and --report. Prediction/report paths are caller-relative; hidden reference and config are resolved from the Judge's own file. If ground_truth.npz exists it takes precedence; otherwise baseline_reference.npz is used. A malformed existing truth asset is an evaluator error and never silently falls back to the baseline. This release has no calibrated actual truth and ships only the baseline. Public observations are loaded from the same task's data directory only to check observation consistency. Malformed arrays,missing assets,invalid metric configuration or nonfinite arithmetic produce empty metrics,statuserrorandexit2; valid below-boundary submissions exit1;pass exits0. Report-write errors print a diagnostic and exit2. The Judge never imports submitted code.

Unit and comparing tests consume frozen numeric arrays only. The fixtures' source original calls and the one-line qualified correction are recorded in validation; test execution does not import the original source. Hidden baseline_reference is the qualified TV method image. No ground_truth file is shipped because no calibrated physical truth is available. Requirements contain NumPy,SciPy,Matplotlib from the shared environment;Torch,PyLops,OpenCV,pandas and image codecs belong solely to isolated private verification.
