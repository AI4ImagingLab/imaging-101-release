# Actual interfaces and data flow

`src.preprocessing.load_data(path='data/raw_data.npz')` reads allow_pickle=False and removes the single batch axis, returning nine acquisition arrays. Computation is float64. All84 points of each channel remain included.

`src.physics_model.unpack(parameters,dead=True)` returns intensity, broadening, offset, buried/surface roughness, suppressed thickness, magnetic/nuclear SLD and film thickness; a uniform-model vector omits suppressed thickness and gets d=0. `layer_stack(parameters,dead=True)` returns widths,nuclear,magnetic,roughness in incident-to-substrate order. `layer_reflectivity(q,width,nuclear,magnetic,roughness,spin)` returns unbroadened84-point intensity. `gaussian_resolution(q,values,sigma)` integrates intensity piecewise-linearly against the exact truncated Gaussian and returns84 intensities. `predictions(parameters,data,dead=True)` returns (2,84) dimensionless intensities, applying offset, broadening and common intensity. `depth_profiles(parameters,depth,dead=True)` returns (521,2) nuclear/magnetic SLD in1e-6 Angstrom^-2. These functions neither read hidden assets nor write files.

`src.solvers.bounded_simplex(objective,initial,lower,upper,radius=.15,xtol=1e-7,ftol=1e-9,maxiter=15000)` returns parameters,objective,iterations,calls,scaled_size,objective_spread,history. It executes explicit bounded derivative-free updates and raises when convergence criteria fail. `fit_model(data,dead=True,initial=None)` uses the original initial vector unless an explicit sensitivity start is provided; it adds prediction,profiles,reduced_chi_square to the fit dictionary. `reconstruct(data)` fits the suppressed-layer model and returns (output,result), where output has reconstruction(1,521,2) and parameters(1,9).

`python -m src.main` reads data/raw_data.npz, calls reconstruct and writes output/reconstruction.npz. It does not import plotting or change a backend. Visualization helpers are invoked by the notebook with fresh numerical results. The notebook separately runs fit_model(dead=False) for the actual uniform-magnetization comparison. This comparison is not silently substituted for the required output.

`evaluation/judge.py` independently duplicates forward/profile mathematics and never imports src or submitted code. It validates both required outputs and physical bounds, uses actual truth if present otherwise the explicit method baseline, checks reference consistency, and evaluates all metrics. Caller-supplied prediction/report paths resolve against cwd; hidden assets are relative to the Judge. Missing/malformed input or assets return error/exit2 with empty metrics; valid poor output returns fail/exit1; passing output returns pass/exit0. UTF8 JSON never contains nonfinite values and report-write failure emits stderr/exit2. Native original execution is confined to private maintainer archives; frozen NPZ tests import no Refl1D/Bumps.
