# Shipped execution and interfaces

Standard command is `python -m src.main`, calling main.main(). It resolves task root from __file__, reads data/raw_data.npz, invokes reconstruct with nominal defaults, creates output/ and writes output/reconstruction.npz. No hidden reference, plotting module, private source or domain library enters that path. There is no generator because all benchmark observations and independent calibration already existed.

`preprocessing.load_data(path)` reads allow_pickle=False and returns unbatched copied arrays for9public keys. `pad_flux(data,mode='linear_ramp')` returns flux float64(301,401), padded x float64(401),y float64(301). Its input flux has shape151×201, with measured xs201,ys151. It preserves original coordinate arithmetic and default zero ramp endpoints. X_PAD100,Y_PAD75 are fixed analysis-boundary constants.

`physics_model.frequency_grid(shape,dx,dy)` returns float64 Kx,Ky,K of shape, in rad/um, using exact shifted FFT bins. `psf_transfer(psf)` returns complex128 transfer of the same shape after ifftshift sets its array-center origin. `hanning(k,cutoff=1.)` returns a dimensionless real radial window with radius sqrt2*cutoff. `invert_spectrum(flux_k,psf_k,kx,ky,k,h,standoff=1.)` returns(current_spectrum,factor), complex128(2,rows,cols)and(rows,cols), preserving the given signed transfer and explicit zero DC. `forward_spectrum(j_k,psf_k,kx,ky,k,standoff=1.)` returns complex128 flux spectrum, using the full spatial field and zero K0 response. MU0 is the SciPy1.17.1 numerical constant; STANDOFF1um.

`physics_model.diagnostics(current,data,cutoff=1.)` builds its local full forward from real current(2,301,401) and public calibration. It returns filtered_forward_residual,divergence_ratio,dc_ratio and prediction_k,target_k spectra. The latter are used only by notebook visualization. The standalone Judge separately implements equivalent forward mathematics and never calls this helper or imports src.

`solvers.reconstruct(data,cutoff=1.,standoff=1.,pad_mode='linear_ramp',use_psf=True)` returns(outputs,stages). outputs contains reconstruction float64(1,2,301,401)in author signed a.u.; axes batch,component,y,x. Stages has padded_mag301×401,padded_xs401,padded_ys301,mag_k/psf_k/Kx/Ky/K/H/factor/jx_k/jy_k301×401,full_complex complex128(2,301,401),and scalar imaginary_ratio. The helper rejects a significant imaginary result before real projection. Optional height, boundary and identity-PSF arguments are implemented sensitivity paths, not alternative benchmark defaults. It performs no file I/O.

`visualization.metrics(x,y)` compares each signed component by cosine and relative L2 against a nonzero standard-method reference. `run_experiments(data,corrected_references,unmodified)` executes three fresh cutoff inverses, three fresh height inverses, one identity-kernel inverse and one zero-boundary inverse. It returns current/stage arrays, parameter table, ablations, original complex field, scalar metrics and forward spectra. References are used only after fresh reconstruction. `make_figures(data,e)` creates five scientific multi-panel groups without selecting a backend. `export(figures,data,e,directory)` explicitly saves private PNG/SVG/PDF, exact numeric_sources.npz and metrics.json in a caller-selected location.

The notebook selects `%matplotlib inline` in its first code cell, imports only local modules, loads raw data and independently captured reference archives, actively executes the complete selected inverse/comparison path, evaluates the fresh nominal output with the independent Judge, writes fresh separately identified notebook measurements and displays5computed figures. Default writes use output/reconstruction.npz and output/judge_report.json; optional IMAGING_REVIEW_PREDICTION/REPORT/EXPORT route maintainer review files elsewhere without hard-coded private dependency. Library imports never call matplotlib.use or switch a backend.

`evaluation/judge.py` exposes cosine,relative_l2,physical_metrics,evaluate,main. Paths to hidden assets resolve from __file__; caller-specified prediction/report paths remain caller-relative. It validates real float64 exact(1,2,301,401), required key and finite values using allow_pickle=False. It prioritizes actual ground_truth.npz if available, otherwise the standard baseline_reference.npz. It reads the seven canonical top-level `<metric>_boundary` entries in metrics.json as actual scoring boundaries, with directions from the separate comparisons dictionary; missing boundaries are evaluator errors. It computes both components' metrics independently and public-calibration physical constraints, emitting finite UTF-8 JSON status,passed,metrics,thresholds,errors. Exit0pass/1valid poor/2malformed or evaluator/report failure. Report parents are created. It never imports/runs submitted solver code.

Tests under test/ use independently captured original numeric fixtures, analytic Fourier modes, centered delta/even kernels, DC/divergence, exact coordinate/data contracts, full CLI/foreign-cwd Judge execution and malformed/poor/evaluator/write-error cases. `test/fixtures/corrected_stages.npz` is consumed completely by stage tests, including stored dx/dy. `notebooks/reference_outputs/corrected_0.5,1,1.5.npz` are original corrected method results used in cutoff parity and notebook posthoc comparisons; `unmodified_original.npz` retains the original full complex current and old Kx/Ky for discrepancy review. `cleaned_measurements.npz` is written by the fresh notebook then read as a separately identified measurement record, never as inverse input. Original source/papers/capture logs are private outside the task; there is no cross-task dependency.
