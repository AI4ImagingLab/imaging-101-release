# Shipped interfaces and actual execution flow

## Standard complete path

`python -m src.main` loads the sole public NPZ, retains native lower clipping, builds the complete16-by5 angular design, computes the native pseudoinverse and all five full-resolution fields, then writes output/reconstruction.npz. It uses no hidden reference, original library, cross-task import or display normalization. Existing observations are reused for the benchmark. The separate generate_data.py generates only the maintainer sensitivity perturbations described below; it does not regenerate or overwrite the primary observations.

`preprocessing.load_observations(path=None) -> dict` defaults to task-local data/raw_data.npz. It loads allow_pickle=False, requires exactly intensity/polarizer_psg/polarizer_psa, finite floating arrays and declared batch-first shapes. Returned arrays remove the singleton batch axis: intensity(16,2048,2448)float32 instrumental radiance and angles(16,)float64 radians. It reads no metadata JSON or target. Module constants HEIGHT2048,WIDTH2448,FRAMES16 agree with README.

`preprocessing.prepare_intensity(intensity) -> ndarray` accepts finite(frame,row,column) intensities and returns clip(input,0,None). HDR values above1 remain unchanged. It performs no gain fit, gamma correction, crop, averaging or mask selection.

## Explicit physical operators

`physics_model.design_matrix(polarizer_psg,polarizer_psa,complete=False) -> float64(states,5)` builds the five stated trigonometric terms. Angles must be equal finite one-dimensional vectors in radians. With complete=True, return shape(states,9), adding analyzer-only and generator-only sine/cosine terms in the documented review-control order. It does not read a library Mueller operator.

`coefficients_to_fields(coefficients) -> ndarray(5,row,column)` applies the source sums/differences, two amplitudes and signed U formula to five linear coefficient maps. `fields_to_coefficients(fields) -> ndarray(5,row,column)` evaluates the exact inverse map using the two complex magnitudes. Both preserve instrumental radiance units and neither clips the inferred U. These functions also work on smaller analytic fixture grids without changing the complete standard loader contract.

`forward(fields,polarizer_psg,polarizer_psa) -> ndarray(states,row,column)` explicitly applies the angular matrix to coefficients obtained from the five physical fields. `components(fields) -> dict` returns unpolarized, sum_amplitude, difference_amplitude, sum_phase and difference_phase maps; amplitudes use radiance units, phases radians modulo pi. Native source F/R map to sum/difference respectively. Phase at zero amplitude is a display convention and is not an evaluated output quantity.

`relative_residual(fields,intensity,polarizer_psg,polarizer_psa,block_rows=64) -> dict` predicts every observation and accumulates squared float64 residual/observation norms over64-row blocks. It returns scalar relative_l2, full-image rms_map in radiance units and per-state frame_relative_l2. The row blocking changes memory use only: all states/pixels enter. Original lower clipping is applied to observations; output fields are not clipped. No file is written.

## Inverse mathematics and CLI

`solvers.reconstruct(intensity,polarizer_psg,polarizer_psa) -> dict` supports any full-spatial grid with at least rank-five angular states. After lower clipping, it builds W, rejects rank<5, uses np.linalg.pinv with the unchanged original default and computes the original tensordot in(row,column,state) representation. It returns reconstruction(5,H,W),coefficients(5,H,W),design(states,5),pseudoinverse(5,states), all float64. There are no iterative defaults, initial states, regularizers or stopping rules to conceal. Every matrix/field unit follows approach.md.

`main.main() -> dict` calls only load_observations and reconstruct, creates task-local output and writes exactly reconstruction(1,5,2048,2448)float64. It returns the fresh inverse dictionary and prints complete-path runtime. It neither imports visualization nor mutates Matplotlib's backend. Importing main in a Notebook is safe.

## Active review-only controls

`solvers.unrestricted_mueller(intensity,polarizer_psg,polarizer_psa) -> dict` computes the full rank-nine comparison least squares, returning coefficients(9,H,W) and design(states,9). It preserves all measured states and is not the standard answer. `review_comparisons(data,fresh) -> dict` actively computes angle-only measurement-budget fields for5/8/12/16 states, evaluates all-state prediction errors, computes full9basis residual maps and three newly generated full-grid noise perturbations. Frozen state indices are[5,7,9,10,14],range8,range12,range16. The native16 result is reused by reference inside this comparison, explicitly identified as the same already computed primary, rather than run a redundant duplicate inverse.

The noise controls reset diagnostic RNG31917 at each level for common random perturbations and use sigma fractions0.005/0.01/0.02 of each measured frame's full-spatial RMS. They retain the source lower clipping and measure newly clipped fractions. Returned dictionaries contain support_fields keyed by state count, support_metrics, rms9,frame_relative9,relative9, noise_metrics and noise_sum_amplitudes keyed by fraction. All images are full native resolution. No noise-perturbed observation enters the benchmark raw_data.npz or standard CLI. Larger temporary arrays are released between controls; no GPU is required.

`generate_data.add_gaussian_perturbation(intensity,frame_rms,fraction,seed=31917) -> float64(states,row,column)` performs that same frozen sensitivity-only generation. Inputs are finite images in instrumental radiance units, one measured nonnegative RMS per frame and a nonnegative dimensionless standard-deviation fraction. It copies images to float64, constructs the NumPy default generator and draws/adds one complete frame at a time in unchanged order. It returns un-clipped perturbed observations and writes no file. The caller measures negative fraction, then reconstruct applies the original lower clip. This helper extraction preserves every previously computed full-field noise control bitwise; it does not change the selected inverse or any threshold.

`visualization.make_figures(data,original,fresh,residual,comparisons,upstream_summary,directory=None) -> (figures,metrics)` consumes actual outputs of those methods. It returns six figures and full-precision metrics, using locally scoped rc settings without backend mutation. Optional export writes figure1–6 PNG/SVG/PDF, figure_numeric_source.npz, figure_metrics.json and figure_provenance.json. Full original/fresh fields, displayed observations, RMS/relative residual maps, budget/noise amplitudes, angle coverage and per-state metrics have explicit numeric sources. Quantile saturation/colorbar extensions and sqrt/sRGB display transformations never modify the inverse or metric arrays.

The canonical Notebook has six problem/data/physics/method/results/conclusion chapters. It loads the public input, actively calls main, then loads the independent original reference only for comparison. It actively computes all review controls, runs standalone Judge, displays all six figures and saves numeric fresh_review.npz diagnostics. Full fresh fields already exist in output/reconstruction.npz; they are not duplicated as a second full hidden reconstruction array. upstream.npz holds independently captured original scalar diagnostics. The single full original method reference is evaluation/baseline_reference.npz and is explicitly identified wherever used.

## Standalone evaluation and tests

Judge resolves hidden/reference/calibration paths from its own file directory. ground_truth.npz has priority whenever present; otherwise it uses baseline_reference.npz. The actual real dataset supplies only the method reference. Invalid truth never silently falls back. Prediction/report paths remain relative to caller cwd. load_prediction forbids pickles and requires exactly reconstruction, the declared shape, supported real float32/float64 and finite values; no reshape/crop/type coercion hides errors.

Judge independently evaluates the direct sum/difference angular formula, not runtime source imports. It measures all five full-channel norm ratios and a complete observation residual. Each boundary must be a positive finite number; degenerate reference/observation norms are evaluator errors. UTF-8 finite JSON has status,passed,metrics,thresholds,errors. Exit0 denotes pass,1valid poor prediction,2input/evaluator/report-write error; malformed input has empty metrics. Report parents are created when possible, and write failure emits stderr.

Frozen original stage tests consume only numeric fixtures. Analytic forward/Jones/derivative/rank/unit tests independently validate signs and scale. Judge cases cover both precisions, foreign cwd, zero/scaled/permuted/magnitude/clipped or missing quadratures, malformed NPZ/key/shape/dtype/object/NaN/Inf, missing assets/calibration, invalid thresholds, actual-truth precedence and report failure. Full CLI and active Notebook are separately executed, with final artifact/parity tests linking their actual outputs and diagnostics. No normal test imports an upstream/oracle module.
