# Shipped execution and interfaces

`src.preprocessing.load_data(path)` loads all public NPZ arrays with allow_pickle=False, checks the three principal float64 arrays (1,228,125), finite samples, valid time lengths and baseline count; returns a dict retaining batch dimension. `case_data(data,index)` returns valid float64 time, kidney signal, aortic signal vectors of length L and calibration dict with tr, flip_angle, tissue_t1, blood_t1, relaxivity, volume, field_strength, n0 and H. NCASES=228, MAX_TIME=125, HCT=.45. No hidden file is opened.

`src.physics_model.exponential_convolution(flux,transit,time)` returns a normalized exponential convolution vector on arbitrary strictly increasing sampled seconds. Zero transit returns a copy of input as the original limit. `compartment_concentration(arterial_plasma,time,parameters)` accepts M input and parameter vector [Fp,vp,f,Tt]; returns (2,L) M tissue-normalized concentrations. `steady_signal(scale,R1,tr,flip_angle)` accepts scalar or array R1 in s^-1 and angle degrees, returns real magnitude in scale units. `arterial_concentration(signal,cal,sequence='SS')` returns mol/L blood concentration; comparison sequence='lin' invokes linear calibration. `predict(parameters,time,arterial,cal,scale,sequence='SS',delay=0.)` receives already calibrated blood input, returns (signal (L,),compartments (2,L),R1 (L,)); delay in seconds is used only by the explicit comparison variant.

`src.solvers.fit_case(time,signal,aorta,cal,variant='measured')` returns (parameter vector,fitted signal,diagnostics). Primary vector length4; linear_delay length5 with delay first. Diagnostics contains arterial_concentration, compartments, R1, scale and covariance. It copies cal before modifying comparison T1. Supported variants are measured, ss_literature, linear and linear_delay. INITIAL=[.02,.15,.1,120], LOWER=[0,0,0,30], UPPER=[.05,.3,.3,inf]. No hidden initialization or learned calibration. `reconstruct(data,variant='measured')` iterates all228 cases and returns (outputs,diagnostics list); primary reconstruction is float64 (1,228,4), signal float64 (1,228,125), padding zero. The optional delay comparison has five parameters and is not a valid primary submission.

`src.main.main()` resolves task root from module path, loads data/raw_data.npz, reconstructs primary model, writes output/reconstruction.npz and prints runtime. No Matplotlib backend is selected at import. `src.visualization.clinical_statistics(mri,isotope)` returns bias, population SD (ddof0), RMSE in mL/min and P30 fraction, using all supplied cases without bias removal. `bland_altman(mri,isotope,groups)` returns a two-panel Figure, grouping by field strength1/3T and displaying identity/bias/95% population limits. It does not save or choose a backend.

Standalone evaluation/judge.py has no solver imports. load_arrays enforces required keys, exact shapes, real float64 and finite values. metrics evaluates four parameter errors, maximum signal-reference and observed-signal errors, and padding. Nonpositive transit is rejected before logarithms. Public lengths and measured signals are read relative to the Judge. evaluate returns (report,code), prefers actual truth if present, otherwise baseline_reference; no parameter truth exists here. main implements --prediction/--report with 0 pass,1 quality failure,2 malformed/evaluator/report-write failure, UTF-8 finite JSON and report-parent creation. Prediction paths follow caller CWD; hidden references follow Judge path.

test/fixtures/upstream_stages.npz holds original calibrated arterial curves, compartments, R1, baseline scales and independent source-function synthetic probe outputs, consumed by comparing tests. These synthetic probes validate mathematics only; benchmark observations remain entirely measured. evaluation/baseline_reference.npz stores original primary parameter/fit arrays. notebooks/reference_outputs/upstream.npz stores original primary and comparison outputs plus independently measured isotope values (raw stored scale), consumed solely for review. Fresh cleaned_measurements.npz is separately generated and labelled after validation, never a solver input or active notebook reconstruction replacement. Original archives, paper, raw CSVs, capture scripts and logs remain outside this task under the private bio_med archive.

The notebook uses cleaned modules for complete primary and three alternative cohort reconstructions, then computes fresh metrics and visual comparisons. Additional profile-likelihood computations explicitly call local predict with general SciPy curve_fit; no domain solver is imported. Plans and public contract preserve units, source metadata discrepancies, original defaults, returned shapes and actual execution paths.
