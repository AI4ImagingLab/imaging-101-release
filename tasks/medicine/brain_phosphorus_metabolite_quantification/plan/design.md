# Shipped interfaces and execution flow

The standard command is `python -m src.main`. `src.main.run(data_path=None,output_path=None)` loads `data/raw_data.npz` with pickle disabled, calls the complete local reconstruction and writes `output/reconstruction.npz`. Defaults are relative to the task module directory; explicit path arguments are caller-relative. The result contains every required output quantity, and run also returns fresh numerical diagnostics and actual elapsed seconds. No hidden reference or checkpoint is read by the solver. Importing main neither executes reconstruction nor changes a notebook backend.

`preprocessing.time_axis(n,spectral_width=10000.0,deadtime=300e-6)` returns a float64 `(n,)` time vector in seconds using the exact original arange convention. `interleave(fid)` returns float64 `(2*n,)` real/imaginary pairs with no magnitude conversion. The shared constants `SPECTRAL_WIDTH_HZ`, `DEADTIME_SECONDS` and `NUCLEAR_FREQUENCY_MHZ=120.0` are checked against the README and source fixture. The public FID is complex128 `(1,1024)`; the solver works on its single batch as `(1024,)`.

`physics_model.components(parameters,time)` takes `(K,5)` real parameter rows in amplitude/Hz/damping-per-second/radian/g order and float64 `(n,)` seconds, returning `(K,n)` complex128 component FIDs. The standard K is 16 and g=0; the complete published expression is explicit. `forward(parameters,time)` sums those components into `(n,)` complex128. `physical_jacobian(parameters,time)` returns float64 `(2*n,4*K)` derivative columns in per-peak amplitude/frequency/damping/phase order; g is excluded because it is fixed in this binding. These routines do not access files or import an MRS library.

`solvers.py` defines exact original effective `INITIAL_VALUES`, `LOWER_VALUES`, `UPPER_VALUES` (80 floats), `FREE_INDICES` (37 integer indices) and `PEAK_NAMES` (the complete 16-component order). The arrays are maintainer algorithm/physical-prior constants, not reconstructed targets. `expand_parameters(free_values)` maps a `(37,)` physical vector to `(16,5)` and applies explicit multiplet amplitude/frequency/damping ties, common phase and original bound clipping. `internal_values(external)` and `external_values(internal)` implement the invertible Minuit bound maps over the 37 free values. `residual(free_values,time,fid)` returns the unnormalized observed-minus-modeled real/imaginary residual `(2*n,)`.

`solvers.reconstruct(fid,use_lm=True,phase_constraint=True)` consumes the complete complex vector and returns `reconstruction` `(16,)`, `frequency_hz` `(16,)`, `linewidth_hz` `(16,)`, `phase_rad` `(1,)`, complete final and first-stage parameter arrays `(16,5)`, `(n,)` fitted FID, `(2*n,)` residual, `(37,)` final free vector, objective, tolerance and optimization counters. All returned physical values are float64 except the explicitly complex FID. Default use_lm=True performs the full published LM->TRR path. use_lm=False is the notebook's labeled TRR-only comparison. phase_constraint=False is rejected because this binding has one physical receiver phase; independent-phase fitting is not silently substituted. The standard command never changes defaults based on hidden results.

`visualization.amplitude_metrics(estimate,reference)` implements standard NCC and dynamic-range NRMSE, rejecting degenerate references. `observation_metrics(measured,predicted)` separately names uncentered relative L2, original centered relative squared error and the residual sum of squares. `spectrum(fid,spectral_width=10000.0)` returns FFT-bin frequencies in Hz and a complex forward-FFT spectrum. Matplotlib is a plotting dependency only; no library module selects a backend.

The active notebook calls run() on all raw observations, compares fresh outputs with the independent upstream measurements and computes all additional method/time-window/noise experiments using cleaned source modules. Its figures and tables identify observations, numerical method references and fresh fits separately. It imports neither the upstream domain library nor a private capture script. Files in `notebooks/reference_outputs/` hold identified independent source and fresh measurements solely for review; they are not solver input or a cache substituted for reconstruction.

The independent standalone `evaluation/judge.py` validates each declared key/shape/float64 dtype/finiteness and its physical sign/range. It independently evaluates every submitted amplitude, frequency, linewidth and phase, then recomputes the explicit complex observation model from public FID/timing. Hidden references resolve relative to the evaluator, not the caller's working directory. Actual truth would take precedence if independently supplied; this binding has only a method reference. The CLI writes UTF-8 strict JSON and returns 0 for pass, 1 for valid low quality and 2 for malformed input or evaluator/report-write errors. It never imports solver code or coerces complex predictions to real.

All tests, frozen source fixtures and authoritative validation evidence reside under test/. Original source/archive/PDF/capture scripts/logs and the separate oracle environment remain in a maintainer-only directory outside this task. The cleaned runtime uses only standard library, NumPy, SciPy and Matplotlib. No generator module is included because an existing author observation is reused, even though that author's original benchmark was synthetic.


Precision refinement: reconstruct retains its existing callable signature and37-free-variable constraint expansion. Its TRR stage now uses the independently executed original publicAPI precisioncontrols described in approach.md. It returns the same four outputarrays and existingdiagnostics. The notebook also consumes upstream_default.npz as a separately labeled superseded original-default measurement to show actual linewidth/amplitude shifts; it is not the Judge reference or a fresh substitute. Final baseline_reference and upstream_standard come only from the newly frozen independently converged original run.
