# Implemented mathematical and numerical method

This binding uses the complete 1,024-point author-released complex FID and the author's 16-component phosphorus resonance model. It is an existing author-synthetic benchmark, not data newly simulated by the cleaned code. No exact generating parameter array for this particular noisy file has been independently identified; the independent original method result supplies a method reference, not fabricated truth. The nominal field label is 7 T while the exact nuclear frequency used by the source is 120 MHz. The raw ASCII observations are converted without numerical change to batch-first complex128 NPZ.

With t_n=300e−6+n/10000 seconds, predict y(t)=sum_k a_k exp(i phi_k) exp(−d_k(1−g_k+g_k t)t) exp(i2πf_k t). The full published lineshape expression is explicit executable code; this selected benchmark fixes every g_k=0 and uses one common receiver phase, so d_k=πw_k gives a Lorentzian FWHM w_k in Hz. Amplitudes are signal values extrapolated to time zero, not sample-zero measurements and not calibrated molar concentrations. Frequencies are Hz relative to the carrier, phases radians, damping s⁻¹. No Fourier-sign reversal, complex conjugation, amplitude normalization or truncation occurs in the standard pipeline.

All 80 original scalar parameter entries are represented locally as 16 rows [amplitude,frequency,damping,phase,g]. Free indices follow the original insertion order: the BATP parent contributes amplitude/frequency/damping/phase, and each of the remaining 11 parent or independent resonances contributes amplitude/frequency/damping. Thus there are 37 free physical parameters. The complete constraints are explicit: BATP2 and BATP3 have half BATP amplitude, ±15 Hz frequency offsets and equal damping; AATP2 and GATP2 have their parent's amplitude, −16 Hz offset and equal damping. Every resonance shares BATP phase; every g is fixed to zero. The source's bound clipping is retained when evaluating dependent expressions, but all final fitted multiplet relationships are inside their respective bounds and retain the exact specified splitting. No weak peak or nuisance quantity is dropped.

The public README specifies the physical resonance ranges. Source parsing converts prior values to initial float32 values before building its lmfit parameter objects, while some bounds are computed at float64 precision. The cleaned INITIAL_VALUES, LOWER_VALUES and UPPER_VALUES preserve the independently captured effective source numbers verbatim, including those initial rounding conventions. Examples are BATP amplitude 1.409999966621399 and BATP damping 182.58937072753906 s⁻¹; these are starts, not hidden targets. Full initial values are the named 80-entry constant vector in solvers.py, with a one-to-one original-parameter hash/index record in validation. Initial parent amplitudes derive from the published prior table; they are maintainer algorithm parameters and are not bundled as input calibration. The standard starts are not changed to fit the captured answer.

The objective is the **unnormalized sum of squared real and imaginary observation residuals**. Interleave a complex vector into [Re(y0),Im(y0),Re(y1),Im(y1),…]. The residual is observed minus predicted; its squared sum equals the complex squared L2 residual. There is no division by N or 2 in the reported objective. SciPy least_squares internally reports half that sum as cost, so the code returns objective=2*cost. The time-domain fit uses all 1,024 complex points and all 16 resonances.

Stage one reproduces the original bounded Levenberg–Marquardt initializer using explicit Minuit-style internal coordinates. For finite lower and upper bounds l,u, external v=l+(sin(z)+1)(u−l)/2 and z=asin(2(v−l)/(u−l)−1). For a finite lower bound only, v=l−1+sqrt(z²+1), z=sqrt((v−l+1)²−1); the corresponding upper-only map is v=u+1−sqrt(z²+1). Unbounded coordinates are unchanged. Tiny internal values below 1e−15 in absolute value are set to zero, as in the source. These transforms are executable local mathematics, not an imported parameter-fitting wrapper.

The residual wrapper maps the 37 internal values to physical values, expands every multiplet/common-phase constraint and evaluates all components. SciPy `leastsq` uses no supplied Jacobian, full_output=1, col_deriv=0, gtol=0, epsfcn=1e−10, factor=100, diag=None and maxfev=2000. The source's 1,000 guarded evaluation limit is never reached on this binding; the successful initializer takes 766 reported function evaluations. Both xtol and ftol are sqrt(abs(max(fid)))*1e−6, with complex maximum interpreted using the source NumPy convention. This evaluates to 2.9561933263337957e−6. The original default finite-difference and step settings are preserved. There is no custom line search or replaced inverse update.

Stage two uses the original public fit_kws precision controls to refine the physical least-squares estimand, rather than reproducing the premature original default stop. It starts from the unchanged stage-one physical vector and calls general SciPy least_squares with method='trf',jac='2-point',exact physical bounds,ftol=xtol=gtol=1e-14,x_scale='jac',linear loss,f_scale=1,diff_step=None,max_nfev=4000. The unmodified original API was independently run with exactly these controls before local precision changed. NativeLM,publicprior and a third perturbedpublicprior converge to the same full16-component optimum within the unchanged physical boundaries. This is an explicit precision-refined published model, not an unchanged-default pipeline claim. The previous default output and its failure under better convergence are archived. Source wrapper and directSciPy finite-difference evaluation counters remain different conventions. Failed optimizers raise rather than substitute cached results.

The local forward model forms each component in the original operation order: amplitude times phase exponential times damping exponential times frequency exponential, then sums components. The physical Jacobian before constraints includes derivatives with respect to amplitude, frequency, damping and phase. For component s, they are s/a, i2πts, −t(1−g+gt)s and is. The 64 physical derivative columns are independently compared to the original source and central differences. The 37-free-variable constrained Jacobian has full rank on the bound observations. Spectral views use an explicit NumPy forward FFT only for plotting, with bin frequencies from fftfreq; no spectrum crop affects fitting.

The standard output is four arrays: all 16 amplitudes, all 16 frequencies in Hz, all 16 FWHM linewidths in Hz and the single common phase in radians. g is a fixed physical model convention and is not an unknown output. Amplitude NCC uses cosine similarity without mean subtraction; amplitude NRMSE uses reference dynamic range. Frequency and linewidth use maximum absolute errors over every component. Phase uses the principal angle of exp(i delta), with output constrained to [−π,π]; no estimated alignment is allowed. An independent Judge re-evaluates the complex acquisition model from the submitted quantities and checks its uncentered observation-relative L2 error. Definitions and thresholds are explicit in metrics.json.

The original source's `Compare_to_OXSA` reports squared complex residual divided by the energy after subtracting the **complex mean**. That historical/source quantity is preserved under the explicit name `upstream_centered_relative_squared_error`; it is not relabeled NRMSE. The uncentered observation-relative L2 value is approximately 0.1870531235, whereas the centered squared source value is approximately 0.04483. The notebook computes and labels both. The original method reference is not independently measured physical truth.

Optional notebook experiments retain the same physical model and include the complete LM->TRR standard, the actual LM initializer alone, TRR-only from priors, shortened acquired time windows with unchanged start time, and added complex observation-noise reruns. The full 1,024-point selected benchmark is always actively reconstructed first. These comparisons are computed afresh and explicitly labeled; they do not replace the standard path or fabricate missing OXSA/clinical experiments from the paper.
