# Shipped interfaces and execution

The runtime uses NumPy2.4.6; Matplotlib3.11.1 supports review figures. No SciPy, MRI domain library, upstream checkout, private capture environment or other task is imported. Complex encoding MRI observations are preexisting derived observations from a fully executed original acquisition pipeline; no synthetic benchmark generator is needed or shipped.

- preprocessing.load_observations(path=None) resolves default data/raw_data.npz relative to task root, loads with allow_pickle=False and validates finite complex64(1,27,4,54,67,100). Returns this public array without normalization.
- preprocessing.native_order(images) validates the same contract and returns contiguous complex64(100,67,54,27,4), axes x,y,z,time,encoding. It copies the public input and never changes its values.
- physics_model.phase_differences(encoding_images) takes native5Dcomplex arrays ending in4encodings, returns native real x,y,z,time,3principal radians. Default data yield float32. It is pure and requires no file access.
- physics_model.encode_phasors(velocity,venc_m_s=.16) accepts a real array ending in3m/s components and returns a complex128 array with4reference/directional unit phasors. This explicit analytic forward helper serves independent test cases; it does not generate bound data.
- solvers.recover_velocity(encoding_images,venc_m_s=.16,mask_fraction=.1,remove_temporal_mean=True) takes native x,y,z,time,4 and returns(velocity,diagnostics). Velocity is x,y,z,time,3with the input precision's real dtype; standard data produce float32m/s. Diagnostics have phase_differences(native radians), temporal_velocity_mean(x,y,z,1,3m/s), reference_magnitude(x,y,z,timearbitrary signal) and mask(bool x,y,z,time). It computes original strict support and temporal gauge locally. Optional settings are scientifically labeled review comparisons, not extra standard entry points.
- solvers.reconstruct(images,mask_fraction=.1,remove_temporal_mean=True) receives public-layout data, calls native_order and recover_velocity, and returns(output,diagnostics). Output has exactly reconstruction with finite float32(1,27,3,54,67,100),m/s. There are no file side effects and no hidden input.
- main.main() is python-m src.main. It loads public observations, actively reconstructs, creates output/ and writes output/reconstruction.npz. It returns the written pathlib.Path. It does not import Judge, read a reference or change Matplotlib's backend.
- visualization.make_figures(images,result,diagnostics,upstream,comparisons,judge_report,export_dir=None) consumes fresh results and independently identified upstream review measurements, returns figure objects and optionally exports actual PNG/SVG/PDF, exact plotted numeric_sources.npz, metrics.json and manifest. It does not select a backend; standard CLI does not call it.
- visualization.plot_component_means(ax,velocity,original_means) plots every temporal sample for each encoding direction, pairing original and fresh by color. Native public output without its batch axis has shape(time,3,z,y,x); original_means has shape(time,3). It returns fresh mean components(time,3)inm/s; plotted axes usecm/s. Independent known-field artist tests verify temporal sample count and direction association.

The notebook is the maintainer review caller: load observations; time complete fresh standard reconstruction; save fresh output; invoke independent Judge; compute complete fresh comparison settings; load only explicitly identified upstream measurements for comparison; display and optionally export all scientific groups. It actively recomputes the declared inverse and does not substitute original arrays as a fresh estimate. Kernel/runtime and actual execution evidence are recorded in test/validation.md. Private acquisition reconstruction and its raw-MRD sorting are provenance stages outside this task runtime.

evaluation/judge.py is independent of src. CLI options --prediction and --report are required and caller-relative. Hidden metrics/reference paths resolve from the evaluator file. The evaluator validates all declared output keys/shapes/dtypes/finiteness before scoring. A legitimate ground_truth.npz takes precedence over baseline_reference.npz; malformed truth is an error. Both files, if needed, carry exactly the public output's reconstruction array; the current baseline is an original method result, not truth.

The Judge compares all samples globally and separately for3directions, and independently calculates complex128 phasor/support observation metrics using public data. Its10finite boundaries are explicit in metrics.json; cosine>=bound and errors<=bound must all pass. It emits UTF8JSON status/pass/metrics/thresholds/errors, creates report parents and returns0/1/2for pass/valid fail/error. Invalid input or evaluator failure has empty metrics. Report-write failure diagnoses stderr and returns2. It never imports a solver, executes submitted code, crops, reshapes or coerces an invalid submission.

test/fixtures/upstream_stages.npz contains frozen original selected6x6x6x27x4complex observations, all3principal phases, reference magnitude, strict mask and full selected velocity; test/comparing_test consumes every key. Hidden baseline independently supports the complete native-grid parity test and Judge. notebooks/reference_outputs/upstream_measurements.npz contains original xy(z27),xz(y33),yz(x50)velocity sections at every time/component plus complete-volume mean components and mask counts/fractions; every quantity is consumed by the notebook figures. Original PDFs/source/MRD/download archives/logs/capture scripts remain outside the final task, indexed in validation. No redundant observation or unconsumed full-array copy is shipped.
