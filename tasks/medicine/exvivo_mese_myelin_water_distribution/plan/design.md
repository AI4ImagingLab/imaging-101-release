# Shipped interfaces and execution flow

## Runtime boundary

Solver-visible files are README.md, data/raw_data.npz and environment information. Everything described below is maintainer-only. Raw data preserve the original four-repeat float64 echo magnitudes, complex128 foreground observations, float64 independent T1 and original float32 transmit map. Frozen masks and cluster labels/centers are independent/observation-derived calibration, not answers. No upstream source, code URL, checkpoint or reconstruction enters raw_data.npz.

## Modules and callable signatures

- `preprocessing.load_data(path)` reads NPZ with allow_pickle=False and removes the single batch dimension from all eight raw keys. It returns a dictionary retaining these arrays, plus `observed` (120,120,32) float64, `mask` (120,120) bool, `y` (2629,32) float64 in NumPy row-major mask order, and `labels` (2629,) integer cluster indices 0..99. It does not recluster, infer hidden calibration or modify supplied observations. Constants `T2_MS` (100,) ms and `LAMBDA` match the README.
- `physics_model.rf_matrix(angle,phase)` returns a complex128 (3,3) RF matrix. Both arguments are radians; the caller applies kappa to angle only. It has no file or global-backend side effects.
- `physics_model.epg_signal(t1_ms,t2_ms,flip_scale,magnitude=True)` accepts scalar T1 in ms, a one-dimensional T2 array in ms, and scalar dimensionless kappa. It returns (B,32) float64 magnitudes by default, or complex128 Fourier signals if magnitude=False. The implementation holds (B,3,257) complex128 states and uses all 32 refocusing pulses. Initial state, TE, TR, crusher orders and phases are fixed as documented.
- `physics_model.build_dictionary(centroids,t2_ms)` accepts (100,2) float64 T1/kappa centers and (100,) bin coordinates, and returns (100,32,100) float64 calibrated columns. No normalization or inverse lookup is used.
- `physics_model.predict(dictionary,coefficients,labels)` accepts (100,32,100), (N,100), and (N,) arrays and returns (N,32) complete curves. It groups pixels by the supplied labels without excluding any.
- `solvers.active_set_nnls(A,y,ridge=0.,tolerance=1e-11)` accepts a real (E,B) matrix, (E,) observation and nonnegative ridge weight; it returns (B,) feasible coefficients. It starts at zero, uses explicit feasible active-set updates and raises after 1000 updates. Ridge calls general dense solves; the unregularized comparison calls general least squares. No files are read or written.
- `solvers.solve_distribution(dictionary,y,labels,ridge)` loops over every original cluster and every corresponding pixel, returning (N,100) masses. It neither crops nor subsamples the observation set.
- `solvers.objective_and_gap(dictionary,x,y,labels,ridge)` returns two (N,) float64 arrays: unnormalized per-pixel objective and stable primal-dual gap. Ridge must be positive for this certificate. This helper serves tests/notebook diagnostics; the Judge independently implements its equations.
- `main.reconstruct(data_path,ridge=LAMBDA)` actively loads observations, builds all dictionary columns and fits every estimation pixel. It returns `(outputs,auxiliary)`; outputs has the four named batch-first arrays from README, and auxiliary contains `data`, `dictionary` and `coefficients` for notebook diagnostics. No output file is written by this callable.
- `main.main()` resolves task root from __file__, calls reconstruct on data/raw_data.npz, creates output/ and writes output/reconstruction.npz. It prints measured reconstruction seconds. `python -m src.main` is the standard entry point. Importing this module does not select a Matplotlib backend.
- `visualization.make_figures(data,results)` accepts the preprocessing dictionary and an insertion-ordered mapping from six explicit method names to actual four-array output dictionaries. It returns a list of five Matplotlib Figure objects; it does not read caches, perform inversions, save files or change backends. The notebook controls saving to the private maintainer review archive.

## Evaluator and reference flow

`evaluation/judge.py` is a standalone CLI with required --prediction and --report. Hidden paths resolve from its own file location; prediction/report paths remain relative to the calling working directory. It loads strict positive finite scalar thresholds, rejecting bool/string/container/null/NaN/Inf/zero/negative/missing configurations. It independently builds the calibrated forward matrix from raw_data.npz and exact physical metadata, validates baseline_reference.npz (or ground_truth.npz first if supplied), then evaluates the submission. All required arrays must be finite nonnegative float64 of exact shape, fraction <=1, and bin masses satisfy the objective-implied public bound.

Six reported metrics are objective_sum, scaled_duality_gap, total_density_consistency, myelin_fraction_consistency, predicted_echoes_consistency and outside_mask_max. A valid reconstruction passes only if all six meet their declared bounds. Numeric metrics must remain finite. The report always has status, passed, metrics, thresholds and errors, serialized with allow_nan=False. Malformed inputs or unavailable/invalid hidden assets return error with empty metrics and code2; a valid poor result returns code1; pass returns code0. Failed report writes return code2 with stderr text.

`evaluation/baseline_reference.npz` stores the complete author V2 RNNLS result, with the same four output keys. This is not actual truth. `notebooks/reference_outputs/upstream_v1_mode0.npz`, `upstream_v1_mode1.npz`, and `upstream_v2_mode0.npz` are complete captured comparison branches; mode0 denotes unregularized and mode1 ridge. The notebook reads the V2 ridge source result from evaluation instead of keeping a redundant second array copy. Fresh cleaned outputs live in output/reconstruction.npz and active notebook variables, separately labeled.

## Tests and notebook caller flow

Test fixtures contain independently executed source dictionary/preprocessing cases, source V2 ridge coefficients/objectives, and the separately generated Bloch ensemble cases; each has a provenance/consumer entry in validation.md. Source voxel vectors use MATLAB column-major mask order; parity tests explicitly convert that ordering before comparison. Public image arrays retain original row,column coordinates.

The comparing tests verify all 100 source dictionaries, original means, bin coordinates and a source ridge objective. Unit tests validate physical Bloch trajectories, ideal exponential decay, zero-flip behavior, analytic ridge cases, stable duality, Judge config/schema, all output arrays, reference precedence, malformed NPZs, poor predictions, foreign working directory and report errors. The complete active notebook follows problem/data/physics/method/results/conclusion, computes both fresh full-plane inversions, performs independent Judge scoring, reports source/fresh objectives and measured execution times, and produces all five figures. Source V1 is preserved as an incorrect-phase counterfactual with a distinct label.

No source generator is shipped because all benchmark observations are original measured data. Requirements list only the runtime NumPy and Matplotlib subset; pytest and Jupyter are development tools. Full upstream source trees, native Octave portable runtime, papers, instrumented capture scripts, original logs and download archives remain outside this task under the private worker archive.
