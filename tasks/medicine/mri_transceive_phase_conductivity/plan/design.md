# Shipped interfaces and data flow

Runtime requirements are NumPy 2.4.6, SciPy 1.17.1 and Matplotlib 3.11.1. The solver uses the first two; Matplotlib supplies notebook review plots. Original C++/Eigen/Boost/HDF5 tools remain private and are never imported at runtime.

`src.preprocessing.load_observations(path)` reads NPZ with pickle disabled, validates the four declared arrays, native float32/bool shapes, finite interiors, native NaN exteriors, positive magnitude and the input-defined 11-cuboid output support. It returns phase and magnitude `[25,96,96,80]` float32 and the observation mask `[96,96,80]` bool. `average_repeats(values)` accepts a nonempty repeat-first spatial array and returns a float64 spatial mean, preserving the original division-before-accumulation order.

`src.physics_model.kernel_geometry(shape='cube', radius=5)` returns a cached read-only bool footprint `[2r+1,2r+1,2r+1]` in z,y,x order. Shapes are cross, sphere or cube; radius is a positive integer voxel half-width. `second_derivative_kernels(shape='cube', radius=5)` returns cached read-only float64 coefficients `[3,2r+1,2r+1,2r+1]`, first index the x,y,z derivative. They are dimensionless and computed locally from polynomial normal equations.

`valid_support(mask, shape='cube', radius=5)` returns the bool eroded support. `laplacian(field, shape='cube', radius=5, spacing=SPACING_XYZ)` accepts a real or complex three-dimensional array and physical spacing in x,y,z order (metres). It returns derivative and support arrays of the same spatial shape. Derivative dtype is float64 or complex128 and units are input units per square metre; invalid exterior is NaN. Correlation applies the explicit coefficients and does not contain a domain inverse solver.

`phase_conductivity(phase, shape='cube', radius=5, frequency=FREQUENCY_HZ, spacing=SPACING_XYZ)` accepts real radians and returns apparent S/m and its bool support. Frequency is positive Hz. `full_helmholtz(phase, magnitude, shape='cube', radius=5, frequency=FREQUENCY_HZ, spacing=SPACING_XYZ)` requires matching real fields and positive finite observed magnitude; returns conductivity S/m, relative permittivity (dimensionless) and support. This helper is only an explicitly identified notebook comparison.

`src.solvers.reconstruct(phases, shape='cube', radius=5)` returns `(conductivity, support, mean_phase)` on the native spatial grid. Conductivity is float64 and exactly zero outside support; mean phase retains NaN exterior. `reconstruct_repeats(phases, shape='cube', radius=5)` actively computes each repeat and returns `[repeat,z,y,x]` float64 conductivity, with NaN invalid exterior. Neither function writes files.

`src.main.main(input_path=None, output_path=None)` resolves defaults to task-relative `data/raw_data.npz` and `output/reconstruction.npz`, loads observations, calls the selected reconstruction, creates the output parent and writes only `reconstruction` with an added batch axis. It returns execution seconds and support count. `python -m src.main` is the standard CLI. Importing the module changes no plotting backend and writes nothing.

`src.visualization.agreement(estimate, reference, mask)` returns cosine NCC and dynamic-range NRMSE and rejects degenerate/nonfinite references. `slice_image(ax, volume, mask, title, *, cmap='viridis', limits=None, unit='S/m', z=None)` draws a masked axial slice, physical millimetre axes and a colorbar on an existing Matplotlib axis; default z is the central plane. This helper does not reconstruct or substitute any reference.

The active notebook separately loads frozen original arrays from `notebooks/reference_outputs/upstream_results.npz`, reconstructs the primary field and all fresh comparisons from public observations, and compares methods using explicit fixed masks. Its figures and numeric plot sources are exported to the maintainer archive. No private source implementation is imported.

The independent `evaluation/judge.py` resolves its assets relative to its own file, while CLI prediction/report paths follow the caller's current directory. It validates configuration, baseline, public mask and submitted NPZ without solver imports. Every declared finite real float32/float64 native array is checked before scoring; extra/missing keys, wrong shape/type, nonfinite values or nonzero exterior are errors. It returns native exit 0/1/2 for pass/fail/error, respectively, and writes strict UTF-8 JSON; a report-write failure returns 2 and diagnoses stderr. Hidden standard-method assets are never advertised as measured truth.

All tests are under `test/`. Frozen original coefficient/mean fixtures are consumed by comparing tests; independent analytical physics, metric and strict Judge CLI tests are under `test/unit_test/`. `test/validation.md` identifies the exact source/data hashes, private captures, consumers and executed checks. No data generation module is shipped because every observation is reused unchanged from the real acquisition.
