# Selected method and explicit mathematics

The selected published method is raw actual-flip-angle imaging (AFI), not spatial filtering or joint T1/B1 estimation. Its unknown is B, the actual/nominal excitation ratio throughout the complete native 88×128×32 volume. Observations are float32 magnitude S1,S2 in arbitrary scanner units at equal TE=3.53 ms, nominal a0=60π/180 radians, alternating TR1=20 ms and TR2=100 ms. The steady-state approximation depends on n=TR2/TR1=5 and eliminates common receive sensitivity and M0. It assumes complete transverse spoiling and TR1,TR2≪T1.

With a=B a0, c=cos(a), the forward ratio is r=abs(S2/S1)=(1+n c)/(n+c). Algebra gives c=(n r−1)/(n−r), a=acos(c), B=180 a/(π·60). Computation uses float64 without changing float32 stored observations. There is no data-fitting objective, regularizer, learned weight, initialization, iterative update, step size, line search or stopping condition: the selected inverse is closed form. Positive-angle arccos branch fixes the angular ambiguity on declared support.

The implementation follows qmrpy B1AFI raw behavior: for abs(S1)<10⁻¹² return NaN internally; r=n uses cosine argument 1; r>1 maps to cosine argument 1; finite cosine arguments are clipped into [−1,1]. These guards only define behavior outside the supported task data and do not modify any valid output. The public fixed mask is derived from paired magnitudes before local implementation: each channel is at least 10% of its global maximum, r>1/5 and r≤(1+5 cos(π/6))/(5+cos(π/6)). The latter upper ratio is exactly B≥0.5, matching the upstream's explicit spurious-field flag. Supported voxels number 80,238; all original observations remain public, including excluded voxels, and all outputs outside support are zero. No anatomy, target map or other task asset defines this mask.

To assess approximation bias independently, `exact_steady_state` implements the two-delay Bloch fixed point. Let E1=exp(−TR1/T1), E2=exp(−TR2/T1), M0 be equilibrium scaling, and Z1,Z2 the pre-pulse longitudinal magnetization. The recurrence is Z2=M0(1−E1)+E1 c Z1 and Z1=M0(1−E2)+E2 c Z2. Thus Z1=M0[(1−E2)+E2 c(1−E1)]/[1−E1E2 c²], Z2=M0[(1−E1)+E1 c(1−E2)]/[1−E1E2 c²], and paired signals are Z1 sin(a), Z2 sin(a). This diagnostic takes explicit T1; no unavailable T1 map is assumed by reconstruction. Shrinking both TRs at fixed ratio makes exact and approximate ratios converge. The notebook actively demonstrates finite-TR bias with labeled analytic diagnostic parameters, not invented benchmark truth.

Data have stored axes phase/readout/slice with pitches 2/2/5 mm; FOV is 176/256/160 mm. There are no spatial boundary conditions or FFT conventions. The archive's acquisition screenshot lists readout first (128×88×32), whereas NIfTI stores 88×128×32; this is an axis-order difference, not resampling.

NCC is uncentered cosine similarity of complete flattened maps; NRMSE is RMS error divided by reference maximum minus minimum. Nonzero numerical tolerance is NCC≥0.999999 and NRMSE≤10⁻⁶, fixed before judging. A separate ratio-consistency RMS threshold is 10⁻⁶ dimensionless on valid support. The upstream result is a numerical standard-method reference, never ground truth. Exact Bloch recurrence, scale cancellation, asymptotic limit and perturbation sensitivity supplement reference agreement. Finite-TR bias and unknown spoiling adequacy remain scientific limitations; no absolute in-vivo accuracy claim is made.
