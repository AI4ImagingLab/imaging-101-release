# Shipped interfaces and execution flow

`python -m src.main` calls `main()`, resolves `data/raw_data.npz` relative to task source, calls reconstruct, creates `output/` and saves `output/reconstruction.npz`. Imports do not change any Matplotlib backend. There is no synthetic generator because all bound observations are real and unchanged.

`preprocessing.load_data(path)` loads NPZ with `allow_pickle=False`, checks native shapes, original float32 dtype and finiteness/positive masked signals, and returns signal `(88,128,32,2)` in scanner units and bool mask `(88,128,32)`. Original volume axes and values are preserved.

`physics_model.afi_ratio(b1)` computes dimensionless S2/S1 under the selected short-TR AFI model using fixed TR1=20 ms, TR2=100 ms, nominal angle=60 degrees. `invert_afi(signal)` consumes `(...,2)` paired magnitudes and returns float64 relative field with final channel dimension removed; invalid/noise guards match upstream raw inversion. `exact_steady_state(b1, t1_ms, m0=1., tr1_ms=TR1_MS, tr2_ms=TR2_MS)` returns `(...,2)` exact fully spoiled steady-state signals in m0 units. This function is a physics/notebook diagnostic and is not called by reconstruction; its T1 argument is never obtained from another task.

`solvers.reconstruct(path)` calls load_data → invert_afi on supported voxels → full-volume zero fill. It returns a dict with `reconstruction`, float64 `(1,88,128,32)`, dimensionless actual/nominal excitation, without file-writing side effects. Only main writes the submission.

`visualization.metrics(estimate, reference)` returns uncentered NCC and dynamic-range NRMSE using all input values. `comparison(fresh, reference, mask=None)` returns a Matplotlib Figure showing reproduced upstream, freshly computed local and signed-difference maps at a declared middle slice; slicing is for display only. Notebook cells also show multiple native slices, measured signals and finite-TR analytic diagnostics. Full-volume arrays remain evaluated and are never cropped for reconstruction.

`evaluation/judge.py` is independent of solver modules. It validates required float64 finite `(1,88,128,32)` predictions and references before scoring complete maps. It independently evaluates the rational forward ratio from predicted B and compares observed S2/S1 on supplied support. Hidden paths are relative to Judge, CLI prediction/report paths relative to caller. JSON is UTF-8 with finite metrics, status/pass/errors/thresholds; exit 0 is pass, 1 is a valid insufficient prediction, 2 is input/evaluator/report failure.

Frozen sampled original scalar upstream inverse fixtures are consumed by parity tests, while full-volume comparisons use independently reproduced upstream numerical references. Tests additionally check analytic roundtrip, unknown intensity cancellation, direct pulse/recovery iteration, exact-model short-TR convergence, public constants/mask and standalone Judge contracts. The notebook actively reconstructs every supported voxel and evaluates the fresh complete volume; no archived map serves as a fresh result. Private NIfTI, original upstream code, acquisition screenshot, capture scripts and execution logs have no runtime import path. No cross-task imports or calibration maps are used.
