# Implemented arterial-input Logan inversion

The spatial unknown is the total distribution-volume slope V in mLplasma/mLtissue. Measured tissue activity C is Bq/mLtissue; measured arterial plasma activity is Bq/mLplasma, multiplied by measured parent fraction f to obtain CP. The dataset is actual [11C]PS13 human PET, sub-01baseline, native200×200central slice z55, all27frames. Public input is batch,time,z,y,x; internal activity is z,y,x,timefloat64, obtained losslessly from stored float32. Mask is fixed before inversion from late observed mean>=1000 and positive30min+ concentrations;16negativeV estimates are retained, not clipped or masked away after fitting.

Convert all scanner/blood times from seconds to minutes before interpolating. Frame midpoint m=start+duration/2. Include a zero-parent sample at injection t=0, then np.interp the19measured products plasma_activity×parent_fraction at the27midpoints. This is the exact input convention used in the isolated original run; interpolating in seconds instead differs by about3e-11Bq/mL due to floating rounding, so the local code preserves minute-based interpolation. No additional decay correction, metabolite recovery correction, dispersion correction, dose calibration or tissue-density correction is introduced. PET-BIDS defines images/blood relative to common timezero; supplied image metadata identify injection0anddecayreference0. Whole-blood samples are not needed by this selected equation and are not bundled as unused inputs.

For a last-axis activity sequence a, calculate the original trapezoidal cumulative array I: I0=start0×a0/2; subsequent increments (a[j]+a[j−1])/2×(m[j]−m[j−1]). The original docstring mentions frame-end integration, but actual trapz code uses frame midpoints; we preserve executable mathematics and explicitly document the discrepancy. Bound start0=0, so integral at first midpoint is0. Thus the initial0-to-firstmidpoint half-frame area is omitted rather than silently supplied. It is a known quadrature approximation to the continuum Logan integral from0; notebook measures sensitivity to adding that area, separately labeled, and never substitutes corrected quadrature for the selected standard. The explicitly labeled trapz_injection sensitivity adds duration0×first_activity/4, assuming a linear rise from zero at injection to the first midpoint. It is a local diagnostic extension and is not substituted for the selected original default. Optional rect comparison uses cumulative sum a×duration with same initial start correction, exactly as upstream.

Use original late selection frame_start>=30min, after integrating the complete time series, including earlyframes. For each included voxel construct x[j]=[1,IP[j]/C[j]],y[j]=IC[j]/C[j] on those selected frames. IP and IC denote cumulative parent-plasma and tissue activity integrals. Weights w[j]=frame_duration[j] in minutes; no normalization or square is added. Solve (X^T W X)c=X^T W y with scipy.linalg.solve(assume_a='sym'), Wdiagonalw, c=[b,V]. This minimizes sum w(y−b−Vx)² (an optional1/2factor changes no minimizer). There is no spatial penalty, positivity constraint, iteration, initialization or arbitrary stopping rule: the2×2normal equations directly evaluate the selected inverse. If an input tissue TAC equals the supplied plasma TAC within original np.allclose defaults, upstream special-cases V=1; local preserves it with b=0 nuisance placeholder. Original singular-solve fallback assigns both coefficients1; preserved, but no bound voxel triggers it. Invalid or nonpositive late tissue data raise before division. All output maps have zero exterior and float64 physical scale.

The original author code calls its generic input 'reference TAC' and parameter 'DVR'. With k2prime=None, its design column is integral(input)/tissue. Supplying measured arterial parent-plasma activity makes this algebra exactly the1990 arterial-input Logan relation; its slope is V, not a ratio to another tissue. We retain all original computations and explicitly change only the physical label. We never invent a reference region, subtract1as bindingpotential, or interpret V as specificreceptor density. The continuum1990 slope includes equilibrium tissue distribution and vascular contribution; this task does not separately identify blood volume or background binding. Sourceclass1996citation describes reference-tissue use; the task's selected physical equation is the independently verified1990arterial form.

Return V as reconstruction(1,1,200,200), mLplasma/mLtissue. Nuisance b in minutes is returned by local functions for diagnostics, not a required submission array.
