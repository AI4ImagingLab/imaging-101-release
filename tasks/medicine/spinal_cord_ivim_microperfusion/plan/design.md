# Shipped design

`python -m src.main` calls `run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz',method='one_step')`. Paths are caller-relative. run loads public arrays, reconstructs all supported voxels and writes one compressed NPZ with S0,diffusion,fraction,pseudodiffusion, each(1,128,134,6). It returns the float64 parameter stack(128,134,6,4). Output parent directories are created; no upstream package or hidden reference is read.

`preprocessing.load_data(path)` returns image(128,134,6,11)float64,mask(128,134,6)bool,b(11)float64 and affine(4,4)float64. It rejects nonfinite intensities and nonpositive supported values. There is no scientific preprocessing beyond selecting the author mask in inverse loops.

`physics_model.signal(b,S0,D,f,Dstar)` evaluates native intensity, broadcasting NumPy arrays. `log_signal(b,lnS0,D)` evaluates the high-b logarithmic model. `jacobian(b,S0,D,f,Dstar)` returns an extra final axis of four derivatives in parameter order S0,D,f,Dstar. They have no file side effects.

`solvers.to_internal(p,lower,upper)` and `from_internal(q,lower,upper)` implement scalar sine box transforms. `bounded_fit(model,data,initial,lower,upper,method,rng=None)` returns parameter vector and dictionary evaluations,capped; model maps parameter vectors to observations. This is the local task pipeline's general scalar least-squares adapter, not a domain-library call. `fit_voxel(values,b,seed=20261027,method='one_step',capture=False)` returns four float64 parameters; capture=True returns(parameters,three stage dictionaries) with params,prediction,residual,chisqr,evaluations,capped. The initial log stage has two parameters lnS0,D and3 data points. The two nonlinear stages have four stored parameters and11 data points, including fixed D in the comparison. Unknown method values are rejected. Failures propagate rather than substituting zero.

`reconstruct(image,mask,b,method='one_step',seed=20261027)` traverses np.argwhere(mask) in native C ordering, applies seed+index per voxel, and returns complete parameter stack zero outside mask. It has no file I/O. main and active notebook use it; no cross-task imports.

Visualization functions acquisition_figure(image,mask),map_figure(parameters,mask),spectral_figure(image,mask,b,one,two,mono),residual_figure(image,mask,b,one,two,mono),reference_figure(fresh,reference,mask) return Matplotlib figures without selecting backend or writing files. Maps zoom only their display extent to the full support bounding box. `residual_values(image,mask,b,parameters)` returns(predicted-observed) of shape(2523,11), native intensity units. Notebook comparisons use fresh computed full fields and independently archived originals.

Standalone evaluation/judge.py imports only standard library and NumPy. `evaluate(prediction)` returns(report,exitcode), validating keys,shape,float32/64,finite/range/outside-support constraints. It independently evaluates six metrics against actual truth if available, otherwise explicit baseline_reference.npz; no filename guessing or solver imports. Invalid input/assets return error/2 with empty metrics; valid poor predictions fail/1; all boundaries pass gives pass/0. CLI requires --prediction and --report, creates report parents, reports write errors on stderr and exits2. Reference/config paths are anchored to Judge, while CLI paths are caller-relative. Every quantity and all observations contribute as defined in README.

Fixtures are original three-stage captures at first,middle,last supported voxels for both algorithms. Hidden upstream_one_step and upstream_two_step arrays are original full results for comparisons. baseline_reference contains original primary outputs, not physical truth. Active notebook fresh_comparisons and fresh_measurements identify fresh reconstruction, fixed-D comparison and monoexponential ablation separately. No generator, external native files, complete source checkout or oracle dependencies are included in task runtime.
