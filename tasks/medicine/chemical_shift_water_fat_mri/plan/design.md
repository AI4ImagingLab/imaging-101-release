# Shipped architecture and interfaces

Runtime: validated Windows CPU Python3.11, NumPy2.4.6, SciPy1.17.1, Matplotlib3.11.1, and the documented generic discrete-optimization exception thinqpbo0.1.5. Only NumPy and thinqpbo participate in reconstruction. SciPy and Matplotlib support notebook visualization. Original MRI package, scikit-image, joblib, YAML and its checkout remain private and are never imported by cleaned modules, Judge, tests or notebook. No generator is shipped because preexisting author observations are reused.

`src.preprocessing.load_observations(path: str|Path='data/raw_data.npz')->dict` loads with allow_pickle=False, requiring only echoes, shape(1,3,101,101,4),complex64,finite values. It returns the public array without rescaling. `parameters(data,mu=.1,multiscale=True,icm_iterations=10,algorithm='QPBO')->tuple` returns explicit numerical parameter containers d,a,m for the fixed acquisition, selected provisional/final decay grids and field labels. d.data is a copy, so later source-compatible in-place normalization cannot mutate the input. These containers contain named constants/arrays, not reconstruction library objects.

`src.physics_model.model_matrix(dPar,mPar,R2)` returns complex64(3,2) first-echo-normalized spectral matrix. `modulation_vectors(nB0,N,realEstimates=False)` gives diagonal complex64(nB0,N,N) field matrices. `pseudoinverse_and_projection_matrices(dPar,aPar,mPar)` returns inverse matrices(145,100,2,3) and null projectors(145,100,3,3),complex64. `B0_stepsize(dt,nB0,B0)` returns ppm per label. `B0_residuals(Y,null_proj,iR2cand,D=None,chunk_size=1000)` returns field costs(100,voxels); `R2_residuals(Y,dB0,null_proj,nB0,D=None,chunk_size=1000)` gives final rate costs(145,voxels). Their underscore helpers compute one chunk. `estimate_rho(Y,pinv,R2,dB0,D=None)` returns complex coefficients(2,voxels). Source auxiliary real-estimate helper formulas remain explicit but are not called by the selected complex-estimate entrypoint; the public task does not require that optional variant.

`src.solvers.get_neighbour_indices(neighbourhood,shape,cyclic)` returns flattened neighbor indices and boundary masks. `get_neighbourhood(radius,voxelsize)` includes positive-axis immediate neighbors. `find_minima(J,num_minima=1)` returns strict cyclic local minima sorted by costs. `get_downsampling(shape,voxelsize)`, `downsample_residual(J,coarse_shape,fine_shape)`, and `upsample_B0(labels,coarse_shape,fine_shape)` implement the actual padding/block-average/repeat rules; no generic image-resize backend is involved.

`QPBO(D,V,ngb_index)` accepts unary costs(2,voxels),pair tables(4,neighbors,voxels),neighbor indices(neighbors,voxels),constructs all generic unary/pairwise terms and returns float labels0/1/−1. The four-entry pair table is indexed by(q,p), so the primitive call uses endpoints(q,p), the sole qualified correction to the source(p,q) bug. thinqpbo performs only binary energy optimization; the mathematical energy and all imaging-specific construction are local. `ICM(prev,L,max_update,num_iters,J,V,w,ngb_indices)` implements the explicit finite source update schedule and returns integer labels. `calculate_fieldmap_MRF(J,V,aPar,shape,voxelsize,cyclic,offresPenalty=0,offresCenter=0)` recursively solves the spatial field labels; `calculate_fieldmap(dPar,aPar,shape,J)` selects QPBO or the explicitly comparative ICM-only variant. Optional nonzero upstream off-resonance penalty is outside the selected benchmark and is rejected rather than requiring an unused imaging dependency.

`core_fatwater_separation(dPar,aPar,mPar,B0map=None,R2map=None)` runs copied-data normalization, explicit variable projection, multiscale field inverse, decay selection and complex coefficient recovery; returns rho complex64(2,101,101,4),fieldmap float64(101,101,4)ppm and rate float64(101,101,4)s^-1. Its dPar.data is normalized in place; the public reconstruct wrapper owns that private copy. `reconstruct(data:dict,mu=.1,multiscale=True,icm_iterations=10,algorithm='QPBO')->dict` returns all five required batch-first maps, with water/fat/fat_fraction float32 and fieldmap/r2star float64. It performs the original aggregate spectral-weight and fraction conventions. It does not read hidden references or write files.

`src.main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz')->dict` loads public observations, reconstructs, creates output parent and writes all five maps in one NPZ. `python -m src.main` accepts --input/--output overrides and is the sole standard entrypoint. No module chooses a Matplotlib backend on import.

`evaluation/judge.py` is independent: load_arrays validates every required exact shape/dtype/finite array. numeric_metrics computes float64 cosine and dynamic-range NRMSE. evaluate(prediction) selects ground_truth if present, else baseline_reference, validates metric definitions, computes ten independent scores and returns(report,exitcode). main writes UTF8JSON with status,passed,metrics,thresholds,errors;0pass,1valid below bounds,2malformed/evaluator/report-write errors. Reference paths are relative to Judge; prediction/report paths are caller-relative. No submitted or reference solver code is imported. Undefined reference metrics fail configuration, and malformed inputs have empty metrics.

`test/fixtures/upstream_stages.npz` is independently captured qualified-author-run evidence: full inverse/null projectors, first1000-voxel field/rate residuals, and unary/pairwise/neighbors/labels at four selected graph levels. test_upstream.py consumes every key, compares discrete labels exactly and floats using frozen tolerances, and verifies fresh full-map exact equality. The hidden baseline holds qualified author method outputs for all five quantities, never truth. Notebook reference measurements identify original vs fresh data/revision/parameters/runtime and metric conventions without redundant arrays. Private upstream code, paper PDFs, captures and logs remain outside the package.

The notebook actively calls cleaned reconstruct on raw observations for its canonical run and every displayed variant. Visualization takes these fresh maps and separately labeled author references, computes scientific comparisons and exports seven groups plus numeric_sources.npz/metrics/hashmanifest only when an optional maintainer export directory is selected. Standard notebook execution still displays all groups. Every exported plotted value has an actual numeric source; historical multi-case reports are not synthesized from this single bound case.

`notebooks/reference_outputs/unmodified_original.npz` stores all five separately identified unmodified source maps. Its documented consumer is the active notebook and visualization correction-comparison group. It is not used by the Judge or substituted for fresh outputs. The qualified original baseline and unmodified result have distinct provenance; no redundant array copy is retained. `visualization.make_figures(data,fresh,original,variants,noise_results,diagnostics,unmodified)` returns seven figures, plotted numeric arrays and metrics, including an explicit unmodified-source/corrected-energy comparison. The unit energy tests independently enumerate all four endpoint assignments and an asymmetric global-minimum case.


## Current benchmark contract v2 (2026-10-29)

Current acceptance independently evaluates the static finest-lattice 100-label circular MRF, including R=40 curvature-derived weights and nonperiodic nearest-neighbor edges. Final decay is integer 0..144; full raw-echo complex coefficients are profiled at submitted field/decay, checking submitted water/fat magnitudes and fraction. Both graph-energy and final profiled-echo SSE excesses are <=1e-6 after full observed-norm normalization. Coefficient consistency <=1e-6 and fraction <=1e-4 percentage points allow measured complex64 roundoff (original amplitude mismatch 3.5864e-7). Independent improving single-voxel field/decay, circular alias modulation and wrong-but-fraction-consistent magnitudes were tested. No coarse/QPBO trajectory identity or biological truth is claimed. The source reconstruction is unchanged.

Historical pixel/parameter identity thresholds and prior notebook reports refer to v1. The external benchmark_readiness_20261029 archive preserves old README/Judge/metrics/tests and actual current CPU command logs, including failed diagnostics. Source algorithms and arrays were not changed.
