## Numerical discrepancy investigation and environment qualification

Initial literal NumPy extraction differed in sensitive raw rates. Investigation captured native case2716 r/J/JTr/JTJ, damping, LU step, trial cost, predicted cost, gain and accept/stop state at every attempt. Source transposed-self products call SYRK rather than GEMM; native odd-leading-dimension Prescott JTr uses a two-lane order. Source cbrt(eps) differs from NumPy cbrt by one ULP; its exact constant is retained. Native Julia SSE uses 1024-block recursion and FMA accumulation. Local fused square/add uses error-free arithmetic with exact rational tie resolution; 20,001 private native C fma cases were bitwise matched. A naive multiply-then-add fails 175, including the explicit halfway counterexample. No high-precision double-rounded operation is mislabeled fused.

Fresh raw preprocessing initially differed by about7,000 out of3,963,000 Ct values at <=2.22e-16 and amplified one ve parity error to2.15e-6, above the frozen1e-6. That run was not accepted. The correct source is Julia's Tang near-one log, not system libm/OpenLibm. Its exact explicit branch now gives **bitwise full R1 and Ct**; native check_log_native.jl confirms FMA_NATIVE=false. All actual E lie [.9670352821616592,.9983510964410126]. General outside-branch helper values use the same mathematical logarithm through NumPy with potentially different rounding. The full bound input remains exact. The raw mismatch and failed OpenLibm hypothesis remain private evidence.

Modern shared OpenBLAS must use its Katmai kernel to reproduce original Prescott SYRK. The CLI creates a process-local OPENBLAS_CORETYPE=Prescott, OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1 child; modern library's actual core name was independently queried as Katmai. This does not modify the shared environment or require an upstream library. Notebook launcher sets the same values before creating a private kernel. First ambient jupyter dispatch incorrectly chose Anaconda; it was stopped, logged, and replaced by the explicit shared Python nbconvert frontend and private kernelspec argv.
