# Shipped execution design

Requirements are NumPy 2.4.6, SciPy 1.17.1 and Matplotlib 3.11.1 in the shared Python 3.11.11 runtime. No upstream Julia or domain package is imported by this task.

`python -m src.main` is the standard entry point. It starts a child Python process with task-scoped OpenBLAS/OMP thread count one and OPENBLAS_CORETYPE=Prescott, then writes exactly output/reconstruction.npz. The parent imports only standard-library modules, so importing src.main cannot change a notebook plotting backend. Paths are relative to the task by its source location. This backend condition is necessary for the independently frozen original parity checks and does not modify shared settings.

`preprocessing.load_observations(path)` returns a dictionary with exactly four float64 arrays, strict shapes as declared in README, finite values and positive measured signal/calibration. `signal_to_concentration(signal_curves, relaxation_rates)` accepts (N,T>=2) float64 signal units and (N,) s^-1 calibration, returns (N,T) R1 in s^-1 and Ct in mM. `prepare_curves(observations)` retains all 60x50 pixels in Fortran raster order and returns R1,Ct,t_minutes,Cp_mM. No hidden reference enters preprocessing.

`physics_model.acquisition_log(values)` implements source near-one arithmetic and a general log fallback. `conv(cp,kep,t)` accepts (T,) mM, (N,) min^-1 and (T,) minutes and returns (N,T) mM*min unnormalized convolution. `fma_square(a,c)`, `julia_square_sum(a)` and `prescott_transpose_product(jt,f)` implement documented numerical primitives; the latter accepts (N,2,T) and (N,T). No file side effects occur.

`solvers.fit(y,t,cp,max_iter=100,trace=None,initial=(.01,.01))` accepts (N,T) concentration, times and plasma. It returns raw (N,2) K/k rates, residual (N,T), and attempt counts (N,). An optional caller-owned trace list receives copies of each iteration's parameters, Jacobian, damping matrices, RHS, step, residuals and gain quantities. It does not change iteration mathematics. `reconstruct(observations,initial=(.01,.01),max_iter=100)` actively converts the full observations and fits every pixel. It returns the two batch-first (1,60,50) physical maps plus diagnostic raw rates, residual, iterations, concentration, effective relaxation, reduced SSE and source_success. The latter is never used to shrink evaluation support.

`generate_data.perturb_signal(observations,relative_sigma,seed)` is a maintainer sensitivity helper only. It copies all observations, adds independent Gaussian signal-unit noise scaled by each pixel's two-frame mean and the given nonnegative fraction, without clipping, and leaves calibration/times/plasma untouched. The existing bound noisy phantom is not generated by this helper. Seeds and amplitudes of notebook sensitivity experiments are reported there, not treated as public calibration.

`visualization` supplies plot export and numerical sidecar utilities. The active notebook imports the local reconstruction and helper, reconstructs all bound pixels, compares independent truth and frozen original outputs, performs additional small full-time-series sensitivity inversions, evaluates the independent Judge and exports actual figures. It is executed in a private kernel inheriting the same one-thread backend condition before NumPy import. Optional comparisons never replace the active bound reconstruction.

`evaluation/judge.py` is independent of solver imports. Its CLI accepts --prediction and --report, validates exact keys, shape, real float32/64 dtype, finiteness and declared physical bounds, and uses actual ground_truth.npz before baseline_reference.npz. An existing invalid truth is an evaluator error with no fallback. It computes both required metrics for both fields, returns 0/1/2 for pass/threshold failure/error and writes finite UTF-8 report JSON. Hidden paths resolve from the Judge file; prediction/report resolve from caller cwd. Invalid cases, foreign-cwd use and report-write failures have contract tests.

Frozen numeric stage fixtures are consumed only by comparing tests; reference_outputs/upstream_result.npz is a separately identified original result consumed by notebook and full-parity test. Neither is imported by the runtime. Ground truth is independently specified by the native QIBA patch design. test/validation.md indexes original source, data, logs, numerical checks and final execution evidence.
