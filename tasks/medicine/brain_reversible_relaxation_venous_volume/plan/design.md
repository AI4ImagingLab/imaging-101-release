# Shipped interfaces and execution

All paths below are relative to this independent task. Runtime imports only standard Python, NumPy and Matplotlib; numerical reconstruction requires NumPy. No upstream package or cross-task import is used.

`src.preprocessing.load_observations(path)` loads `data/raw_data.npz` with allow_pickle=False; validates finite nonnegative float32 shape (1,4,64,64,10,24), returns a copied (4,64,64,10,24) array in source magnitude units. `TAU` is float64 shape (24,), seconds; `CONDITIONS` names the four acquisitions; `SPACING_MM`=(3.75,3.75,5.0). `observation_mask(signals)` requires that same unbatched signal shape and returns bool (4,64,64,10), using only observed signal and index coordinates. `log_measurements(signals)` accepts arbitrary nonnegative finite signal shape and returns float64 natural logarithms with zero-magnitude logs replaced by zero.

`src.physics_model.design_matrix(tau=TAU,cutoff=.015)` returns float64 X of shape (1+L,3) and selected integer frame indices of length 1+L, where L counts positive displacements strictly greater than cutoff. It validates exactly one zero and at least two selected long times. Default L=13. `forward_log(parameters,tau=TAU,cutoff=.015)` accepts [...,3] parameters in [DBV fraction,R2-prime s^-1,log magnitude] order and returns [...,1+L] predicted logs. `oxygen_diagnostics(r2prime,dbv)` broadcasts real arrays and returns OEF fraction and dHb g/dL; no finite clipping is performed because singular ratios are review evidence.

`src.solvers.fit_signals(signals,tau=TAU,cutoff=.015)` accepts [...,24] magnitudes by default, checks time length, returns float64 parameters [...,3] and log-domain residual RMS [...]. `reconstruct(signals)` calls this full fit and observation mask. It returns `(outputs, diagnostics)`: outputs contains reconstruction and dbv, both float64 (1,4,64,64,10), zero outside mask; diagnostics contains unmasked parameters (4,64,64,10,3), log_rmse (4,64,64,10), and mask. It does not write files or load references.

`src.main.main()` resolves task root from its module, loads the public observations, runs reconstruct, creates output if needed, writes `output/reconstruction.npz`, prints elapsed seconds, returns None. `python -m src.main` is the standard entry point. Importing this module does not select a Matplotlib backend.

`src.visualization.rmse(a,b)` returns float RMS difference for broadcast-compatible numeric arrays. `field_grid(fields,titles,limits,cmap='viridis',slice_index=4)` receives lists of (4,64,64,10) arrays, matching titles and (min,max) color limits; returns a Matplotlib Figure, with one row per supplied field and four condition columns. It does not save plots or mutate backend. The notebook computes other explicitly labeled summary statistics directly with NumPy and actively calls cleaned reconstruction and sensitivity fits.

`evaluation/judge.py` is standalone and imports no solver modules. `load_arrays(path)` validates exact required keys/shapes/real float64/finiteness. Its own observation_mask reads public data relative to evaluation and independently implements the public region. `metrics(prediction,reference)` returns twelve values: R2-prime RMSE, DBV RMSE and maximum outside value for each condition. `evaluate(prediction_path)` returns (report,exitcode), preferring ground_truth.npz when present, otherwise baseline_reference.npz. No truth exists for this task. `main(argv=None)` implements the documented --prediction and --report interface; 0 pass, 1 quality fail, 2 malformed/evaluator/report-write error. JSON is UTF-8 with finite numbers only.

Hidden assets: evaluation/baseline_reference.npz contains original masked target fields; notebooks/reference_outputs/upstream.npz contains the unmasked original R2-prime, DBV, OEF and dHb fields for scientific comparisons. test/fixtures/upstream_stages.npz contains five selected original voxel curves per condition and independently captured original logs, design, selected Y and fitted p. Consumers are comparing tests; original arrays are never runtime solver inputs. Notebook reference_outputs/cleaned_measurements.npz is generated after validation and identified as fresh cleaned results. All source archives, NIFTIs, source MATLAB, instrumentation and logs remain in the external maintainer archive.
