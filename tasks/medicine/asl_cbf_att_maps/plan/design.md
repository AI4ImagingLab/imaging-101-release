# Shipped interfaces and execution

`python -m src.main`, called from the task directory, invokes `main()` without arguments. It loads public data, runs a fresh inverse, creates `output/`, and writes `output/reconstruction.npz` with exactly two output maps. Its returned dictionary contains those same arrays; timing is printed. Importing `src.main` does not select or change a Matplotlib backend.

- `src.preprocessing.load_observations(path=Path('data/raw_data.npz')) -> dict`: loads with allow_pickle=False. Returns copied `magnetization` float32 (1,7,5,35,35), `m0` float32 (1,5,35,35), and binary `mask` uint8 (1,5,35,35). Signal and M0 are scanner magnetization units. It validates exact keys, shapes, dtypes, finite values, binary mask, and positive M0 in the mask; it neither reads hidden arrays nor rescales data.
- `src.physics_model.buxton_signal(tau,w,m0,flow,att,partition=.98,blood_t1=1650.,efficiency=.85) -> ndarray`: equal 1D timing vectors in ms; scalar M0, raw flow mL/g/ms and ATT ms; returns float64 signal (T,) in scanner units. It explicitly evaluates arrival, delivery and washout branches. Constants LABEL_DURATION and POST_LABEL_DELAY define the seven acquisition pairs; FLOW_TO_CLINICAL is 6000000.
- `src.physics_model.forward_volume(reconstruction,arterial_transit_time,m0,partition=.98,blood_t1=1650.,efficiency=.85) -> ndarray`: inputs matching (B,Z,Y,X) maps, CBF in clinical mL/100g/min and ATT in ms; returns float64 predicted magnetization (B,7,Z,Y,X). It converts flow units and broadcasts finite-bolus transport. It applies no mask and performs no alignment.
- `src.solvers.reconstruct(magnetization,m0,mask,initial=(1e-5,1000.),lower=(0.,0.),upper=(1.,5000.),partition=.98,blood_t1=1650.,efficiency=.85) -> dict`: each masked voxel undergoes bounded curve_fit. It returns float64 `reconstruction` and `arterial_transit_time` maps (1,5,35,35). Raw optimizer parameters first undergo the upstream float32 storage convention. It does not save files. Exterior and RuntimeError fits return zero. Optional parameters support explicitly labeled notebook sensitivity experiments; the CLI uses the stated defaults.
- `src.solvers.single_delay_approximation(magnetization,m0,mask,partition=.98,blood_t1=1650.,efficiency=.85) -> ndarray`: optional notebook-only clinical CBF comparison from the final timing pair, shape matching M0, float64. It does not estimate ATT or modify standard results.
- `src.visualization.metric_pair(estimate,reference) -> (float,float)`: standard cosine NCC and dynamic-range NRMSE; rejects degenerate references. `summarize(maps,reference) -> dict` applies it separately to both fields. `save_figure(fig,directory,stem)` writes PNG/SVG/PDF only when an explicit directory is supplied and otherwise has no filesystem side effect. `map_panel(array,title,unit,vmin=None,vmax=None,cmap='viridis')` creates a labeled five-slice display. Presentation scaling uses explicit percentiles and never modifies saved numerical results.
- `evaluation/judge.py`: independent NumPy-only evaluator; no source imports. `evaluate(prediction,asset_dir=HERE) -> (report,exit_code)` validates the submission and hidden arrays, prioritizes actual truth if present, loads fixed thresholds and computes both fields' metrics and independently evaluated signal residual. Hidden reference/config paths are resolved from the evaluator directory; public calibration is its task's `data/raw_data.npz`. `main(argv=None)` requires --prediction and --report, resolves caller paths normally, writes strict UTF-8 JSON and implements exits 0/1/2. A malformed input or unavailable asset returns empty metrics. Report-write failures return 2 with stderr.

The notebook uses cleaned modules to reconstruct public observations from scratch. It separately loads the identified upstream comparison and the fresh measured reference record, reports independent metric definitions, predicts observations and inspects residuals. It reruns sensitivity fits and the single-delay approximation. All notebook results are generated actively. A maintainer-provided IMAGING_FIGURE_DIR environment variable exports figure PNG/SVG/PDF files and numerical source arrays outside the task; without it figures are displayed inline only.

`test/fixtures/upstream_forward.npz` contains independently captured point-model stages. `test/fixtures/upstream_pipeline.npz` contains the original pipeline's raw and converted parameters. Unit tests cover physics branches, units, contracts, metrics and Judge failures. Comparing tests evaluate independent bolus quadrature and full upstream parity. Tests import no upstream libraries. Existing observations are reused, so no synthetic generator ships. Source code never reads evaluation or notebook reference assets.
