Public README defines the finite observation model,y,h,x,discrete units and output grids. All400fixed anatomical parcel means and all152author surface samples are retained. Preprocess each parcel with sample zscore(ddof1). Follow the actual original two in-place filter calls: broad[0,sys.float_info.max]then[.01,.08]Hz. Each filter extends a lengthNrecord to2Nby concatenating its reversal, FFTs along time, zeros bins below low or at/above high, inverse FFTs,takes firstNand adds the input mean. The original code aliases bold_sig_deconv and bold_sig, so the second filter also changes deconvolution input. The local implementation explicitly uses this actual filtered signal for both stages. It neither silently fixes the alias nor claims the docstring’s independent passband flow. Public README discloses actual behavior.

Construct a double-gamma canonical kernel with response delay6s,undershoot16s,dispersions1s,response/undershoot ratio6,onset0and24sduration. The gamma density is b^a*t^(a−1)*exp(−bt)/Gamma(a). Source internally samples at dt/Tthen downsamples byTand normalizes kernel sum1. Time derivative uses finite onset shift1s; dispersion derivative uses response-dispersion increment.01. Gram–Schmidt orthogonalizes these3columns without normalizing their Euclidean norms, preserving source convention.

Candidate events are unit impulses at positive local maxima exceeding1sample standard deviation of each filtered parcel, with1neighbor on either side. Edges are excluded according to the original one-based-to-zero-based loop. Insert2zeros after each event to form microtime impulses. For candidate lag l=6..12microbins(4..8s),shift events earlier by lwith zero endpoint padding. Causally convolve the event train with each basis column,truncate to the observed record,and sample at scan indices times3+T0−1. Append an intercept. Fit y=Xbeta+u, u_t=phi*u_(t−1)+e_t using the explicit source Cochrane–Orcutt loop. Initial OLSuses pivoted economicQRand rank selection based on machine spacing; rank-deficient cases use least squares. Estimate phi from residual lag regression,whiten design/response,refit,update residuals; maximum20iterations and coefficient tolerance min(1e-6,max|beta_initial|/1000). Lag score is residual covariance(ddof1),not the whitened SSE.

Select lag using the source knee rule: for each internal split,fit prefix and suffix straight lines using cumulative sums; minimize total absolute line residual; if its score differs by more than half the score range from the absolute minimum,fall back to the minimum; then use the next candidate index as in author hrf_fit(the final index is backed off before this step). Preserve these indexing choices. HRFh=B*beta_basis,with event amplitude1fixing its discrete scale; intercept does not enter h. No claim that HRF/neural scaling or timing is physiologically unique.

Recover relative input independently per parcel as realIFFT(conj(H)*Y/(H*conj(H)+.1*mean(H*conj(H)))). This is the closed-form minimizer of||C_h*x−y||²+lambda||x||²with lambda=.1*sum(h_TR²); no artificial iteration or time-step multiplier. C_his periodic convolution.
