# Shipped interfaces and actual flow

The required unsmoothed512²DRCpath uses NumPy arrays and SciPy general morphology. Matplotlib supports review figures. No MATLAB/Octave, CVX, Clarabel, OSQP, domain OCT library or external source checkout is imported by the shipped solver, tests, Judge or notebook. Original commands and QP environment remain private provenance.

preprocessing.load_data(path) loads only oct_signal with allow_pickle=False; requires exactlyfloat64(1,512,512), finite nonnegative intensity, and returns a copied(512,512)array. surface_indices(signal) returns(512,)native zero-based crossing rows using full-depth sorted thresholds. tissue_mask(signal) returns(512,512)bool using fixed source dilation/erosion boundaries. These are deterministic observations-only operations.

physics_model.optical_response(z=None,focus=1.,rayleigh=.29017970000000004) returns confocalh and spectralfallofff matching zshape; zdefault is512-depth0..2.358mm. corrected_signal(signal,mask,focus=FOCUS,rayleigh=RAYLEIGH,noise_power=NOISE_POWER,include_confocal=True,include_falloff=True) returns masked restoration-corrected J(512,512). Optional flags are notebookablation controls only; main uses both optics/defaultknowncalibration. cell_signal(attenuation,dz=DZ,scale=1.) evaluates explicit cell-integral Beer–Lambert signal along axis0 for independent mathematics; it generates no benchmark observations. consistency(attenuation,term,dz=DZ) returns the full nonfinal-row normalized selected-integral residual. Constants define dz,dx,focus,apparentRayleigh,wavelength/pixelresolution and authornoise units and match README.

solvers.depth_inverse(term,dz=DZ) returns same-shapedfloat64attenuation from native reverse sums throughpenultimate depth, finalrow0. reconstruct(signal,**kwargs) computes native mask and corrected_signal with forwarded known-calibration arguments and returns(mu,info), where mu(512,512)mm^-1,info['mask']boolsame-shape,info['term']correctedintensity. No fitting/training checkpoint or hidden reference is read.

main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz') uses caller-relative paths, loads full signal, callsreconstruct and writes float64reconstruction(1,512,512)to the selectedNPZ. It returns(mu,info,elapsedseconds). main.main() printsseconds,shape,maskpixelcountandconsistency; `python -m src.main` is the only standardentrypoint. Importing main changes no plotting backend. Paths are caller-relative as in the repositorytask command convention, rather than claiming module-relativedefaults.

Optional local comparisons are explicitly separate from the requiredsolver. native_vermeer(signal,mask) returns fullsourcecurrent-inclusive logarithmiccomparison; gaussian_comparison(attenuation) returns nativefive-squareconvolution; native_rof(attenuation,theta=1.) returns the sourcefive-iterationhistoricalcontrol with originalboundaryoverwrites. horizontal_adjoint(dual) maps a length511dual to its exact length512Neumann-forward-differenceadjoint. intensity_weighted_tv(attenuation,masked_signal,mask,eta=6.,epsilon=.001) returns(full512²nonnegativefield,diagnostics)for the distributed-code weightedTVobjective. Diagnostics include max_relative_gap,max_iterations and active-row row_iterations, plus **row_cleanup_sweeps(512,)int64**,max_cleanup_sweeps and row_lbfgs_iterations(512,)int64. Rows solved directly have0count; actual coordinate sweeps are counted after completing bothparities. Generic optimizer and explicitcleanup update values are unchanged from the alreadyqualifiedcore.

Plotting backend selection belongs to notebook/CLI only.
