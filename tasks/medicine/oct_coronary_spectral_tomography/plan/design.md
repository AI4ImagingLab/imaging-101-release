# Shipped interfaces and execution

All source uses NumPy; Matplotlib is used only by maintainer visualizations. No domain package is imported. Array order is channel,sweep/depth,A-line inside source and batch-first at disk boundaries. Core computation preserves original int64 ADC background subtraction, complex64 analytic-fringe storage, float64 interpolation/Hann windows, and complex64 saved depth image.

`preprocessing.load_data(path)` accepts a Path/string to raw_data.npz, loads with allow_pickle=False, removes the leading singleton batch dimension, and returns copied fringes/background/chirp/dispersion arrays with no calibration fitting. `subtract_background(fringes,background)` returns int64(2,1600,1024) using original truncation convention.

`physics_model.calibration(chirp,dispersion)` accepts float64(800) and float32(1600), returning integer(800) indices, complex(800) interpolated phase correction, and float64(800,1) Hann window. `analytic_spectrum(corrected,indices,dispersion)` returns the calibrated complex spectrum(2,800,1024). `depth_transform(spectrum,window)` returns complex64(2,2048,1024). `windowed_spectrum(depth)` and alias`forward(reflectivity)` return the normalized reverse spectral representation(2,2048,1024), used by physics tests and diagnostics. Constants NUM_SAMPLES1600,NUM_DEPTH2048,ZOOM2,CARRIER_INDEX400,REVERSE_INDEX1024,FLIP_DEPTHTrue,SCALE1e-6 agree with the public contract.

`solvers.reconstruct(data,dispersion_correction=True,apodize=True)` calls the preprocessing/calibration/spectral/depth routines and returns `(image,stages)`. Image is complex64(1,2,2048,1024); stages contains spectrum,indices,dispersion,window. Optional flags run real sensitivity ablations and do not affect standard defaults. No function writes a file except CLI and explicit visualization export.

`main.main()` resolves task root from its own path, loads data/raw_data.npz, runs the nominal reconstruction, creates output/, and writes only output/reconstruction.npz. Standard entry point is`python -m src.main`. Importing src.main does not import plotting code or change a Matplotlib backend.

`visualization.run_experiments(data,upstream)` recomputes nominal, no-dispersion, and no-window images and returns measured profiles/errors plus nominal. `visualization.make_figures(data,experiments)` returns three fresh Matplotlib figures. `export(figures,experiments,directory)` explicitly saves PNG/SVG/PDF figures and compact numeric NPZ/JSON sources to a maintainer-only directory. It is called by private gallery generation, not CLI.

Notebook notebooks/oct_coronary_spectral_tomography.ipynb actively loads raw observations, reconstructs all three selected conditions using local src, evaluates fresh nominal against separately identified upstream.npz, and plots computed comparisons. It imports no original library. Saved upstream.npz is consumed only for comparison, never used to replace reconstruction. test/fixtures/oracle_stages.npz supplies independently captured stage arrays to parity tests. evaluation/baseline_reference.npz is consumed by the standalone Judge and parity tests; it is a standard-method reference, not anatomical truth.

`evaluation/judge.py` has independent evaluate(prediction),relative_l2(x,y),main() functions. It resolves hidden assets relative to itself and command paths relative to the caller, validates exact shape/complex64/finite values, evaluates both detector channels and every pixel, creates report parents, and returns0/1/2 for pass/fail/error. It never imports src. test/unit_test covers known metrics, malformed/overflow inputs, hidden-asset errors, report-write failure and foreign-cwd operation. test/comparing_test covers complete original parity and the numerical observation representation.
