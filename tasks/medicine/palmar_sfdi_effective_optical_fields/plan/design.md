# Interfaces and execution

`python -m src.main` calls `run(root=None)`, resolving omitted root against its own module. Returns `(hand,phantom,rcal,freq,cal,observed,parameters,predicted)`. Shapes are5 by 3 by 500 by 400,float32 for frames;5float64 for rcal/freq;500 by 400 by 5float32 for cal;50 by 40 by 5float32 for observed;50 by 40 by 2float64 for parameters;50 by 40 by 5float64 for predicted. It creates output and writes the batch-first transposed arrays declared in README to output/reconstruction.npz.

`preprocessing.demodulate(phase)` takes3 by H by W intensity and returns float32 DC/AC images. `calibrate(hand,phantom,known_reflectance)` consumes the full bound5 by 3 by 500 by 400 phase stacks and5known reflectances, returning500 by 400 by 5calibration. `average_blocks(reflectance,block=10)` checks divisibility and preserves source Fortran array summation order and returns block means; no files are touched. `load_data(path)` loads allow_pickle=False, checks finite arrays and native frame dimensions, and returns the first six run values. No synthetic data generator is supplied.

`physics_model.diffuse_reflectance(parameters,frequencies,index=1.4)` takes two positive real coefficients and a frequency vector and returns their dimensionless response. `objective(parameters,frequencies,observed,index=1.4)` returns scalar sum-squared residual. Core transport and boundary equations are local NumPy operations.

`solvers.reconstruct(observed,frequencies,index=1.4,frequency_indices=(0,1))` runs independent general SciPy Nelder-Mead calls using the two fixed frequency indices on every cell using the settings in approach.md and returns parameters and predicted reflectance. It raises RuntimeError if any final cell is invalid. There are no upstream imports, LUTs or checkpoints.

`visualization.field_figure(parameters,upstream,predicted,observed,frequency)` returns a2 by 3figure with fresh/source maps and residual summaries; arrays use native row,column,channel order. `residual_validity_figure(parameters,predicted,observed,frequency)` returns all5frequency residual maps and a dimensionless diffusion-validity diagnostic. `index_sensitivity_figure(base,low,high)` returns100times(high-low)/base per coefficient for independently computed n1.35 and1.45 fits and the n1.4 base. Figures have no automatic save or backend side effects.

`evaluation.judge.model(p,f)` independently implements transport on2 by 50 by 40coefficient fields. `observations(raw)` independently demodulates public calibration to5 by 50 by 40. `evaluate(prediction,root=None)` resolves evaluator assets by its own path, validates reference and output shapes/dtypes/finite positivity, computes per-cell selected-low2objective ratios and all-reflectance forward consistency, and returns(report,exitcode). Actual truth is preferred to method baseline and requires explicit truth metric configuration. CLI caller-relative prediction/report paths, JSON schema and exit0/1/2 conform to AGENTS. No solver code is imported. Malformed input and evaluator errors have empty metrics; all metric values and boundaries are finite.

The notebook actively calls run, then the standalone Judge, and additionally performs a complete5frequency comparison and two complete low2refractive-index sensitivity inversions. Frozen source arrays serve only labeled comparisons. It never imports source libraries or private capture scripts. Numeric fixtures under test are consumed by parity/physics tests, not the solver.
