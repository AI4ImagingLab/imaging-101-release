# Actual interfaces and flow

`python -m src.main` is the standard entry point. `main()` resolves the task root from its source file, calls preprocessing.load_data on data/raw_data.npz, calls solvers.reconstruct on the entire200000-event sequence and writes output/reconstruction.npz with one required reconstruction array float64(1,200000,3). It creates output/ if needed and returns the unbatched point cloud. It never imports upstream code, other tasks,domain libraries or hidden references.

`load_data(path)` uses allow_pickle=False and checks exact shapes/dtypes/finitevalues/positivevoltage. It returns float64(200000,2) detector coordinates incm and float64(200000,) voltage inV. `validate_events(xy,voltage)` validates arbitrary unbatched finite float64(N,2)/(N,) arrays for numerical tests and comparison/sensitivity paths. It preserves event order.

Physics constants declare FLIGHT_PATH_MM110.,FIELD_FACTOR4.,DETECTION_EFFICIENCY.7,IMAGE_COMPRESSION1.4,EVAPORATION_FIELD_V_NM19.,ATOMIC_DENSITY_NM3 60.2. `radius_evolution(voltage,kf=4.,field_evap=19.)` returns float64(N,)Rinnm. `launch_geometry(xy,voltage,flight_path_mm=110.,kf=4.,icf=1.4,field_evap=19.)` returns Rinnm,azimuth inrad,corrected angle inrad and detectorradius inmm, each(N,). `depth_increments(xy,voltage,flight_path_mm=110.,kf=4.,det_eff=.7,icf=1.4,field_evap=19.,avg_dens=60.2)` returns float64(N,)dzinnm using the maximum-radius analysis area of the passed sequence. `project_to_detector(xyz,voltage,flight_path_mm=110.,kf=4.,icf=1.4,field_evap=19.)` returns float64(N,2)detectorcm via an independently derived analytic inverse angle relation; z is not used because it contains cumulative evaporation history.

`reconstruct(xy,voltage,flight_path_mm=110.,kf=4.,det_eff=.7,icf=1.4,field_evap=19.,avg_dens=60.2)` returns float64(N,3)Geiser atomcoordinatesnm inrecordedeventorder. It validates, computes launch/cap geometry, applies volume increments and stacks x,y,z. `bas_reconstruct` has the identical signature and returns float64(N,3)coordinatesnm with the current source's corrected SI conversion and Bas cap. It is called only in comparisons; standard output remains Geiser. Both are direct analytical inverses and have no stopping or optimizer side effects.

`visualization.metrics(a,r)` returns scalar ncc/nrmse dict with uncenteredcosine/dynamicrange semantics. `depth_histogram(xyz,bins=80)` computes all-event integer depthcounts and bin edges innm. `point_view(xyz,title,ax=None)` renders deterministic display-only decimation, at most approximately12000points, to a Matplotlib3Daxis and returns it. Scientific calculations,metrics,histograms and output use every event. No module selects a Matplotlib backend at import.

`evaluation/judge.py` is independent NumPy/stdlib code. load_prediction validates reconstruction exactfloat64(1,200000,3), finite real. score uses independent cosine and dynamic-range equations. evaluate resolves hidden assets from evaluation/,gives ground_truth precedence if available,validates metric config and returns(report,exitcode). Actual shipped hidden asset is baseline_reference; no truth is invented. CLIprediction/reportpaths are callerrelative. pass0,qualityfail1,error2; malformed input has empty metrics and descriptive errors. JSON is strict finiteUTF8; missing hidden assets and reportwritefailure are evaluatorerrors. No submittedsolverorcheckpoint code is imported.

Fixture consumers: test/comparing_test/test_upstream.py uses small constructor inputs and independently captured Geiser/Bas outputs. Full-pipeline parity uses the independently captured baseline. Notebook explicitly loads that original Geiser methodreference and notebooks/reference_outputs/upstream_bas.npz/positions_nm for its original Bas comparison, actively computes fresh both methods and labels provenance. Numericplots/sweeps are exported only to the private archive. Canonical executed notebook is the sole review notebook. All required source/plans/README/defaults/signs/units/paths are reviewed together before completion.
