# Implemented atomic geometry

The unknown is the complete3D point cloud of the first200000 consecutive processed detector events from the real OXCART pureAl acquisition. Source event ordering and full detector field are preserved. This is an acquisition-prefix selection, not a target/spatial/species crop or a reduced-resolution simulation. No earlier events are omitted from this initial prefix. The public input contains only xdet,ydet in nativecm and standing voltageV. The source HDF5 also contains previously reconstructed coordinates and mass information; none of those columns are used by the oracle or local reconstruction or bundled as visible input. No actual atom-position truth is available.

Fixed parameters follow the author reconstruction widgets and material table: flight lengthL110mm,kf4,efficiencyeta.7,image compressionxi1.4,Al evaporationF19V/nm and atomic densityrho60.2atoms/nm³. They are explicitly assumptions/conventions, not a fit to the stored original reconstruction. The task does not claim independently calibrated crystallographic accuracy.

For each event convert detector coordinates fromcm tomm by multiplying10. Compute r=hypot(xdet_mm,ydet_mm) and phi=atan2(ydet_mm,xdet_mm). The dynamic radiusR=V/(kf*F) is innm. Apparent angle thetaP=atan(r/L). Corrected angle thetaA=thetaP+asin((xi-1)*sin(thetaP)). Then d=R*sin(thetaA), x=d*cos(phi),y=d*sin(phi),cap=R-R*cos(thetaA). These explicit equations preserve the author's Geiser branch and its exact order of arithmetic; no opaque reconstruction library is called.

The analysis-area convention is AD=pi*max(r)^2 over the whole selected sequence inmm². The geometric magnification M=L/(xi*R) is inmm/nm, so AS=AD/M² is innm². Per detected ion, the inferred material volume is Omega=1/(rho*eta) innm³. Thus dz=Omega/AS is innm; cumulative depth is cumsum(dz), including the first increment. Return z=cumulative+cap without reorigin,voxelization or rigid alignment. This volume normalization is intrinsic to the published/reference projection convention and uses observation-derived detector support rather than hidden target geometry.

The chosen inverse is analytical. There is no objective normalization, regularizer,initialization,iteration count,line search or convergence threshold. Parameters controlling the instrument/model are fixed above; notebook sensitivity runs change one at a time and retain the standard result separately. Valid arrays must be finite, standing voltages positive,efficiency in(0,1],positive density/geometry,nonzero detector field and valid arcsine arguments.

The comparison Bas branch follows the same current upstream file. Its radius is computed inmetres as V/(kf*(F/1e-9)); flight length is L*1e-3m; detectorcm becomesmetres by*1e-2. M=Lm/(xi*Rm),x=xdet_m/M,y=ydet_m/M. AD uses pi*max(hypot(xdet_m,ydet_m))² and atomic volume(1e-9)^3/rho. Its dz formula is the equivalent explicit SI expression in the original file. Its cap is Rm*(1-sqrt(1-(x²+y²)/Rm²)). Return coordinates*1e9nm. The current author's comment identifies an older cm->m error of1e-3 in this alternative branch; the checked exact commit already corrects it to1e-2. We preserve the corrected published-software revision and independently test units, rather than silently reintroducing the older100x depth-scale bug. Bas is an active scientific comparison, not an extra submitted output.

The independent forward check derives tan(thetaP)=sin(thetaA)/(cos(thetaA)+xi-1) from the corrected-angle identity, then projects each lateral coordinate back to detectorcm. This closes the lateral inverse without copying its sequence of atan+asin operations. Atomic volume is independently checked by sum(AS*dz)=N/(rho*eta). A zero-radius ray has exactly x=y=0 and still acquires cumulative depth. These checks complement independent frozen original small/full outputs; matching an original formula alone would not validate dimensional consistency.

Hidden baseline_reference/reconstruction contains original Geiser(N,3) coordinates, batchfirst. It is a method result, not truth. Every coordinate is scored in fixed event order with uncentered NCC and reference-dynamic-range NRMSE. No centering,rotation,permutation or fitted scale is allowed. A zero baseline error cannot define a useful zero threshold; fixed nonzeroNCC>=.999999999 andNRMSE<=1e-10 target float64 numerical reproducibility. Repeated original/local runs and reordered arithmetic sensitivity establish the numerical envelope, while poor/malformed predictions are independently rejected. Physical calibration uncertainty is explored but is not erased by baseline agreement.
