# Shipped execution design

`python -m src.main` is the sole standard entry point. It reads `data/raw_data.npz` relative to the caller's task workspace, invokes the local closed-form inverse and writes `output/reconstruction.npz`. Importing `src.main` does not execute reconstruction or change a Matplotlib backend. Runtime source has no imports from upstream libraries, oracle archives or other tasks. No synthetic observations are generated by the task; `src/generate_data.py` is therefore omitted.

| Module / callable | Arguments and defaults | Return / side effects |
|---|---|---|
| `preprocessing.load_observations(path="data/raw_data.npz")` | Path-like public NPZ; required `measurements` float64 shape (1,30,30,30), `probe` float64 shape (1,14,14); all finite | Tuple of arrays (measurements[30,30,30], probe[14,14]), preserving stored values and Angstrom units. Rejects incompatible input; no mutation. |
| `physics_model.dilation(surface, probe)` | Real image/stack with final axes [row,column], 2-D probe; converts numerical computation to float64 | Contact-forward array, same shape as input, Angstrom; finite-field maximum with minus-infinity outside. No files or global state. |
| `physics_model.erosion(measurements, probe)` | Same array interfaces | Float64 upper-envelope surface, same shape; mathematically reversed offsets and plus-infinity outside. No nonnegative clipping. |
| `solvers.reconstruct(measurements, probe, nonnegative=True)` | Observation stack [30,30,30], known probe[14,14] | Float64 recovered surface stack; applies max(0,erosion) by default. `False` exposes raw erosion for comparisons. |
| `solvers.blind_comparison(measurements, epochs=200, tip_size=10, lr=0.1, weight_decay=0.0011)` | Independent notebook comparison, internally float32 PyTorch CPU tensors | Tuple (surfaces float32[30,30,30], tip float32[10,10], losses float64[200]); locally implemented opening, inverse updates, nonpositive clamp and tip recenter. No files. |
| `main.main()` | No arguments; standard workspace paths | Writes float64 `reconstruction`[1,30,30,30] to `output/reconstruction.npz`; creates output directory. Returns unbatched surfaces. |
| `visualization.metrics(estimate, reference)` | Same-size real arrays, meaningful nonzero/nonconstant reference | Dictionary containing flattened cosine `ncc` and dynamic-range `nrmse`; verified against an independent analytic case and Judge. |
| `visualization.make_figures(raw, probe, truth, fresh, plain, blind, blind_tip, blind_loss)` | Numerical arrays from active notebook reconstruction | (five named Matplotlib figures, exact numeric-source dictionary, full-precision metric table). Computes fresh probe-scale and smoothing ablations. Does not select backend, write files or load archived reconstructions. |

The standard caller flow is `main.main -> load_observations -> reconstruct -> erosion -> save NPZ`. The notebook independently calls these same functions on the bound public data, saves a fresh standard submission, runs the standalone Judge and freshly executes `blind_comparison`. It loads `notebooks/reference_outputs/upstream_methods.npz` solely for original-versus-cleaned assertions and explicitly identified comparisons. It never substitutes that archive for a fresh plotted method.

The canonical notebook uses inline plotting selected only by its own magic. With `IMAGING_FIGURE_DIR` set by a maintainer, it exports the five scientific groups in PNG, SVG and PDF, plus exact `numeric_sources.npz`, a full-precision JSON metric table and SHA-256 figure manifest. Without that variable it still actively reconstructs, evaluates and displays all figures. The execution timeout is 240 seconds, substantially above the measured approximately 12–18 second blind comparison and figure export overhead. Executed review notebooks and rendered figure archives live outside the final task directory.

`evaluation/judge.py` imports only standard-library modules and NumPy. Its own `contact_forward` implements the fixed observation model independently of solver imports. Hidden assets resolve relative to the Judge file; prediction/report CLI paths resolve relative to the caller. `evaluate(prediction)` returns (structured report, exit code). `main(argv=None)` writes the UTF-8 report and returns 0 for pass, 1 for a valid below-boundary prediction, 2 for malformed inputs, unavailable assets or report-write failure. It validates required key, exact shape, real float64 and all finite values before scoring, with pickle disabled. It performs no coercion, alignment, reshape, cropping or prediction substitution.

Tests are exclusively under `test/`: `comparing_test` consumes the independently captured upstream stage fixture and original blind-method archive, tests exact main-stage parity, general asymmetric-probe order adjunction, analytic contact geometry and acquisition noise. `unit_test` tests metrics and Judge/process contracts including poor estimates, missing data/key, shape, real/complex dtype, object arrays, NaN/Inf, evaluator failure, report-write failure and arbitrary caller working directory. `test/validation.md` is the single authoritative provenance and acceptance record. Source/data licenses are retained in task `LICENSE`; all upstream repositories, papers, original capture scripts and logs are private maintainer archives.
