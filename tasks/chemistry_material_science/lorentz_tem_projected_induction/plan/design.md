# Shipped execution flow

Each task runs independently with NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1 in the shared CPU environment. No PyLorentz or electron-imaging package is imported by source, tests, Judge or notebook. Original source, PDFs, TIFFs, raw archive, capture scripts and verification environments remain in the private archive indexed in test/validation.md.

`src.preprocessing.load_observations(path)` loads allow_pickle=False and validates two real finite nonnegative float32 arrays of shape(1,7,512,512). It returns two(7,512,512) arrays. Constants PIXEL_NM=5.1066,VOLTAGE_V=200000.,DEFOCUS_NM are explicit and checked against README. `prepare(unflipped,flipped,index=0)` validates pair index, computes gain-normalized selected images and common in-focus image, and returns `(stack,infocus,difference_B,difference_E)`, shapes(5,H,W),(H,W),(H,W),(H,W), float32 normalized intensity. No disk effects.

`src.physics_model.wavelength_nm(voltage=200000.)` returns relativistic wavelength in nm. `periodic_gradient(image)` returns(dy,dx) centered periodic pixel derivatives. `frequency_filters(shape,pixel_nm=5.1066,qc=0.)` returns the float64 inverse-q-square response and bool circular aperture. `even_extension(image)` returns an even mirrored float64 double-size array. `phase_to_induction(phase,pixel_nm=5.1066)` returns(Bx,By), float64 T·nm maps with second-order edge derivatives. `defocus_derivative(phase,infocus,pixel_nm=5.1066,voltage=200000.)` supplies an independent spectral forward diagnostic in intensity/nm, without using inversion stencils or regularization. `propagate(phase,defocus_nm,pixel_nm=5.1066,voltage=200000.,amplitude=None)` returns coherent propagated intensity, used for an independent weak-phase sign/scale test. These functions are pure and do not generate or replace benchmark observations.

`src.solvers.reconstruct_phase(infocus,difference,defocus_nm,pixel_nm=PIXEL_NM,voltage=VOLTAGE_V,qc=0.,symmetric=False)` performs the direct double-Poisson TIE formula and returns float64 minimum-zero radian phase. The optional symmetric flag supports standalone phase inversion; the multi-output reconstruction instead mirrors the selected stack before differencing to preserve original float64 promotion. `reconstruct(unflipped,flipped,index=0,qc=0.,symmetric=False)` returns a dictionary with phase_B,phase_E,Bx,By (float64 maps), infocus,difference_B,difference_E (normalized intensity diagnostics; float32 normally, float64 for mirrored mode). Defaults specify the shipped standard method, not a proposed optimizer.

`python -m src.main` resolves task data and output relative to the module's task root, calls load_observations then reconstruct, and writes four batch-first float64 arrays to output/reconstruction.npz. `src.main.main()` returns that Path. It does not invoke the Judge or notebook, mutate Matplotlib's backend, or read hidden assets.

`evaluation/judge.py --prediction PATH --report PATH` independently loads four declared arrays and all thresholds. Hidden paths are relative to its own file, CLI paths relative to caller CWD. It prefers existing ground_truth.npz over baseline_reference.npz, rejects malformed truth without fallback, and currently evaluates a standard-method reference because no actual truth exists. All boundary numbers must be finite non-boolean values, cosine boundaries within[-1,1], error boundaries nonnegative. It rejects missing/key/shape/dtype/complex/nonfinite/object problems before scoring; finite-overflow metrics become error reports with empty metrics. Returns0 for pass,1 for valid low-quality prediction,2 for invalid submission/evaluator/report-write error. UTF8 reports contain status,passed,metrics,thresholds,errors; parent directories are created. It imports no solver module and never executes submissions.

The active notebook loads observations, reconstructs standard and comparison groups using cleaned modules, loads explicitly identified upstream results for comparison, computes diagnostics and metrics, and calls visualization. Figure exports use IMAGING_FIGURE_DIR when set, otherwise output/review_figures as a generated review location; the delivered task contains no redundant review exports. Exports include PNG/SVG/PDF, exact numeric arrays and hash manifest. The final canonical notebook preserves actual execution counts and inline PNG output. nbconvert uses a240-second per-cell timeout, justified by measured complete CPU runtime recorded in validation. Tests under test/unit_test cover interface, metrics and malformed/evaluator boundaries; test/comparing_test consumes frozen original numerical stages and tests independent coherent propagation, gradient adjoints, flipping symmetry, induction units and source pipeline parity.
