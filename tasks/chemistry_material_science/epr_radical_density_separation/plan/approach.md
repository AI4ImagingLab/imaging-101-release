## Spatial and spectral discretization

Let N=1200, P=40, K=2 and M=100. Array row a is y and column b is x:

```math
x_b=\delta(b-M/2),\quad y_a=\delta(a-M/2),\quad
H_j[k]=\sum_{n=0}^{N-1}h_j[n]e^{-2\pi\mathrm{i}kn/N}.
```

B is supplied in gauss; g is supplied in G/cm. Use ΔB=B[1]−B[0]=.10833740234375G exactly, retaining the author's coordinate rounding. The Fourier period is NΔB, not the endpoint span. For k=0,...,N/2 define angular field frequency ωk=2πk/(NΔB), unit G⁻¹, and retain

```math
T_{pk}=\mathbf1\left\lbrace\|g_p\|k<N\Delta B/(2\delta),\ k<N/2\right\rbrace.
```

The explicitly implemented acquisition is

```math
\widehat s_p[k]=T_{pk}\delta^2\sum_j H_j[k]\sum_{a,b}u_j[a,b]
\exp\left(\mathrm{i}\omega_k(g_{xp}x_b+g_{yp}y_a)\right),
\qquad A(u)=\operatorname{irFFT}_N(\widehat s).
```

The positive phase corresponds to h(B+g·r). Inverse real FFT includes1/N and the conjugate negative frequencies. Excluding the Nyquist channel follows the source. This is a periodic field-axis representation; spatial images have finite support with zero extension, not periodic spatial boundaries.

The local nonuniform Fourier evaluations use direct separable exponential sums, not a NUFFT package. With dimensionless nodes qx=−δgxω and qy=−δgyω, type2 evaluates the sum with phase exp(−i[qx bx+qy ay]), where centered integer modes bx=b−M/2 and ay=a−M/2. Type1 explicitly evaluates its positive-phase conjugate transpose. Two cached exponential tables per grid size permit matrix multiplication without constructing the full imaging matrix.

For a real data array v, let V=rFFT(v). The adjoint uses coefficients Vp[k]conj(Hj[k]), halves the k=0 coefficient, completes the negative-frequency sum as2Re, and multiplies by δ²/N. These factors give the Euclidean real-array adjoint, independently tested by dot products and a shifted point source.

## Cross-species Toeplitz normal operator

Four200×200 real kernels implement A* A. For output species k and input species j:

```math
\phi_{kj}[r]=\frac{2\delta^4}{N}
\operatorname{Re}\sum_{p,\ell\ge0}w_\ell T_{p\ell}
H_j[\ell]\overline{H_k[\ell]}
\exp\left(-\mathrm{i}\omega_\ell\delta\,g_p\cdot r\right),
\quad w_0=\tfrac12,\quad w_{\ell>0}=1.
```

Here r is a centered integer displacement on the padded200×200 lattice. The sign follows the adjoint applied to the forward response. The implementation constructs these sums directly, then transforms each kernel with rFFT2. For each input field, pad to200×200, multiply Fourier coefficients with the corresponding kernel, invert, and retain the lower-right100×100 block. Sum over input species. This crop is the fixed Toeplitz embedding operation, not a crop of the reconstructed field or evaluator.

The kernel representation is independently compared against direct A* A. Cross terms are required for the primary method.

## Objective, finite differences and parameter normalization

Let v=A* s and Nop=A* A. The selected objective is

```math
E(u)=\tfrac12\|Au-s\|_2^2+W\sum_j\operatorname{TV}(u_j),\qquad
\operatorname{TV}(z)=\sum_{a,b}\sqrt{(D_yz)^2+(D_xz)^2}.
```

Dy and Dx are nodal forward differences, with zero last row/column differences. No1/δ is included. The divergence is the negative adjoint of this difference operator; terminal dual components are ignored. The norm bound is Lgrad=√8.

The normalized author parameter λ=10 is converted exactly as

```math
W=\max_j(\max h_j-\min h_j)\,
\frac{P}{2\pi}\,\frac{N}{B_{N-1}-B_0}\,\delta\,\lambda .
```

The endpoint span in this parameter normalization is intentional and differs from the first-difference Fourier period. The data term is an unnormalized sum of squared receiver units. W multiplies the discrete nodal TV and therefore has receiver²·cm²/relative-amount units. The author's normalized λ is a numerical convention tied to the specified receiver/field/length units; do not treat its number as universally unit-invariant. For example, expressing length in mm changes density by1/100 and requires λ to change by10 to retain the same physical prior. The implemented primary constants remain in G/cm and cm.

## Initialization and Lipschitz bound

Each initial source is computed only from measured data:

```math
u_j^0=v_j/(\delta^2\sum_{a,b}v_j[a,b]).
```

This sets an initial relative integral of one; it does not use the true source amount. Run the original normalized power iteration on Nop, starting from this initializer. Iterate x←Nop(x), estimate its Euclidean sequence norm l, and divide x by l. Stop when |l−lprevious|≤tol|l| or1000 iterations, using tol=1e−5. A final norm ratio gives the spectral estimate; multiply it by1.05 to obtain Lf. Source-wise squared norms are summed in the source order.

## Explicit CP2016 primal-dual updates

Initialize the extrapolated primal variable ū=u0 and dual vectors pj=0. The steps are

```math
\tau=\frac{1}{2L_f},\qquad
\sigma=\frac{L_f}{(L_{\rm grad}W)^2}.
```

Cache the data gradient g=Nop(u)−v. For every source, perform

```math
p_j^{n+1}=\frac{p_j^n+\sigma W D\bar u_j^n}
{\max\{1,\|p_j^n+\sigma W D\bar u_j^n\|_2\}},
\qquad
u_j^{n+1}=u_j^n+\tau\left(W\,\mathrm{div}(p_j^{n+1})-g_j^n\right),
\qquad
\bar u_j^{n+1}=2u_j^{n+1}-u_j^n.
```

The dual norm and maximum are pointwise. No positivity projection is used in the primary method. The data gradient for all sources is updated only after the source-wise sweep, preserving coupling and source order. The source calls this a Condat–Vũ-like scheme presented in CP2016; it is not replaced by a generic optimizer.

Stop when

```math
\sum_j\|u_j^{n+1}-u_j^n\|_2^2
<\mathrm{tol}^2\sum_j\|u_j^{n+1}\|_2^2
```

or after5000 updates. The strict comparison follows the source. The bound experiment stops at1334. Optional energy logging every20 iterations evaluates the same quadratic through Nop and v plus TV; it does not change any update and is verified bitwise against logging disabled.
