# Provenance and validation: two-species EPR density reconstruction

## Binding and scientific scope

This is an author-defined simulated spatial acquisition, using the original published generator and real measured spectral templates. It is not an existing measured spatial data set. Forty full gradient spectra jointly constrain two complete 100 by 100 density fields (20,000 unknowns); neither the hidden object geometry nor its seed is public calibration. The true concentrations are nonnegative. The selected original default estimator is unconstrained signed TV: small signed background estimates are retained, never interpreted as physical negative concentration and never clipped.

The selected numerical configuration is explicitly nondefault float64 and FINUFFT eps=1e-12, fixed before local implementation. It losslessly promotes the original float32 generated observations and calibration. It does not regenerate, denoise, select or alter observations. The original float32 complete experiment and the nonnegative comparison remain privately archived. No mathematical upstream correction was made.
