# Shipped execution flow

`python -m src.main` loads `data/raw_data.npz`, executes `reconstruct`, and writes the two declared batch-first float64 arrays into `output/reconstruction.npz`. The CLI prints elapsed reconstruction time. It does not load hidden reference assets.

`preprocessing.load_data(path)` validates three finite float32 arrays of shape (1,468,468), positive flat values, and returns normalized grid and sample arrays of shape (468,468), float32. Constants PERIOD, KERNEL and AVERAGE are 12.68550106609808, 7 and 13.

`physics_model.correlation_model(period)` returns the seven-parameter correlation function used by curve_fit. `average_coefficients(coefficients, average=13)` maps a (455,455,5) coefficient array to channel-first (5,35,35) block averages. `moments_from_coefficients(grid_coefficients, sample_coefficients, period=PERIOD, average=13)` returns covariance (3,35,35), transmission (35,35), and mode ratios (5,35,35), all float64. `mode_ratios(covariance, transmission, period=PERIOD)` predicts five local Fourier ratios. `covariance_eigenvalues(covariance)` returns ascending eigenvalues with shape (2,35,35). These functions do not clip signed moments.

`solvers.extract_coefficients(grid, sample, period=PERIOD, kernel=7, capture_covariance=False)` returns coefficients (2,455,455,5) and either None or conditional fit covariance (2,455,455,5,5). `solvers.reconstruct(grid, sample, period=PERIOD, kernel=7, average=13, capture_covariance=False)` calls that function and the linear tensor inversion; returns covariance, transmission, and diagnostics containing coefficients, fit_covariance, and ratios. Capturing covariance changes recording only, not the fit or method.

`visualization` contains figure construction and conditional uncertainty diagnostics used by the active notebook. It never selects a Matplotlib backend. Figures compare measured images, all output fields, original/fresh agreement, directional forward predictions, eigenvalues, and constrained comparisons. The notebook selects a private figure directory using IMAGING101_FIGURE_DIR; exported figures are not required solver output.

`evaluation/judge.py` is an independent standalone evaluator. It validates both required arrays, loads hidden standard-method arrays relative to its own file, scores four quantities and directional residual, writes strict JSON, and returns 0/1/2 for pass/valid failure/error. It does not import src. Tests consume frozen original arrays only, never the upstream package. The notebook actively imports local modules, reconstructs all observations, saves the fresh submission, calls the Judge, and loads separately identified source results for comparison. No synthetic-data generator is shipped because all benchmark observations already existed.
