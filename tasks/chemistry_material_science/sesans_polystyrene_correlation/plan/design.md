# Shipped interfaces and execution

The standard entry `python -m src.main` actively reads `data/raw_data.npz`, estimates two physical parameters, generates the501-sample radial autocovariance and writes `output/reconstruction.npz`. It prints JSON run/convergence/measurement chi squared information. Source paths are relative to the module's task directory. No import changes a plotting backend, reads hidden reference arrays, downloads assets or imports sasmodels/Bumps/sasdata.

`preprocessing.load_observations(path=ROOT/'data/raw_data.npz')` uses allow_pickle=False and returns a dictionary of the five README keys with the leading batch axis removed. Each is a copied real float64 `(40,)` array: spin_echo_length/length_standard_error/wavelength in Angstrom, and depolarisation/standard_error in Angstrom^-2 cm^-1. It validates exact shape/dtype/finiteness, positive standard errors and increasing nominal length. It performs no unit conversion, downcast, point rejection, interpolation or recomputation of published reduced measurements.

`physics_model.hankel(data)` returns `(q,H,H0)` with shapes `(32216,)`, `(32216,40)`, `(32216,)`, all real float64. q is inverse Angstrom, H/H0 weights are inverse square Angstrom. The32216-by40 Bessel matrix is built once per reconstruction; memory is roughly10.3MB plus temporary arrays, well below the scheduling threshold. The finite quadrature and physical acceptance correction are detailed in approach.md. `sphere_amplitude(x)` returns real float64 normalized sphere amplitude with matching shape, including stable x=0. `sphere_intensity(p,q)` accepts parameters radius/fraction `(2,)` and q axis and returns real cm^-1 intensity `(32216,)`. `forward(p,q,H,H0)` returns real `(40,)` reduced depolarisation. `residuals(p,data,q,H,H0)` returns standardized `(40,)` model-minus-data residuals. `bounded_residuals(p,data,q,H,H0)` returns53 real components including the original Bumps prior/penalty convention. These mathematical helpers do not write files.

`physics_model.autocovariance(p,r=RGRID)` returns dimensionless real correlation matching r, default `(501,)`. It uses the explicit3D sphere overlap polynomial/support and phase-fraction variance amplitude. Constants SLD1.41/2.70, acceptance.0168radian, nominal initialization, bounds and parameter error scales are defined explicitly in the same module. No cached result or domain API substitutes for mathematics.

`solvers.reconstruct(data,initial=INITIAL)` builds the Hankel grid, evaluates explicit bounded residuals through MINPACK LM with the preserved SciPy fitter controls, requires a successful finite termination and returns `(result,info)`. Result arrays are float64 `reconstruction` `(1,501)` and `parameters` `(1,2)` in the exact public order/units. Info contains runtime seconds, residual evaluation count, success, optimizer message and measurement chi squared; the13 zero prior components are not mistakenly counted as extra measurement degrees of freedom. There are no filesystem side effects. `main.main()` creates output, writes the single declared NPZ, prints info, and returns the same tuple.

`visualization.comparisons(data,fresh,upstream)` builds a Matplotlib three-panel comparison and returns the figure. The first panel shows all real reduced observations with original errors, actual initialization, independently rerun original model and freshly computed local fit. The second shows separately identified original/local inferred radial autocovariances, never truth. The third shows measured standardized residuals. Length axes are labeled in micrometers after dividing Angstrom by10000 for display only; numerical arrays/evaluation retain Angstrom. No scalar metric is independently redefined by visualization.

`evaluation/judge.py` is standalone with required `--prediction` and `--report`. `evaluate(path)` returns `(report,code)`, where0=pass,1=valid below quality boundary,2=malformed submission/evaluator problem. It resolves hidden reference, metric and public observation paths relative to its own location and CLI paths relative to the caller. It loads allow_pickle=False, checks both arrays' exact shapes/float64/finiteness, validates nondegenerate and correctly shaped evaluator references, and validates finite positive thresholds. It independently implements the sphere/Hankel model to score measurement consistency without importing solver or submitted code. No crop/reshape/cast to real/reference substitution occurs. Invalid cases return empty metrics and descriptive errors. `main()` creates the report directory, writes strict UTF-8 JSON and emits stderr/2 on write failure.

The notebook actively loads all observations and calls the cleaned solver; it saves/judges that newly computed result, prints parameter/metric tables, and shows the scientific three-panel comparisons. `notebooks/reference_outputs/upstream.npz` identifies the real exact-source original inversion; `cleaned.npz` separately identifies a fresh CLI result, neither is used as a fresh notebook inversion. `test/fixtures/upstream.npz` contains complete q/H0/intensity/initial-final measurement/residual/parameter arrays and149 representative Hankel rows, avoiding a redundant full10MB kernel copy while preserving low/high-grid and evenly sampled Bessel evidence. Full original H stays private. Tests consume frozen oracle arrays and add analytic sphere/Guinier/integral/support checks, the inactive acceptance discrepancy check, strict Judge contracts and an active end-to-end inversion. A deliberate preimplementation test run failed on missing local source and is archived as red evidence. Logs, source archives, original files, paper XML/PDF access evidence and temporary execution/figure assets live outside the shipped task and are indexed by validation.md. No generator is included because no synthetic observation is generated.
