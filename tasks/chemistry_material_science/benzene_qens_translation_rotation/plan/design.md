# Shipped interfaces and execution

All arrays are NumPy float64 unless explicitly stated. No source checkout, scipp, dynesty or other task is imported by runtime, Judge or tests. Requirements are NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1; pytest/Jupyter are development tools.

| Module and callable | Inputs | Returns and side effects |
|---|---|---|
| preprocessing.load_raw(path) | NPZ path | Dict of fourteen public batch-first arrays; exact dtype/shape and explicit native NaN masks validated; no writes |
| preprocessing.overlap_rebin(signal,standard_error,old_edges,new_edges,q_limits,divisor) | Arrays (3,249,320), matching errors in U, edge vectors in inverse Angstrom, pair of Q limits, scalar divisor | Signal and variance (3,newQ,320), U and U^2; unselected native missingness retained |
| preprocessing.prepare(raw) | Loaded public dictionary | Dict keyed '360','197'; each contains q,energy,y,sigma,response,resolution,rebinned_signal,rebinned_variance,q_index,energy_index |
| physics_model.lorentzian(energy,gamma) | Energy vector and positive width, meV | Continuous Lorentzian samples in meV^-1 |
| physics_model.kernel_basis(global_parameters,measurement) | (3,) g,h,v physical coefficients; one measurement dictionary | (12,92) or (14,169) empirical-reference-convolved basis in meV^-2 |
| physics_model.predict(parameters,data) | (31,) full physical parameters and prepared data | Dict '360','197' curves in U; no writes |
| physics_model.weighted_sse(predictions,data) | Two curves and prepared observations | Python float aggregate J |
| solvers.profile_energy(basis,y,sigma) | Same-shape Q-by-energy arrays; basis meV^-2, y/sigma U | Tuple objective,N,backgrounds,prediction; scalar N, Q vector, full curve |
| solvers.profile(global_parameters,data) | Three physical global coefficients, both measurements | Tuple objective,(31,) parameters,curves dictionary |
| solvers.reconstruct(data) | Both prepared measurement groups | Tuple parameters,curves,diagnostics; diagnostics J, grid/start counts, iterations, success/message |
| main.run(raw_path=None,output_path=None) | Defaults task-root data/raw_data.npz and output/reconstruction.npz | Exact three-key batch-first result dict and diagnostics including seconds; creates output parent and writes NPZ |

`python -m src.main` calls `run` and prints diagnostics. Paths use the module's resolved task root rather than current working directory. It never changes Matplotlib backend, including when imported. Library functions have no global filesystem mutations; only `main.run` writes reconstruction.

Prepared data shapes: q (12,) or (14,) in inverse Angstrom, energy (92,) or (169,) meV, y/sigma/response/resolution corresponding Q-by-energy arrays. Response has U and resolution is dimensionless algebraic-normalized. rebinned_signal/variance are (3,12,92) or (3,14,169) in U/U^2 before subtraction/360 half scaling. q_index,energy_index are int64 source-grid column vectors. No metadata JSON is needed. All constants match README tables and exact native stored coordinates.

`evaluation/judge.py` is standalone and does not import src or submitted code. It implements independent validation, overlap reduction, trigonometric Bessel expressions and direct discrete convolution. `evaluate(prediction,evaluation_dir=HERE)` returns a JSON-compatible report and exit code. Actual ground_truth.npz, when present, precedes baseline_reference.npz; reference format/support is validated, but hidden parameter/curve similarity is not a scoring criterion for this non-unique observational fit. Thresholds are independent fixed quality/consistency definitions. CLI requires --prediction and --report; resolves hidden assets relative to itself and supplied paths relative to the caller. Exit0 pass,1 valid poor,2 malformed or evaluator failure, with empty metrics on errors and finite strict JSON. Report parents are created. Native raw NaN exceptions require exact explicit acquisition masks; no other nonfinite array is allowed.

`visualization` creates fresh-data/point/source-comparison figures and returns Figure objects without filesystem writes. The notebook is the only caller of comparison plotting. It actively calls `main.run`, loads separately named upstream comparison arrays, evaluates fresh output through the standalone Judge and shows a parameter/unit table. Review PNGs are extracted privately from the executed Notebook outputs, without any canonical savefig call or absolute destination. It never imports upstream kernels or substitutes a reference as a fresh result.

The plotting signatures are `native_observations(raw)`, `analysis_observations(data)`, `all_q_comparison(data,n,fresh,source,posterior)`, `residual_diagnostics(data,fresh,source,posterior)` and `parameter_and_model_limits(data,fresh,source,posterior)`. All return a Matplotlib Figure and have no path/default arguments or filesystem writes. Here n is the string '360' or '197'; fresh/source are the exact three-key batch-first submission-format dictionaries; posterior is the upstream summary dictionary loaded by the notebook. Native plots show all six group arrays and explicit missingness, full-Q comparison figures retain every selected row and all six percentile boundaries, and parameter diagnostics retain all31 unknowns through histograms/tables/backgrounds. The notebook's `show(fig,name)` displays and closes its Figure; name is a descriptive review identifier and does not create a file. Private maintainers extract embedded image outputs after execution for visual QA.

Frozen fixtures: source_selected_rebin tests all group preprocessing; qens_source_physical_forward_cases tests full 31-coordinate forward/likelihood; qens_source_v2_global_derivative_cases tests fixed-theta derivatives after physical coordinate mapping; qens_independent_profile_oracle tests constrained nuisance minima; qens_native_energy_affine_adapter_cases supports unit/coordinate physics checks. Reference_outputs/source_best_sample is original maximum sampled likelihood, source_joint_posterior_summary is full original Bayesian mean/bands/histograms. These are comparisons, not public calibration or physical truth. Raw data alone plus README/environment define the problem.
