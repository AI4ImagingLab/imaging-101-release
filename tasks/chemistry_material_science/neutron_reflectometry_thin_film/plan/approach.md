# Implemented mathematics and reconstruction

This task implements the maximum likelihood thin film fit in the refnx getting started example, using the actual 408 point PLATYPUS curve. It is a modern NumPy/SciPy extraction of the selected deterministic fitting stage, not a rerun of every demonstration in the tutorial or of the paper's posterior experiment. No synthetic data are generated. A real microscopic ground truth is unavailable.

The eight element parameter vector is p = (s,b,d1,sigma1,d2,rho2,sigma2,sigma3), ordered identically in the public contract. All lengths are angstroms, SLDs are stored as numerical multiples of 10^-6 Angstrom^-2, and the intensities, s and b are dimensionless. The four slab rows are `(0,2.07,0,0)`, `(d1,3.47,0,sigma1)`, `(d2,rho2,0,sigma2)`, `(0,6.36,0,sigma3)`, whose columns are thickness, real SLD, imaginary SLD and roughness. Bounding layers are semi-infinite.

For each Q, set k_j = sqrt(Q²/4 - 4 pi (rho_j-rho_0)); multiply the stored SLD difference by 10^-6 before this calculation. An infinitesimal imaginary SLD `+i 10^-30` in the converted difference establishes the upstream outgoing square root branch. The interface coefficient is `(k_j-k_(j+1))/(k_j+k_(j+1)) exp(-2 k_j k_(j+1) sigma_(j+1)^2)`. The finite layer propagation factor is beta_j = exp(i k_j |d_j|). The characteristic matrix elements are beta, r/beta, r*beta, and 1/beta. The first interface has beta=1. The local `abeles` function reproduces the upstream matrix product ordering explicitly and returns `|M01/M00|²`, without a domain reconstruction API. Negative Q nodes generated by resolution quadrature retain upstream Q² conventions.

Point dependent instrumental convolution uses 17 point Gauss–Legendre nodes x_l and weights w_l on [-1,1]. With sigma_Q = q_fwhm/(2 sqrt(2 ln 2)), evaluate the reflectivity at `Q_i + 3.5 sigma_Q_i x_l`, multiply by `3.5 w_l exp(-(3.5 x_l)²/2)/sqrt(2 pi)`, and sum. This truncates the Gaussian at ±3.5 sigma **without renormalizing**, matching upstream exactly. The resulting integral is multiplied by s, then b is added. Changing the truncation normalization would change intensity conventions. Tests compare exact initial and final upstream intensities and include independent Fresnel, total reflection, zero contrast and layer subdivision checks.

For observed intensity R_i and supplied standard error e_i, define y_i=log10(R_i), m_i=log10(prediction_i) and t_i=e_i/(R_i ln 10). The residual sign is `(y_i-m_i)/t_i`. The objective is the Gaussian negative log likelihood `0.5 sum(((y_i-m_i)/t_i)^2 + log(2 pi t_i²))`. There is no division by sample count, regularizer, learned prior, gradient shortcut, or estimated noise scale. The additive normalization remains in the objective because differential evolution's stopping tolerance depends on the objective offset. The reported chi squared is the residual sum of squares without its factor 1/2. The best chi squared is around 919.586 for 408 points and eight unknowns: reduced chi squared is about 2.299. This indicates residual model/uncertainty limitations; it is not evidence of unit variance microscopic accuracy.

Initialization is `[1,3e-6,30,3,250,2,3,3]`, used for diagnostic initial comparisons. The global optimizer's population is Latin hypercube initialized by SciPy, not initialized at that diagnostic vector. Bounds, in parameter order, are `[.6,1.2]`, `[1e-9,9e-6]`, `[15,50]`, `[1,15]`, `[200,300]`, `[.1,3]`, `[1,15]`, `[1,15]`. These preserve the upstream tutorial constraints. `scipy.optimize.differential_evolution` uses seed 2718, population multiplier 15, maximum 1000 generations, tolerance 1e-8, default absolute tolerance zero, default best1bin mutation/crossover settings, single worker, immediate updating, and its default L-BFGS-B polish. Convergence is the SciPy population-energy standard deviation criterion `std(E) <= atol + tol*abs(mean(E))`; there is no task-specific step size or line search. The general-purpose polishing optimizer owns its standard line search; no published custom inverse update is replaced. The reference run converged after 147 generations. Solver return information includes convergence status and message.

The depth representation uses fixed z_j=-30+0.5j, j=0,...,820. At interface positions 0,d1,d1+d2, add the SLD jump times `[1+erf((z-z_interface)/(sqrt(2)*sigma))]/2`. Output is real float64 in the original SLD scale. The profile is not used to secretly regenerate observations; the slab model is the explicit forward approximation. Small roughness and thin layer regimes of this conventional approximation should not be interpreted as exact microscopics.

Evaluation uses upstream standard inversion results, explicitly not truth. Profile NRMSE is RMS error divided by reference dynamic range. Parameter error is maximum elementwise absolute difference normalized by its bound width, so tiny background values are not hidden under a dimensionless absolute tolerance. Forward consistency uses the same physical acquisition conventions in an independent standalone evaluator implementation. Profile tolerance 2e-5 and parameter error 2e-4 were selected from independent upstream seed reruns before comparing the local reconstruction, not from self comparison. The independently rerun profile NRMSE was 2.1706e-6; its largest parameter range normalized difference was approximately 2.51e-5. The observation chi squared limit 930 is close to the bound method's 919.586, retaining the observed residual systematics without pretending the statistical fit is perfect. All required arrays and metrics must pass, with no alignment or rescaling. Full threshold rationale and precise results are in test/validation.md.
