# Shipped interfaces and execution flow

`python -m src.main` resolves paths from its module location, reads `data/raw_data.npz`, reconstructs on CPU, and writes `output/reconstruction.npz`. The caller's current directory need not determine data paths. The command should be launched in the task workspace to import the `src` package. It prints a JSON runtime/convergence summary. It neither downloads data nor imports an upstream package. Importing main has no plotting backend side effect.

`src.preprocessing.load_observations(path=ROOT/'data/raw_data.npz')` returns the tuple `(q,r,error,dq)`, four float64 arrays of shape `(408,)`, with the public batch axis removed explicitly at the input boundary. It uses `allow_pickle=False`, validates compatible one dimensional shapes, dtype, finite values and positivity, and returns copies. Units are Angstrom^-1, dimensionless, dimensionless, Angstrom^-1 respectively. The source data are retained exactly, without resampling, point rejection, precision conversion or noise correction.

`src.physics_model.slabs(p)` accepts float64 parameter vector `(8,)` and returns `(4,4)` slabs; columns and physical constants are detailed in approach.md. `abeles(q,layers,scale=1.0,bkg=0,threads=0)` accepts arbitrary shaped real Q arrays and slab rows, returns matching real float64 intensity shape, and explicitly performs the complex matrix operations. Its retained threads argument is ignored, as in the upstream pure Python backend. Default scale/background are used internally; task nuisance parameters are applied after convolution. `forward(p,q,q_fwhm)` accepts `(8,)`, `(N,)`, `(N,)`, returns predicted `(N,)` intensities and applies the 17 point quadrature. `profile(p,z=Z)` returns a real float64 SLD array matching z, with default `(821,)`. `residuals(p,q,r,error,dq)` returns weighted log residuals `(N,)`; `negative_log_likelihood(p,q,r,error,dq)` returns a scalar. None of these functions write files, import optional libraries or access reference outputs.

`src.solvers.reconstruct(q,r,error,dq,seed=2718)` runs bounded single worker SciPy differential evolution. It returns `(result,info)`. Result is a dictionary containing `reconstruction` `(1,821)` and `parameters` `(1,8)`, both real float64. Info contains runtime seconds, negative log likelihood, iteration count, optimizer success and message. All optimizer settings and bounds are in source and approach.md. A nonfinite final objective raises RuntimeError; optimizer convergence is also checked by the pipeline validation test. There is no file side effect.

`src.main.main()` calls the loader then reconstruct, creates output if needed, saves the two result arrays, prints info as JSON, and returns `(result,info)`. It does not import Matplotlib. `src.visualization.comparisons(data,result,upstream)` accepts the observation tuple, a fresh result dictionary and an identified upstream reference mapping with reconstruction/parameters/prediction. It returns a Matplotlib figure showing measured/initial/upstream/fresh reflectivity, paired SLD profiles and fresh weighted residuals. It does not save files or compute benchmark quality metrics independently.

`evaluation/judge.py` is independently executable with `--prediction` and `--report`. Its `evaluate(path)` helper returns `(report,exit_code)` and never imports src or a submitted solver. Hidden reference and metric paths are relative to the evaluator file, while prediction/report CLI paths are relative to the caller. It validates both required arrays, rejects complex/nonfinite/wrong shape/wrong dtype outputs, checks hidden reference validity and metric definitions, then scores both arrays and observation consistency. Invalid predictions and evaluator assets return error/2 with empty metrics, valid poor outputs fail/1, and valid accepted outputs pass/0. `main()` writes UTF-8 strict JSON, creating the report parent; write failure returns 2 and a stderr diagnostic. The evaluator includes a separate explicit Abeles/convolution implementation and uses only public q/R/error/resolution for its consistency term.

`notebooks/neutron_reflectometry_thin_film.ipynb` actively calls the cleaned loader and solver on the complete raw data, writes the newly computed submission, evaluates it, and plots it against an independently run upstream result. It has no cache shortcut. Precomputed arrays in `notebooks/reference_outputs/upstream.npz` identify the oracle run; `cleaned.npz` identifies the first fresh local command run. The notebook's figure and metrics use its own newly calculated result. A parameter comparison table is evaluated actively. The selected comparison is deterministic maximum likelihood; tutorial MCMC/posterior and unrelated synthetic/straight line demonstrations are explicitly out of scope, not filled with fake data.

`test/fixtures/upstream.npz` is the frozen independently executed upstream oracle, consumed by parity and exact data tests. Tests under `test/comparing_test/` compare initial forward predictions/residuals, fitted forward predictions, profile generation, physical limiting cases and a new full inversion. Tests under `test/unit_test/` cover output/Judge metrics, malformed arrays, evaluator failures, arbitrary caller directories, report-write failure and backend safety. Logs, source checkout, paper, capture scripts and executed notebook remain in the external maintainer archive indexed by test/validation.md, not in this task.

The final evaluator explicitly gives the exact ground_truth.npz asset precedence when present; otherwise it loads baseline_reference.npz. Malformed existing truth is an evaluator error, never a reason to fall back to a baseline. This task ships only the validated standard-method baseline.
