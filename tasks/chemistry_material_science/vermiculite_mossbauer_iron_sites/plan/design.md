# Runtime interfaces and caller flow

Standard python -m src.main loads public data with preprocessing.load_data(path=Path('data/raw_data.npz')), returning velocity(4,512) mm/s and normalized transmission(4,512), float64. It calls solvers.reconstruct(velocities,observations), writes output/reconstruction.npz and prints runtime/per-specimen SSE. No hidden source arrays are read.

physics_model.lorentzian(fwhm,offset) evaluates unit-area line density. source_quadrature(nodes=64) returns scaled offsets and dimensionless source weights, each length64. transmission(velocity,parameters,nodes=64) returns a float64 normalized intensity vector and implements original source scaling/finite-wing correction and powder depth explicitly. Selected parameter layout44 is documented in approach. No domain-library or original package import occurs.

solvers.source_norm(values), jacobian(function,parameters,velocity,fixed,base), elimination(hessian,damping,gradient) are readable source-convention numerical stages. jacobian returns row-Jacobian and active parameter indices. paired_lm(velocity,observed,initial,fixed,bounds,outer_limit=75,inner_limit=25,eps=1e-10,recheck=True) returns fitted44-vector and accepted-step history. configuration(start_index=0,count=4) constructs independent priors/fixed slots/bounds; count supports notebook simpler-model comparisons, not a hidden fixture lookup. outputs(parameters,velocities) canonicalizes sites and returns reconstruction(1,4,4,3) mm/s, optical_thickness(1,4,4), baseline(1,4), transmission(1,4,512), all float64. reconstruct repeats two independent starts for every observed specimen and returns (output_dictionary,diagnostic_records), with both SSE values and selected accepted-step history.

Standalone evaluation/judge.py imports no solver. It validates all4 output arrays, prefers actual truth if supplied, otherwise honest original-method reference, and implements its own physical quadrature to enforce parameter/spectrum agreement. It reports native0/1/2, per-quantity numerical errors, per-specimen RMS and finite positive configured thresholds. Prediction/report paths are caller-relative and hidden assets file-relative. No submitted source is imported.

The active notebook calls cleaned reconstruction on all4 raw records, evaluates fresh outputs, compares independent original full measurements, shows full spectra/residuals/site quantities, retains original1/2/3/4 component necessity diagnostics, and freshly fits a simpler3-component model plus computes local Jacobian conditioning and isolated component absorption. Reference arrays are labeled and are never a cached fresh substitute. visualization.review_figures returns three figures, without backend selection or file writes. Notebook owns display and recorded measurements; requirements document validated shared numerical primitives. All tests/fixtures live under test/, provenance and original scripts/source/logs outside the shipped task.
