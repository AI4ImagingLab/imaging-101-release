# Implemented nuclear transmission inversion

The four real normalized transmission records each contain512 velocity samples. Public data are exactly the source CSV first two columns (velocity mm/s and measured Data/100), in fixed specimen order. Source fitted envelopes/doublets are neither read for initialization nor exposed. Known source calibration is independent iron foil. No new synthetic observations are generated.

Each specimen has four powder doublets and one baseline. Source parameter layout p has8 baseline slots plus9 slots per site,44 total; only17 are free: baseline p0 and per-site effective optical thickness I, isomer shift delta, quadrupole half-splitting epsilon, Lorentzian absorber FWHM Gamma. Other baseline slots, Gaussian broadening and texture are fixed0; Gaussian width ratio fixed1. The component transition centers delta±epsilon and all widths are mm/s. Public output QS=2epsilon. Canonical site order is ascending delta, breaking ties by epsilon. Unknown recoil fractions mean I is an effective resonant thickness, not true site abundance.

The unit-area Lorentzian is L(s;Gamma)=(Gamma/2)/[pi*(s²+(Gamma/2)²)]. In the source scaled velocity convention h=.28, natural FWHM Gamma0=.098mm/s. For64 coordinates e uniformly−.989..+.989, form offsets f(e)=sum(c_l log[(l+e)/(l-e)]), c=(.027181,22.7718,−33.6937), and Jacobian f'(e)=sum(2l c_l/(l²-e²)). Source quadrature weight w=L(f;h*Gamma0)*f'(e)*delta_e. At source node, E=h*v+f, and powder optical depth is pi*h*Gamma0/4*sum_k I_k*[L(E-h*(delta_k-epsilon_k);h*Gamma_k)+L(E-h*(delta_k+epsilon_k);h*Gamma_k)]. Sum w exp(-depth), then add1-sum(w) for unsampled distant source photons assumed unabsorbed, and multiply baseline. The original complex2x2 powder cross-section is scalar; its dispersive phase cancels in the unpolarized intensity. This scalar expression is analytically the same selected full-thickness branch, not a thin-absorption replacement. Node reduction follows original order. No periodic/spatial boundary or artificial regularizer occurs.

Minimize unweighted sum of squared normalized intensity residuals, observed-minus-predicted. Original custom LM is explicit. Finite-difference Jacobian rows use max(1e-12,abs(p_k)/1e6), omitting fixed and exactly zero-response columns. Set H=J*J^T and g=J*residual. Solve (H+diag(damping))*step=g with original nonzero-pivot Gaussian elimination and ordered back-substitution. Damping scale tau starts.001, growth nu starts2.618. Alternate source strategies: uniform max(H)*tau and refreshed Jacobian/diagonal(H)*tau. The source norm is norm_source(v)=sqrt(sum((v/len(v))²)), not RMS or Euclidean norm. Gain ratio is [norm_source(old residual)²-norm_source(trial residual)²]/abs(step dot(damping*step+g)); retain its N^-2 factor. Rejected trials increase damping by nu, then nu*=2.618. Accepted trials update current model/residual and follow the source diagonal/uniform damping branch, including tau and nu resets. No generic optimizer replaces these custom updates.

Crossed box bounds shorten the complete step to the nearest bound, auto-fix that parameter, refresh the Jacobian, then recheck once after nudging newly fixed parameters inward by max(1e-12,abs(p)/1e6), using half the outer limit. Initial baseline1 constrained.95..1.05; I .0001..5; delta−.2..1.7mm/s; epsilon.02..2mm/s; absorber FWHM.02..1.5mm/s. These are broad independent model constraints, not source fitted labels. Two generic initial mixtures are explicit in configuration(): baseline1; first I=.12,Gamma=.25, (delta,epsilon)=(.3,.25),(.4,.55),(1.1,1.05),(1.2,1.45); second I=.15,Gamma=.3,(.25,.3),(.55,.65),(.95,1),(1.35,1.5). Choose lower final SSE. This independent-start reliability extension is disclosed, not claimed as the author's historical automatic initialization.

Retain75 outer and25 accepted-inner iteration limits, eps1e-10, source small-step test norm(step)<eps² norm(free params), gradient and source reduced-chi change tests, and original stall counters. The source uses variance abs(normalized data)+1 in a stopping statistic; because these are already normalized observations, that is an algorithmic convention, not a physical Poisson uncertainty estimate. Covariance calculation from the broad original GUI is not part of the required output; notebook uses explicitly labeled normalized-Jacobian conditioning rather than fabricating uncertainty.

Judge compares every specimen/site by separately max absolute IS/QS/FWHM error<=.001mm/s, thickness<=.002, baseline<=1e-5 and transmission<=1e-5. Independently evaluate model/parameter self-consistency<=1e-8 and each observed transmission RMS<=1.1 times its actually reproduced original RMS. Criteria were frozen after complete original exact-data/reliability runs, before local extraction. No true material parameters exist. Canonical order removes only permutation freedom; no shift, scale, crop or alignment is permitted. Weak components and local minima are explicitly reviewed, never converted into truth.
