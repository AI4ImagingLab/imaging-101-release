## Physical task and semantic identity

Acquired reversal-curve magnetic moment is inverted to a signed coercivity–interaction-field switching response and conditional uncertainty. This is physical parameter-space imaging, not a spatial microscopy map or statistics-only feature extraction. The existing catalogue has no hysteretic switching density inverse. This differs from electrochemical relaxation, magnetic field/current imaging, crystal strain, EPR radical/distance inversion and material orientation tasks. The complete source acquisition has 15,644 numeric rows: 15,504 branch observations plus 140 instrument calibration samples. The calibration rows are parsed by the author software but unused with drift correction disabled; they are not duplicated as unused public arrays. All 15,504 actual branch observations remain public and enter neighborhood inference. No fitted-pixel quality mask is used.

## Independently investigated discrepancies and scientific limits

1. **Paper normalization error in original code.** Appendix A Eq. A4 with a=−3/4 and j=4 nonintercept terms requires Gamma(9/4)/Gamma(1/4)=(5/4)(1/4)=5/16. Therefore its logarithm is −1.1631508098056809. Original `Bayes_factor(...,order=1)` hardcodes −1.3862943611198906=log(1/4). The difference is log(1.25)=0.22314355131420976. The j=5 and j=9 source constants agree with the independently derived gamma expression. The unit test derives the full expression using independent gamma evaluation and validates all three orders. A private copy changes **only that scalar constant**; the source diff and hashes are preserved. The original source and full unmodified run remain archived. The corrected source is rerun independently, and its numeric fixtures were frozen before judging the corrected local implementation. No fixture is generated by the local function being tested. The correction changes 110 native diagnostic labels and 109 density samples, with largest absolute density change 0.0027710978379770386 A m² T⁻². Smoothing remains factor two. The notebook actively compares original, corrected-source and fresh-local outputs; it never calls this unchanged-source parity.

2. **Exterior stale-value/rank defect.** Original `execute` evaluates exterior positions beyond its own `in_window` reporting predicate. At source index 15296, c=0, u=−0.188094 T, the selected local quadratic has only eight neighbors and rank five, while small-n cubic evidence is undefined. Source variables `rho2`/`se2` may retain a previous iteration's values. The full original exterior output remains archived as negative evidence. The task declares exactly the native source reporting predicate, selecting all 11,310 native positions independently of outputs; all 15,504 observations still supply neighbors. Every supported native point has more than ten neighbors and a full-rank quadratic; no failed interior point was removed. No density or confidence claim is made for exterior positions. This is the complete author figure's native domain, not a postfit crop.

3. **Historical versus shipped settings.** Paper Figure 4 uses 15,364 measurements and a 2,646-member full VARIFORC search. The present bound source defaults retain 140 first-branch points, and the selected published special case constrains sc0=sc1=su0=su1 and lambda=0. The six factors are 2,3,4,5,7,10, generated by the source's rounded six-point geometric spacing on [2,10]. The paper explicitly permits this reduced family and its reported UB199B optimum is isotropic factor two. The source default high-field correction is 70%; first-/last-point removal, drift and mass normalization are disabled. The paper's recommendation of approximately 2,000 selection positions is followed. A 1,000-position discovery preflight is archived separately and does not establish the shipped configuration.

4. The density is signed, and the conditional SE is a local regression uncertainty. Model selection can set density/SE to zero when the mixed term is unsupported; this is not zero physical uncertainty. Neither upstream agreement nor these conditional intervals establish absolute physical accuracy. Mixed derivatives cannot uniquely recover global moment boundary functions. The local rectangle-integral identity and moment residual checks are correctly labeled and do not substitute an invented global forward reconstruction.
