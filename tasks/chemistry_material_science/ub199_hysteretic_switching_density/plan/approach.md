# Implemented mathematical approach

This task estimates the signed switching response of the complete author UB199B acquisition. It follows the published Bayesian local-regression framework using the author's explicitly supported constant, isotropic smoothing family. It does not claim to repeat the paper's complete 2,646-member anisotropic search or every preprocessing setting used for its historical Figure 4. The paper's reported optimum is the same isotropic factor two, but historical values are not treated as measurements of this implementation.

Let B be applied induction and R be reversal induction, both in tesla, and m the acquired magnetic moment in A m². Fields and moments are kept in stored float64 precision. Define c=(B−R)/2 and u=(B+R)/2. The unknown signed density is rho=−(1/2)∂²M/(∂B∂R), in A m² T⁻². There is no mass, saturation-amplitude, spatial, or sign normalization. The public instrument predicate fixes 11,310 output positions before reconstruction; all 15,504 noncalibration observations remain usable as neighbors. The complete original output, including its invalid exterior region, is archived privately and explicitly distinguished from this domain.

The actual local field increment d is the arithmetic mean of consecutive B values in the largest acquired curve identifier. It is not recomputed from the rounded nominal header increment. Preprocessing first fits m≈a+bB using observations with B>0.70 max(B), then subtracts bB from every moment. This removes a high-field susceptibility term with identically zero mixed derivative. Drift correction, mass normalization, first-point deletion and last-point deletion are disabled, matching the chosen current upstream default settings. The paper's 15,364 versus this binding's 15,504 samples is documented; no claim of identical historical preprocessing is made.

The lower branch is estimated on a grid from min(B) to max(B), containing 50 floor((max(B)−min(B))/d)+1 points. At each grid position, select observations within ±2.5d. Of their branch identifiers, use only the last ten distinct branches, or all available branches when fewer exist. Fit an unweighted quadratic in B and evaluate at the grid position. Linear interpolation gives L(B), which is subtracted from the corrected moments: y=m−bB−L(B). This H-only correction also has zero mixed derivative. The code preserves the original inclusive selection and branch-order conventions. Data outside the lower-branch interpolation interval are not extrapolated; the bound observations have no resulting exclusions.

To find the loop-opening field, compare first branch samples with the same smooth lower branch, interpolate this difference at B=0, and find the largest negative B whose difference is no more than 5% of the interpolated value. Its negative is Bopen. The scoring triangle additionally requires |B|<Bopen and |R|<Bopen. Draw 2,000 of these acquisition positions using the source RandomState(999) convention, sort the sampled indices, and use the same positions for every candidate. This RNG selects measured positions and does not generate an unknown specimen. The paper recommends approximately 2,000 or more locations; an earlier 1,000-position preflight is archived and is not the shipped configuration.

The smoothing ensemble is s∈{2,3,4,5,7,10}. It is the source's six logarithmically spaced, rounded factors over [2,10], with sc0=sc1=su0=su1=s and lambda=0. For a center (c0,u0), observations enter the local regression if |c−c0|/d<s and |u−u0|/d<s. The source's general size law is min((1−lambda)s1+lambda|h|/d, max(s0,|h|/d)); the shipped constant family is its exact special case. No iterative or neural inverse is introduced.

For evidence comparison, scale y by its positive acquisition maximum. Form columns [1,B,R,B²,R²,BR,B³,R³,B²R,BR²]. Model H1 uses the first five columns, H2 the first six, H3 all ten, and H0 is constant. Fit each by the source normal-equation inverse and compute R²=1−RSS/sum((y−mean(y))²). The H1 normalization scalar is explicitly corrected to paper Appendix A; all other evidence arithmetic is preserved, and unchanged-source and corrected-source captures are separately identified. In the log evidence relative to H0, for p=4,5,9 nonintercept terms, use

```math
\ell_p=A_p+\log\Gamma((n-p-1)/2)-\log\Gamma((n-1)/2)
+[-(n-p-1)/2+1/4]\log(1-R_p^2),
```

where n is the local sample count and A4=−1.1631508098056809, A5=−0.8128078577831402, A9=1.5205488938776595. H0 has log evidence zero. Select the score label by argmax of [0,ell4,ell5,ell9] minus [log(10),log(10),0,log(10)], assigning H0 if the largest unpenalized log evidence is below one. Select the first candidate maximizing the number of H2 labels. The standard source factor-10 support preference and first-tie convention are preserved. Final domain-point diagnostic model order is the argmax of unpenalized evidence; the source sets density and SE to zero if that order is H0 or H1. This model-support decision is an estimator operation and not an evaluation mask.

For supported H2/H3 locations, estimate density with the full *quadratic*, as in the source; H3 is a diagnostic of inadequate local quadratic fit, not a different cubic reconstruction. Define z=|h|/d and t=z−s. The one-axis weight is 0 outside z>s, 2t² for s−0.5<z≤s, 1−2(t+1)² for s−1<z≤s−0.5, and 1 for z≤s−1. The two-dimensional weight is the product for c and u. Solve min_beta sum w(y−X beta)² by NumPy least squares with rcond=0. Let a be the BR coefficient; rho=−a/2. With n local points and six coefficients, residual variance is RSS/(n−6), coefficient covariance is that variance times (XᵀWX)⁻¹, and SE=sqrt(C55/4). The source two-sided diagnostic p value uses 2(1−StudentTCDF(|rho/SE|,n)); it is not an evaluation metric. Rank-deficient selected quadratic systems cause an explicit error. All selected systems on the fixed native reporting domain are independently checked full rank.

There is no optimizer initialization, line search or stopping tolerance: all inverses are finite local regression and discrete model selection. Defaults are the ensemble above, 2,000 scoring points, 70% high-field threshold, ten lower-branch curves, 50 grid subdivisions and 5% opening criterion. The notebook compares fixed smoothing and added observation noise using fresh computation, documents the actual runtime, and preserves the paper's key curve, model-order, density and coercivity-profile comparisons.

NCC is flattened cosine similarity without mean subtraction. NRMSE is RMS error divided by reference dynamic range. Both density and SE are required and compared without alignment, interpolation or renormalization. The independent upstream execution is a method reference, never truth. Threshold provenance, independent backend measurements and the exterior upstream defect are recorded in test/validation.md.
