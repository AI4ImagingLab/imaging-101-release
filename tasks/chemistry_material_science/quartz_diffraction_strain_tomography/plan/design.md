# Actual shipped interfaces and execution

`python -m src.main` loads `data/raw_data.npz`, reconstructs all six fields, and writes only the declared batch-first float64 reconstruction into output/reconstruction.npz. It prints actual seconds, optimizer iterations and objective. It never loads hidden truth or oracle arrays. `preprocessing.load_data(path)` returns a dictionary without batch axes: strain_measurements/noise_std (500,192), diffraction_vectors (3,500,192), angles(500), all float64, and support(106,96) bool. It rejects changed shapes/dtypes/nonfinite observations. `weights_and_directions(data)` returns float64 W(500,192) and S(6,500,192).

`cuda_runtime.project(images, angles, rays=192)` accepts real images (channels,rows,columns), degree angles, and returns float32 (channels,events,rays). It casts exactly as the upstream numerical backend, compiles visible src/joseph_kernel.cu on first use using general nvcc/MSVC tooling, and loads only that self-compiled DLL plus general CUDA runtime. Temporary compilation happens under the system temporary directory with an imaging101-quartz prefix, outside the task package. It caches a DLL handle only within the process. close_runtime unloads the handle before deleting its verified temporary directory; the atexit handler invokes it automatically. Failure to locate the validated compiler/SDK or a CUDA error raises a descriptive exception. No oracle path, ASTRA import or ASTRA DLL exists in this execution path.

`physics_model.radial_basis(support,size=8,scale=.16)` returns float64 CSR (10176,65). `render(basis,coefficients,shape)` maps float64 (6,65) coefficients to (6,106,96). `TensorAcquisition(data,size=8,scale=.16)` constructs B, support-normalized P, W, S, and matched bound Jacobian J(96000,390). Its `mean_project(images)` returns normalized float32 projections; `forward(coefficients)` returns weighted directional predictions(500,192), float64. `adjoint(residual)` returns J-transpose residual(6,65). `objective(flat)` returns scalar sum-squared cost and flat gradient(390). `field_prediction(field)` predicts unweighted directional strains from a supplied six-component field. Constructor and methods allocate approximately0.5GiB CPU and well under0.5GiB GPU memory on the bound problem; execution is single CPU thread with the explicit GPU acquisition kernel.

`solvers.reconstruct(data,maxiter=None,size=8,scale=.16)` constructs the model, invokes unchanged effective L-BFGS-B settings, and returns field(6,106,96), plus diagnostics containing model, coefficient array, objective/gradient-infinity evaluation history, iterations, success, message and final objective. None means6*number_of_basis_functions iterations as in the source. The canonical CLI and notebook use defaults; notebook-only convergence diagnostics are explicitly labeled. General SciPy optimization does not hide the acquisition or inverse gradient mathematics.

`visualization` builds and exports scientific figures without selecting a backend. The active notebook reconstructs fresh data, runs a fresh shortened convergence comparison, evaluates actual truth and original/corrected references, and exports private figures and numeric sources. Hidden source references supply comparisons only and never substitute for active reconstruction.

`cpu_diagnostic.joseph_matrix(shape,angles,rays,texture_quantization=True)` is a pure NumPy/SciPy CPU forward operator used for independent ray-sum and adjoint checks and the numerical error comparison. It returns a float32 CSR matrix with rows(event,detector) and columns(row,column). It preserves the geometric equations and texture-fraction quantization, but floating-point sequence differences make it unsuitable as a standard-backend replacement. The active notebook computes its probe projections freshly and compares them with the frozen source GPU projections. Its previously captured full inverse is separately labeled historical maintainer diagnostic.

`evaluation/judge.py` loads no solver module, resolves its own hidden truth and metric boundaries relative to its file, validates the one output array, evaluates all six full fields, writes strict JSON and returns0/1/2 for pass/valid below-boundary/error. Tests run source stage/complete parity, analytic physics, bound Jacobian/gradient, output/metric contracts, and temporary DLL lifecycle checks. Frozen fixtures are numeric source captures, with no upstream imports. The original environments and full upstream checkouts remain private outside the task.
