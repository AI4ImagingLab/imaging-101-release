# Shipped execution and interfaces

All paths below are task-relative. There are no upstream/domain-package imports or cross-task imports.

- preprocessing.load_observations(path) reads data/raw_data.npz with allow_pickle=False and returns a dictionary: spectra float64 (1,2,2,300,480,51), frequency_hz float32 (1,2,51), calibration_images float64 (1,2,300,480). Shapes, finite values, dtypes and increasing frequencies are validated. Values are copied; no second normalization is applied.
- preprocessing.normalize_and_bin(native,bin_factor=4) accepts float-convertible (configuration,window,native_row,native_column,frequency), normalizes each native spectrum by its maximum and averages disjoint spatial blocks. It is a fixture/review helper, not the primary input path.
- physics_model.fma(a,b,c) uses float64 multiplication/addition then casts to float32 if the combined dtype is float32, otherwise evaluates ordinary arithmetic. It approximates task-source contraction; it is not a general exact FMA emulator.
- physics_model.model_jac(x,p) takes GHz frequencies (F,) and parameters (N,6), returns predicted normalized fluorescence (N,F) and analytic Jacobian (N,F,6), using the parameter dtype. Parameter order is center GHz, width GHz, three contrasts, offset.
- physics_model.tree_sum(a) zero-pads a final axis of length 51 to 64 and performs the source float32 binary reduction; returns the remaining leading dimensions.
- physics_model.equations(x,p,data) takes frequencies (51,), parameters (N,6), observations (N,51); returns objective (N,), gradient (N,6), Gauss–Newton Hessian (N,6,6), in parameter dtype.
- physics_model.initial_guess(data,frequency) takes spectra (...,51) and GHz frequencies (51,), returns float32 (...,6) initial parameters. It uses source cumulative-sum initialization and does not enforce bounds itself.
- physics_model.physical_fields(parameters,height=300,width=480) accepts float32 (2,2,height*width,6), returns float64 (1,4,height,width), with quantity order and mixed units specified in README.
- solvers.gauss_jordan(a,b) accepts float32 (N,6,6) and (N,6), returns explicit pivoted solutions (N,6); works on a newly concatenated augmented array.
- solvers.fit(x,data,initial,steps=1000,dtype=np.float32,capture=None) returns fitted parameters (N,6), SSE (N,), and iteration counts (N,). The optional capture(step,parameter_copy) callback receives active iteration snapshots. It does not load/write files.
- solvers.reconstruct(observations,max_iterations=10000,chunk_size=2048) fits every spectrum from load_observations. Independent per-spectrum chunks preserve acquisition order. Returns dictionary reconstruction float64 (1,4,300,480), parameters float32 (2,2,144000,6), sse float32 (2,2,144000), iterations int32 of the same leading shape, and measured seconds. No reference assets are read.
- generate_data.perturb_spectra(data,sigma,seed) creates independent Gaussian additive fluorescence perturbations with a local generator; maintainer sensitivity only.
- visualization.review_figures(observations,fresh,default,qualified,upstream_default,sensitivity,export_dir=None) constructs six scientific figure groups. Optional export writes paired PNG/SVG/PDF and numeric source/provenance; notebook displays the returned figures.
- main.main() resolves paths from its own task root, loads public observations, calls reconstruct with the primary defaults and writes only reconstruction to output/reconstruction.npz. Run python -m src.main. Importing this module does not select or alter Matplotlib's backend.

The canonical notebook actively calls reconstruct twice for full-field 10000 and 1000 iteration caps. It computes selected-pixel noise controls with the same fit/model and calls the independent Judge on its fresh primary output. Frozen original results are loaded only for comparisons, never substituted as fresh predictions. It prints actual kernel executable, library versions and runtimes.

evaluation/judge.py is independent of src. evaluate(prediction,reference_dir=None) resolves its hidden assets from its own directory (the optional directory supports isolated contract tests), selects ground_truth.npz first if available, otherwise baseline_reference.npz, validates the complete numeric NPZ and returns a JSON-compatible report. The CLI preserves caller-relative prediction/report paths; native exit codes are 0 pass, 1 valid low score, 2 malformed input/evaluator/report-write error. No file writes occur until the CLI report operation.

Fixture consumers: test/comparing_test/test_parity.py uses upstream_stages.npz for independent 38-real-pixel initialization and six iteration-cap stages, plus the full reference for a complete fresh pipeline. test/unit_test/test_physics.py uses independent_physics.npz for source-vs-complex-step Jacobian checks and analytic Zeeman/normal-system cases. The preprocessing test uses native_preprocessing.npz for unchanged-source native normalization/binning. Judge tests exercise every required quantity, invalid data, reference priority, independently known metrics, foreign working directory and report failure. Reference-output files are consumed by the active notebook and labeled original results.


Additional operator fixture consumers: test/comparing_test/test_operators.py loads source_model.npz/source_lm.npz for304 independently captured native model/J/g/H/scaled-system steps. The fresh noise experiment uses sensitivity_experiment(observations,indices=None), returning indices, four sigmas, fit parameters, four fields and RMSE; native12 fixed pixels, source10000cap. Judge RMSE uses mathematically equivalent scaled sum-of-squares to prevent overflow.
