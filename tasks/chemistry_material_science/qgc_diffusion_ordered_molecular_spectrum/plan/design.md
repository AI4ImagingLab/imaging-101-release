# Interfaces and execution

`python -m src.main` -> preprocessing.prepare(data/raw_data.npz) -> solvers.reconstruct(prepared,nbiter=200000,lamda=.01,precision=1e-12) -> output/reconstruction.npz. Runtime reads public observations only. Input spectra(1,16384,30),b_values(1,30),chemical_shift(1,16384) are float64; support_indices(1,2277) int64. prepare returns a dictionary of unbatched spectra, support, list of29 integer-index groups, observations(29,30), public SI b, ppm, eta(29), noise scalar. All amplitudes dimensionless, b s/m², ppm chemical shift.

physics_model.DIFFUSION is256 SI diffusion nodes; kernel(b_values,diffusion=DIFFUSION) returns(30,256) float64 attenuation matrix. forward(amplitudes,b_values) maps (...,256) to (...,30). Internal dimensionless scaling preserves the author multiplication convention.

solvers.approximate_lambert_exponential(values) is elementwise on any numeric array. entropy_l1_prox(values,lamda=.01,a=1.) returns the same shape. ball_projection(values,observations,eta) acts on independent columns of shape(M,R). ppxa(K,inverse,observations,eta,nbiter=200000,lamda=.01,precision=1e-12) accepts observations(R,M),eta(R), returns amplitudes(R,N) and per-band last iteration indices(R). reconstruct returns a dictionary with reconstruction(1,29,256) and diagnostic dictionary containing last_iteration,kernel,eta,residual. It has no disk side effects. CLI saves output and prints timing; notebook separately reconstructs and saves its fresh result in identified reference_outputs for review.

Judge is independent, implements its own public band integration/noise/physical forward calculation, and loads only prediction, public data, declared metrics and evaluator reference. It validates float64 shape/finiteness before metrics, uses actual truth first if present, otherwise the honest standard-method reference. Every band is scored via worst band relativeL2/mincosine/maxballratio/maxnegativity. Its output obeys native0/1/2 and JSON contract.

Notebook reconstructs all29 bands actively, compares original measured outputs, shows complete spectral/diffusion maps, individual attenuation curves and residual radii, and actively compares sparsity/entropy weights on one representative measured band. The source paper's regularizer-family comparison is retained at the selected experimental condition; it is not represented as the original figures or a neural-network reproduction. visualization imports pyplot only, never changes backend. Tests use numeric frozen original arrays with no original domain imports. Source and original runtime remain in maintainer archive. No synthetic generation module is needed.
