# Shipped implementation and execution

Evaluation revision 2 adds `evaluation/gradient_contract.py`. Its `derived_gradients(raw_path)` returns horizontal and vertical two-component wrapped gradient observations and their scalar edge weights, computed independently from the public image and reciprocal carriers. `residual_metrics(displacement_nm, raw_path)` returns `stationarity_max` and `mean_displacement_nm`. The standalone Judge loads this local evaluator module by absolute file path, validates the declared NPZ schema, and evaluates these two metrics without loading upstream or cleaned solver functions or hidden reconstruction arrays. CLI and report locations remain unchanged. Historical solver/reference agreement below concerns reproduction validation, not the current acceptance semantics.

`python -m src.main` is the standard entry point. `run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz')` actively reconstructs public observations, creates the output parent, writes a compressed NPZ with reconstruction float64(1,2,512,512)nm and returns this same array. It does not load hidden references or import the original package.

`preprocessing.load_data(path)` uses allow_pickle=False and returns batch-unwrapped image uint16(512,512)counts and reference_vectors float64(3,2)cycles/pixel. `prepare(image)` returns float64 mean-centred counts of the same shape. Constant NM_PER_PIXEL=.88 is calibration, not a tuned solver parameter.

`physics_model.wrap_phase(a)` wraps to[-pi,pi). `lockin(image,k,sigma)` returns complex128(512,512) spatial demodulation. `adaptive_lockin(image,k,sigma,kw,kstep)` returns(best complex response,selected carriers), shapes(512,512) and(2,512,512); carrier components follow row,column. `weighted_projection(phase_differences,kvecs,weights)` returns float64(2,H,W) pixel-displacement differences, with H/W possibly one less along a derivative direction. It checks positive local normal-equation determinant.

`solvers.divergence(dx,dy)` pads edge fluxes with zero and returns their image-sized divergence. `integrate_gradient(dx,dy,weight,kmax=10)` accepts column differences(N,N-1), row differences(N-1,N) and a square weight(N,N); it returns float64(N,N) integrated displacement and raises for rectangles. `reconstruct(data,sigma=None,adaptive=True,kmax=10)` uses source-prescribed default window33pixels and returns float64(2,512,512) signed inverse displacement in nm. adaptive=False is the notebook fixed-carrier comparison; alternate sigma values are scale studies. These helpers have no filesystem side effects.

`visualization.agreement(x,r)` returns cosine NCC and dynamic-range NRMSE independently checked against hand-computable Judge cases. `panel(ax,a,title,cmap='RdBu_r',vmin=None,vmax=None)` displays calibrated nm axes. `acquisition_figure(data)`, `comparison_figure(fresh,reference)` and `sensitivity_figure(fields,reference)` return figures only. Shared signed displacement limits compare both components and methods; numerical differences have separate explicitly labelled scales. No module selects a Matplotlib backend.

The active notebook calls run, compares to `notebooks/reference_outputs/upstream.npz`, computes all three alternate fields and records fresh_measurements.npz. Its reconstruction, fixed, small_window, large_window and runtime_seconds arrays are consumed by private batch figure exports and source-data tracing. Reference filenames/keys remain hidden from solvers. No new synthetic observations are bundled, so generate_data.py is omitted.

The standalone Judge imports only standard library and NumPy. `evaluate(prediction,asset_dir=ASSET_DIR)` returns(report,code) with explicit shape/dtype/finite checks and truth priority. No solver imports, sample cropping, magnitude conversion or implicit registration is allowed. Its asset directory defaults to the judge file's directory; CLI paths remain relative to caller cwd. Successful quality comparison returns0; valid poor prediction1; malformed input, unavailable assets or report-write failure2.

Fixture upstream.npz is a frozen independent run: input_image/reference vectors, output_u in source pixel units, output_lockin and selected reciprocal-vector maps. Comparing tests consume these arrays without original-code imports. Unit tests check known metrics and Judge failures, and physics tests check analytic carrier response, weighted linear inversion, affine-gradient integration, gauge and unchanged metadata. Square-grid restriction explicitly scopes the documented upstream Poisson-denominator discrepancy.
