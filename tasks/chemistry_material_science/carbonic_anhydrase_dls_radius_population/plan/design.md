# Shipped interfaces and data flow

preprocessing.load_data(path) reads public NPZ without pickle, returns time_s(373,), g2(373,2), radius_nm(200,), native_lag_us(373,). It removes only first native lag and converts microseconds to seconds. transform(t,g,lag_us) returns beta(2,), field(373,2) with internal NaN only beyond invalid correlation, and valid(2,) prefix counts. No library backend is changed.

physics_model.relaxation_times(radius_nm)->s(200,) uses explicit physical constants. kernel(time_s,relaxation_s)->K(373,200). curvature_matrix(n)->M(n,n) zero boundary rows/interior second difference. predict(weights,t,s,beta)->G(373,2), with weights(2,200). objective(weights,k,g1,alpha=.1) returns one replicate's scalar augmented quadratic objective.

solvers.solve(time_s,g2,relaxation_s,beta,field,valid,alpha=.1) takes all prepared arrays; g2 is included in this common comparison signature but only field,beta,valid enter the fit. alpha can be a scalar or two values. Returns weights(2,200), predictions(373,2), augmented residual norms(2,), curvature norms(2,). No file I/O. compare_lcurve(t,g,s,beta,field,valid) returns alpha grid(80,), residual/penalty arrays(80,2), selected alpha(2,), fitted populations(2,200), predictions(373,2). lcurve_corner(residual,penalty) returns an integer selected index.

main.run(root=None) resolves root from source if omitted; reads data/raw_data.npz, calls local preparation/physics/solve and writes output/reconstruction.npz. It returns the full11-item tuple (t,g,r,s,beta,field,valid,p,pred,res,pen) used by the notebook. Standard entry point python -m src.main writes batch-first reconstruction(1,2,200) and correlation(1,2,373). visualization.comparison(t,g,r,p,pred,upstream,alphas,res,pen,selected,adaptive) returns a2x2 Figure with data/fit, population comparisons, full L-curve and residuals, no side effects.

Notebook actively calls main.run and the full local L-curve comparison, reads separately labeled original fixed/L-curve measurements, calls an independently imported standalone Judge and shows comparison tables/figures. Judge evaluate(prediction,root=None)->(report,code); root is an evaluator-test hook. Normal evaluator assets resolve from __file__, while CLI prediction/report paths resolve relative to caller. report fields status,passed,metrics,thresholds,errors and exits0/1/2 meet the standalone contract. Evaluation never imports solver code. Invalid input/asset errors have empty metrics; report-write failures return2.

No data are synthetically generated. Source archive/capture environments are private and never imported by task runtime, tests, notebook or evaluator. Complete frozen upstream stage evidence is in test/fixtures/upstream.npz; upstream_lcurve.npz is consumed by the active notebook. LICENSE/NOTICE preserve original redistribution terms. Both plans were reviewed against final actual signatures, factors, units, array order and execution roles.

The early gate is applied to original lag_us<5.0 before any seconds conversion; source exact5microseconds is excluded. Positive prefix stops at first native G<1.0, so exact1.0 is retained. No reconstruction/threshold change.
