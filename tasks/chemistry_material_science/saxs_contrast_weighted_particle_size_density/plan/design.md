# Shipped execution flow

All modules are local and independent of other tasks. Runtime dependencies are NumPy, SciPy for notebook independent special-function/integral checks, and Matplotlib for notebook figures. The solver imports NumPy only; no HDF5 reader or domain package is needed. The public HDF5 source was converted once to NPZ without changing numeric values. No generator exists because the original author observations are reused.

`preprocessing.load_observations(path)` opens NPZ with allow_pickle=False and returns three float64 vectors(q,I,error), each length500, from batch0. Units are angstrom^-1,cm^-1,cm^-1. `estimate_background(q,intensity,q_min=0.5,q_max=1.0)` returns a Python float B in cm^-1 using the inclusive observed high-q range. `radius_grid(n_bins=500)` returns float64 increasing angstrom centers over10..30000. `bin_widths(radius)` returns the source full-endpoint widths, with singleton width1 for independent unit cases.

`physics_model.sphere_amplitude(qr)` returns a float64 array of the input shape, with the small-argument branch defined in approach.md. `build_kernel(q,radius)` returns shape(observation,radius) float64 with units cm^-1 per normalized contrast-weighted bin mass. `forward(density,background,q,radius,widths)` returns the full fitted intensity vector. `weighted_objective(bin_mass,kernel,target,error)` returns the unnormalized weighted residual sum of squares with target=I-B.

`solvers.interior_point_gradient(kernel,target,error,max_iter=1000,approach=0.95)` implements every explicit preconditioned gradient, positivity-limited exact line-search and discrepancy step. It returns dict keys bin_mass(float64 n-vector),iterations(int),history(float64 vector of actually computed postupdate chi² values). `reconstruct(q,intensity,error,n_bins=500,background=None,max_iter=1000)` estimates B unless an explicit notebook comparison background is supplied, forms the full matrix, solves, and returns those entries plus reconstruction(density n-vector),background(float),radius(n-vector),widths(n-vector),kernel(500,n),model(500),residual(500 standardized). All observations are used for every resolution. The optional resolution/background parameters exist for active ablations; the standard path uses their defaults.

`main.run(data_path=None,output_path=None)` resolves default paths relative to the task directory, reads public observations and calls the default full reconstruction. It creates output parent directories and saves only reconstruction(1,500) and background(1,1), float64, in output/reconstruction.npz. It returns the reconstruction dictionary for the active notebook. `python -m src.main` prints the actual iteration count and chi². Importing main changes no Matplotlib backend.

`visualization.density_metrics(estimate,reference)` returns dict ncc/nrmse using the declared definitions. `size_integrals(density,radius,widths)` returns bin_sum_contrast,bin_weighted_rms_radius and source_trapezoid_contrast; the two integral conventions are explicitly distinguished. It does not label an uncalibrated contrast integral volume fraction.

The notebook locates the task, imports cleaned modules, actively calls main.run, loads independently frozen upstream_standard.npz for labeled comparisons, computes actual ablations/perturbations, writes fresh_standard.npz with density/background as a separately identified notebook measurement, and independently scores the saved submission. It imports no private archive or domain solver. Its saved figures are computed from these fits.

The standalone evaluation/judge.py loads references relative to its own file, with actual ground_truth.npz precedence if independently supplied in a future evaluator; this bound task has only baseline_reference.npz. It imports no src code. It validates exact shape,float64,finite,nonnegative arrays and computes all four metrics, including a separately implemented full forward calculation using public observations. Its CLI accepts --prediction and --report, resolves those paths relative to caller, writes strict UTF8 JSON and returns0(pass),1(valid poor output),2(malformed/evaluator/report errors).

test/fixtures/upstream_numeric.npz is the frozen unmodified upstream execution, consumed by stage/full parity tests. evaluation/baseline_reference.npz is consumed by the Judge. notebooks/reference_outputs/upstream_standard.npz and fresh_standard.npz are consumed or produced by the active notebook, respectively. Original HDF5, checkout, archives, capture scripts and all logs remain in the private maintainer archive indexed by test/validation.md.
