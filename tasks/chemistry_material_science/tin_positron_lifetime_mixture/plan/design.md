# Shipped interfaces

`python -m src.main` calls `run(root=None)` and resolves an omitted root from its own module. It loads all6native conditions, reconstructs each completely and creates output/reconstruction.npz with all7declared arrays. Returns `(counts,prompt,binned,parameters_native,predicted,histories)`; shapes6by10000int64,10000int64,6by1000float64,6by13float64,6by1000float64,and6lists of(objective,nfev). No synthetic generator is shipped.

`preprocessing.load_data(path)` loads NPZ allow_pickle=False, validates raw axes/count nonnegativity, strips batch and performs exact integer10channel sums before float64 conversion. `prepare(binned)` returns area(6,)and initial background(6,), using inclusive33..948and749..948ranges respectively, with no file side effects.

`physics_model.prediction_native(parameters,area)` evaluates the explicit bin integral for a13parameter native-channel vector and returns1000float64counts. Order is(tau1,I1,tau2,I2,tau3,I3,FWHM1,mean1,c1,FWHM2,mean2,c2,B). All time-like entries are in50psunits. `residual(parameters,observed,area)` returns915float64values:914weighted counts plus the soft normalization residual. `package(parameters,predicted)` sorts physical component labels and converts time-like parameters to ps, returning the7batch-first arrays declared publicly. It never reads references.

`solvers.reconstruct(observed)` consumes6by1000float64binned counts, calls prepare and the local residual through general Levenberg-Marquardt, and returns the final parameter matrix, full prediction and actual histories. Initialization/stopping/budget are in approach.md. It validates converged finite physical parameters and has no file side effects.

`visualization.spectra_figure(observed,predicted,source)` returns6log-count panels comparing observations, independently executed source and fresh curves. `parameter_figure(parameters,source)` returns condition-dependent lifetimes,intensities,response widths/weights/shifts and background. `residual_figure(observed,predicted)` returns all selected weighted residual panels. `prompt_figure(prompt,parameters)` shows the independent prompt response and sample-estimated Gaussian response shapes with explicitly diagnostic peak alignment. Modules do not set the Matplotlib backend.

`evaluation.judge.read(path)` independently enforces every key, batch-first shape,float64dtype,finite values,physical sign and declared component ordering. `model(out,area)` uses a separately written normal-CDF/log-CDF formula and returns6by1000predictions from physical ps outputs. `evaluate(prediction,root=None)` loads independent observations/reference/config relative to its own task root, scores sixobjectives and sixfull-forward errors, optionally scores actual truth preferentially, and returns(report,exitcode). No solver imports are present. The CLI honors caller-relative --prediction/--report, creates report parents, returns0/1/2and writes finite UTF8JSON. Missing/malformed assets, invalid submissions, nonfinite computations or report-write failures are errors, not silently repaired.

The active6chapter notebook calls the entire run path, then independent Judge, using frozen source arrays only for labeled comparisons. All diagnostic figures consume fresh results. Public input is README/raw/env only. Fixture consumers are parity tests; original C++source,MPFIT,PDF/XML,data zip and logs remain private and are never imported by task modules/tests/notebook.
