# Implemented reconstruction mathematics

The existing aligned CC0 HAADF tilt series contains 76 frames. Remove blank/backlash frames at original zero-based indices 49 and 50. Retain rows/columns 2:1154 and compute each 9 by 9 arithmetic detector-block mean in float64. This is a fixed observation-pixel integration operator; both original oracle and local reconstruction receive exactly this same 74 by 128 by 128 array. No simulated observations or estimated target-derived calibration are introduced. Angles are -75,-73,...,75 degrees, omitting 23 and 25. Source pixels are nominally 0.71 nm, hence nominal 6.39 nm output pitch.

For each horizontal x slice, q is a row-major vector on a 128 by 128 cross-section with column y increasing to the right and row index increasing opposite physical depth. Square pixel edges are integers from -64 to 64. Ray r has offset r-63.5, normal (cos a,sin a), and direction (-sin a,cos a), with angle a in radians after conversion from degrees. A has 74 times 128 rows and 128 squared columns. Its nonzero entry is the distance traversed inside a pixel in voxel units, computed by intersecting each ray with grid lines, retaining segments whose midpoint lies inside the square. Matrix entries are float32; the exact upstream convention sets values with absolute size below 1e-10 to zero. Matrix dimensions, ordering, intersections and values have independent frozen-oracle and analytic tests.

The objective for each slice is one half of the unnormalised squared L2 residual, f(q)=||Aq-b||_2^2/2. Its gradient is A^T(Aq-b). There is no additional regularizer or total variation term. Starting at q=0, perform exactly 100 Landweber steps q <- q+0.0001 A^T(b-Aq), then clip the entire stored volume to nonnegative values after each outer iteration. No line search, adaptive stopping, or reweighting is used. The step is the selected original Tomviz Landweber-SIRT configuration. Calling the selected method SIRT does not imply row/column normalization; the source offers alternatives which are not selected here.

Preserve the original mixed precision: the volume is float32 in Fortran storage order; observations are float64 and the matrix float32. The shared work vector initially is float32, becomes float64 after its first gradient update, and retains that dtype across slices and iterations. Assignment into the volume rounds to float32. This source convention is reproduced rather than silently changing the arithmetic. If a caller supplies an exact zero angle, the upstream adjustment adds 0.001 degrees to all angles; bound angles are odd and never exercise that branch. Negative observations would be shifted by their global minimum as upstream; bound observations require no shift.

Monitoring, every ten iterations, is ||Av-b||_2/||b||_2 across all slices. Monitoring does not modify the update. The output is float32 (1,x,z,y), in arbitrary detector-count response per voxel-length. It is not an absolute composition or mass-density measurement. The hidden baseline is the unmodified modern Tomviz reconstruction, not actual truth and not a claim that this repository version was used in the 2016 dataset paper.

Judge computes full-volume cosine NCC without mean subtraction and dynamic-range NRMSE, without any fitted scale or alignment. It independently builds a ray-pixel segment matrix and checks all observations. Original rerun stability fixes numerical reference thresholds; the separate projection-residual boundary is 1.01 times the upstream residual, fixed before evaluating the local result. Independent physics tests cover constant path lengths, segment-intersection agreement, adjoint identity, objective directional derivative, and positivity with decreasing residual. Reference agreement does not establish atomic resolution or compensate for the missing wedge.
