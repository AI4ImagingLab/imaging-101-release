# Shipped interfaces and execution

`src.preprocessing.load_data(path)` loads only the seven allowlisted arrays with allow_pickle=False; returns a dictionary of copied float arrays, each(1,N,2). It checks exact lengths, finite values and increasing energy. `prepare(raw)` returns energy(160,), observation(160,), standards(6,160), float64 in eV/dimensionless units, selecting inclusive floor indices and linear interpolation. No side effects.

`src.physics_model.forward(weights,standards)` accepts a six-vector and(6,N) standards, returns predicted dimensionless(N,) using original sequential arithmetic. `bounded_weights(internal,model)` accepts k internal sine coordinates and a tuple of k+1 zero-based standard indices; returns six physical weights, with last expression clipped. `residual(internal,model,observation,standards,scale=.001)` returns dimensionless standardized residual. `affine_jacobian(model,standards,scale=.001)` returns(N,k) derivative in physical free weights in the interior simplex; used in physics tests.

`src.solvers.fit_model(observation,standards,model,initial=None)` returns weights(6,), fit(N,), statistics(6,) ordered chi-square, reduced chi-square, AIC, BIC, number of free parameters, MINPACK evaluations. Optional initial supplies physical free weights for diagnostics; production defaults reproduce original example. `solve(observation,standards)` executes eleven MODELS in declared order and returns dictionary weights(11,6), fits(11,N), statistics(11,6), best scalar index. It raises on unsuccessful MINPACK termination.

`src.main.reconstruct(path)` calls load_data, prepare, solve and returns energy,observation,standards,result. `main()` resolves task root from its own file, reconstructs raw_data.npz and writes output/reconstruction.npz with selected weights(1,6), reconstruction(1,160). `python -m src.main` is the only standard solver entry point. Import has no plotting or backend side effect.

`src.visualization.comparisons(energy,observation,standards,result,upstream)` returns three figures: measured library, measured/fitted spectra and residuals, all-model paired statistics/weights. `ambiguity(energy,observation,standards,result)` returns two figures for singular values/correlations and actively recomputed calibration sensitivity. The notebook calls these after fresh reconstruct; supplementary affine all-six fit is labeled. No plot replaces a missing result with an archived result. Functions import Matplotlib pyplot without forcing a backend.

Standalone `evaluation/judge.py` imports only standard library and NumPy. `load(path)` validates both required prediction or reference arrays. `evaluate(prediction)` reads reference relative to its file (actual ground truth would take precedence), validates metric boundaries, and independently interpolates public calibration for forward/measurement consistency. It returns the full report dictionary. `main(argv=None)` parses required prediction/report paths relative to caller, writes strict UTF8 JSON, returns0/1/2 for pass/fail/error; report failure returns2 with stderr diagnostic.

test/fixtures/native.npz stores native preprocessing, initial weights and eleven complete fitted outcomes, consumed by comparing tests. notebooks/reference_outputs/upstream_comparisons.npz stores explicitly identified native results consumed by plots. baseline_reference.npz is consumed only by the independent Judge. No file imports upstream code. All supplementary notebook calculations use shipped local functions and general numerical primitives. Six narrative sections run the entire benchmark and full comparisons; canonical notebook retains executed outputs.
