# Shipped execution flow

`python -m src.main` loads data/raw_data.npz relative to caller task directory, preprocesses observations, runs a fresh inversion, and writes output/reconstruction.npz. `main()` returns (result, info), prints objective, MINPACK termination and elapsed seconds, and creates output/ if needed. It does not set or change the Matplotlib backend and writes no diagnostic images into output/.

`preprocessing.load_data(path=Path('data/raw_data.npz')) -> dict` loads NPZ with allow_pickle=False and removes only the declared leading batch dimension. It returns concentration_repeats (3,30,6) and charge_repeats (3,3000,2), float64. `compensated_mean(values) -> ndarray` computes the original Kahan mean over first axis. `preprocess(data) -> (c,q,initial)` returns averaged c(30,6), q(3000,2), initial(15), all float64. Times remain in first columns, hours; other c columns are micromol/L and q columns C. Functions have no writes.

`physics_model.derivatives(c,time,rates) -> (15,)` evaluates explicit mass-action rates with c(15) micromol/L and rates(11) h^-1. `concentrations(time,initial,rates) -> (len(time),15)` runs original-default odeint. Time is ascending hours and starts at the initial condition. `charge(c) -> (len(c),)` converts concentrations to C, using corrected electron weights and subtracting first-row charge, retaining per-column summation order without mutating c. Constants RATE_NAMES, SPECIES, FARADAY and VOLUME_L define ordering, charge conversion and units.

`solvers.relative_residual(observed,predicted)` returns the elementwise symmetric relative residual with zero at (0,0). `residual(rates,c,q,initial)` returns (3150,) for the full fit. The optional q=None helper returns 150 chemical residuals for the explicitly labeled notebook ablation. `reconstruct(c,q,initial) -> (result,info)` returns result keys rates(1,11), reconstruction(1,150,15), charge(1,150), float64; info contains nfev, status, message and objective. It always runs an inversion, including for q=None. It reads no hidden reference and writes nothing. No upstream or other task package is imported.

`visualization.plot_observations(c,q,initial,result,upstream,raw)`, `plot_hidden_and_residuals(c,q,initial,result)`, and `plot_ablation(result,chemical_only)` return Matplotlib figures without changing backend or writing files. The notebook owns display and PNG export to notebooks/reference_outputs; these plots are maintainer review artifacts. In particular the concentration-only ablation is freshly fitted with q=None, and its predicted electrical consequence is not a zero substitute or cached fit.

The notebook separately loads upstream_measurements.npz for marked original-run comparisons and frozen upstream profile measurements for identifiability. It actively calls cleaned reconstruction for the standard path and chemical-only ablation. It independently scores the fresh result with evaluation/judge.py. It never imports upstream sources. Figures show all five tracked species and electrical data, both hidden-pool groups, physical-unit residuals, paired rate bars and electrical ablation predictions.

The standalone Judge uses only stdlib and NumPy, resolves its own configuration/reference paths, strictly loads all three arrays with required float64 shapes and finite values, and evaluates all 27 metrics. Actual ground_truth.npz takes precedence when available; this task has no physical truth and uses baseline_reference.npz. It reports pass/fail/error with native exit 0/1/2, creates report parents, and handles malformed inputs and report-write failures. It never imports solver code.

Tests under test/unit_test cover analytic physics, independently known metric cases, and native Judge contracts including foreign CWD and evaluator/write failures. test/comparing_test uses upstream frozen fixtures for preprocessing/forward/residual/full fit parity. No test imports the upstream library. test/validation.md is the provenance and gate ledger; archive paths point outside the task.

The six independent starts in reconstruct preserve source LM updates and select minimum objective. ELECTRON_WEIGHTS is the explicit corrected fifteen-state electron vector; its unknown-layer increments are assumptions. Historical index-charge runtime is archived and is not the shipped method.
