# Shipped interfaces and caller flow

The standard entry point is `python -m src.main`. It reads only public NPZ observations/theoretical path tables, actively reconstructs, creates `output/`, writes the declared `reconstruction.npz` and prints runtime, evaluation count, solver message and R factor as JSON. No import changes Matplotlib's backend. There are no downloads, model checkpoints, cross-task imports or upstream/domain dependencies in the cleaned runtime.

`preprocessing.load_observations(path=ROOT/'data/raw_data.npz')` returns a dictionary with all seven README keys, each a copied float64 one dimensional array with the batch dimension explicitly removed. It loads allow_pickle=False, validates finite/dtype/dimensions and matching observation/table shapes, and increasing experimental k. Measurements are500 samples, theoretical tables59 samples. No raw coordinate or table entry is recomputed or rounded.

`physics_model.model_grid(data)` returns500 uniformly spaced model k samples at0.05 Angstrom^-1. `scattering_splines(data)` returns four zero-smoothing cubic UnivariateSpline objects in phase/amplitude/real momentum/mean-free-path order. They are generic interpolation primitives over the public theoretical table, not domain-library operators. `forward(p,k,splines)` accepts `(4,)` real parameters, a real `(N,)` k axis and those four splines; it returns dimensionless real float64 chi `(N,)` through explicit complex arithmetic. `kaiser_window()` returns a float64 `(2048,)` full zero-padded-axis taper. `transform(chi)` accepts a real evenly sampled spectrum `(N,)` and returns complex128 `(1024,)` Fourier samples with units Angstrom^-3. `selected_transform(chi)` returns the fixed52 complex first-shell samples. `epsilon_r()` returns the scalar fit normalization. `residuals(p,k,chi,splines)` returns104 real interleaved transformed residual components. These functions do not perform file I/O.

`physics_model.pair_density(p,r=R)` returns float64 density on the chosen separation axis, default `(801,)`, in neighbors/Angstrom. It rejects nonpositive variance and does not silently clip it. `rfactor(p,k,chi,splines)` computes the squared complex first-shell relative residual as a Python float. This scalar is the observation consistency criterion; it is not misnamed NRMSE or a truth score. Constants, parameter units and Fourier conventions are given in approach.md.

`solvers.reconstruct(data,initial=INITIAL)` linearly resamples the data to the model grid, constructs the public table splines and performs MINPACK LM with fixed controls. It returns `(result,info)`: result keys `reconstruction` `(1,801)` and `parameters` `(1,4)` are float64; info contains seconds, nfev, success, MINPACK message and R factor. A nonfinite solution, unsuccessful MINPACK status or nonpositive final variance raises an error. No cached arrays or hidden reference paths enter the solver. `main.main()` saves the result and returns the same tuple.

`visualization.comparisons(data,fresh,upstream)` returns a three-panel Matplotlib figure. It contrasts real full measured chi against independently reproduced upstream and freshly computed local first-shell models, shows measured/initial/upstream/fresh Fourier magnitudes with the fixed fit interval, and shows both inferred Gaussian densities. High-shell residual features remain visible. It neither fills uncomputed methods nor mistakes phase-uncorrected Fourier radii for physical bond distances. Scalar metrics are computed by the same explicitly defined physics helpers and independently checked Judge, not hidden within plotting code.

`evaluation/judge.py` is standalone: `--prediction` and `--report` paths resolve from the caller, references/metrics/public calibration resolve relative to the evaluator file. It never imports src or submitted code. Its explicit physical model and scoring functions are separately embedded in this file so observation consistency does not execute the submission. `evaluate(path)` returns `(report,code)`, with code0 pass,1 valid failing quality,2 malformed input or evaluator failures. Both arrays must have exact shapes and float64 dtype and finite real values; there is no reshape/crop/complex magnitude conversion. Reference shape/dtype/finiteness and nondegenerate density and finite positive metric boundaries are checked too. Invalid reports have empty metrics and descriptive errors. `main()` creates the report parent, writes strict UTF-8 JSON and returns2 with stderr on report-write failure.

The notebook actively calls `reconstruct(load_observations())` on all bound observations, saves and judges that newly computed output, and plots all comparisons and a parameter table. `notebooks/reference_outputs/upstream.npz` contains oracle reconstruction/parameters/prediction/complex transform, while `cleaned.npz` separately identifies a fresh command-line run. Neither is substituted for the notebook's live calculation. Test fixtures are independent frozen oracle arrays consumed by stage parity tests. Unit tests cover deterministic known Fourier sign/scale, Gaussian moments/coordination, metric known cases, strict Judge malformed/poor outputs/evaluator failures, cwd/report-write handling and backend import behavior. Private capture/build scripts, source archives, original logs and review images remain externally archived and are indexed in validation.md. There is no generate_data.py because existing published reduced observations are reused.

The final evaluator explicitly gives the exact ground_truth.npz asset precedence when present; otherwise it loads baseline_reference.npz. Malformed existing truth is an evaluator error, never a reason to fall back to a baseline. This task ships only the validated standard-method baseline.
