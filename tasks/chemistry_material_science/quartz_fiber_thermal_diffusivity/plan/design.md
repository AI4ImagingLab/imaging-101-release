# Shipped interfaces and flow

`python -m src.main` calls `run(input_path='data/raw_data.npz', output_path='output/reconstruction.npz')`. It loads observations, reconstructs the complete two-frequency benchmark, creates the output parent, writes the three specified arrays, and returns their dictionary. No backend is changed on import.

`preprocessing.load_data(path)` validates float64 shape(1,2,164,1280), finiteness and returns unbatched amplitude(mK) and phase(degrees). `native_to_vertical(amplitude,phase)` returns two(1280,164) arrays, with amplitude clipping and phase conversion. `linear_fit(x,y)` returns `(coefficients(2), slope_stderr)` after finite-pair filtering. `estimate_angle(vertical_amplitude)` returns a degree scalar using the fixed observation ROI. `excitation_center(image,npoints=100)` returns integer(x,y). `orient_and_crop(amplitude,phase,angle)` returns cropped oriented images(1280,41) and integer center. `centerline_profiles(amplitude,phase,center,max_distance=.6)` returns distance(L) in mm and profiles(2,L,2), branch then distance then observable, with documented NaN padding.

`physics_model.thermal_profile(distance,diffusivity,frequency,loss_rate=0.,amplitude=1.,phase=0.)` computes complex temperature for mm,mm²/s,Hz,s⁻¹,mK,rad inputs. It is an independent physics-test helper. `diffusivity_from_slopes(amplitude_slope,phase_slope,frequency)` broadcasts arrays and returns mm²/s. `fit_forward(distance,coefficients)` evaluates slope/intercept lines with output leading coefficient axes followed by distance; used in tests, with equivalent explicit evaluation in the independent Judge.

`solvers.reconstruct(amplitude,phase,fit_window=(.2,.6),correct_angle=True)` returns `(submission,rows)`. Submission keys and shapes match README. Two diagnostic dictionaries contain amplitude,phase,angle,center,distance,profiles,fit_indices,coefficients,slope_stderr,diffusivity. They are fresh calculated arrays, not reference loads. The optional parameters support notebook sensitivity comparisons.

`visualization.relative_error(estimate,reference)` returns maximum componentwise relative difference, rejecting zero references. `profile_figure(rows)` returns a four-axis Matplotlib figure with full measured profiles and fitted segments; caller owns backend, display and saving.

`evaluation/judge.py` is standalone and imports no solver. `evaluate(prediction,asset_dir=None)` validates required float32/float64 arrays, references and thresholds, computes four scalar metrics and returns the report contract. A ground_truth.npz, if present, takes precedence for quantity comparisons; this task supplies only baseline_reference.npz. Fixed observation profiles are always read from baseline_reference.npz independently of the quantity-reference choice. `score(pred,ref,x,observed)` contains independent arithmetic. CLI handles UTF8 report IO and exit0/1/2. It uses fixed profiles extracted from the same public observations by the original implementation, with no extra measurement or hidden truth. It resolves assets relative to its own file, not current working directory.

Tests consume frozen original stages from `test/fixtures/upstream_stages.npz`; the active notebook loads only original output measurements for comparisons, reconstructs public observations using local modules, evaluates fresh results and actively computes every supplementary estimator. No source checkout or upstream package is imported by any task file.
