## Independent investigation of the inherited size correction (parent review)

The selected original code computes R²=sum[J(SW+1/6)]/M over the square ROI, with M=sum(JW). This was preserved, not silently repaired. The Crocker/Weeks author explanation at https://faculty.college.emory.edu/sites/weeks/idl/radius.html derives a 1/6 pixel² contribution from each included unit-square pixel's area moment. For a strictly masked aperture this gives Rmasked²=sum(JSW)/M+1/6. It does not provide a physical justification for an additional contribution from excluded pixels. The current original sdt implementation's unmasked additive term is therefore documented as an inherited implementation convention, not claimed as an exact physical radius of gyration. The Kilfoil author's old tools page was unavailable during this investigation; no historical theoretical justification for the outside-circle term was verified.

An independent private calculation reconstructs shifted ROIs from frozen original filtered frames/candidates, checks all 77 sizes against original rows (absolute tolerance 1e-14), and verifies R²-Rmasked²=sum(J outside W)/(6M). Across all 77 real features, R-Rmasked has median 0.000022800714625015317 pixels and maximum 0.006548803248604296 pixels; maximum relative difference is 0.004170343709571573 (0.417034%). The squared-size extra term has mean 0.0014360440720675425 and maximum 0.020610411697537283 pixel². Outside-circle intensity divided by M has mean 0.008616264432405254 and maximum 0.1236624701852237. These measurements quantify the convention's effect on the actual bound observations and do not modify the selected method, references, solver outputs, thresholds or figures. README now explicitly defines this effective estimator and distinguishes it from the masked central-moment alternative.

Private evidence: investigate_pmhc_radius.py; pmhc_radius_convention_investigation.npz and .json; pmhc_weeks_radius_author_note.html (author explanation archived 2026-10-20). This investigation resolves the scientific labeling issue while retaining exact upstream parity; physical equivalence of the unmasked extra term is not asserted.
