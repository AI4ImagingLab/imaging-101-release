# Implemented fixed-spectrum amplitude inverse

Observed d(nu,y,x) is thermodynamic microkelvin at5frequencies22.8,33,40.7,60.8,93.5GHz. Spatial positions are fixed supplied Galactic longitude/latitude arrays. Native NSIDE512 NESTED sky samples are already1degree-smoothed; no FFT,boundary extension or spatial filter is applied locally. Sampling and mK-to-microkelvin conversion occurred privately before freezing the bound observation NPZ, with exact source indices/provenance recorded in validation.

The mixing matrix columns are CMB response1, synchrotron (nu/22.8)^beta_s*g(nu)/g(22.8), and modified-blackbody dust (nu/93.5)^(1+beta_d)*expm1(h*93.5GHz/(kTd))/expm1(h*nu/(kTd))*g(nu)/g(93.5). Here g=expm1(x)^2/(exp(x)*x²),x=h*nu/(kTcmb). SI h=6.62607015e-34J s,k=1.380649e-23J/K,Tcmb2.7255K. Default beta_s−3,beta_d1.54,Td20K. Foreground amplitudes are thermodynamic microkelvin at their own reference frequencies, rather than common-frequency radiances. No fitted offsets,gains,color corrections or hidden spectral maps are used. This is the explicitly selected monochromatic fixed-spectrum special case of the published parametric method; no claim of full free-spectral-parameter recovery is made.

For each sky position, minimize half the sum over five frequencies of (A m-d)². Channel weights are equal; spatially correlated smoothed noise is not represented as independent physical uncertainty. There is no regularizer,no positivity/no spectral bounds,initialization,iteration,line search or stopping heuristic. The exact linear inverse uses reduced SVD A=U diag(s)V^T,weights W=V diag(1/s)U^T, m=W d. The response covariance-like matrix V diag(1/s²)V^T is the unit-noise amplitude-response covariance, not an absolute instrument-noise posterior. Core task-specific spectral laws and inverse products are local NumPy operations. The underlying real-sky model is approximate; negative recovered dust values are retained, not clipped.

Notebook ablations solve the same inverse with the dust column removed, recompute leave-one-band-out inverses, and vary foreground spectral indices while holding the actual observations fixed. All compared maps are computed. Changing beta is a sensitivity study, not an alternative standard-method result or a truth estimate.

Each required map is independently scored with uncentered cosine similarity and RMS error normalized by that reference map's dynamic range. All6boundaries must pass; no shared dynamic range lets the strongest component dominate the weaker ones. No phase,translation,gain or mean alignment is allowed. Hidden reference is the independently reproduced author-method result; it is not physical sky truth.
