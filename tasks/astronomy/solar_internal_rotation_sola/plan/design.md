# Shipped modules and actual execution

Each task is independent. Cleaned runtime imports only standard library, NumPy, SciPy and Matplotlib. No Fortran binary, upstream Python/domain package, precomputed factorization, truth or reference array is imported by runtime. Raw NPZ supplies observations and source-independent calibrated factors/model quantities.

`preprocessing.load_data(path='data/raw_data.npz')` removes the singleton batch from each allowlisted array and checks full29617observation/5151mesh dimensions and finiteness. It returns a dictionary of native float64/int64 arrays. `quadrature(data)` returns weight, square-root weight and inverse-square-root vectors `(5151,)`, with inverse1at zero weight. `cubic_interpolate(x,y,value)` evaluates explicit native four-point Lagrange interpolation and returns a float. `radial_target_widths(data,width=.06,reference_radius=.7)` computes known-model sound speed and returns101dimensionless radial widths. Public model constants are cgs; no conversion to SI is performed in the original dimensionless sound-speed expression.

`physics_model.RotationOperator(data)` constructs293contiguous pseudo-Kronecker block descriptors, retains factor arrays and error whitening, and exposes nr=101,nt=51,nm=29617,np=5151. `forward(field,whiten=True)` accepts a5151-value or101×51nHz field and returns29617coefficients, whitened by default. `adjoint(coefficients,whiten=True)` returns the flattened algebraic transpose with matching whitening. In physical mode, forward returns nHz; in whitened mode it returns error-scaled coefficients. It materializes only small block contractions, never a full dense observation matrix.

`gaussian_targets(mesh,radial_widths,target_indices,angular_width=.1)` returns `(5151,n_targets)` normalized symmetric target columns; all arguments are known mesh/method parameters. `initial_target(mesh)` returns the fixed native unscaled starting Gaussian `(5151,)`. `ConstrainedOperator(operator)` computes Householder vector/tau/signed norm/alpha, feasible q0 and constraint kernel. `householder(x)` applies H to a29617-vector. `forward(x)` maps29616reduced coefficients to5151weighted kernel samples; `adjoint(x)` reverses that map. These implement the exact constrained acquisition, not an inverse-library wrapper.

`solvers.modified_gram_schmidt(basis,vector,count)` performs the original sequential BLAS MGS pass, returning the updated vector. `lanczos_bidiagonalize(operator,start,iterations=1000,progress=False)` returns U `(5151,1001)`, V `(29616,1000)`, diagonal/subdiagonal `(1000,)`. Arrays are float64, U/V column-contiguous. Progress prints100step milestones only when requested. Zero-norm breakdown raises ValueError; the native starting target is nonzero and no random fallback is needed for this case.

`solve_projected(alpha,beta,projected_targets,tradeoff=3.)` accepts projected target columns `(iterations+1,n_targets)` and returns regularized coefficient columns `(iterations,n_targets)` via an explicit tridiagonal system. `apply_measurements(operator,V,coefficients,splittings)` applies freshly calculated SOLA weights to a complete29617-vector and returns estimates for its target columns. This is used for conditional noise experiments, without recomputing a calibration-only basis or substituting a saved answer.

`invert_from_basis(data,operator,U,V,alpha,beta,tradeoff=3.,width=.06,angular_width=.1,target_batch=128,kernel_indices=None)` evaluates every5151target, solves all projected systems, applies the actual observation vector and returns `(output,diagnostics)`. `operator` is the constrained operator. Default kernel indices are the nine declared native locations in the source, selected only for diagnostic plots and parity fixtures; they do not reduce reconstruction support. Output has only `reconstruction` `(1,101,51)` nHz. Diagnostics include the full formal-error map,101target widths, selected index vector, selected averaging kernels `(9,101,51)`, whitened estimator coefficient rows `(9,29617)`,9×9covariance, full projected coefficient matrix `(1000,5151)`, projected targets `(1001,5151)`, a/b, and freshly computed U/V. They remain in memory and are not extra submission keys.

`reconstruct(data,iterations=1000,tradeoff=3.,width=.06,angular_width=.1,progress=False)` creates the explicit forward/constrained operators, starting target, full Lanczos basis and all-target inversion. It returns output/diagnostics without file I/O. `main.run(data_path='data/raw_data.npz',output_path='output/reconstruction.npz',progress=True,iterations=1500)` calls load_data and reconstruct with the explicitly requested1500-step convergence setting, creates the output parent, writes the one declared NPZ, and returns output/diagnostics/elapsed seconds. Standard `python -m src.main` calls this exact full path. Importing main never selects a plotting backend.

`src.visualization` supplies observation, field-comparison, resolution and sensitivity figures from passed numerical arrays. It loads no solver reference. The notebook calls main.run freshly, then uses local operators/solvers for ablations and noise studies. Only labeled comparison arrays come from `notebooks/reference_outputs/upstream.npz`. The source never imports a private factorization or original code.

`evaluation/judge.py` is standalone standard library/NumPy code. It validates exact required key, shape/dtype/finiteness before scoring. It loads the hidden independent public-objective target field and fixed metric boundaries relative to itself; public calibration for the forward-consistency criterion comes from the sibling data directory. Its acquisition calculation independently forms128full rows at a time and contracts them directly against the submitted field, rather than importing the optimized solver operator. It returns0/1/2for pass/valid-below-threshold/malformed-or-evaluator-error, writes caller-relative UTF8JSON with explicit status, metrics, thresholds and errors, and diagnoses report-write failures on stderr. No crop, normalization fit, shape coercion or solver execution is permitted.

Frozen original arrays under test/fixtures are consumed only by parity tests. Notebook comparison arrays contain full native field and formal error, explicitly a method result rather than truth. Test code independently checks adjoints, rows, normalization, cubic interpolation and reduced-objective stationarity, and reruns the complete native-sized inverse. No generate_data module exists because no new synthetic benchmark observations are generated. Private stage harnesses, native binaries/model archives/logs/PDFs and temporary executed notebooks remain outside the task.
