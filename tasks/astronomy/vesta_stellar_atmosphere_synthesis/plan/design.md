# Shipped interfaces and actual data flow

`python -m src.main` is the standard entry. `main.run(root=None,seed=20261028,progress=None)` reads public raw data, constructs a local SpectralModel, executes both dual preliminary fits, estimates runtime discrepancy noise and runs all100burn+1000production sweeps. It writes `output/reconstruction.npz` with real float64 `reconstruction`(1,4) and `spectrum`(1,52570). Parameters are kelvin/cgs dex/metallicity dex/km/s; spectrum uses author flux units in input order. It also writes identified fresh maintainer measurements under `notebooks/reference_outputs/fresh_measurements.npz`; this file is never an input to the solver. It returns prediction, diagnostics, model and measured seconds. Importing main does not configure a plotting backend.

`preprocessing.load_observations(path)` loads NPZ with allow_pickle=False, copies arrays and removes the single batch dimension. `select_ranges(raw)` returns wavelength/flux/uncertainty in the original window order. `mask_flux(wavelength,flux,uncertainty,masks)` returns five arrays: masked wavelength/flux/errors and masked/full ranked diagnostic velocities. It retains concatenated mask order and any duplicated entries. Wavelengths are angstrom; velocities are km/s; flux/error use author units.

`physics_model.SpectralModel(raw)` requires the unbatched public arrays. It builds the rescaled three-dimensional Delaunay geometry, stores independent calibration and identifies masks. `interpolate_weights(parameters)` and `interpolate_weights_fidelity(parameters)` accept float64 internal p4=(Teff[kK],logg,MH,profileSpeed[km/s]), returning350weights, with original hull/local-grid checks. `forward(p,masked=False)` and `forward_fidelity(p,masked=False)` return new complete52570arrays or selected3643arrays. The latter preserves source ordering for finite-difference-sensitive optimization. `forward_batch(parameters,masked=False)` returns(n,52570)/(n,3643), only batching the deterministic known-model linear algebra. Invalid parameters/hull points raise ValueError. These methods never read hidden references or mutate observed arrays and use no RNG.

Known calibration construction remains executable: `build_operators(raw,progress=None)` reads only model basis/mean/scale, model and observation wavelengths and range endpoints, returning the ten unbatched operator arrays documented in README. It never reads flux, uncertainty, fitted parameters or noise. `FixedCubic(coordinates).operator(query)` constructs not-a-knot knots, cubic collocation and a general banded-LU solve to return a sampling matrix. `velocity_grid`, `rotation_kernel`, `finite_convolution`, `source_order_broadening` and `normalize_continuum` implement the visible finite-window sampling, kernels, constant-fill convolution and dynamic observed/model normalization. General SciPy numerical primitives implement spline evaluation, linear solves, geometry and1D convolution; no domain reconstruction package is imported.

`solvers.window_error(synthetic,observed,uncertainty,wavelength,resolution=.2,threshold=3.,variant='source')` returns Gaussian centres/widths/amplitudes and a scalar robust residual scatter. The explicit variant `aligned_diagnostic` is only a review comparison. `estimate_error_map(model,parameters,variant='source')` uses source-order spectra and measured flux to return the full and masked maps plus identified regional quantities. It does not load a fitted uncertainty from raw data.

`dual_curve_fit(model,masked_wave,masked_flux,masked_error,tolerance=.001,initial=None)` performs the original pair of robust general optimizations, returning internal p4,4x4covariance and uncertainty factor. `prepare_likelihood(model)` returns second-fit parameters, covariance/error/width, masked wavelengths/observations/input errors, runtime full/masked maps, both scaling factors, first-fit measurements and diagnostic velocities. Its second fit starts at the first fit; the main sampler's likelihood uses the separately recomputed map, not an externally supplied target-derived calibration.

`log_probability(p,model,likelihood)` returns the source Gaussian log probability or negative infinity for invalid points. `log_probability_batch` preserves ordered evaluations and falls back to individual evaluations if a batch contains a rejected hull point. `initialize_walkers(initial,width,model,likelihood,seed=20261028)` generates sixteen actual starting points. `stretch_posterior(model,likelihood,burn=100,production=1000,seed=20261028,progress=None)` returns chain(16,1000,4), log probability(16,1000) and acceptance(16) under defaults. Smaller lengths exist solely for unit/statistical transition tests. `reconstruct(model,seed=20261028,progress=None)` always executes the complete benchmark protocol and returns the declared prediction plus diagnostic chain/likelihood quantities.

`evaluation/judge.py` imports no solver code. References resolve relative to its own file; caller prediction/report paths resolve relative to the caller working directory. It validates both exact keys/shapes/dtypes and finite values, then evaluates parameter-standardized maximum error, full-spectrum dynamic NRMSE and selected-observation weighted RMS. Actual truth takes precedence if separately supplied; this task ships only a validated method baseline. A reference-method scale/noise array supports fixed normalization, never pretends to be acquisition truth. Public wavelength/flux/masks are the only data arrays needed by its observation metric. CLI exits0/1/2 for pass/valid failure/input or evaluator error, creates report parents and reports write failures on stderr.

`visualization` is a notebook review path; it displays computed fresh outputs and labeled independent originals without changing a Matplotlib backend. The notebook actively calls the complete `run`, applies the standalone evaluator and then computes genuine noise-heuristic and parameter-response diagnostics. Archived reference arrays are comparisons only. `upstream_stages.npz` identifies the original2.0backend stages, while `upstream_sensitive_stages.npz` identifies independently captured original2.4backend stages for strict deterministic matching. `upstream_measurements.npz` contains the completed original full sampling result. `upstream_noise_diagnostic.npz` identifies a separate original-source noise-ranking experiment. Every such file has a documented consumer in validation.md.

All source checkouts, native observations/model binary, paper PDFs, capture programs, original logs, execution manifests and visual inspection PNGs remain in a private maintainer archive outside the task. There is no generator because no new synthetic observations are produced. Static model-response plots are forward sensitivity diagnostics, not invented measured experiments. The task has one test tree and one validation report.
