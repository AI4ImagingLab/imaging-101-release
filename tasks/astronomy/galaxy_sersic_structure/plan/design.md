# Shipped interfaces and execution flow

Standard command: python -m src.main. It reads data/raw_data.npz, calls local full three-band inversion and writes output/reconstruction.npz. No upstream PySersic, JAX, NumPyro, SEP, FITS reader, frozen fixture, baseline or other task is imported by the solver. NumPy and PyTorch provide generic FFT, quadrature nodes, automatic differentiation and Adam; the acquisition/profile/objective and fitting pipeline are explicit local code. Matplotlib supplies figures. SciPy is used only by the independent analytic integration test in the shared development environment. CPU execution and one numerical thread are validated. No library or main import changes a plotting backend.

preprocessing.load_data(path='data/raw_data.npz') returns independent arrays images(3,120,120),inverse_variance(3,120,120),psfs(3,63,63),mask(1,120,120), after checking exact batch-first input shapes, finite values and positive inverse variance. Raw floating observations/calibration remain float32; maskbool hasTrueexcluded. SHAPE=(120,120) is the bound geometry. The original acquisition mask is provided, not regenerated from hidden output.

physics_model.sersic(x,y,parameters) accepts broadcast Torch coordinates in pixel units and at least the first seven physical parameters; returns surface brightness, preserving Torch dtype/automatic derivatives. PixelModel(psf,shape=(120,120),num_os=12,os_pixel_size=6,dtype=torch.float32) caches fixed image coordinates, central quadrature coordinates/weights and psf_fft. shape is(row,column), PSF dimensions are(row,column). attributes region,xos,yos,weights correspond to the documented12x12centralpixels. psf_fft is complex(120,61); no target-dependent setup occurs. PixelModel.intrinsic(parameters) returns(120,120)galaxy-only integratedbrightness. PixelModel.observed(parameters) applies calibrated periodic PSFconvolution andadds parameter7constant sky. Both retain gradients; neither reads/writes files. objective(parameters,model,image,rms,valid) returns scalar Gaussiannegative loglikelihood plus weak position/sky prior; validTrueincludes pixels, the opposite of publicmask. Full mathematical normalization and unit/sign conventions are in approach.md and source.

solvers.physical_parameters(latent) maps Torch(8) unconstrained variables to physical(8), positions/sky via affine transforms and five bounded quantities via sigmoid. LOW/HIGH hold explicit predeclared bounds. fit_band(image,inverse_variance,psf,mask,max_train=20000,patience=250,initial_latent=None) returns(parameter8,intrinsicimage,observedimage,history), with physical float32NumPy outputs and float64history container of actual scalarfloat32losses. It performs one original warm Adam update, all three learning-rate rounds, actual stopping and best-state restoration. INITIAL_LATENT(3,8) holds independently captured pure-prior original seed draws; reconstruct passes the corresponding row. The optional argument defaults to row0 for a standalone g-band call, and notebook variants explicitly pass each corresponding band row. Inputs use per-band shapes above; publicmaskTrueexcludes. Nonfinite objective raisesValueError. No filesystem or upstream reference side effect occurs. reconstruct(data,return_diagnostics=False) fits all threebands and returns parameters(1,3,8),reconstruction(1,3,120,120). With diagnosticsTrue it returns(result,dict) containing observed(3,120,120) and a list of three variable-length actual histories. It never fills a missing band with a reference.

The notebook explicitly sets its own Torchthreadcount, actively calls reconstruct and independently evaluatesfresh results. The two PSF variants call fit_band for everyband; NumPyFFT constructs the hypotheticalblurredPSF from public calibration. Circularannuli are a plottingdiagnostic and do not replace the elliptical model or intrinsic reconstruction.
