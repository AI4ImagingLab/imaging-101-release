## Investigated paper/code discrepancies

The paper's BIC definition implies an added parameter requires a decrease exceeding log(N); its printed Eq2 sign is inconsistent with this definition. The selected original code correctly tests cnew<cmin-log(N), reproduced locally. Its exploration threshold is the minimum, whereas a paper passage describes the median. The original high-pass operator includes a discrete asymmetric ramp and nonlinear continuum division beyond the paper's ideal-window sketch. Its attenuation-law loss clips squared differences then squares again, giving a fourth-power discrepancy. These details, along with200-Angstrom smoothing, are explicit in the implementation and plans rather than silently represented as the simplest paper sketch.

Initial single-SSP scores use their own three-sigma masks; later branch scores use the chosen mask. Original branch-zero mixtures can update that mask during mixing; local code preserves exact behavior. Thus candidate objectives are not claimed to be a common calibrated posterior. The original impossible isnan AND isinf high-pass guard is inactive on the finite bound data; local code instead validates finite results. Its separate fine-attenuation nonfinite guard was triggered at the five padded bins of the rejected binding and correctly reproduced; final supported binding has zero such bins. No fabricated mass/population truth is used.
