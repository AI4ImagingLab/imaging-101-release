# Shipped execution flow and interfaces

`preprocessing.load_data(path='data/raw_data.npz')` loads all13 arrays with allow_pickle=False and removes the leading batch axis. It preserves original observation precision and big-endian float32 where present. `normalize_models(data,models)` returns a(M,N) array with each model's median equal to the lengthN data median. It introduces no fitted target input.

`physics_model.highpass(flux,windowsize=20,start=20)` implements the explicit original FFT/ramp/continuum formula and rejects nonfinite output. `calzetti(ebv,wavelength)` returns dimensionless transmission for Angstrom wavelengths and magnitude E. `smooth_curve(wavelength,curve,length=200.)` returns the strict-window running median. `forward(weights,attenuation,templates,flux)` returns2308 flux densities after normalization; `adjoint(residual,normalized_templates)` returns198 weight-space inner products. No function writes files or changes plotting backend.

`solvers.sigma_clip(values,sigma=3.)` returns retained values and final lower/upper cutoffs. `fit_population(flux,error,models,max_iterations=10)` returns all candidate weights,chis,branches,best_weights,best_index,initial fixed mask,actual branching history and retained pre-mixing count. It executes the entire explicit BIC search and mixture expansion. `determine_attenuation(data,normalized)` returns(attenuation,ebv,diagnostics), including full high-pass fit,filtered flux/errors/templates,fine attenuation,bad-bin mask and extinction-grid losses. `reconstruct(data)` returns(output,diagnostics), where output has the three declared batch-first arrays, and diagnostics has highpass,final,prediction,templates. All intermediate computed arrays are float64 except original data retained in acquisition dictionaries.

`python -m src.main` reads public NPZ, calls reconstruct and writes output/reconstruction.npz. It imports no plotting library. The notebook independently invokes reconstruct, evaluates its new output and writes notebooks/reference_outputs/cleaned.npz. It also freshly fits the same full2308-bin data with no attenuation and with the fitted analytic Calzetti curve, using fit_population and explicitly labeling these scientific comparisons. Archived native results and rejected-edge prediction are loaded only for identified comparison overlays, never as a fresh solver result.

`visualization.residual_statistic(prediction,data)` returns mean standardized squared residual; `marginal(weights,coordinate)` returns unique nodes and summed weights. `acquisition_figure(data,result,original,rejected)`, `population_figure(data,out,original)`, `dust_figure(data,out,result,no_dust,calzetti_fit)` and `exploration_figure(data,result)` return matplotlib Figures from supplied arrays. Their caller handles display and optional private review-image writes. All16 panels are actual computed scientific comparisons.

`evaluation/judge.py` is standalone: load_output validates all keys/shapes/float dtypes/finite values and physicality; predicted_flux independently evaluates normalized mixtures; score evaluates all output quantities and public observations; evaluate chooses ground_truth first if available, otherwise baseline_reference, and returns(report,exit_code). main supports --prediction and --report, relative to caller cwd; hidden references are relative to the evaluator file. No src/submitted/upstream code is imported. Tests consume frozen independent NPZ arrays and exercise invalid data, poor valid predictions, hidden-asset failure, GT precedence and external cwd. Test temporary files are outside the package, with caller basetemp precedence.
