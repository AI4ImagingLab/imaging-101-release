# Shipped runtime and review flow

`python -m src.main` calls preprocessing.load_data(path='data/raw_data.npz') -> float64(3,60,3), solvers.reconstruct(observations) -> (output dict, diagnostics), then writes only output/reconstruction.npz. main creates output, reports chosen start/log objective, never imports plotting or changes a backend. Runtime consumes no hidden fixture, source archive or other task.

preprocessing.prepare(observations) returns sorted time/value/error/channel vectors180, original means3, indicator design(180,3) and scalar baseline. channel IDs1..3 preserve native convention. load_data rejects wrong shape, nonfinite or nonpositive errors.

physics_model.unpack(parameters) maps8float64 log/linear fit values to positive sigma/tau and3-element lag/width/scale arrays. covariance(t1,id1,t2,id2,parameters) returns float64(len(t1),len(t2)); explicit private exponential primitives and channel-block assembly implement the convolved stochastic acquisition model. There is no domain-library import or hidden native execution.

solvers.likelihood(p,data,components=False) returns scalar log objective, or four terms plus q(3) when components=True. Illegal physical parameters return -1e300. predict(p,data,times) returns mean and conditionalSD, both(3,len(times)); negative computed variance raises. reconstruct uses declared3starts and up to5native-equivalent restarts, returning reconstruction(1,3,600),transfer(1,2,3),continuum(1,2). Diagnostics include8fit parameters,600times,conditionalSD(3,600),three final parameter/log-objective sets,actual optimizer rounds and selected index. No random generator or training exists.

visualization functions accept observed data, fresh outputs/diagnostics and clearly named original measurements; their Matplotlib figures display measurements, reconstructions, mode/transfer/covariance comparisons and limitations. The notebook actively calls the same reconstruct path, separately computes the likelihood slice, and records runtime. It loads notebooks/reference_outputs/upstream.npz only for original comparisons; fresh measurements there are archived outputs from an executed clean path, never a reconstruction substitute.

Standalone evaluation/judge.py imports no solver. Its required CLI flags are --prediction and --report; prediction/report paths use caller CWD, assets use its own resolved location. It validates three required arrays and physical parameters, prefers ground_truth.npz when present otherwise baseline_reference.npz, evaluates all outputs and observed WRMS, writes finite UTF8JSON and exits0/1/2. Report-write failure yields2withstderr. test/unit_test covers physics and evaluator contracts; test/comparing_test consumes frozen native covariance/likelihood/prediction/full-fit arrays. Reference fixture and reference-output duplicate have separate test/review consumers documented in validation. No generated-data module is shipped because observations are actual measurements.
