# Runtime interfaces and data flow

The runtime is CPU float64 NumPy plus standard library. Matplotlib is review-only. Astropy, SORA, SPICE, Gaia queries and all original source remain isolated outside the task. No cross-task imports or generation of synthetic benchmark observations occurs.

- `preprocessing.load_data(path=None)` loads public NPZ with allow_pickle=False and removes its singleton batch dimension. Returns limb_points(10,2)km,velocity(10,2)km/s,timing_sigma(10)s,times_jd(10)UTCJulian days,negative_path(2394,2)km,contour_angles(360)rad. Arrays are copied. Default path is task-relative data/raw_data.npz.
- `preprocessing.radial_uncertainty(data)` returns ten scalar km uncertainties from speed times timing weight.
- `physics_model.ellipse_contour(parameters,theta)` accepts one5vector and angular vector, returns len(theta)-by2sky coordinates in km. It implements the published pole-angle convention directly.
- `physics_model.contact_chi2(parameters,points,sigma)` accepts one5vector or M-by5trial array, contact positions(10,2), and ten km errors. Returns Munnormalized radial chi-square values. Original contact accumulation order is preserved.
- `physics_model.negative_margin(parameters,path)` returns minimum radial clearance in km for one ellipse against path coordinates. Positive means clear; nonpositive means an intersection/touch and rejects the candidate.
- `physics_model.contact_time_residuals(parameters,points,velocity)` is a review helper implementing the local ray/ellipse quadratic independently from the radial objective. Returns nearest signed time shifts in seconds; missing trajectories return Inf for this diagnostic only. The production Judge handles missing contacts by an explicit zero-miss criterion and finite time statistic.
- `solvers.monte_carlo_fit(data,seed=24713,loop=100000,number_chi=20000,dchi_min=10.)` runs the actual original search and mandatory negative filtering. Returns best5vector plus dictionary parameters(M,5),chi2(M),negative_clear(M)bool,best_index(int),batches(int). It never reads hidden references or caches.
- `solvers.reconstruct(data,seed=24713,loop=100000,number_chi=20000)` returns (output,diagnostics). Output is parameters float64(1,5) and reconstruction float64(1,360,2). Diagnostics are the search ensemble. No file writes occur.
- `main.main()` loads public data, actively reconstructs, creates output/ and writes output/reconstruction.npz, returning its Path. Standard command is python -m src.main. It does not select a plotting backend.
- `visualization.make_figures(data,output,stages,upstream,comparison,export_dir=None)` returns six Matplotlib figure objects; optional export writes PNG/SVG/PDF plus exact numerical sources and hash manifest. It never changes backend. Inputs identify source ensembles, fresh ensembles and separately computed sensitivity/negative-filter alternatives.

The notebook is an independent caller of cleaned reconstruction and visualization functions. It actively computes the full standard inverse, at least one additional seed, positive/continuous/exposure filter comparisons, then evaluates the fresh NPZ through the standalone Judge. Hidden reference-output arrays supply only explicitly labeled original comparisons and known optional exposure geometry, not fresh reconstruction values. All6figures display inline after real computation.

`evaluation/judge.py` imports no source modules. Its public CLI uses --prediction/--report, caller-relative paths, and resolves metrics/reference/public observations relative to the evaluator's own path. It validates exact required float64shapes, real finite arrays, positive radius and valid oblateness, and every required boundary before scoring. Ground truth takes precedence over baseline if present. Independent Qmatrix geometry evaluates all parameters, all contour coordinates, parameter/contour consistency, every positive trajectory and every negative sample. Valid poor outputs yield fail/exit1; malformed inputs or evaluator failures yield error/empty metrics/exit2; pass yields0. UTF8reports create parent directories and report-write failures print stderr diagnostics.

Tests consume frozen upstream_cases.npz for original trial objectives, source contour and full method parity; they never import original source. Unit tests cover known circles, rotated ellipses, ray quadratics, angle periodicity, independently bad parameters/contour, required thresholds, reference priority, malformed submissions/configurations, foreign cwd and report-write failures. Private captures, original checkouts/PDFs/logs and executed temporary notebook copies remain outside the task.
