# Shipped architecture and execution

`python -m src.main` calls `run(output_path='output/reconstruction.npz')`. It actively processes every native sample in eight observations, reconstructs all eight independent κ values and the stitched κ, writes float64(1,9) under reconstruction, prints runtime/values and returns that array. The CLI has no plotting/backend import or side effect.

`preprocessing.load_observations(path=Path('data/raw_data.npz'))` loads32 numeric arrays without pickle and returns eight Spectrum objects. `make_spectrum(intensity,frequencies,times,mjd)` accepts full(native-frequency,native-time),frequency(Nf,),time(Nt,) and scalar MJD, applies only the actual source clock/short-integration rule and retains physical coordinate fields. `reflecting_laplacian(shape)` returns a CSR five-point2D matrix. `fill_gaps(intensity,method='biharmonic')` returns a new float64 matrix, with explicit L² sparse inversion or the source combined-gap mean rule; observed values are unchanged. `stitch(first,second)` returns a new Spectrum retaining the original first-frequency/clock conventions, inserts missing temporal samples and does not estimate κ.

`physics_model` contains explicit selected mathematical stages adapted from the source. General helpers `is_valid(array)`, `svd_reconstruct(arr)`, `svd_model(arr)` and `get_window(nt,nf,window='hanning',frac=0.1)` implement finite detection, rank-one approximation/division and tapers. Spectrum is a small container of observed/calibrated arrays and method intermediates, not a vendored reconstruction framework. Only the validated branches are shipped. Methods are `trim_edges(bandwagon_frac=0.5)`, `correct_dyn()`, `calc_sspec(lamsteps=False,window='hanning',window_frac=0.1)`, `scale_dyn()`, `norm_sspec(eta=None,delmax=None,startbin=1,cutmid=0,numsteps=None)` and `fit_arc(delmax=None,numsteps=10000.0,startbin=3,cutmid=3,etamax=None,etamin=None,low_power_diff=-1,high_power_diff=-0.5,constraint=[0,inf],nsmooth=5)`. They mutate explicit fields: dyn normalized intensity(Nf,Nt), lamdyn wavelength-resampled intensity(Nλ,Nt), sspec/lamsspec logarithmic secondary power(Nfft_f/2,Nfft_t),fdop(mHz),tdel(μs),beta(m⁻¹),eta_array and norm_sspec_avg(1D curvature/power),betaeta(m⁻¹mHz⁻²),betaetaerr(empirical source convention),parabola_standard_error(corrected covariance diagnostic). No source I/O, plotting, orbital fitting, domain library or arbitrary-geometry branch remains.

`physics_model.arc_beta(doppler_hz,kappa)` broadcasts the thin-screen forward relation. `physical_kappa(author_curvature)` converts the source mixedmHz units. `fit_parabola(x,y)` returns fitted values, peak and independently corrected physical-coordinate covariance error; source empirical error is computed separately. `solvers.reconstruct(path='data/raw_data.npz')` returns reconstruction(1,9), a list of9active Spectrum diagnostics and a runtime/count dictionary. It owns the actual single/combined caller flow and all frozen fit settings. No hidden numerical asset is read by reconstruction.

`visualization.secondary_image(axis,spectrum,wavelength=True)` draws the selected frequency- or wavelength-conjugate power array on an existing Matplotlib axis and returns an AxesImage. Coordinate units, source display limits and the fresh fitted arc are applied only to that axis; reconstruction arrays are not modified. The active notebook reconstructs all nine cases, calls the independent Judge, uses frozen original measurements only as labeled comparisons, preserves native-versus-prepared/frequency-versus-wavelength/individual-versus-stitched scientific views, and separately compares legacy and corrected auxiliary errors. A preview/cache cannot replace this path. PNG review exports are temporary in output, later archived privately; canonical notebook embeds final figures.

The standalone `evaluation/judge.py` imports no solver. `evaluate(prediction_path,asset_dir=HERE)` validates exact shape/dtype/finite/positive values and loads its own hidden baseline/thresholds. `score(prediction,reference)` evaluates all nine κ values and their measured profile power using independent NumPy routines. CLI reference paths use the evaluator location, prediction/report paths use caller cwd, and native exits0/1/2 distinguish pass/valid threshold failure/malformed or evaluator error. Missing/zero/nonfinite hidden references and report-write failures are tested.

`test/fixtures/upstream_stages.npz` is the independent original first-segment stage capture, consumed by comparing_test. `evaluation/baseline_reference.npz` contains the exact original9κ values and observed power profiles used by the Judge. `notebooks/reference_outputs/upstream_measurements.npz` identifies reproduced originalκ, empirical noise errors and legacy uncorrected auxiliary errors for review. None is actual ground truth. All public keys are legitimate observed intensity/coordinate/calibration arrays. Original source/PDF/ASCII/capture code/logs stay outside the task in the private archive.
