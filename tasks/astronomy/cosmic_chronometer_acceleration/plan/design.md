# Shipped architecture

`src.preprocessing.load_observations(path="data/raw_data.npz")` returns three float64 vectors of length30: redshift, rate and positive error. `reconstruction_grid()` returns200 uniform redshifts0..1.965. No side effects occur during import.

`src.physics_model.covariance_operators(x,y,theta,kernel="SquaredExponential")` returns K(Nx,Ny), parameter gradients(2,Nx,Ny), K01(Nx,Ny), K11(Nx,Ny). Theta has amplitude and redshift correlation length. `acceleration_parameter(redshift,hubble,hubble_derivative)` broadcasts arrays and returns dimensionless q. `q_delta_standard_deviation(redshift,hubble,hubble_derivative,point_covariance)` returns marginal delta-method standard deviations, not cross-redshift bands.

`src.solvers.factor_observations(z,y,error,theta,kernel)` returns K, gradients, lower Cholesky factor and alpha. `negative_log_likelihood(theta,z,y,error,kernel)` returns a scalar and analytic length2 gradient. `condition(z,y,error,grid,theta,kernel)` returns H, Hprime and point covariance(Ngrid,2,2). `fit_kernel(z,y,error,grid,kernel,initial_factor=1.)` optimizes and returns these three arrays plus theta/evaluation/status/objective metadata. `reconstruct(path="data/raw_data.npz",initial_factor=1.)` invokes all four kernels in the fixed public axis order and returns the complete five-key submission dictionary plus four metadata records.

`python -m src.main` invokes reconstruction and writes `output/reconstruction.npz`. CLI and notebook both use the same local mathematics. Main does not switch any Matplotlib backend during import. `src.visualization` provides save_review_figure(figure,path), which exports a computed figure at150dpi and returns the destination Path. The notebook reconstructs the full primary cohort afresh, evaluates the fresh arrays through the independent Judge, and runs two additional initialization-scale fits. Frozen upstream measurements are only labeled comparisons. Historical48-point mixed-acquisition results remain in the private archive and are not substituted for the selected30-point benchmark.

The standalone `evaluation/judge.py` imports no solver modules. It resolves its hidden reference and metric specification beside itself, loads all NPZ without pickle, enforces exact float64 shapes and finite values, positive expansion rates and symmetric positive-definite marginal covariance, scores every required output, validates all metric/boundary values and emits the standard pass/fail/error JSON with native exit0/1/2. Invalid evaluator assets yield empty-metric errors. The observation-consistency score uses only public measurements with fixed linear grid interpolation. All tests are under test/, with frozen upstream cases under test/fixtures/. No domain library, original source or cross-task code is imported by runtime, tests, Judge or notebook.
