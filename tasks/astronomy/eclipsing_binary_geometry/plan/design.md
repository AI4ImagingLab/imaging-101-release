# Shipped interfaces and execution flow

All runtime mathematics is local NumPy/SciPy. No ellc, compiled Fortran DLL, emcee, astropy, corner, or cross-task import is used. Matplotlib is only used by maintainer visualizations. CPU numerical libraries run with one thread; no GPU is required.

## Modules and callables

`src.preprocessing.load_data(path)` reads `data/raw_data.npz` with allow_pickle=False. It returns six tuples `(t,y,s,wt,flag)` in WASP/NITES/OED/BYU/KPNO/RV order. Times are float64 HJD, y/s/wt are float32 original numeric columns and adjusted inverse variances, flags int8. Tuple lengths are7968,3490,239,2199,1564,28. No targets are read. Storage arrays remain full-decimal float64, batch-first; preprocessing unpacks their batch dimension using declared shapes.

`src.physics_model.brent(f,ax,bx,cx)` returns a scalar minimizer for the supplied bracket. `periastron(t0,e,omega,inc)` accepts epoch days and angles radians, returning HJD days. `eccentric_anomaly(m,e)` broadcasts float64 mean anomaly radians and eccentricity and returns wrapped eccentric anomaly radians. `orbit(t,p,lighttime=False,geometry=False)` accepts time vector and seven-vector in README units. Default returns `(separation,secondary_in_front,primary_velocity)`; geometry=True appends projected relative x/y arrays, all with the time shape. Separation and x/y use relative semimajor axis units; velocity is km/s. `brightness(x,y,R,ld)` broadcasts projected coordinates/radius in a common unit and dimensionless quadratic coefficients, returning dimensionless relative intensity. `disk_grid()` returns three44-entry arrays of unit-disk x/y/weights. `disk_mean(R,ld)` returns a scalar area-normalized mean brightness. `region_integrals(a,b,lower,upper,R,ld)` uses vector region endpoints and boundary functions, returning brightness and area integrals. `blocked(R,r,d,ld,dx=None,dy=None)` returns a blocked background-flux fraction for each separation; optional coordinate arrays specify finite-grid translation. `photometry(t,p,group)` returns normalized flux for direct observation times; group0..4 selects the fixed band/physics convention. These functions do not access files or alter plotting backends.

`src.solvers.valid(p)` returns the seven-parameter physical support check. `models(p,groups)` returns six unoffset model arrays in magnitude or km/s. `residuals(p,groups,details=False)` returns one concatenated15488weighted residual vector; details=True instead returns `(six_chi_squared,six_offsets,15488unoffset_predictions)`. `log_probability(p,groups)` returns -0.5total chi-square or -infinity outside physical support. `initialize(groups)` returns `(point,covariance,diagnostic_dict)` from raw-only fitting. Its covariance has shape (7,7) and parameter-unit products.

`ensemble(groups,initial,covariance,rng,walkers=50,updates=1000,progress=None,probability=None)` returns `(chain,acceptance)` with shapes(walkers,updates,7) and(walkers,). rng is a NumPy Generator. The optional scalar probability callback is only used for independent sampler tests. Standard execution uses the physical likelihood. Optional progress receives `(completed_updates,mean_acceptance)` at every100 updates. No random chain is compared for exact seeded equality.

`solve(groups,rng=None,progress=None)` always performs the standard raw initializer followed by 50 walkers/1000 updates/burn500. Its result dictionary contains parameters(7,), chain(50,1000,7), acceptance(50,), chi_squared(6,), offsets(6,), prediction(15488,), initial_parameters(7,), and initializer diagnostics. It has no file writes. The default random generator is fresh; its stochastic summary may differ from the original finite-chain median.

`src.main.main()` resolves the task root from its own file, loads raw observations, runs solve, creates output if needed, and writes exactly `output/reconstruction.npz` with reconstruction shape(1,7). It prints progress and a JSON runtime/fit/acceptance summary. It does not write source chains as public calibration and does not import plotting utilities or change notebook backends.

`src.visualization` supplies maintainer plotting helpers used by the active notebook. Their actual figures are measurements/models/residuals for all six groups, source/fresh parameter summaries, posterior correlations and traces, source/fresh acceptance or chain diagnostics, numerical light-time controls, and explicitly computed conditional ablations. Plot-only downsampling is labeled and does not affect scoring.

## Evaluation boundary

`evaluation/judge.py --prediction PATH --report PATH` is standalone. Its independent source contains deterministic orbit, eclipse, observation preprocessing, and weighted profiling mathematics, and imports no solver. Hidden metrics resolve relative to the evaluator file; public raw data resolves relative to the task root. Submission and report paths resolve relative to the caller when not absolute. Exactly reconstruction shape(1,7), finite real float32/float64 is accepted. Physical-domain violations are invalid input errors. The metric configuration must contain exactly one positive finite total_chi_squared boundary and comparison<=; empty, missing, unknown, malformed, NaN or nonpositive configurations are errors. Scores include six group diagnostic components and jointly thresholded total. Exit0 means pass,1 valid below-quality output,2 input/evaluator/report-write error; error reports have empty metrics. JSON is UTF-8 with nonfinite numeric values forbidden.

The original median in evaluation/baseline_reference.npz is explicitly a method result, not truth. It supports provenance and maintainer comparisons, rather than fixing parameter identity. `test/fixtures/v2_original_forward_likelihood.npz` holds16 original six-group forward/offset/likelihood cases. `v2_original_orbital_helpers.npz` holds independently captured original helper cases. `notebooks/reference_outputs/upstream_posterior_summary.npz` holds original full-budget posterior summaries and block metrics; it is not read by inference. Fresh full-run outputs are separately identified in that directory after execution.

## Review path

The final canonical notebook also includes the full seven-by-seven triangular joint posterior plot from the same chain computed earlier in that complete execution. Histograms use all retained samples; pairwise points are thinned only for display. A separate same-chain plotting notebook was used only for private visual preflight and is not shipped as a replacement for active reconstruction.

The six-chapter notebook actively calls solve on raw observations with the complete50 × 1000 budget, evaluates the returned point with the standalone Judge, and computes its declared comparisons. Archived original summaries only supply labeled upstream comparisons. Original V1/V2 errors and finite-radius light-time controls are explained explicitly. Figures use fresh computed predictions, not substituted source curves. Test and notebook provenance, actual process exit statuses, wall times, hashes, environment, and figure review are recorded in test/validation.md and the private worker archive.
