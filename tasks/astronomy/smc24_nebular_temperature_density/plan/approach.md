# Implemented method

The unknowns are electron temperature T (K) and electron density n (cm^-3) inferred independently for four ordered temperature/density diagnostic pairs. The order is NII/OII,NII/SII,OIII/OII,OIII/SII. Each is a conditional same-ion ratio interpretation; there is no common-temperature optimization across all ions. No actual truth exists. The published author line list is processed observations; model calibration comes from independent atomic calculations.

Each ion has a fixed number of levels: NII6,OII5,OIII5,SII5,SIII6,NeIII5. Excitation energies E are inverse Angstrom, statistical weights g are dimensionless, and A[j,i] is spontaneous j-to-i decay in s^-1. Collision data Upsilon[i,j,k] store lower,upper,temperature-node order, with log10(K) node coordinates. Use linear interpolation in log10(T), clamping to endpoint strengths outside the table. The model uses only levels shared by energy/A and collision tables; SII's additional collision-table levels do not introduce states into its five-level model.

Downward rates q[j,i]=K Upsilon[j,i]/(sqrt(T) g[j]), with K=8.629132419846745e-6. Upward rates q[i,j]=g[j]/g[i] exp((E[i]-E[j])/(b T)) q[j,i], b=6.95034760642295e-9 inverse Angstrom/K. K matches cm^3/s with this temperature convention. Detailed balance is tested independently. Form the transition matrix C=n*q+A; its off-diagonal values are from-to rates. Set equilibrium matrix to C transpose, replace its diagonal by negative outgoing row sums, and replace row0 by ones. The right-hand side is (1,0,...,0); solve directly for fractional populations. This explicitly evaluates the published linear statistical equilibrium, with no domain library, opacity, radiative pumping or manufactured iteration.

Line emissivity per ion/electron pair is p[j] A[j,i] h*c*1e8*(E[j]-E[i])/n in erg cm^3/s, h=6.62606957e-27 erg*s, c=29979245800cm/s. The factor1e8 converts inverse Angstrom to inverse centimetres; its omission was caught and corrected by original-stage parity. Ratios cancel h,c,n and abundance, and the inverse implementation evaluates ratios directly from populations times A times energy differences.

Observational preprocessing preserves original author's read precision. The original parser stores observed intensities as float32 values within float64 arrays and c(Hbeta) as float32. Apply the CCM89 optical polynomial/nearIR power-law extinction curve X=RV*a+b with RV3.1. The original implementation uses X=0 beyond3.333micron; preserve that explicit boundary. Deredden absolute intensities Fcorrected=Fobserved*10^(0.4*E(B-V)*X). Do not renormalize to Hbeta afterwards. The original float32 E(B-V) conversion is archived as0.0325583778321743011mag and supplied explicitly in README; recomputing under NumPy2 changes its rounding. It is a known author-supplied extinction conversion, not inferred from the hidden conditions.

The four inverse pairs use recursive n-section root search in logarithmic temperature/density coordinates. Temperature search spans the chosen ion's collision-temperature table extrema. Density spans1 to1e8cm^-3. At each recursion, evaluate30uniform log-coordinate samples, choose minimum absolute fractional line-ratio residual, return if residual<0.001, otherwise bracket using the two neighboring samples (move an endpoint minimum one index inward) and recurse. Permit recursion indices0through20; beyond20 returnNaN. This preserves the original search and its fractional residual criterion; upstream prose calling this percent is not used to change the code.

Initialize density at T=10000K, then infer temperature at that density. Perform up to5crossed updates: new density uses old temperature, new temperature uses old density (Jacobi, not Gauss-Seidel). Stop when both relative changes, computed against new values, are at most1percent. ReturnNaN on failure, and main rejects nonfinite output. There is no regularizer, gradient, line search, latent seed, neural network or alternate optimizer.

All four pairs must satisfy separate maximum-relative-error metrics for T and n, with bounds1e-4 fixed before extraction. These nonzero bounds measure independent method reproduction, not physical accuracy beyond the original n-section resolution. No reference rescaling, alignment, shape guessing or cropping occurs. The notebook retains all seven original diagnostic curves and an actual omission-of-extinction reconstruction, with source-original versus fresh condition comparisons. Its shaded ratio bands assume5percent component flux errors and are explicitly not measured uncertainty.
