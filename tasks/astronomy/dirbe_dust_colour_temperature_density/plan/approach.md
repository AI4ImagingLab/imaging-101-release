# Implemented monochromatic PTS greybody inverse

Observations d(b,y,x) and relative sigma(b,y,x) are real DIRBE quoted brightness in MJy/sr, at nominal wavelength lambda=(100,140,240)micrometres. Native sky-centre sampling is fixed. No filter, beam deconvolution or background subtraction is added locally. Real ZSMA already subtracts the zodiacal model; calibration and astrophysical residuals remain. The selected source method is the original PTS GreyBody.fit monochromatic fit, applied to independent sky samples. This is a deliberate effective-colour approximation and an application to new real data, not reproduction of the source paper's EAGLE galaxy experiment or a newly claimed passband-corrected published method.

For frequency nu=c/(lambda*1e-6), Bnu=2hnu³/c²/[exp(hnu/kT)-1]. Opacity kappa=.192*(nu/nu350)²m²/kg. Predicted I=Sigma*kappa*Bnu/1e-20 MJy/sr. Constants exactly match upstream h6.62606957e-34,k1.3806488e-23,c2.99792458e8,pc3.08567758e16,Msun1.9891e30. These historical constants are intentionally not silently modernized.

The optimizer preserves the original numerical flux parameterization: D=1pc, M is a solar-mass coefficient for an arbitrary one-steradian reference area; Sigma=M*Msun/pc². This is an algebraic unit transformation and assumes no physical cloud distance. Compute fluxJy=M*Msun*kappa*Bnu/pc²*1e26 and fit measuredMJy/sr*1e6, sigma*1e6. This exactly equals the radiance problem because the arbitrary area cancels in Sigma. Preserve operation order for independent numerical parity.

For every pixel minimize sum_b[(fluxJy_b(T,M)-1e6*d_b)/(1e6*sigma_b)]². No half factor or spatial regularizer. scipy.optimize.curve_fit uses the default unconstrained Levenberg-Marquardt method, initial(T,M)=(20,.01), absolute_sigma=False,maxfev5000 and upstream default LM termination tolerances. No positivity bounds, line-search changes or amplitude renormalization are added. Original positive-data guard returns zero pair when any flux<=0; all bound observations are strictly positive and all final fits physically positive and finite. Trial LM temperatures can produce exp overflow warnings, preserved and recorded; final evaluations are valid. Each line of sight is independent. Return maps[0]=T and maps[1]=Sigma, then recompute monochromatic radiance with the same expression.

Analytic local Jacobian: dI/dT=I*x/[T*(1-exp(-x))], x=hnu/kT; dI/dSigma=I/Sigma. Independent central differences and Rayleigh-Jeans/asymptotic tests check physics. Frozen source Planck, flux and full-pipeline arrays check upstream parity before final evaluation.

The separately labeled diagnostic computes quoted band brightness J_b=integral I_nu*R_b(nu)dnu / integral(nu_b/nu)*R_b(nu)dnu with the actual public response table. Spectral coordinate nu descends, so both integrals have the same negative orientation and their ratio is correct. Colour factor K_b=J_b/I(nu_b), and physical monochromatic brightness would be quoted/K_b. This does not alter the selected fit. Notebook compares residuals and K maps, and explicitly reports the resulting known passband bias. A beta sweep and two-band fits are independent sensitivity/identifiability experiments, not alternate truth.

Evaluate T and Sigma separately with uncentered cosine NCC and dynamic-range NRMSE. Reference is the independent original PTS fit, not actual cloud truth. NCC>=.999999 and NRMSE<=1e-5 are nonzero algorithmic tolerances, chosen before scoring local outputs, much larger than measured roundoff but far below meaningful parameter errors. No transformations or masks are used.
