## Remaining helper signatures and review figures

- `integrate_radii(log_pressures, planet_mass, planet_radius, temperature_spline, mu_spline)` returns a one-dimensional radius array, including the one-bar starting point. Inputs use log(Pa), kg, m, K and atomic mass units. It performs no file IO.
- `hydrostatic_radii(pressure, temperature, mu, planet_mass, planet_radius, star_radius, above)` accepts full ascending pressure/thermal/mass profiles and the visible-layer boolean mask. It returns descending visible radii [m] and positive adjacent widths [m]. `above` is fixed by cloud pressure, not reconstruction error.
- `visualization.spectra(raw, observed_model, original, high_wave, high_depth, predictive=None)` returns a two-panel Matplotlib figure with all 42 bands, a fresh full-grid spectrum and residuals in nominal uncertainty units. Optional predictive has shape `(sample,42)` and contains physical model draws, not noisy observations.
- `visualization.traces(chain, logp, original_logp)` returns two figures: all 50 trajectories for all eight parameters, and per-transition maximum posterior. Chain is `(50,1000,8)` and each log-probability array is `(50,1000)`.
- `visualization.corner(chain, original_chain)` returns an eight-parameter marginal/pair figure. Both inputs are `(50,1000,8)` in SI/log units. Display conversions are solar radius, Jupiter mass/radius, kelvin and the unchanged logarithmic/dimensionless coordinates. All samples are retained.
- `judge.validate(path)` returns the three validated arrays. `judge.prior(p)` evaluates a scalar prior in declared coordinates. `judge.evaluate(prediction, assets=ASSETS)` returns `(JSON-compatible report, exit_code)`. `judge.main()` handles required CLI arguments and report directory creation; report-write errors return 2 with stderr diagnostics.

The notebook's `clean_wave_ticks(axis)` only changes wavelength-axis tick locators and labels. It has no numerical effect on data, physics, inference or metrics. Final display polish is separately traced to the already completed full notebook measurement. The original native full sampler cell and its outputs remain unchanged; private rendering context does not appear in the canonical reconstruction path.
