# Shipped interfaces and execution

The task is self-contained. Its numerical runtime uses NumPy2.4.6 and SciPy1.17.1; Matplotlib3.11.1 is used only for maintainer figures. Source domain packages, FITS readers, compilers and original executables are confined to the private oracle archive. The public NPZ was converted from the unchanged source FITS without altering its62x150x150 float32 samples.

## Modules

`src.preprocessing` owns input-only support and spectral summaries:

- `search_mask(cube)` accepts a finite native `(62,150,150)` float32 intensity array in Jy/beam and returns `(mask,statistics)`. `mask` is boolean with the same shape; the dictionary holds observed median,MAD,spread,high threshold and growth threshold in Jy/beam. `_components(array)` implements the source extended connectivity using general connected-component labeling plus explicit unions. No hidden target or source mask is read.
- `first_moment(cube,mask)` returns a `(150,150)` float32 LOS velocity map in km/s, with NaNs only where the observational summary has zero denominator.
- The module declares signed-independent pixel magnitude and velocity-axis constants matching README. They are not parsed from Markdown.

`src.physics_model` owns the executable forward mathematics:

- `beam_kernel(major_arcsec=59.3287870284,minor_arcsec=58.6053617292,angle_deg=-79.446372986,cutoff=1e-4)` returns a normalized nonnegative float64 kernel. Defaults give `(15,15)`; modified beams are explicit forward-sensitivity diagnostics rather than alternate observations.
- `beam_convolve(cube,kernel,scale=1.0)` accepts channel,y,x arrays and returns the float32 zero-boundary SAME convolution with the actual source cutoff.
- `internal_rings(radius_edges_arcsec,parameters,density=1.0)` accepts float32 radii and either one `[rotation,dispersion,PA]` row or one row per radial knot. Rotation/dispersion are km/s,PA is degrees. It returns `(rings,metadata,edges)`. Internal rings are float64 storage of original float32 assignments with columns radius arcmin,rotation m/s,dispersion m/s,inclination rad,PA rad,density,z0 arcmin,center x/y pixel,systemic m/s,velocity-draw count. Metadata has17 numeric values: ring count,nx,ny,nchannels,box lower x/y,exclusive upper x/y,signed x/y arcmin steps,spectral CRPIX,first velocity m/s,channel step m/s,positive channel width m/s,instrumental sigma m/s,pixel area arcmin²,radial step arcmin. `edges` stores `[radius arcsec,PA deg,inc deg,center x,center y]` for the projected annular loss.
- `ring_geometry(shape,ring_edges,box_origin=(0,0),pixel_arcsec=16.00000038756)` returns boolean sky annulus and float64 disk azimuth in radians, each with `shape=(ny,nx)`.
- `azimuthal_loss(cube,observation,mask,ring_edges,metadata)` returns a normalized float32 cube and an8-value float64 summary. Loss metadata is `(nx,ny,nz,bloX,bloY,number_of_edges,noise,weight_power,blank_penalty_power,function_type)`. The selected function type is2,cos² weighting and blank penalty power1. Observation/model share channel,y,x axes. The normalization and mixed-dtype summation order are described in approach.
- `CloudRandom(seed=-1)` provides canonical uint32-based float uniforms and explicitly transformed normal draws. `canonical(n=1)`, `uniform(n=1)` and `normal(n)` return float32 arrays. It is a general sampling helper, not an inverse solver.
- `nearest_integer(value)` returns int64 halfway-away-from-zero indices.
- `cloud_cube(internal_rings,metadata,seed=-1,cdens=10.0,quadrature=None)` returns the float32 Monte-Carlo channel,y,x model. `_cloud_samples(geometry_key,metadata_key,seed,cdens)` has a bounded16-entry memoization of geometry-dependent quadrature only. Rotation and dispersion are not part of that cache and no output field,objective or model cube is cached. The returned raw model is newly evaluated on every call. Optional `quadrature` is a fixture-only `(ncloud,66)` float32 array: internal-ring index,three independent uniform variates and62 normal deviates. `_conditioned_cloud_samples` computes radius,azimuth,height,projected pixels and line-of-sight factors from these primitive inputs. The normal runtime passes `None`; the captured source projected coordinates are checked outputs, never supplied calibration.
- `zero_moment(cube,mask)` returns float32 integrated line intensity `(150,150)` in Jy/beam km/s, with missing summaries as NaN.
- `azimuthal_profile(moment0,parameters)` returns float64 `(41,5)` nuisance profile columns integrated sum,valid subpixel count,blank subpixel count,sky surface brightness,face-on surface brightness. The last two columns have Jy/beam km/s/arcsec² units. Only the observed moment image and supplied field geometry are used.
- `full_model(cube,mask,parameters,seed=-1)` returns `(model,profile)`: complete `(62,150,150)` float32 emission in Jy/beam plus that `(41,5)` profile. This is the selected original post-fit flux treatment, not a fitted pixelwise gain against residuals.

`src.solvers` owns initialization and inverse updates:

- `projected_velocity(coordinates,parameters)` accepts `(n,2)` x/y coordinates and source7-parameter vector `(Vsys,Vrot,Vrad,PA,inc,x0,y0)`, returning `(n,)` float32 km/s.
- `prepass_derivatives(coordinates,parameters)` returns `(n,2)` source float32 partials for rotation and PA, in dimensionless and km/s/degree units respectively.
- `prepass_normal_equations(coordinates,velocity,weights,parameters)` returns float64 `(chi,matrix,vector)` with scalar chi,2x2 matrix and length2 vector. It is independently compared with two original linearizations and analytic finite differences.
- `_gauss_jordan_inverse(matrix)`, `_damped_prepass_fit(coordinates,velocity,weights,initial,tolerance=.001)` and `_select_prepass_data(moment,parameters,inner,outer)` implement the actual normal-system inversion,inner LM and changing data-selection rules. Their returned arrays preserve the documented source precision.
- `initialize_rings(moment)` returns `(initial,details)`, where initial is `(41,3)` float32 physical profiles and details stores all40 fitted prepass states,counts,qualities and outer-loop statuses. The qualified copy-bound handling preserves all41 output knots.
- `ring_objective(cube,mask,ring_index,initial,noise,seed=-1,free_angle=True,repair_random=None,global_rotation_max=1120.,global_angle_limits=(-360.,360.),smooth=True)` builds the explicit annular objective. Standard reconstruction supplies the original global bounds computed from the observation-derived initialization and one persistent repair sampler. Its callable mutates a float32 trial vector exactly as the source bound rules require. `smooth=False` is an explicitly labeled forward-model ablation, not the standard bound method.
- `nelder_mead(objective,initial,steps,tolerance=.001,trace=None,diagnostic_iterations=None)` returns a dictionary with parameters,loss,converged,evaluations,iterations. When supplied, the trace list receives actual simplex points,values,sums and counts at each loop. A diagnostic iteration cap only truncates fixture tests and returns non-convergence; the full method uses the source stopping criterion and budget.
- `reconstruct(cube,seed=-1,smooth=True,progress=None)` returns `(fields,diagnostics)`. Fields is `(41,3)` float32 `[rotation km/s,dispersion km/s,PA deg]`. Diagnostics contains observation mask,first-moment map,initial profiles,prepass states/counts/qualities,all two-stage fitted fields/losses/evaluation and iteration counts,PA scatter and noise estimate. `progress(stage,ring,field,result)`, if provided, is called after each completed annular fit. The function raises on incomplete or scientifically rejected rings; it never filters the output to successful rings.

`src.main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz',seed=-1,progress=None)` reads only the public NPZ with `allow_pickle=False`, calls the complete reconstruction, creates the output parent if needed, writes all three named `(1,41)` physical arrays and returns `(result,diagnostics)`. It never loads references or fixtures. `src.main.main(argv=None)` implements `python -m src.main`, with optional input/output/seed arguments and textual ring progress. Importing the module does not select a Matplotlib backend.

## Standard data flow

`python -m src.main` → validate complete public spectral cube → recompute SEARCH support and velocity map → fit original40-ring 2D initialization → apply qualified bounded copy into all41 ring initializations → scale cube and fit all41 three-variable annuli → restore float32 intensity scale → compute selected auto-median PA → rescale/refit all41 two-variable annuli → restore scale → write physical named output arrays. No optional comparison,plot or evaluator is part of this inverse path.

## Standalone evaluation

`evaluation/judge.py --prediction ... --report ...` resolves references and metrics relative to its own file. Prediction/report paths remain caller-relative. `evaluate(prediction,reference_dir=None,data_path=None)` additionally supports isolated contract tests with explicit hidden/data locations. The Judge imports no solver,task source or submitted code. It contains only explicitly embedded acquisition calculations and independent profile metrics; it has no inverse optimizer or fitted-field cache.

`load_reference(directory)` prioritizes an existing actual `ground_truth.npz`; an invalid actual truth is an evaluator error, never a reason to fall back. This real task ships only `baseline_reference.npz`. `_arrays(path)` validates each required key,exact shape,real float dtype,finite values and nonnegative speed/dispersion. `load_configuration(path)` rejects boolean,string,negative and nonfinite boundaries. `profile_metrics(estimate,reference)` independently computes the two separate range errors and wrapped angular RMS, rejecting constant speed references and arithmetic overflow.

Every complete candidate is scored in all three quantities. A failed field gate returns valid-quality `fail` without the expensive forward calculation, explicitly marked `observation_consistency_evaluated=false`. Passing all field gates is insufficient for success: the evaluator then recomputes observation-only support,nuisance brightness and full physical emission from the submitted fields, and evaluates all1395000 observed voxels. Reports contain UTF-8 finite JSON status,passed,metrics,thresholds,errors. Exit codes are0 pass,1 valid failed quality,2 malformed prediction/evaluator/report-write error. No hidden output replacement or cropped evaluation occurs.

## Notebook and evidence

`src.visualization` provides `rms(array)` in the array's physical units, `signed_norm(*arrays)` with symmetric limits and neutral zero, and `spectral_slice(cube,angle_deg,radius_arcsec=None)` for a bilinear major-axis display of all62 channels (default181 radii from-1100 to1100arcsec). The latter respects the negative image-x angular step; it does not change evaluator support. `plot_data(cube,mask,moment,statistics,directory=None)`, `plot_operator(original_raw,fresh_raw,original_kernel,fresh_kernel,original_smoothed,fresh_smoothed,directory=None)`, `plot_fields(original,fresh,source_seed2,source_seed3,prepass,directory=None)`, `plot_residuals(cube,original_model,fresh_model,position_angle,directory=None)`, `plot_initialization(cube,initial,prepass,fresh,initial_model,fresh_model,directory=None)` and `plot_sensitivity(cube,nominal_model,variant_models,position_angle,directory=None)` return actual Matplotlib figures. `save_figure(fig,slug,numeric,caption,directory=None)` exports PNG/SVG/PDF,numeric NPZ and source JSON to an explicit directory or private `IMAGING_FIGURE_DIR`; without either it has no file side effects. Library imports never set a backend.

The canonical notebook is the active complete reconstruction/review entry point, distinct from the CLI. It uses cleaned modules, computes fresh fields and forward diagnostics, and loads separately identified original captures only for comparisons. Private original checkouts,binaries,FITS files,paper PDFs,capture scripts and logs are indexed in validation outside this package. Frozen NPZ fixture keys name actual original inputs/parameters/outputs and are consumed by named comparing tests; analytic and adversarial Judge cases are in unit tests. No synthetic observation generator is needed for this unchanged real acquisition; any displayed parameter/beam sensitivity uses these same observations.
