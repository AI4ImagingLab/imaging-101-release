# Implemented inverse mathematics

The acquisition contains all 383 existing OGLE-IV I-band measurements. Time t is HJD-2450000 in days; magnitude m and supplied error em are in mag. No epoch is omitted, reweighted, interpolated or synthesized. Convert f=10**(.4*(22-m)) and ef=em*f*log(10)*.4. The zero point 22 defines arbitrary relative flux units and does not estimate an intrinsic luminosity.

For geometry p=[t0,u0,tE], define tau=(t-t0)/tE, u=sqrt(tau**2+u0**2), A=(u*u+2)/(u*sqrt(u*u+4)). The mean flux is fs*A+fb. The units are days for t0 and tE, Einstein-radius units for u0, and magnitude-22 flux units for fs and fb. This is the published point-source, point-lens, rectilinear model for the isolated final stellar subevent. It contains no finite-source, limb-darkening, parallax or triple-lens correction. The 2014 paper explicitly fits this acquisition separately using the same model.

At each geometry, construct D=[A,1], w=1/ef and solve c=argmin ||diag(w)*(D*c-f)||^2 using numpy.linalg.lstsq with rcond=-1. c=[fs,fb]. There is no regularizer, fixed blend, nonnegative constraint or mean subtraction in the standard path. This is an exact linear elimination, not a separately initialized inverse iteration. Define the profiled objective chi2=sum(((f-D*c)/ef)**2), without a half factor or division by sample count.

The nonlinear search is scipy.optimize.minimize(method='Nelder-Mead') starting at [5380,.5,25], matching the original example. SciPy 1.17.1 defaults use a simplex perturbation of 5% for nonzero coordinates, reflection 1, expansion 2, contraction .5 and shrink .5; non-adaptive simplex, xatol=fatol=1e-4, maximum evaluations and iterations 200 times the three-dimensional search size unless stopping occurs first. No custom line search or gradient is used. tE<=0 returns infinite objective to match the original physical parameter restriction; this branch is not visited by the bound original trajectory. A failed optimization raises an error. Return abs(u0) to select the physically equivalent positive branch; tE and fs must be positive. Do not clip fb.

For independent differential validation, dA/du=-8/(u^2*(u^2+4)^(3/2)). Known u=1, far-field, time/reflection symmetry, weighted normal-equation orthogonality and magnitude roundtrip tests independently check the acquisition mathematics. Frozen original fixtures establish conversion, magnification, linear projection, objective and complete inverse parity.

The optional blend=False diagnostic removes the constant column and returns fb=0 after otherwise identical fitting. The notebook also computes a constant-flux weighted mean, an initial-geometry fit, a profiled impact/timescale landscape at fixed t0, and 40 residual-bootstrap fits with seed 4821. Bootstrap samples resample centered standardized measured residuals around the fresh fit, preserving flux-error weights through inverse magnitude conversion. These are labeled conditional robustness experiments, not new benchmark data or a calibrated posterior.

All five requested quantities are evaluated. Geometric errors are absolute errors in their own units. Flux error is norm([fs,fb]-reference)/reference_fs. Reduced chi-square is the observed flux-space objective divided by 383-5=378. Fixed boundaries are .01 day for t0, .001 for u0, .02 day for tE, .002 for normalized flux error, and 1.2 for reduced chi-square. These numerical reproducibility limits were proposed before extraction and checked against independent original starts, float32 representation and known bad predictions. No alignment, rescaling or dynamic-range normalization is applicable to the heterogeneous parameter vector.
