# Actual module interfaces and execution flow

`src.preprocessing.load_data(path="data/raw_data.npz")` returns unbatched float64 time, magnitude and magnitude_error arrays (383,), using allow_pickle=False. `flux_from_magnitude(magnitude,error)` returns flux and propagated error with the same shape, in magnitude-22 flux units. `magnitude_from_flux(flux)` returns magnitudes. ZEROPOINT=22 is explicit and agrees with the README.

`src.physics_model.separation(time,parameters)` returns dimensionless separation for parameters (3,)=[t0,u0,tE]. `magnification(time,parameters)` returns dimensionless A, shape matching time. `magnification_derivative(u)` returns dA/du, used by independent physics tests. `predict(time,parameters,fluxes)` returns flux (N,) for fluxes (2,)=[source,blend]. These functions have no filesystem or plotting side effects.

`src.solvers.fit_fluxes(amplification,flux,error,blend=True)` returns coefficients (2,) and modeled flux (N,); when blend=False the second coefficient is zero. `profile_objective(parameters,time,flux,error,blend=True)` returns scalar chi-square, or infinity for nonpositive tE. `reconstruct(data,initial=None,blend=True)` uses INITIAL=[5380,.5,25] when initial is None and returns two dictionaries. The first contains batch-first reconstruction (1,3) and source_blend_flux (1,2). The second contains flux, error, model, chi2 and nfev. Inputs are not modified. Failed minimization raises RuntimeError.

`src.main.main()` loads the public NPZ, reconstructs, creates output/ and writes output/reconstruction.npz. Standard invocation is `python -m src.main`. No reference assets enter this path. No library module changes the Matplotlib backend.

`src.visualization.comparison_figure(data,result,details,upstream)` returns a four-panel Figure with complete measured/fitted magnitudes, all standardized residuals, residual histogram and independent original-versus-fresh model difference. It does not write files. The notebook calls this function after a fresh reconstruction, then computes its six-panel ablation, landscape, bootstrap and trajectory comparison through local modules. The separately stored upstream NPZ is used only as an identified original reference. Historical paper Table 1 values are explicitly labeled and never used to generate the reconstruction.

`evaluation/judge.py` is independent of solver imports. Its load(path) validates both required keys, exact shapes, float32/64 and finite arrays. score(a,b,data) evaluates every required quantity and observation consistency. Hidden reference selection prefers ground_truth.npz when present, else baseline_reference.npz. Hidden assets are resolved relative to the Judge; caller prediction/report paths retain normal CLI semantics. Invalid physical parameters are malformed submissions. Missing/corrupt assets or invalid metric boundaries are evaluator errors. Reports use finite UTF-8 JSON and return codes 0 pass, 1 valid prediction below bounds, 2 malformed/evaluator/report-write failure.

test/fixtures/upstream.npz is consumed by stage and complete-pipeline parity tests. notebooks/reference_outputs/upstream.npz is consumed by review comparisons. evaluation/baseline_reference.npz contains the original five-parameter method estimate, not ground truth. Original source, environment, downloaded observations, capture scripts and logs remain in the private archive. There is no cross-task import and no upstream/domain dependency in the cleaned runtime.
