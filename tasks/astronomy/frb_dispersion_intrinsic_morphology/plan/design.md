# Shipped interfaces and caller flow

preprocessing.load(path="data/raw_data.npz") returns an unbatched dictionary: measurements[16384,162] float64 intensity U, frequencies[16384] float64 MHz, times[162] float64 seconds, good_channels[16384] bool, and noise_rms[16384] float64 U. weights(data) returns float64 inverse RMS for good channels and zero for excluded channels.

physics_model.gaussian_model(q,frequencies,times,ff=8,ft=4,analytic_time=False) accepts six parameters, F channel centers and T time centers, and returns model[F,T] float64 intensity U. The independent analytic_time branch uses Gaussian erf exposure integrals; ff controls frequency quadrature. K, NOMINAL_DM and REF_FREQ match the explicit README constants. Chunks of 128 channels limit memory; no samples are discarded.

solvers.initial_parameters(data) returns the raw-only six-vector initialization. fit_fixed(data,fixed=None,ff=8,ft=4,initial=None) returns the reconstruction dictionary and optimizer information: success, cost, function-evaluation count and termination message. reconstruction has shape[1,6], float64, in the declared parameter order. fixed maps names in KEYS to scalar values. When initial is None, initialization uses public observations. reconstruct(data,ff=8,ft=4) fits all six quantities without a warm start or fixed parameters. main.main loads data, reconstructs, writes output/reconstruction.npz and reports duration. Importing it does not change the plotting backend.

visualization.display_waterfall(array,good,factor=64) forms good-channel means for display, normally shape[256,162]. It does not modify fitting data. model_comparison(data,model) returns a full-window measured/model/residual figure with physical axes. The Notebook actively reconstructs all native observations, loads separately identified original Gaussian and failed-scattering diagnostic results, and computes parameter, fluence, likelihood, actual ablation and perturbation comparisons.

The standalone Judge embeds its own explicit full Gaussian response and imports no solver. It validates the exact metric configuration, required reconstruction key, declared shape, float64 dtype, finite values and physical positivity. Acquisition assets resolve relative to its file. It scores every good channel and all162 native time bins, writes UTF8 JSON, and returns0/1/2 for pass/valid quality failure/invalid input or evaluator error. Invalid cases have empty metrics; report-write failures produce a diagnostic and return2. No submitted code, alignment or hidden parameter identity is used. Extra NPZ keys do not substitute for the required reconstruction.
