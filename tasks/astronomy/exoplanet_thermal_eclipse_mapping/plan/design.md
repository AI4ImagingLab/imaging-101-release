# Shipped interfaces and actual flow

`python -m src.main` loads only data/raw_data.npz, calls reconstruct with default seed20261025,steps4000,burn400,components3, writes output/reconstruction.npz and prints minimum ESS/maximum tau. The only required output key reconstruction is real float64(1,32,64),axesbatch,latitude,longitude, stellar-normalized surface brightness per planet-normalized projected area. CLI creates output; no backend changes occur on import. No newly synthesized observations exist, so generate_data.py is omitted.

`preprocessing.load_data(path='data/raw_data.npz')` loads with allow_pickle=False and returns copied arrays without batch axis: time,measurements,uncertainty(126,),wavelength(1,),latitude/longitude(32,64),allfloat64. Units days,fluxratio,fluxratio,micrometres,radians. No historical target enters this operation.

Physics callables: `harmonics(lat,lon)` returns broadcast coordinate shape plus9real harmonics. `cells(n=20)` returns sixfloat64(n^2,)arrays radial lower/upper bounds, angular start/end and projected midpoint x/y; radii are planet normalized,anglesradians. `visible_areas(x,y,radius=1/.155313,n=20)` returns(n^2,)visibleprojectedareas. `geometry(time)` returns correctedoccultorX,Y,Z and uncorrectedobserverlongitude/latitude for a scalar day. `basis(times)` returns harmonicintegratedcurves(9,N)and tileareas(N,400). `paired_lightcurves(times)` returns(17,N)originalsignpairedbasisincludingunitstellaroffsetandareas(N,400).

`eigencurves(lightcurves)` returns covariance eigenvectors(16,16),scores(16,N),eigenvalues(16,),descendingwithfixedsigngauge. `design_matrix(lightcurves,scores,components=3)` returns(N,components+2),columnsuniform,constant,selectedPCs. `spherical_coefficients(parameters,pca_coefficients)` accepts(...,components+2)and(16,16),returns(...,9); the stellar nuisance offset is omitted. `brightness(coefficients,latitude,longitude)` is a pointwise harmonic contraction with compatible coordinate broadcasting. The reconstruction instead evaluates the grid H@coefficients directly. Every task-specific geometry, area integral, harmonic and PCA convention is executable locally.

Solver callables: `initialize_parameters(design,observed)` preserves the author sequential residual summation and scipy leastsq defaults, returning(D,)initial parameters. `log_probability(parameters,design,observed,uncertainty)` acceptsoneorbatchparametersandreturns(batch,)Gaussianlogdensitywithc0,bnonnegativeprior. `stretch_proposal(active,complement,random,scale=2.)` returns proposalpositions and(D-1)logz. `ensemble_step(positions,logp,design,observed,uncertainty,random)` copies its input positions/logp, performs a shuffled two-half proposal/acceptance update, returns positions,logp andbooleanacceptance. `sample_posterior(initial,design,observed,uncertainty,seed=20261025,steps=4000,walkers=32)` returns fullchain(steps,walkers,D)andperwalkeracceptance(32,). It explicitly consumes original single-move-choice RNG draws. `autocorrelation_time(chain)` returns(D,)Sokalwindowtausfromtime-first retainedchain. No domain samplers are imported.

`reconstruct(data,seed=20261025,steps=4000,burn=400,components=3)` computes fresh geometry/PCA/design, author leastsqinitializer, explicit sampler, retainedmeans, harmonicmap andpredictions. Returns image(32,64)and statedictionary: prediction(N,),mean_parameters(D,),spherical_coefficients(9,),chain(steps-burn,32,D),autocorrelation(D,),effective_sample_size(D,),acceptance(32,),initial(D,),design(N,D),pca_coefficients(16,16),scores(16,N),eigenvalues(16,),lightcurves(17,N),areas(N,400). ComponentsD=components+2. It reads no hidden reference/oracle/checkpoint.

Notebook-only visualization callables `map_image(ax,image,d,title,limits=None,cmap='magma',unit='Stellar-normalized brightness')`, `acquisition(d)`, `physics(d,s)`, `comparison(d,m,original_maps)`, `residuals(d,s)`, `posterior(d,s,original)` and `sensitivity(d,standard)` render actual calculations.
