# Shipped modules and execution flow

## Public acquisition and output

The standalone task reads data/raw_data.npz only. The five public keys are link_records(float64,1×496180×11), record_valid(uint8,same shape), projected_links(float64,1×2472×5), grid_xy(float64,1×38063×2), and rain_coefficients(float64,1×2×201×3). Their column conventions and units are defined in README. A zero with mask0 is unavailable, not an observed zero. Geometric calibration is input-only; rainfall-derived references are hidden and never supply calibration.

The command python -m src.main writes output/reconstruction.npz with only reconstruction, shape1×38063, float64, daily rainfall in mm. It actively executes the whole native96-interval target accumulation and does not read notebooks, fixtures or evaluation assets. It prints actual runtime. It neither imports visualization nor selects a plotting backend.

## Actual module interfaces

src.preprocessing.prepare(raw) accepts an NPZ-like mapping with the public arrays and returns the full valid chronological record table, float64(N,11), with missing polarization represented internally as NaN. For this binding N=465514. It validates raw shape, float64 values, uint8 binary mask and finite stored values; restores availability; performs original frequency, repeated-time and metadata-consistency checks; and returns a new table. It does not mutate raw.

src.physics_model.retrieve_links(data,projected_links,rain_coefficients,*,wet_dry=True,outlier=True,step8=True,wet_threshold=-1.4,specific_threshold=-.7,antenna_db=2.3) accepts the prepared(N,11) table, the2472×5 projected-link calibration and2×201×3 coefficient table. It returns a dictionary of six float64(N,) arrays: Dry(dimensionless0/1), F(dB·h/km), Pref/PminCor/PmaxCor(dBm), Rmean(mm/h). Unavailable derived estimates remain NaN. The native main defaults are explicit. wet_dry=False uses all available samples for reference estimation and omits wet/dry power suppression; outlier=False omits the outlier rejection. These comparison controls do not change bound observations.

The function computes the original rolling maxima, all-four-endpoint Euclidean neighborhood checks, neighborhood medians, wet/dry temporal extension, original F diagnostic convention, reference medians, power correction and nonlinear attenuation inversion locally. math.fsum preserves original extended-precision summation decisions without threshold padding. It does not call an upstream library.

src.physics_model.rainfall_from_powers(data,pref,pmin_cor,pmax_cor,rain_coefficients,*,antenna_db=2.3) accepts the same table, three(N,) inferred/corrected power arrays, the calibration table and an effective correction in dB. It returns a new(N,) intensity array in mm/h, using explicit log-frequency interpolation and the published power law. retrieve_links calls this function. The notebook also calls it directly for clearly labeled antenna-calibration diagnostics without rerunning unchanged reference inference. No synthetic observations are generated, so no generate_data.py is shipped.

src.solvers.climatological_variogram(timestamp,time_scale_hours=.25) takes an integer-like YYYYMMDDhhmm timestamp and numerical duration in hours. It returns(partial_sill,nugget,range), with variance units(mm/h)^2 and range in km, from the exact selected seasonal formula. The midnight day-of-year transition is preserved.

src.solvers.spherical_variogram(distance,sill,nugget,radius) evaluates the explicit spherical semivariogram on a numeric scalar/array of distances in km. It returns the same broadcast shape, in(mm/h)^2. The value at exact zero is zero; a strictly positive separation includes the nugget.

src.solvers.midpoint_observations(data,rainfall,projected_links,timestamp) selects finite rainfall at one interval and averages exact coincident projected midpoints. It returns positions(float64,K×2,km) and mean intensities(float64,K,mm/h) in first-appearance midpoint order. It raises ValueError if that interval has no valid observation. This selection is the specified inverse-data availability convention; it never crops the output grid.

src.solvers.interpolate(points,rainfall,grid,timestamp,*,method='OK',neighbors=50,chunk_size=256) accepts K×2 observation positions in km, K intensities in mm/h and Q×2 queries in km. It returns float64(Q,) intensities in mm/h. OK computes explicit spherical semivariogram matrices and unit-sum saddle solves for the nearest min(50,K) points. IDW computes inverse-square weights over all K points, with exact coincidence handled explicitly. A method outside OK/IDW raises ValueError. Chunking controls temporary memory only. SciPy cKDTree supplies neighbor search; NumPy supplies general linear-system solves. No domain reconstruction API, upstream import or saved inverse result is called.

src.solvers.reconstruct(raw,*,method='OK',wet_dry=True,outlier=True,retain_fields=False,**retrieval_options) is the complete native inverse pipeline. It calls prepare, retrieve_links, midpoint_observations and interpolate for every one of the96 target interval ends, accumulating each full field with the physical0.25h weight. It returns a dictionary with reconstruction(float64,1×38063,mm), data(the prepared table), stages(the six full link arrays), and timestamps(float64,96,exact integer-coded UTC interval ends). With retain_fields=True it additionally returns fields(float64,96×38063,mm/h), all actively computed. The default main does not retain those extra fields. This is a direct estimator; there is no optimizer iteration budget or early termination.

src.main.main() has no arguments and reads/writes the fixed standard paths relative to the current task workspace. The __main__ guard calls it; importing the module does not execute the reconstruction or change the Matplotlib backend.

src.visualization.export_figure(fig,directory,name,numeric,caption) writes a figure's PNG/SVG/PDF representations, compressed numeric NPZ and a JSON file recording consumers and file hashes. It returns the PNG path. src.visualization.image_panel(ax,image,title,extent=None,signed=False,limit=None) is a generic imported presentation helper; the active notebook uses its own direct scatter rendering for the irregular native grid instead. The visualization module imports pyplot but never calls matplotlib.use. Backend selection is confined to the external notebook execution environment. No cross-task runtime imports occur; presentation code is shipped independently.

## Independent evaluation

evaluation/judge.py imports only the standard library and NumPy. load_field(path) strictly validates reconstruction, shape1×38063, real float32/64 and finiteness. field_error(estimate,reference) computes full-field dynamic-range NRMSE, rejecting degenerate references and overflow. evaluate(prediction,evaluation_dir=None) resolves hidden assets relative to its own directory by default, prioritizes actual truth when present, and never falls back after malformed truth. It validates both numerical thresholds, rejects bool/string/nonfinite/negative values and malformed count thresholds, then evaluates full-field error and negative-value count. It returns the standard status/passed/metrics/thresholds/errors report. The main CLI accepts --prediction and --report, creates report parents and returns0/1/2 for pass/fail/error. It never imports or executes submitted solver code.

evaluation/baseline_reference.npz contains the actual complete original wet/dry field, not true rainfall. No ground_truth.npz is invented. metrics.json retains the pre-extraction source-only quality boundary, plus the physical nonnegativity check. The Judge's scalar metric is independently checked by known numerical cases; contract tests cover unavailable or malformed assets, overflow, poor fields, truth priority, foreign working directories and report-write failure.

## Frozen evidence consumers

test/fixtures/original_stages.npz stores the actual full original prepared table, Dry/F/Pref/PminCor/PmaxCor/Rmean arrays and daily field. Stage tests consume the prepared table and all six derived arrays. The complete daily field also provides independently recorded full-pipeline parity. test/fixtures/original_kriging.npz stores the actual original midpoint coordinates, midpoint intensities and complete spatial grids at three native times; its comparing test consumes every key.

notebooks/reference_outputs/original_comparisons.npz stores actual original complete wet/dry, IDW and original-script no-wet/dry daily results. The active notebook displays them with explicit source roles and independently computes the selected main and IDW method. original_instantaneous.npz stores the actual full-grid20:45UTC original intensity and its timestamp; the notebook compares the fresh field at that declared instant. These are comparisons only; the reconstruction pipeline does not read them.

All full source checkouts, R runtimes/libraries, original RDS files, PDFs, CSV conversions, capture scripts, failed/successful logs and temporary executed notebooks are private outside this task. test/validation.md indexes their source, exact revision, hashes, actual process results and intended consumers. No private runtime is needed to run normal task tests.

## Notebook flow and six scientific figure groups

The canonical notebook has explicit Problem, Data, Physics, Method, Results and Conclusion chapters. It loads only public observations for inverse computations, prints the actual Python/NumPy/SciPy/Matplotlib/backend/thread environment, and uses cleaned modules. It executes the complete selected96-interval spatial reconstruction, writes the declared submission and invokes the independent Judge on that fresh field.

Figure1 shows the entire network, native grid, full-time availability, frequency and link-length distributions. Figure2 explains actual measured powers, inferred/corrected powers, retrieved rain and missing-data-aware link diagnostics. Figure3 displays original/fresh full daily fields and signed implementation residuals, explicitly not truth error. Figure4 compares the complete native20:45UTC intensity map and all96 interval means/maxima. Figure5 preserves ordinary-kriging/IDW/no-wet-dry comparisons, with fresh IDW computation and clearly labeled actual original no-wet-dry results. Figure6 actively recomputes link intensities and whole-grid20:45UTC maps for three effective antenna corrections, without inventing new observations or calling those maps alternative daily reconstructions.

Each group exports PNG/SVG/PDF and its actual numeric sources privately via IMAGING_FIGURE_DIR. The six PNG outputs are embedded in the canonical notebook. The supervisor uses the actual shared research Python, a private kernelspec and subprocess.run(shell=False), records stdout/stderr separately, and captures the real nbconvert returncode/runtime. A timeout of3600s per cell allows the complete direct spatial calculation. Temporary executed artifacts stay private; only a real native0 permits replacing the canonical notebook with the executed version.
