# Implemented harmonic inverse

The selected source method is the explicitly supported scipy Lomb-Scargle branch, chosen before extraction. The default approximate Astropy NFFT branch was separately executed and is retained as an original comparison. Both operate on identical324 author-processed measured arcs. No local domain library supplies the inverse.

Split flattened measurements by counts. Sort each arc by increasing corrected elevation and use x=sin(e*pi/180)/cf, where cf is the known carrier half-wavelength in metres. SNR is already detrended; do not center it again. For n samples and span W=max(x)-min(x), use ofac=1/(W*0.005), hifac=8/(n/(2W)), nout=int(0.5*ofac*hifac*n), and the original inclusive linspace from1/(W*ofac) through hifac*n/(2W). Floating-point nout can be1599 or1600; do not silently replace it with an idealized fixed count. Retain h>0.5m.

For cosine vector C and sine vector S at a trial h define CC=C dot C, SS=S dot S, CS=C dot S, CY=C dot y, SY=S dot y. The unnormalized Lomb power is one-half times (SS*CY²+CC*SY²-2*CS*CY*SY)/(CC*SS-CS²). This evaluates the two-column normal-equation solution directly. Amplitude is2sqrt(power/n). Select the first maximum on the original grid. No optimizer, artificial iterations, regularizer, initialization or stopping condition applies. Forward diagnostics solve the two linear coefficients at the inferred height and reproject onto actual uneven x samples.

All324 heights are required, in fixed sorted native arc-file order. Source initial frequency codes1/20/5 mean L1/L2C/L5, not arbitrary channel labels. A fixed chosen model maps signal oscillations to vertical height but not soil water content. No actual height truth is available. The frozen maximum absolute difference bound1e-7m measures numerical extraction agreement; original reruns were bit exact. It does not claim submicrometre physical resolution: the spectral grid spacing is approximately0.005m. Float64 output is explicitly required to preserve this numerical contract. The no-GT reference is never used during inference.

Notebook comparisons freshly reconstruct grid spacings0.01/0.005/0.0025m and every-other-sample arcs, label them sensitivity experiments, and retain independent original fast/direct outputs separately. No benchmark observations are synthesized. Test-only known sinusoids validate phase, carrier scaling and dominant-peak recovery.
