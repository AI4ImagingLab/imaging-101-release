# Actual runtime and interfaces

python -m src.main loads data/raw_data.npz with preprocessing.load_data(path=None), calls solvers.reconstruct(data,precision=.005,stride=1), writes output/reconstruction.npz. Loading removes exactly the leading batch axis and returns copied numeric arrays. reconstruct returns float64(1,324); it has no file-writing side effects. Different precision/stride arguments are notebook sensitivity experiments only.

physics_model.forward(coordinate,height,coefficients) maps inverse-metre sample coordinates and a height in metres plus two voltage coefficients to a same-shaped voltage signal. spectrum(coordinate,signal,max_height=8.,precision=.005,min_height=.5) returns paired trial-height/amplitude vectors after the strict lower boundary. It explicitly evaluates harmonic sums and normal equations; no Astropy/SciPy spectral solver is imported. visualization.examples(data,result) returns measured-signal/spectrum comparisons; summary(data,result,original,fast) returns complete acquisition and numerical parity figures. These functions return Matplotlib figures and never alter a backend.

The standalone Judge imports only NumPy and its own strict NPZ checks; reference paths resolve from its file, command arguments from caller cwd. Actual ground_truth takes precedence if ever supplied, otherwise baseline_reference is used. The notebook actively reconstructs observations and supplementary variants, then loads private original arrays only for comparisons. Numeric fixtures are frozen original stages; no upstream package is imported by tests/runtime/notebook. Private source, receiver files, original processed pickles and logs remain outside the task.
