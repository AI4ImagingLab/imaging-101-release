# Shipped interfaces and actual call graph

## Public observations and preprocessing

`preprocessing.load_data(path=None)->dict` loads allow_pickle=False, checks exact shapes/dtypes/finiteness, and returns unbatched copies of the9 public arrays. Default path is task-relative data/raw_data.npz. `recordings(data)` yields two record dictionaries containing label, intensity(float64 count/255), native time/dt, mode_xy, wave_xy and independently known water_level. `window_specs(record,parameters=None)` yields all admitted native start/window/extension indices. PARAMETERS holds validated reference settings; G and water levels match README constants. Neither raw matrices of inferred wave quantities nor survey arrays are preprocessing inputs.

## Physics operators

`physics_model.analytic_signal(values)` accepts real temporal rows and returns complex128 analytic rows using an explicit FFT multiplier. `dmd(values,rank=6,dt=1.0)` returns periods, phases, amplitudes, eigenvalues, spatial_modes, retained singular_values and singular_values_full. Optical modes and periods are fresh computed diagnostics; principal phases are radians and periods seconds. `kappa_to_mu(kappa)` implements the native explicit dimensionless dispersion approximation. `dispersion_wavenumber(omega,depth)` returns rad/m; depth must be positive. `gamma_from_bed(omega,water_level,bed)` returns dimensionless predicted gamma with native depth safeguard. `phase_difference(phases,reference)` cancels global phase into principal radians. `ransac_trial_count(outlier_probability,desired_probability,sample_size=3)` supplies the adaptive proposal budget.

## Inverse modules and returns

`solvers.extract_modes(data,parameters=None)->list[record]` actively computes every admitted window from both raw count records. Each record contains label, mode_xy(Nm,2), wave_xy(Nk,2), water_level, dt, time, spectra and modes. Each mode dictionary contains key, record, start_seconds, window_seconds, period, omega, phases(Nm), amplitudes(Nm). Spectra include full computed singular values and all trial periods for each window. Approximate sizes Nm5075/26382, Nk2479/7555.

`fit_phase_plane(x,y,phase,rng,parameters=None)->(coefficients(3),inlier_indices,diagnostics)` implements native sequential adaptive RANSAC and normal-equation refit. rng is a NumPy RandomState, matching legacy source choice semantics; proposals are not prefetched. Coefficients are kx,ky in rad/m and intercept in rad. Diagnostics contain the native valid-trial counter trials, actual draw count draws, consensus_count and samples. Collinear or insufficient support raises rather than returning an invented plane. Each3-point normal solve and singular-sample skip follows the source order. Obsolete batching helpers are not part of the shipped implementation.

`estimate_wave_fields(records,seed=20261026,parameters=None,verbose=False)->list[field]` visits all selected modes, K sites and3 radii. Each field contains record,key,start_seconds,window_seconds,period,omega,radii(3),ks/mean_gamma/std_gamma(Nk,3),wave_xy(Nk,2),water_level. Unsupported entries use internal NaN; output submissions do not. A spatial KD-tree accelerates legitimate geometry searches; it is not an inverse solver. `aggregate_wave_observations(fields,parameters=None)->dict` applies native quality filters and returns xy(Nobs,2), gamma,mean_gamma,omega,water_level(Nobs). No survey is accepted by these signatures.

`fit_bed_point(gamma,omega,water,initial)->(bed,diagnostics)` minimizes the dimensionless RMS residual for one already fixed consensus; diagnostics reports optimizer_success,evaluations,gamma_rmse. `spatial_uncertainty(xy,raw_bed,radii)->array(Nb)` computes native NaN-propagating neighborhood SD, not a posterior uncertainty.

`fit_bed(reconstruction_xy,observations,parameters=None)->(submission,bed_diag)` visits all8963 requested sites and performs native consensus initialization, scalar fitting and neighborhood-SD validity. submission contains only reconstruction float64(1,8963) and validity bool(1,8963), invalid exact0 sentinel. bed_diag contains raw_bed,uncertainty,radii,consensus_counts,support_counts,gamma_rmse,optimizer_success arrays(Nb), with internal NaNs where unsupported, integer counts and bool optimizer flags. uncertainty means native local spatial SD, not posterior error. `reconstruct(data,seed=20261026,return_diagnostics=False,parameters=None)` returns submission, or `(submission,diag)` when requested. diag contains records,wave_fields,observations,bed and timings named modes_seconds,wave_seconds,aggregation_seconds,bed_seconds. Its complete wave run prints per-mode progress; optional diagnostics hold fresh computed arrays in memory.

The CLI flow is load_data -> reconstruct -> save the two declared arrays in output/reconstruction.npz. It does not read fixtures, source libraries, survey truth or archived wave fields. Any plotting backend is selected only by an explicit CLI plotting path, never library import. Notebook reconstruction uses the same fresh source modules and requests diagnostics; a separate notebook inspection of historical references never replaces this call.

## Independent standalone Judge

`evaluation/judge.py` never imports submitted code or src. `load_prediction(path)->(x,valid)` loads allow_pickle=False and returns unbatched vectors only after requiring exactly reconstruction/validity, shapes(1,8963), exact float64/bool dtypes, all-finite real elevations and exactly0 at invalid locations. Missing files, extra/missing keys, invalid dtype/shape or sentinel violations are malformed submissions. A missing physical estimate is represented solely by validity=False, never interpreted as a measured0m elevation.

`load_assets(assets)->(y,required,interior,bounds)` requires the independent ground_truth.npz survey, validates finite nondegenerate reference data and frozen footprint/config consistency, and returns the unbatched survey y, original required-support mask, fixed interior mask and metric bounds. baseline_reference.npz supplies only the two observation-support masks for scoring; its method values are not substituted for independent truth. The interior is a subset of original support. A missing truth asset is an evaluator error, not permission to fall back to a method reconstruction.

`score(x,y)->(ncc,nrmse)` computes standard uncentered cosine and RMS error divided by the comparison reference's dynamic range, using stable scale/log arithmetic to retain finite JSON for very poor finite predictions. `evaluate(prediction,assets=HERE)->report` returns status/pass/metrics/thresholds/errors. Six metrics are interior_ncc,interior_nrmse,all_valid_ncc,all_valid_nrmse,required_coverage,interior_coverage. Interior and all-valid physical scores use their respective survey ranges, and the two coverage metrics remain separate. Incomplete interior coverage produces a finite failing interior-metric convention and failed coverage; zero sentinels are never treated as physical depths. Empty/degenerate submitted support is likewise a valid finite failure; malformed hidden references are evaluator errors.

The CLI is `python evaluation/judge.py --prediction output/reconstruction.npz --report output/judge_report.json`. Hidden assets resolve relative to the Judge file, while prediction/report arguments are relative to the caller unless absolute. It creates report parents, writes UTF8 JSON without NaN/Infinity and returns0 pass,1 valid-but-failing prediction,2 malformed/evaluator/report-write error. Report-write failure emits a stderr diagnostic. This implementation is independent from the reconstruction's checkpoints and does not run any solver while scoring.

## Review-only visualization and notebook

`visualization.point_map(ax,xy,values,title,units,valid=None,cmap='viridis',limits=None,symmetric=False)` renders every location with grey unsupported points and colorbars in declared units. Symmetric maps use a zero-centered signed range. `observations_figure(data)`, `mode_figure(records)`, `wave_figure(fields)`, and `bed_figure(xy,submission,survey,native,required)` return Matplotlib figures and neither save files nor select backends. Plot helpers contain no reconstruction logic or external-library inversion. Numerical scores use the independent Judge's defined scoring routine; they are not silently redefined in visualization.

The notebook actively calls reconstruct once on all raw data and saves/evaluates its fresh submission. It then loads survey truth and named upstream references only for labeled comparisons. It plots acquisition, modal/phase/amplitude fields, wave quality, survey/native/fresh/error/coverage, gamma residual/local variation, actual repeated phase-neighborhood robustness, and separately executed downstream window/view/calibration refits. Estimated zeros at invalid locations are masked grey. Phase-noise probes use actual source-captured neighborhoods, independent RandomState seeds, and are labeled small-stage experiments. Temporal-window60s/90s and recording-view oblique/planview ablations use diag.wave_fields freshly computed in this execution, holding DMD and wave fitting fixed; they are not full-pipeline reruns. Water calibration copies diag.observations and changes the known level uniformly before a fresh full-grid fit.

The notebook prints interpreter, versions, runtime, stage timings and independent Judge results; its final measurement JSON is a temporary execution artifact archived privately after validation. Canonical notebook retains actual outputs. evaluation/baseline_reference.npz validity is the full original5615-site support and interior_validity is the separately frozen4410-site interior. Both recall and interior coverage are reported, and paired original/fresh scores use the same interior; own-valid scores remain explicitly distinct. Notebook upstream references contain exactly6consumed keys: first bed/standard_deviation/validity and independent repeat_bed/repeat_standard_deviation/repeat_validity. The separately qualified sequential_upstream.npz supplies same-config original bed/SD/validity for the primary native-vs-fresh map and paired metrics, preserving the earlier source runs as variability evidence. The separate failed_prefetch_local.npz stores the earlier failed local reconstruction/validity and is consumed only by the labeled failure-coverage panel/metric row, never as source truth or fresh recovery. Frozen source fixtures and final evaluation assets have consumers/provenance recorded in test/validation.md. No hardcoded scientific result substitutes for a missing run.
