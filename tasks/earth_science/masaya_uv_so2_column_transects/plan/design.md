# Shipped interfaces and execution

`src.preprocessing.load_data(path="data/raw_data.npz")` returns a dictionary of unbatched public arrays loaded with allow_pickle=False, without dtype conversion. `preprocess(wavelength,spectra,dark)` accepts wavelength (2048,), spectra (360,2048) or a single (2048,) row, and dark (2048,). It returns the fit wavelength (Nfit,) and corrected counts (360,Nfit) or (Nfit,). FIT_WINDOW=(310,320) and STRAY_WINDOW=(280,290), in nm. Rowwise reductions preserve the upstream operation order.

`src.physics_model.instrument_lineshape(fwem,k,aw,ak)` returns 400 normalized float64 samples. `optical_depth(parameters,cross_sections)` returns three separate dimensionless contributions, shape (3,1201). `forward(wavelength,parameters,model_wavelength,solar,cross_sections)` returns modeled counts (Nfit,). These pure functions explicitly implement absorption, asymmetric super-Gaussian profile, finite convolution, wavelength registration and cubic interpolation. MODEL_SPACING=.01 nm.

`src.solvers.fit_spectrum(wavelength,intensity,model_wavelength,solar,cross_sections,initial=None)` returns parameters (13,), covariance (13,13) and modeled spectrum (Nfit,). Default INITIAL is specified in approach.md. `reconstruct(data)` fits every measurement independently and returns SO2 (360,) and a dictionary with parameters, fit, parameter_errors, wavelength and corrected observations. Parameter errors are square roots of native covariance diagonal elements; they can be infinite and must be screened before display. `doas_comparison(data,details)` returns relative SO2 (360,), measured differential optical depths (360,Nfit) and fitted differential depths of the same shape. It is an explicitly labeled diagnostic, not the benchmark reconstruction path.

`src.main.main()` loads data, calls reconstruct, creates output/ and saves batch-first SO2 in output/reconstruction.npz. Invoke `python -m src.main`. Importing this module does not change the Matplotlib backend. `src.visualization.summary_figure(data,details,upstream)` returns a six-panel Figure containing measured spectra, original/fresh SO2, residuals, a representative spectrum and temporal behavior. It has no scoring or file-writing side effects.

The notebook actively calls cleaned reconstruct on all raw measurements. It compares with frozen upstream results, computes the DOAS diagnostic and optical-depth decomposition, and runs fresh profile-initialization sensitivity fits and a no-SO2 ablation. Archived reconstructions are used only as labeled original comparisons. Independent notebook measurements are archived privately.

The standalone Judge imports no solver. It validates exact shape (1,360), float32/64, finite values and a nondegenerate hidden reference, choosing ground_truth.npz when present and baseline_reference.npz otherwise. Its independent score(a,b) computes standard cosine NCC and dynamic-range NRMSE. Hidden paths are anchored to judge.py; prediction/report paths are relative to the caller. The UTF-8 report contains status, passed, metrics, thresholds and errors. Exit codes are 0 pass, 1 valid output below thresholds and 2 malformed input, evaluator failure or report-write failure.

test/fixtures/upstream.npz supplies independent numerical tests. notebooks/reference_outputs/upstream.npz supplies notebook comparisons; these distinct consumers justify both files. The baseline is the original method result, not truth. Original source, capture scripts, logs, downloads and review images remain in the maintainer archive outside the task. No synthetic benchmark generator is needed.
