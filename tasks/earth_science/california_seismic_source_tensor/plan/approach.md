# Implemented source inverse

The bound event is the eight-station native `examples/notebooks/solution/mtinv.in` acquisition. Twelve stations appear in a commented upstream tutorial, but are not the executed default configuration. Every one of the eight native stations and all three depth hypotheses are retained. Observations are actual instrument-corrected displacement records, not newly generated data. There is no known source tensor truth.

The README defines every radiation coefficient, decimal factor, axis, and unit. The unknown is the full symmetric tensor M[Nm] and a discrete depth h[km]. Let a=(MNN,MNE,MND,MEE,MED,MDD)/1e13. Each ten-trace Green calibration is in cm per1e20dynecm. `design_matrix` explicitly mixes the fundamental-fault traces with sin(alpha),cos(alpha),sin(2alpha),cos(2alpha). Its rows are station first, Z/R/T second, and time last. The equations preserve upstream factors0.166667 and0.33333 exactly. They approximate1/6 and1/3; this yields tiny nonzero DD leakage for an isotropic source, quantified in validation. The local method does not silently replace them by rational constants.

`window_waveforms` uses starts[32,32,31,31,31,31,31,32] and150samples of each231sample trace. No new filtering, recorrelation, interpolation, rescaling, or nuisance source parameters are introduced. Data and Green traces share1s sampling and0.02–0.05Hz filtering. Every sample is cast from native float32 to float64 without changing its stored value.

For a fixed depth, minimize J(a)=0.5*(d-Ga)^T W(d-Ga), where d is3600displacements[cm] and W is diagonal with station weight r/min(r), repeated450times. These are objective weights, not square roots that should be squared again. The gradient is G^T W(Ga-d), and the Hessian is G^T WG. The exact inverse solves (G^T WG)a=G^T Wd using a general numerical linear-system solve. Upstream uses custom Gauss-Jordan elimination; the local LAPACK solve preserves the same normal equations and differs below1e-15relative on the bound data. This closed-form inverse needs no initialization, iterations, step size, line search, regularizer, or stopping tolerance. Singular systems raise a numerical error instead of substituting a solution.

Run at all three depths[10,12,20]km. Compute VR=100*(1-weighted squared residual/weighted squared observation), and select the largest VR. Ties choose the first depth in array order. Convert a back to symmetric M and retain signed components. The optional deviatoric comparison has five coefficients and MDD=-(MNN+MEE); its vertical/radial DD term uses the native-0.5coefficients. Optional unweighted and station-subset runs are maintainer sensitivity experiments, not the CLI default.

Evaluation uses relative Frobenius error against an independently executed upstream full-tensor reconstruction, exact discrete depth agreement, and forward observation VR. The reference is a method result, never truth. All arrays use their declared scales; there is no alignment.1e-8relative tolerance exceeds independent solver-roundoff differences by seven orders while requiring eight significant digits of method agreement. VR>=74.46% enforces the native observation fit. These gates are reproducibility criteria, not evidence that Earth-model error is negligible. Observational uncertainty is not calibrated; notebook perturbation and leave-one-station-out summaries are sensitivity studies rather than confidence intervals.
