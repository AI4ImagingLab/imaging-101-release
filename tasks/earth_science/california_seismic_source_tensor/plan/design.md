# Shipped interfaces and execution

Standard command: `python -m src.main`, from task root. It loads only `data/raw_data.npz`, runs the local inverse, and writes `output/reconstruction.npz`. No upstream package or other task is imported. No synthetic generator is shipped because observations are reused.

`preprocessing.load_data(path='data/raw_data.npz') -> dict`: reads NPZ with allow_pickle=False, strips exactly the leading batch axis, and returns copies. Waveforms:(8,3,231)float32 cm; fundamental_greens:(3,8,10,150)float32 cm per1e20dynecm; station distances:(8,)float64 km; azimuths:(8,)float64degrees; coordinates:(8,2)float64degrees. File IO is its only side effect. `window_waveforms(waveforms) -> (8,3,150)float64` applies the fixed public registration. `distance_weights(distance) -> (nstation,)float64` returns distance/min(distance). Constants DEPTHS,NPTS,SHIFTS,STATIONS match README.

`physics_model.design_matrix(greens,azimuth,degree=6) -> (nstation*3*ntime,degree)float64`: explicitly evaluates calibrated radiation formulas; degree is5or6. It has no IO. `coefficients_to_tensor(a) -> (3,3)float64Nm` maps six native coefficients, or five deviatoric coefficients, to NED. `tensor_to_coefficients(tensor) -> (6,)float64` reverses the full-tensor mapping. `forward(greens,azimuth,tensor) -> (nstation,3,ntime)float64cm` predicts observations. `adjoint(matrix,residual) -> (degree,)float64` applies the transpose.

`solvers.variance_reduction(observed,predicted,weights) -> float` computes percent weighted explained energy. `solve(data,degree=6,weight='distance',stations=None) -> dict` runs every native depth. Defaults return reconstruction:(1,3,3)float64Nm, source_depth:(1,1)float64km, tensors:(3,3,3), depths:(3,), variance_reduction:(3,), predictions:(3,nstation,3,150)cm, condition:(3,)normal-matrix condition numbers, and best:int. All are newly computed. Optional stations is an index array; optional weight other than'distance' selects unit weights for notebook comparison. No checkpoint, cache, or hidden asset is read.

`main.main() -> result dict` calls load_data and solve, creates output/, and saves exactly the two required submission keys. Module import changes no plotting backend. `visualization.tensor_relative_error(estimate,reference) -> float` is Frobenius-relative error. `radiation_pattern(tensor,n=161) -> masked(n,n)` gives normalized lower-hemisphere equal-area n^TMn radiation. `plot_tensor_and_radiation(tensor,title='Fresh full tensor') -> Figure` and `plot_waveforms(observed,predicted) -> Figure` draw physical plots without writing files.

The notebook finds task root, imports cleaned modules, actively reconstructs raw data, and computes fresh full/deviatoric/unweighted, leave-one-out and noise-perturbed results. It loads `notebooks/reference_outputs/upstream.npz` only to compare an independently executed original method. The test fixture under test/fixtures has a different consumer: it freezes G,data,weights,all three source tensors and diagnostic scalars for numerical stage tests. This documented duplication is intentional evidence with two consumers; neither is read by solver runtime.

`evaluation/judge.py` is independent of src. Its CLI takes --prediction and --report, resolving those paths relative to the caller. Hidden reference and metric paths are relative to its own directory. It independently synthesizes predictions using public fundamental Green traces. It validates both required output shapes, exactfloat64dtype,finiteness,symmetry,depthset, and nonzero hidden norm. Reports use UTF8strictJSON and status/pass/metrics/thresholds/errors. Exit0meanspass,1validbelowthreshold,2input/evaluator/reportfailure. It never imports submitted code. Contract tests invoke it from other directories and cover malformed submissions and evaluator failures.
