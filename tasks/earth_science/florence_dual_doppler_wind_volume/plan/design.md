# Shipped interfaces and execution flow

The entry point is `python -m src.main`. `main()` loads `data/raw_data.npz`, reconstructs the full field, creates `output/`, and saves `output/reconstruction.npz`. Keys are `reconstruction` (eastward u), `northward` (v) and `vertical` (w), each real float64 (1,9,21,21), axes batch,z,y,x, units m/s. It prints objective/iteration/gradient diagnostics; the notebook separately stores fresh cleaned measurements under notebooks/reference_outputs. Importing src.main changes no backend.

`preprocessing.load_data(path='data/raw_data.npz')` loads with allow_pickle=False, removes the batch axis, and returns copied arrays: radial_velocity, reflectivity, azimuth, elevation and validity each (2,9,21,21); x,y each (21,); z (9,). Units respectively m/s,dBZ,radians,radians,dimensionless and metres. `normalize_observations(data)` returns scalar valid radial RMS, sqrt(sum(validity*velocity^2)/sum(validity)), in m/s.

`physics_model.fall_speed(reflectivity,z,freezing_height=5000.)` returns negative particle terminal speed (2,Z,Y,X), m/s. `projection(azimuth,elevation)` returns dimensionless east/north/up coefficients (2,3,Z,Y,X). `forward(winds,data)` takes float64 winds (3,Z,Y,X) and returns radial predictions (2,Z,Y,X) in m/s including terminal speed. `derivative(values,spacing,axis)` and `derivative_adjoint(values,spacing,axis)` preserve shape; spacing is metres. The latter implements the exact transpose of centered-interior/one-sided-edge first differences. `divergence(winds,data)` returns (Z,Y,X) anelastic divergence, s^-1. `objective_gradient(flat_winds,data,mass_weight=256.,prior_weight=1e-4)` takes 11907 flattened wind variables and returns scalar dimensionless cost and same-length gradient. First/last vertical-plane gradient entries are zero. Task-specific acquisition, density, regularizer and gradient mathematics is explicit NumPy code.

`solvers.reconstruct(data,mass_weight=256.,prior_weight=1e-4,tolerance=1e-9,max_iterations=2000)` uses general SciPy L-BFGS-B with explicit local objective/gradient, bounds +/-100 m/s, zero initialization, history10, factr1 and maxls40. It returns winds (3,9,21,21), radial predictions (2,9,21,21), and a state dictionary with objective, iterations and projected_gradient_max. An optimizer warning raises RuntimeError. It reads no reference, checkpoint or oracle assets. No observations are synthesized, so generate_data.py is omitted.

Notebook visualization callables are `image(ax,array,data,title,unit='m/s',bound=None,cmap='RdBu_r')`, `acquisition(d)`, `physics(d)`, `volume(d,m)`, `comparison(d,m,a)`, `residuals(d,m,p)` and `sensitivity(d,standard)`. Except image they return (Figure,numeric_source_dictionary). Comparison loads independently frozen original fields only for review. Residuals computes zero-air-wind predictions; sensitivity performs five prior and three continuity refits. They do not replace standard reconstruction or modify public acquisition.

The six-chapter notebook actively solves exact bound raw data, invokes the independent Judge on fresh output, and compares original arrays from notebooks/reference_outputs/upstream_measurements.npz. Canonical notebook retains executed outputs and prints actual executable, package paths, versions, backend and threads. Private temporary notebooks, PNG/SVG/PDF groups and numeric sources stay outside the task.

`evaluation/judge.py` imports no solver. It resolves metrics/reference relative to its own file, validates exact keys/shapes/float64/finiteness, and scores all three components. CLI prediction/report paths are relative to the caller. It returns 0/1/2 for pass/valid fail/error and writes status,passed,metrics,thresholds,errors JSON. Frozen test fixtures contain original preprocessing, arbitrary-case cost/gradient and full field; tests consume arrays without upstream imports. Unit tests cover metric cases, malformed/poor predictions, evaluator failures, foreign-cwd execution and backend imports. Provenance and tolerance evidence are in test/validation.md.
