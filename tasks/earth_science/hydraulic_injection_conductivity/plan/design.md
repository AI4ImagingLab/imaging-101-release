# Shipped callable interfaces and data flow

`preprocessing.prepare(raw)` validates public hydraulic_head float(1,30,29)m and well_indices integer(1,30,2)zero-based cells, including uniqueness/interior-column bounds. Returns observed(870)float64 and wells(30,2)int64. It performs no writes and reads no hidden asset. Constants NROW75,NCOL100,GRID_METRES10,WELL_RATE25,RECHARGE.001,NOISE_VARIANCE.25 agree with README.

`physics_model.HydraulicModel(wells)` stores listed cells and row-major observation/exclusion indices. `assemble(log_conductivity,serialize=True)` accepts7500logKsamples and returns7350×7350CSCmatrix and7350×30right-hand sides. Serialization preserves original real32/fixed-text conductivity precision. It explicitly assembles harmonic conductance, recharge, well sources, eliminated fixed heads and transverse no-flux boundary. `forward(log_conductivity,full=False,head_precision='single')` factors and solves all right-hand sides, returning870ordered heads. With full=True it returns(observed,heads), where heads is(experiment,75,100). Single output is float32; head_precision='double' is an explicitly labeled numerical diagnostic. No source library, file or executable is called.

`covariance_operator(vector,length_scale=200.)` returns7500float64samples of the full stationary exponential prior covariance times vector. Circulant embedding, FFT, restriction and ordering are local. `solvers.prior_eigenpairs(n_modes=50,length_scale=200.,seed=1234)` returns descending eigenvalues(n_modes)and vectors(7500,n_modes), computed from that operator. The seed selects a general eigensolver numerical start; no truth or frozen basis is loaded.

`jacobian_products(model,field,base,directions,precision=1e-8)` accepts7500field,870base heads and7500×ndirections, returning870×ndirections float32 finite-difference derivatives. Source perturbation/rounding rules are explicit. `inverse_data_covariance(HZ,variance)` returns a callable applying the double-precision Woodbury inverse of HZ HZᵀ+variance I. `cokriging_candidates(HX,HZ,Z,X,rhs,alphas)` returns7500×24candidate fields and1×24mean coefficients for the standard24damping values. It implements the explicit saddle equations, without target knowledge or imported inversion functions.

`objective(field,predicted,observed,U,eigenvalues,X,beta=None)` returns the scalar data-plus-low-rank-prior objective. A supplied beta evaluates a damping candidate's drift; beta=None analytically eliminates it for line search. `variance_diagnostics(HZ,HX,Z,X,alpha)` returns two7500vectors: the explicitly named source heuristic, including its source upper clip, and the independently complete unknown-mean conditional covariance diagonal. The source missing lower-block contribution is disclosed; the second result is never relabeled as independent geological uncertainty.

`reconstruct(raw,n_modes=50,max_iterations=10,relative_tolerance=.01,compute_variance=True)` performs the entire selected inverse. Returns reconstruction(1,75,100), predicted_heads/initial_heads(1,30,29), trace(list of scalar dictionaries), best_iteration, eigenvalues/eigenvectors, last_linearization(HX,HZ,Z,X,alpha), and optional source_variance_diagnostic/conditional_variance(1,75,100). It does not write files or read references. Each trace entry identifies objective, relative change, head RMS, selected damping and line-search use, or an explicit nonprogress stop. No progress bar/plot backend changes occur on import.

`python -m src.main` loads data/raw_data.npz from the task working directory, calls reconstruct with standard defaults, writes exactly reconstruction to output/reconstruction.npz, and prints runtime and convergence trace. `generate_data.perturb_heads(raw,sigma_m=.1,seed=124)` copies raw arrays and adds independent Gaussian measurement noise in metres to all870heads, leaving listed well geometry untouched. It is a notebook diagnostic helper, not the bound dataset generator; invalid/nonfinite/negative sigma is rejected.

`evaluation.judge.evaluate(prediction,evaluation_dir=None)` is independent of src. It validates real float32/64shape(1,75,100), finiteness, strict finite numeric boundaries and required hidden assets. Actual ground_truth.npz takes precedence; a malformed actual truth never falls back to baseline. `field_metrics(x,y)` implements independently known scaled cosine and range-NRMSE. `hydraulic_rms(field,raw_path)` independently assembles harmonic flux equations from legitimate public observations/calibration and measures all870heads. All scalar metrics must remain finite; overflow/invalid conductivity produces error with empty metrics. CLIprediction/report paths follow caller cwd; hidden paths follow the evaluator. Reports are UTF-8strict JSON; exit0/1/2means pass/fail/error and report-write failure returns2.

Source numeric fixtures are hidden test inputs only: eight full native head fields, first directional Jacobian, all24co-kriging candidates and covariance eigenpairs. The standard implementation never loads them. Notebook original_reconstruction.npz contains independently reproduced source field/heads/reported variance, explicitly labeled separately from actual simulation truth. Tests cover source stages, whole pipeline/physical criteria, exact small covariance/saddle cases, data/generator contracts, poor fields and standalone evaluator/CLIadversarial cases. No cross-task imports occur.

Spatial map axes retain equal physical aspect; abstract observation matrices use independent axis scales. No library selects a backend.
