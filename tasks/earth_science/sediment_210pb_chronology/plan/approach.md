# Implemented approach

The input is all 14 measured layers. Bottom mass depth m is in g/cm², excess activity A and its analytical standard deviation σ are in Bq/kg. The surface has zero age and mass depth. Within layer k, initial activity a(k) and accumulation rate w(k) are constant. Its duration is Δt=Δm/w, its bottom age is the cumulative duration, and its predicted average activity is a exp(−λt_previous)[1−exp(−λΔt)]/(λΔt), λ=0.03118 yr⁻¹. The model assumes deposition without redistribution. The code evaluates the original formula directly, including subtraction order; an independent quadrature test validates the integral.

The canonical proposal sample consists of z(j)=Φ⁻¹((j+0.5)/N), j=0..N−1, where Φ is the standard normal cumulative distribution and N=14. Two independently shuffled copies define paired proposals. The author library generator rounds to four decimal places. `canonical_proposals(n=14, seed=20261029)` uses Python random's shuffle and reproduces preceding sizes 5..n because the author generates a library in that order. This is algorithm state, never a measurement or hidden object. Tests check distribution/support without requiring a seed to produce an exact sample. An independently shuffled seed20261030 is actively reconstructed in the notebook and compared with a separate original run.

For each parameter case p=(mean A, mean w, relative σA, relative σw), proposals are a=mean A(1+relative σA z1) and w=mean w(1+relative σw z2). The map's original floor is w≥0.2×0.0385 g/cm²/yr; it uses the global nominal mean rather than the scanned mean. The floor is inactive throughout the selected domain. The original plotting routine omits the floor, preserved when profiling rounded exchange results and verified on these positive proposals.

The selected native grid has 30 divisions per axis, 810000 cases. Nominal means are [563,0.0385,0.19,0.21], factors [0.2,0.25,0.25,0.30]. Axis i has values mean(i)(1−factor(i))+j×2factor(i)mean(i)/30 for j=0..29: the upper endpoint is excluded. Axes nest A,w,σA,σw, preserving first-minimum tie handling. These are model search settings, not acquisition calibration.

For each layer, evaluate every remaining paired proposal using accumulated previous age and that layer's measured mass thickness. Select the first proposal minimizing the squared unweighted activity residual, remove that pair, and advance age. This is the actual greedy algorithm, not a globally optimal permutation search. It does not weight individual candidate choices by σ, since all candidates at a given layer share that σ. The final score is χν=sqrt(sum[(predicted A−observed A)/σ]²/(N−4)); no time-marker penalty is used. There is no gradient, line search, iterative optimization stopping rule or additional regularizer: the finite grid is exhausted. Independent cases are batched in groups4096; this changes neither per-case arithmetic nor candidate ordering.

The multi-script upstream workflow formats map and best parameters to two decimals for mean A, four for the other parameters, and three for χν. Local reconstruction deliberately reproduces this exchange precision before reporting profiles and selecting confidence groups. It retains the unrounded optimum separately as a diagnostic. The confidence interval uses Δχ²=4.72 for four parameters: upper score=sqrt(minimum_rounded²+4.72/(N−4)). Divide the score interval into three equal widths. All selected cases are retained in the three groups; no scientifically relevant group is discarded. Profile flux A0×w×10 converts Bq/kg times g/cm²/yr to Bq/m²/yr.

Truth is the independent varve bottom ages in the formal paper's TableS1. Surface age zero is collection2007. No varve information enters inversion. Mean SAR inferred by differencing these uncertain ages is not labeled exact truth, and neither is inferred initial activity. Judge therefore compares all ages with actual varves and evaluates every other declared output through positive deposition, mass-duration consistency, full decay consistency and the measured activity errors. Two independent original normal libraries establish fixed acceptance criteria before local extraction. The original runs demonstrate that smaller activity χ need not improve agreement with varves.

Age NRMSE is RMS(age−varve age)/(65−5 yr); NCC is uncentered cosine similarity. Boundaries are in metrics.json. The observation χ uses N−4=10 degrees of freedom. Both physical relative consistency metrics have a1e−8 numerical bound. All arrays retain physical scales; there is no alignment, cropping, reference substitution or per-case rescaling.
