# Shipped execution design

`python -m src.main` calls `run(output_path=Path('output/reconstruction.npz'))`. It loads observations, actively evaluates the entire native grid, constructs the rounded reported profile, writes the four output arrays and prints runtime, minimum χ, parameters and all confidence group sizes. `run` returns a dictionary of float64(1,14) arrays. Importing the CLI has no plotting/backend side effects.

`preprocessing.load_observations(path=Path('data/raw_data.npz'))` returns three float64(N,) arrays: bottom mass depth, activity and reported uncertainty. It validates fourteen finite layers, increasing mass depth and positive errors. `canonical_proposals(n=14,seed=20261029)` returns two float64(N,) canonical shuffled normal samples with four-decimal precision. The seed is algorithm reproducibility state and may change for sensitivity experiments.

`physics_model.layer_activity(initial_activity,rate,mass_thickness,previous_age)` broadcasts numeric arrays and returns Bq/kg under the exact layer integral. `physical_profile(mass_depth,ages,initial_activity)` accepts one-dimensional arrays and returns the observation prediction after deriving rates from mass and age differences. `DECAY_CONSTANT` is in inverse years and matches README.

`solvers.profile_batch(parameters,mass_depth,activity,error,z1,z2,clip_rates=True)` accepts parameters(B,4), observed vectors(N,) and paired proposals(N,). It returns scores(B,) and profiles(B,5,N), ordered initial activity, accumulation rate, bottom age, averaged activity, flux. `parameter_grid(resolution=30)` returns float64(resolution⁴,4), upper endpoints excluded. `reconstruct(mass_depth,activity,error,seed=20261029,batch_size=4096)` returns the best reported profile(5,N) and a details dictionary containing rounded/unrounded parameters(4,), minimum χ scalar, grid(810000,4), scores(810000,), three lists of rounded cloud parameter arrays(K,4), and both normal proposals(N,). It reads no hidden arrays and writes no files.

`evaluation/judge.py` is standalone and imports only standard-library modules and NumPy. `evaluate(prediction_path,asset_dir=HERE)` resolves evaluator assets relative to the supplied evaluator directory, validates the NPZ contract and returns the standard JSON report. Public raw observations are used only for observation/physical consistency. `score(prediction,truth,mass,activity,error)` implements independent numerical scoring; no solver module is imported. CLI prediction/report paths follow caller cwd, hidden files follow `__file__`; exit codes0/1/2 mean pass/valid failure/error. Report-write failures return2. Zero-range or nonfinite evaluator references are errors, not NaN/Infinity reports.

`visualization` is used only by the notebook for confidence envelopes and scientific figures. The active notebook calls local reconstruction for both independently captured seeds, uses original frozen profiles only as explicitly labeled comparisons, evaluates the fresh primary output with the standalone Judge, and shows all three confidence groups, independent varves, complete activity data, parameter topology and initial-activity/accumulation histories. It reports actual runtimes and does not call an upstream library. Optional saved PNGs in output are review exports; canonical notebook outputs retain the figures after these exports are archived privately.

`test/fixtures/upstream_stages.npz` contains101 parameter/profile/χ cases from original functions and the independently measured varve table, with recorded provenance in validation.md. `notebooks/reference_outputs/upstream_profiles.npz` contains the two separate original runs. `evaluation/ground_truth.npz` stores actual measured varve ages plus their analytical uncertainties; it does not contain or imply true initial activity/SAR. The raw input contains only the three measured columns and no algorithm proposals or target-derived calibration.
