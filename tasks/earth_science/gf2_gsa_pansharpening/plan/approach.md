## Explicit 23-tap interpolation

Let c=2*[0.5,0.305334091185,0,-0.072698593239,0,0.021809577942,0,-0.005192756653,0,0.000807762146,0,-0.000060081482]. The symmetric 23-tap filter is concat(reverse(c) excluding its last element,c). Starting with a channel-first image, insert MS samples into zero-based odd indices in the first twofold upsampling stage. Insert intermediate samples into even indices in the second stage. Correlate every row and then every column with the filter, using periodic wrap. The zero-insertion arrays are float64, preserving original phase and rounding. An impulse at MS(row2,column3) peaks at PAN(row10,column14). A constant image is preserved to the supplied filter-coefficient precision. This is the exact source interpolation, not a substitute bicubic operation.

## Adaptive Gram-Schmidt intensity and gains

Let Ub be the interpolated band and meanb its spatial mean. Define centered bands Vb=Ub-meanb, native centered MS Lb=MSb-mean(MSb), and centered PAN h=P-mean(P). Spatially match h to the 64-by64 native grid at half-pixel centers. The upstream call passes cv2.INTER_CUBIC in the third positional slot (dst), so the actual interpolation is the default linear operation, not cubic. Independent tests compare that call with explicit linear and cubic calls: linear is bit-exact, cubic differs by up to0.06815 normalized units. We preserve actual published code behavior and disclose the discrepancy rather than silently correcting it.

For ratio4, each downsampled value is the linear average at source positions (4r+1.5,4c+1.5). Float32 difference-form interpolation preserves upstream arithmetic: top=a+(b-a)*0.5, bottom=c+(d-c)*0.5, result=top+(bottom-top)*0.5. The four source values are at rows4r+1,4r+2 and columns4c+1,4c+2. This exactly matches captured original stage arrays without using OpenCV locally.

Fit alpha=argmin ||[L1,L2,L3,L4,1]alpha-h_low||² by numpy.linalg.lstsq(rcond=None). The unknown regression coefficients describe statistical component substitution using observed inputs; they are not claimed to be independently calibrated nonnegative sensor bandpasses. Evaluate I=[V1,V2,V3,V4,1]alpha on the PAN grid and subtract its mean. The source's gain is gb=cov(I,Vb;ddof=1)/var(I;ddof=0). This deliberate sample/population convention gives a factor N/(N-1); it is preserved and documented. Detail delta=h-I. Set Zb=Vb+gb*delta, recenter Zb to meanb, then clip to[0,1] and output uint8(255*Zb), truncating toward zero. There are no iteration, initialization, step-size, line-search or stopping parameters. A zero-variance I is undefined; the local validation guard rejects it rather than propagating the original divide-by-zero/uint8 cast artifact. The bound observations are nondegenerate and exact original parity is preserved.

## Diagnostics and physical limits

The declared surrogate degradation computes D(B5*X) by box smoothing followed by decimation from zero indices in steps of four. Its residual against native MS is a diagnostic under that surrogate. The correlation of gradient magnitudes with native PAN measures edge agreement. Neither is a calibrated sensor likelihood or high-resolution spectral truth. Missing native PSFs and spectral weights are not estimated using an unavailable answer. Tests check original interpolation and complete GSA parity, impulse phase, low-pass sum/DC conservation, translation equivariance, output bounds and the zero-detail ablation.

## Evaluation

There is no independently measured high-resolution spectral truth. Original GSA on exactly the bound native observations supplies the hidden standard-method reference. Uint8 output is compared without crop, band permutation or rescaling using uncentered cosine NCC and dynamic-range NRMSE. Predeclared numerical-agreement thresholds are NCC>=0.999999 and NRMSE<=1e-6. Original float64 and cleaned replays are bit-exact; the nonzero floor accommodates numerical equivalence rather than physical accuracy. A one-level error across the image fails by several orders of magnitude. Quantization is part of the published implementation and explicit output contract. Other physically useful fusion methods need not agree with this strict standard-method benchmark.
