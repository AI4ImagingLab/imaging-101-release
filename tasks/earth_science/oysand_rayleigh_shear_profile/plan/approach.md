# Implemented forward and inverse mathematics

The task reconstructs seven physical unknowns: thicknesses h1..h3 in km internally and four Vs in km/s. Final outputs multiply by1000 to m and m/s. The fourth layer is a half-space; its stored thickness1km is a source placeholder never a finite bottom boundary. Density is1.95g/cm^3 throughout. Poisson ratios nu=(.3,.3,.49,.49) are fixed. Vp=Vs*sqrt((1-nu)/(.5-nu)). The optimizer retains the four fixed nu columns, hence ndim=11, to preserve original random draws and restart convention; it does not infer eleven independent unknowns.

There is no depth finite-difference grid: every constant-property layer is propagated analytically through its physical thickness, with exact interface continuity. Internal density in g/cm^3 and speeds in km/s imply elastic moduli in GPa, consistent with wavenumber in km^-1; output speeds and thicknesses are converted explicitly.

For angular frequency omega=2*pi/T and k=omega/c, layer vertical wavenumbers derive from k^2-(omega/Vp)^2 and k^2-(omega/Vs)^2. Propagating layers use sinusoidal factors and evanescent layers use exponentially rescaled hyperbolic factors. Local var evaluates these factors with explicit exponent protection. dnka constructs the5x5Dunkin compound matrix, whose components represent minors of the displacement/traction transfer relation. dltar4 initializes the decaying bottom-half-space vector, multiplies through each finite layer upward, and rescales after every product with normc; positive scaling preserves secular roots. If e is the five-component reduced compound boundary vector and C is the current layer compound matrix, the upward step is e_new[i]=sum_j(e[j]*C[j,i]), followed by division by max(abs(e_new)). The vector encodes displacement/traction minors; this Cauchy-Binet propagation enforces continuous interfaces while preserving the decaying half-space boundary subspace. Its first component gives the stress-free-surface secular function. The local code exposes every matrix entry, boundary initialization and normalization rather than wrapping a reconstruction library.

gtsolh takes five Newton steps for a homogeneous Rayleigh speed estimate in the minimum-shear-speed layer. The first root search starts at0.9times that estimate; subsequent fundamental searches begin at the preceding-period root minus1.5dc, with the original initial-speed lower bound. getc carries the fundamental-mode branch over increasing periods. getsol scans phase speed in fixed dc=.0001km/s increments until a sign-changing secular bracket is found, respecting the minimum shear speed and physical bounds. nevill refines a bracket by safeguarded polynomial interpolation/bisection with the original relative convergence1e-6 and original iteration limits; missing fundamental roots raise DispersionError. No higher-mode, group-speed, water-layer or alternate transfer model is substituted. Each period retains its measured value; no wavelength resampling is used.

The objective is J=sqrt(mean(((c(T)-cobs(T))/sigma(T))^2)) across all30 measurements. cobs and sigma use km/s; sigma is half the author interval width, not assumed independently Gaussian. Non-monotone Vs receives infinite optimization penalty; numerical root failure likewise receives infinity. There is no additional regularizer. Bounds are h=(.0004..0012,.0005..002,.004..012)km and Vs=(.08...16,.10...18,.12...22,.15...28)km/s, with each nu fixed as above. These are explicit conditional model/search priors, not measurements of true layer geometry.

Initialization uses legacy RandomState24713, population40. Draw all three finite thicknesses uniformly. Interpolate intermediate Vs linearly over cumulative sampled depths and clip by each layer's bounds. Finally draw all four fixed nu columns, consuming the original RNG sequence even though their bounds coincide. Velocities start at zero and personal/global bests are initialized from all40objectives.

For each generation draw independent40x11uniform cognitive/social arrays. Each particle has velocity v=.7298*v+1.49618*r1*(personal-x)+1.49618*r2*(best-x). Boundary repair computes one scalar factor from the first bound hit along this proposed velocity, scales the entire velocity, and updates x. Evaluate J and immediately update personal and global best with <= ties. This is the source's sequential/immediate-update workers1 variant; later particles can see a newly improved global best. No general-purpose optimizer replaces these updates.

Competitive restart uses radius=max(norm(x-best))/sqrt(4*ndim), delta=log(1+.003*population)/max(.2,log(.01*maxiter)). If radius<delta, reset the worst n personal-best particles, where n=floor((population-1)/(1+exp((iteration/maxiter-1+.5)/.09))). Their current/personal positions are uniform within bounds, velocities zero and personal loss1e30. Retained global best is unchanged.
