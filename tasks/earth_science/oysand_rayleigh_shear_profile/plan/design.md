# Actual interfaces and execution

All runtime acquisition and inverse mathematics is local NumPy code. Matplotlib is used only for notebook review/export. There is no disba/stochopy/evodcinv/Numba import, external binary, cross-task import or synthetic data generator. Original packages exist only in an isolated private oracle environment.

- preprocessing.load_data(path=None) reads task-relative data/raw_data.npz with allow_pickle=False, removes batch1 and returns period,phase_velocity,uncertainty float64vectors30long, in s,km/s,km/s. No writes.
- preprocessing.initial_population(rng,popsize=40) accepts RandomState and returns popsize-by11float64physical-coordinate particles, containing3thickness(km),4Vs(km/s),4fixednu. BOUNDS is11x2 and POISSON length4.
- physics_model.phase_velocity(period,thickness,velocity_p,velocity_s,density,dc=.0001) accepts increasing period30vector and four length4layer vectors in s,km,km/s,km/s,g/cm^3, returning fundamental Rayleigh phase speed vector in km/s. The last thickness is ignored as a finite boundary. Explicit helpers normc,dnka,var,dltar4,nevill,getsol,gtsolh,getc implement scaled compound products and bracketed roots. dltar selects the shipped Dunkin Rayleigh path only; DispersionError reports an unavailable root. No file writes.
- solvers.physical_model(parameters) maps length11 to4x4columns thickness,Vp,Vs,density in the above internal units.
- solvers.objective(parameters,data) returns weighted phase RMS float or infinity for an optimization-invalid model. It evaluates every period, with monotonic Vs constraint.
- solvers.shrink(position,velocity,lower,upper) returns repaired position and velocity vectors of the same shape, using one trajectory-preserving scalar bound factor.
- solvers.competitive_swarm(data,seed=24713,popsize=40,maxiter=300,callback=None) returns best length11vector and stages. Stages are parameters(300,40,11),objectives(300,40),global_objectives(300),best_objective scalar for the selected complete run. callback(iteration,best_fit) is a progress notification only. Source immediate best updates, RNG and competition are explicit.
- solvers.reconstruct(data,seed=24713,popsize=40,maxiter=300,callback=None) calls the complete optimizer and returns output,stages. Output reconstruction(1,4) is Vs in m/s; thickness(1,3) is finite h in m. It writes no files and never reads references.
- main.main() is python -m src.main: load public observations, run full standard40x300path, create output and save output/reconstruction.npz, returning that Path. Importing main never changes a plotting backend.
- visualization.layer_curve(parameters) represents the seven-unknown piecewise field for display only, extending the half-space5m below the last interface in the plot; this does not introduce a physical lower boundary. visualization.make_figures(data,output,stages,source,export_dir=None) returns6figures; optional export saves PNG/SVG/PDF,numeric_sources.npz,manifest.json. source identifies reproduced-original model,prediction,global_misfits and original explored arrays; no reference is used by reconstruction. Actual parameter derivatives require fresh local forward calls. All plot source arrays are exported without pickle/object data.

The active notebook calls load_data/reconstruct directly for all300generations, writes fresh output, plots original/fresh data, all seven unknowns, complete trajectory, low-misfit explored models and actual seven-parameter finite differences, then invokes the independent Judge CLI. Its code never substitutes an archived reconstruction for the fresh result. Review timeout3600s accommodates actual CPU execution rather than shortening the task.

evaluation/judge.py contains its own explicit fundamental-mode compound/root forward calculation. It imports no src or submitted code. read_output(path) requires both exact float64shapes, real finite positive quantities. evaluate(prediction) strictly requires all8finite numeric/nonboolean/nonnegative *_boundary settings, uses ground_truth.npz first if present, otherwise baseline_reference.npz, computes seven absolute errors and full weighted_dispersion_rms, and rejects nonfinite computed values. dispersion_rms uses only public observations and documented density/nu constants. CLI prediction/report paths are caller-relative; evaluator assets are relative to its own file. JSON contains status,passed,metrics,thresholds,errors. Invalid input/config/reference gives empty metrics and exit2; valid poor predictions exit1, pass0; report write failure emits stderr and2.

test/fixtures/upstream_stages.npz freezes actual source model,prediction,period,initial/trial/second populations/objectives and global history; tests consume all named stages required for forward/objective/initialization/update parity. Full300generation parity is separately recorded against the independent original capture, with actual full CLI/notebook execution. Known homogeneous-medium polynomial, physical length/period scaling, shrinking repair and coordinate-scale radius checks provide independent physics/mathematics evidence. Unit tests exercise every actual declared threshold, all7unknowns, curve criterion, malformed and poor outputs, strict evaluator settings, ground-truth priority and foreign-directory/report behavior.

Both plans describe the original code's coordinate-dependent restart variant explicitly; the paper-radius source-only comparison is not part of standard runtime. No artificial extra layers, depth samples, unknown Poisson parameters or unexecuted alternative solver is claimed.
