# Shipped interfaces and execution flow

The standard command is `python -m src.main`. `src.main.run(root=None)` resolves the task root from its source file by default, loads `data/raw_data.npz`, reconstructs all five specimens, writes the sole output array `reconstruction` (real float64(1,5), microtesla) into `output/reconstruction.npz`, and returns `(result, diagnostics)`. Importing main does not configure a Matplotlib backend. No cross-task or upstream imports occur.

`preprocessing.load_observations(path)` returns copied NPZ arrays, loading with allow_pickle=False. `polar_vectors(magnitude,declination,inclination)` accepts broadcast-compatible arrays, measured amplitude units and degrees, returns Cartesian arrays with final axis 3. `arai_observations(raw,index)` uses one of five specimen indices and valid counts, returns a dictionary: temperature/x/y (paired-point vectors), vectors (nPairs,3), native_vectors (nReadings,3), native_temperature and native_code. Arrays are float64 except integer codes. All magnetic amplitudes are dimensionless normalized readings. Missing thermal partners raise ValueError.

`check_observations(arai)` returns `ptrm` and `tail` dictionaries with `points` (nChecks,2), `temperature` and `starting` (nChecks,), retaining the original check filtering conventions. Empty groups have shape (0,2), not fabricated zero methods.

`physics_model.forward_arai(acquired_trm,field,lab_field,intercept)` returns predicted normalized remaining NRM. Field arguments use microtesla. `principal_direction(vectors,anchored=True)` returns signed leading unit direction (3,), MAD in degrees, and three descending eigenvalues. `vector_fraction(vectors,start,end)` returns FRAC for inclusive zero-based endpoints. `scatter_box(x,y,slope,checks,lo,hi,beta_threshold=.1)` returns `(passed,low,high,points)`; line arrays contain intercept/slope, and combined eligible diagnostic points have shape (n,2).

`solvers.major_axis_fit(x,y,lab_field)` returns slope, sigma_slope, beta, intercept, field and sigma_field as Python floats. `reconstruct(raw,trim=0)` returns float64 result (1,5) and five diagnostics dictionaries. trim=0 is the standard path; trim=1 removes one point from both ends solely for notebook sensitivity analysis. Each dictionary contains actual preprocessing arrays, interval indices, fit quantities, predicted observations, anchored/free MAD, eigenvalues, direction, FRAC, check groups and SCAT boundaries/outcome.

`visualization.comparison_figures(raw,result,diagnostics,upstream)` returns four Matplotlib figures and a dictionary of computed trimmed/OLS/scalar-difference fields. It changes plotting style, does not choose a backend, and performs no file writes. This is a maintainer notebook comparison path, not the CLI solver path. Only NumPy and Matplotlib are runtime dependencies.

`evaluation/judge.py` independently validates input existence, key, exact shape/dtype and finite entries, then evaluates max-absolute microtesla discrepancy. Hidden assets resolve from the evaluator's own directory; caller prediction/report paths follow the caller working directory. Actual truth takes precedence if an evaluator supplies it; this task ships a method baseline only. Invalid inputs/assets return status error with empty metrics; valid below-quality outputs return fail. CLI exit codes are 0/1/2. JSON report parents are created and report-write failure returns 2 with stderr.

`test/fixtures/upstream_stages.npz` stores independent original parser, SMA, PCA, FRAC and check/SCAT measurements. `notebooks/reference_outputs/upstream_measurements.npz` stores reproduced upstream fields and separately identified historical reports/expected context. `fresh_measurements.npz` stores actual local measurements and experimental variants generated after validation, identified in validation.md. The active notebook reconstructs before comparison; it never substitutes this file for a fresh result.

All provenance, full source checkouts, capture programs, native text/MAT/XLSX files, logs, paper metadata and temporary executed notebooks are private outside the task. All shipped test inputs and reference arrays have identified consumers. There is no generator because observations are reused, and no ground_truth.npz because physical truth has not been independently established for this binding.
