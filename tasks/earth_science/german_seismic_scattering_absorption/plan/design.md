# Shipped architecture and interfaces

All arrays are float64 in computation. `src.preprocessing.load_data(path="data/raw_data.npz")` reads with allow_pickle=False and removes only the leading singleton batch axis, returning a dictionary. Public arrays retain their acquisition values. `smooth(values,samples=20,pad=True)` returns a one-dimensional Bartlett average with length preserved when padded. `filter_width(band)` returns effective bandwidth in Hz. `observed_energy(velocity,band)` accepts (3,4401) velocity m/s and (2,) edges Hz, returns 4401 energy-density values. `sample_index(time,start)` returns nearest integer time index. `prepare_pair(velocity,band,distance,start,sonset)` returns energy, unsmoothed, tcoda, Ecoda, tbulk, Ebulk, bulk_interval, bulk_weight, distance and noise; it returns None when observed coda is too short. `prepare_band(data,event,band_index)` prepares all acquired slots and adds station_slot to each accepted pair.

`src.physics_model.coda_green(distance,time,scattering)` evaluates positive-time scattered density on the domain ct>distance. `green(distance,time,scattering)` handles causality and the direct pulse on a uniformly sampled time vector. `smoothed_green(distance,time,scattering)` extends the time grid and smooths the causal density. `green_observations(pairs,scattering)` returns a list of coda arrays and list of bulk scalars in pair order. Units are m^-3 throughout.

`src.solvers.design_system(pairs)` returns (design,energy,weights) of shapes (N,S+1),(N,),(N,). `weighted_solve(design,target,weights)` returns coefficients and residual standard error. `solve_scattering(pairs,scattering,system=None)` profiles linear unknowns; its dictionary contains scattering, absorption, source, sites, error, Gcoda, Gbulk, coefficients and model. `reconstruct_band(pairs)` optimizes the scalar coefficient using the documented golden search. `reconstruct(data)` runs all 25 fits and returns (output,details): output contains the three batched contract arrays; details is a five-by-five list of fit dictionaries including pairs. It allocates zero padding only for absent or observed-quality-excluded site slots. These functions have no file-writing side effects.

`python -m src.main` reads data/raw_data.npz, calls reconstruct and writes output/reconstruction.npz, creating its parent directory. It does not change the plotting backend. `src.visualization` provides numerical summaries and plots used by the notebook; plots accept fresh fit results and explicitly identified upstream results. The active notebook calls the same reconstruct function on the complete visible acquisition, evaluates fresh output with the independent Judge and performs separately identified comparisons. Upstream numerical measurements are loaded only for comparison, never solver initialization or reconstruction.

`evaluation/judge.py` is standalone and imports only standard library, NumPy and SciPy. It duplicates explicit observation-reduction and forward equations without importing src. Prediction and report paths resolve against caller cwd; hidden assets resolve against the evaluator's own directory. Actual ground_truth.npz takes precedence if present; otherwise baseline_reference.npz is required. All three keys must have exact shapes, real float32/64 dtype, finite physically positive values and the declared site mask/gauge. Errors return status=error, empty metrics and exit2; valid below-boundary results return fail/exit1; pass returns exit0. Report writing failure returns2 with stderr. Tests compare the evaluator forward path against frozen original intermediates and known analytic transport/least-squares cases, and exercise malformed arrays, missing references, reference precedence and external-cwd invocation.

The task runtime does not import Qopen, ObsPy, statsmodels or other domain packages. Private original source and capture programs live outside this task. Tests consume frozen NPZ arrays and no pickle. There is no generator because all bound waveforms are actual observations.
