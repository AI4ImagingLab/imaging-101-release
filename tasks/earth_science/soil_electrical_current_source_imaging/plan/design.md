# Runtime interfaces and data flow

`python -m src.main` loads data/raw_data.npz through preprocessing.load_data(path='data/raw_data.npz'), calls solvers.reconstruct(data,regularization_weight=1.,conservation_weight=1000.), saves output/reconstruction.npz reconstruction float64(1,17,17), and prints sum/optimality. Imports do not set a plotting backend. No upstream package is required and no reference is read during reconstruction.

load_data returns unbatched copies observations(204,),green_matrix(204,289),source_coordinates(289,2), all float64. observation_weights(observations,error_floor=1.) returns relative weights(204,). physics_model.forward(current_fractions,green_matrix) flattens compatible source arrays and returns(204,)ohm. adjoint(residual,green_matrix) returns(289,)transposed response. regularizer(source_coordinates) returns(528,289)dimensionless signed edge incidence. weighted_system(data,regularization_weight=1.,conservation_weight=1000.) returns Aw(733,289),bw(733,),R(528,289),w(204,). objective_gradient(x,A,b) returns scalarhalf-squarecost and gradient(289,).

solvers.reconstruct returns image(17,17),predictions(204,),OptimizeResult. Image axesx,y preserve exact sourcecolumn order; visualization transposes image to show xhorizontal/yvertical. No physical current density per area is claimed; units are fraction per node. visualization is notebook-only and returns figures plus actual numeric source arrays. Notebook actively solves the selected model and comparisons/sensitivity cases, loads separately identified original arrays, evaluates with the independent Judge and explains numerical conditioning/graph boundary conventions. The Judge imports no src code and resolves hidden config/reference relative to its own file. Tests consume frozen original numeric stages, not an original package import. Existing author simulation is reused; no new synthetic generator is shipped.
