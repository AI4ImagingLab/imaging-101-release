# Shipped interfaces and execution

Public NPZ contains radar(1,512,1040)counts, time_ns(1,512), position_m(1,1040), topo_position_m(1,36), surface_elevation_m(1,36), all float64. Internal arrays omit batch. Source arrays are never replaced by archived reconstruction. There is no generator because the benchmark observations are real. Runtime depends only on stdlib/NumPy/SciPy/Matplotlib, with no source-domain library or cross-task import.

| Callable | Inputs / defaults | Returns and side effects |
| --- | --- | --- |
| preprocessing.load_data(path='data/raw_data.npz') | caller-relative NPZ | radar(512,1040)counts, recorded time_ns(512), profile position_m(1040); strict finite float64/shape; file read only. |
| preprocessing.load_topography(path='data/raw_data.npz') | same public file | independent station positions/elevations(36,)m; validates increasing station coordinates and finite float64. |

| preprocessing.taper(shape,horizontal=100,vertical=40) | temporal/horizontal sizes, linear edge widths in samples | dimensionless(H,W) taper; no disk effects. |
| physics_model.dispersion(n,nx,dt,dx,velocity) | temporal/horizontal sizes, dt s, dx m, v m/s | omega(n/2+1,)rad/s, kx(nx,)rad/m, kz(n/2+1,)rad/m, target/scaling(n/2+1,nx); scaling[0,0] is undefined diagnostic NaN, removed analytically from scored spectrum. |
| physics_model.interpolation_weights(omega,target) | temporal bins and target query grid | lower-bin integer indices and dimensionless fractions, both target-shaped; explicit endpoint extension. |
| physics_model.remap(spectrum,omega,target) | complex temporal×horizontal spectrum | same-sized sampled Stolt spectrum, last row zero. |
| physics_model.remap_adjoint(spectrum,omega,target) | complex output-space coefficients | input-space coefficient accumulation; exact Euclidean adjoint for physics tests. |

No backend selection/file write. |

CLI flow: load_data → reconstruct → prepare → migrate(taper,FFT,dispersion,remap,obliquity,inverseFFT) → batch-first NPZ. The image has no dependence on topology files or hidden arrays. Topography is a public independent survey used only by notebook display; the callable load_topography and terrain_display make this role explicit.

Notebook flow: full raw observation → fresh .14m/ns source convention → fresh .12/.16comparisons → fresh bandlimited diagnostic → save required result and identified cleaned measurements → load explicitly labelled upstream comparison → standalone Judge → complete actual scientific plots/metric tables/boundary-energy report/terrain display. Every fresh plot is computed during execution. It does not import either upstream repository or the disallowed separately licensed CREWES code.

Standalone evaluation/judge.py has independent local metric routines and imports no src code. It resolves hidden assets relative to its own directory, uses true ground_truth when available (absent here), otherwise validated baseline_reference, validates exact shape/dtype/finite/key existence with allow_pickle=False, evaluates all signed image samples, and writes UTF-8 finite JSON status/passed/metrics/thresholds/errors. CLI prediction/report paths remain caller-relative. Exit0pass/1quality fail/2malformed or evaluator error, including report-write diagnostic. No implicit crop/rescale/phase or magnitude conversion.

Comparing tests use only frozen original-upstream numerical captures, including preprocessing, spectra, scaling, all3velocity results and terrain display; independent analytic physics tests do not generate expected values with the cleaned function being tested. Unit tests cover known metric cases, dtype/shape/key/NaN/Inf/missing/poor submission failures, foreign working directory, missing evaluator assets, report failure, strict source frequency boundaries, metadata/odd-length contract, quantified unsupported-band approximation, CLI/backend. No pixel-perfect figure fixture; active notebook outputs are visually inspected.
