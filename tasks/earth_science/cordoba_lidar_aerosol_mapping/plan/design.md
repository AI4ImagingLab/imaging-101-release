# Shipped interfaces and execution

All cleaned numerical code uses NumPy and standard library; Matplotlib serves the notebook and scientific exports. HDF5/NetCDF/native LICEL readers, C++LPP, atmospheric domain libraries and original source are not runtime dependencies. No cross-task imports or synthetic observation generator is present.

- `preprocessing.load_data(path=None)` loads allow_pickle=FalseNPZ, removes its batch axis, and returns independent arrays: signal(66,4096)ADCcount*m²,molecular_backscatter/extinction(4096)in m^-1sr^-1/m^-1,range(4096)m,time_start/time_stop(66)int32UnixUTCseconds. Default task-relative data/raw_data.npz; no file writes.
- `physics_model.reference_integral(values,reference=812,start=53,step=7.5)` accepts a4096vector or arbitrary Ntime-by4096array and returns the same dimensionality, with signed source trapezoidal integration from reference to each valid bin. Values below start remain zero. Units are input times m.
- `physics_model.forward_signal(backscatter,molecular_backscatter,molecular_extinction,lidar_ratio=50.,reference=812,step=7.5)` accepts time-by-height aerosol beta and matching molecular vectors, returns dimensionless predicted relative elastic return. It uses explicit local optical-depth quadrature and normalization. The notebook calls it on the selected759height subset with reference758. This is a review helper, not a Judge import.
- `solvers.source_smooth(values,width=11)` accepts Ntime-by-height arrays and returns a copy containing the source's aliased, sequential moving mean. Even-width conversion is not a runtime feature; selected width11is fixed and odd. Earlier output samples enter later averages; boundaries use available neighbors.
- `solvers.fernald(signal,molecular_backscatter,molecular_extinction,lidar_ratio=50.,smooth=True)` implements complete4096bin original inverse for66profiles. Returns full beta,alpha plus stages p,integral_p,integral_molecular,normalized_signal,beta_unsmoothed,alpha_unsmoothed. Molecular integral is one shared4096vector; time-dependent arrays are66by4096. Physical units are as specified in README and approach. No file side effects.
- `solvers.reconstruct(data,lidar_ratio=50.,smooth=True)` calls the inverse and returns (output,stages). Output keys reconstruction/extinction are float64(1,66,759), the fixed source-height selection54:813. The optional arguments support explicitly identified review sensitivity calculations.
- `main.main()` is the standard python -m src.main path. It reads public data, runs full reconstruction, creates output/and writes output/reconstruction.npz, returning that Path. It never loads evaluator references or changes a plotting backend.
- `visualization.make_figures(data,output,stages,source,experiments,export_dir=None)` returns6figure objects. source identifies original backscatter/extinction; experiments maps chosen lidar ratios to actually computed output dictionaries. Optional export writes PNG/SVG/PDF,numeric_sources.npz and a hash manifest. Every numerical source is flattened into named numeric NPZarrays without object/pickle data.

The active notebook computes fresh standard retrieval and full L30/50/70comparisons using local functions, loads archived original arrays solely for source comparisons, displays6scientific groups and independently evaluates the fresh output. It records actual runtime and complete metric values. No cached source field is presented as fresh, and no missing AERONET or raw-photon measurement is invented.

`evaluation/judge.py` is standalone and imports no solver/physics/source modules. It validates exact output keys, float64(1,66,759)shapes, real finite values, all required numeric/non-bool/finite boundaries, cosine bounds and nonnegative error thresholds. Actual ground_truth.npz takes priority over baseline_reference.npz if supplied. It evaluates both fields and their separate physical forward-return criteria using only public signal/molecular calibration and fixed documented metadata. Its cumulative optical-depth calculation differs structurally from the inverse's bidirectional quadrature. Nonpositive total backscatter violates the physical output contract. Nonfinite metric arithmetic becomes evaluator error before JSONserialization.

CLI --prediction/--report paths are caller-relative. Hidden assets resolve relative to the Judge path; public calibration is task-relative. Reports contain status,passed,metrics,thresholds,errors; missing parent directories are created. Pass/fail/error return0/1/2. Invalid input/evaluator errors have empty metrics; report failures return2with stderr.

`test/fixtures/upstream_stages.npz` contains actual original C++intermediate arrays captured only by added private I/O; mandatory original numerical source runs are separate and unchanged. Tests consume these frozen numbers without importing LPP. `notebooks/reference_outputs/upstream_original.npz` identifies independently reproduced original final fields. Tests validate all upstream stages/full field, known quadrature and Beer-Lambert cases, exact source alias smoothing, gain invariance, all required metric boundaries, both physical outputs and strict Judge malformed/poor/error cases. Private source, native data, calibrated NetCDFs, thermodynamic table, PDFs, compiled binaries, capture scripts and logs remain outside this task.
