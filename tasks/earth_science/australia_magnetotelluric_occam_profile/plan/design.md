# Shipped interfaces and execution

The standard execution is `python -m src.main` from this task directory. `main(argv=None)` accepts optional `--data` and `--output`, defaulting to `data/raw_data.npz` and `output/reconstruction.npz`, calls `load_data`, calls `reconstruct`, creates the output parent, and writes only `reconstruction` as float64 (1,25). It prints the final standardized observation RMS and returns zero. Importing `src.main` has no execution or plotting-backend side effect.

`preprocessing.load_data(path='data/raw_data.npz') -> dict` loads NPZ with pickle disabled, removes the one-item batch axis, copies the arrays, checks float64, finiteness, dimensions, positive uncertainties/periods, and increasing depth. It returns period, log_apparent_resistivity, log_resistivity_std, impedance_phase, phase_std as (23,), and layer_top as (25,). Units are seconds, dimensionless log10(ohm metre), radians, and metres respectively. Only visible inputs are accessed.

`physics_model.response(frequency, log_resistivity, layer_top) -> (rho,phase)` receives (F,), (L,), (L,) arrays in Hz, log10(ohm metre), and metres, returning (F,) log10 apparent resistivity and (F,) phase radians. It explicitly evaluates the Wait transfer recursion. `jacobian(frequency, log_resistivity, layer_top) -> (j1,j2,C)` receives the same arguments and returns two float64 (F,L) derivative matrices and complex128 (F,L) transfer lengths in metres; all propagated layer derivatives are evaluated locally. `weighted_rms(predicted,observed,std) -> float` uses identically shaped arrays and returns dimensionless standardized RMS.

`solvers.roughness_matrix(n) -> (n,n)` builds the zero-first-row first difference. `occam_update(model,residual_rho,residual_phase,std_rho,std_phase,j1,j2,damping) -> (L,)` forms and solves the explicit normal equations; model is (L,), both residuals/standard deviations are (F,), and Jacobian blocks are (F,L). `reconstruct(data,target_rms=1.0,max_iterations=20) -> (model,history)` initializes m=2 and lambda=10, applies the original decade bracket search and target smoothing, and returns the (25,) float64 profile. History contains models (K,25), rms (K,), damping (K-1,), searches (S,7), predicted_log_resistivity (23,), predicted_phase (23,), and final_rms scalar. Search columns are iteration,left lambda,middle lambda,right lambda,left RMS,middle RMS,right RMS. Arrays record actual computations; their lengths depend on target and stopping.

`visualization.similarity(estimate,reference) -> (ncc,nrmse)` implements presentation metrics with the same formula as the independently implemented Judge. `make_figures(data,model,history,upstream,sensitivity,unconstrained) -> dict[str,Figure]` creates four scientific figure groups from fresh provided results, never silently reconstructing missing methods. `export_figures(figures,sources,destination)` writes PNG/SVG/PDF figures, numerical NPZ sources, and a JSON SHA256 manifest to an explicitly selected private destination. No backend is selected by importing any module.

The active notebook resolves the task root, loads the public data, executes standard reconstruction plus sensitivity and six-iteration runs using `src` only, compares the independently frozen corrected-original arrays, reports numerical metrics, generates four figure groups, and exports their numeric sources and rendered figures to the private batch. All plotted reconstructions are freshly computed. The original unmodified failure and corrected-original success are distinguished in its prose.

`evaluation/judge.py` is standalone. `evaluate(prediction,asset_dir=HERE) -> (report,exit_code)` validates configuration, loads actual truth if present or the explicitly named baseline otherwise, validates the prediction, evaluates NCC/NRMSE and independent forward residuals, and returns pass/fail/error with codes 0/1/2. `load_array` requires exactly real float64 (1,25) finite values. `similarity` checks a nondegenerate reference and uses scaled dot products to avoid overflow. `observation_rms` independently implements layered electromagnetic propagation and uses visible calibration/observations relative to the evaluator's task parent. CLI paths are relative to caller cwd; hidden assets are anchored to the script. `main(argv=None)` creates report parents and writes strict UTF8 JSON, returning 2 on report-write failure. No solver imports or submitted code execution occur.

`test/fixtures/upstream_corrected.npz` is frozen before local implementation, consumed by numerical stage/full parity tests. `notebooks/reference_outputs/upstream_corrected.npz` contains corrected-original profile and responses for notebook comparisons; neither is relabeled as truth. `evaluation/baseline_reference.npz` contains the independently captured profile for Judge scoring. No ground_truth file exists because no independently measured subsurface resistivity is available. Tests and authoritative provenance remain under `test/` only.
