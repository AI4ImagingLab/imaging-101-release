# Shipped interfaces and caller flow

preprocessing.load(path="data/raw_data.npz") returns the unbatched observations and calibration arrays with native dtypes. algorithm_inputs(data) builds source-compatible fields: latitude and longitude[N] float64 degrees; depth and origin_correction[N] float32 km and s; pair_first and pair_second[P] one-based event indices; start and end[P] one-based inclusive observation bounds; delta_time, cross_correlation and phase[M]; station_latitude and station_longitude[M] float64 degrees; station_distance[M] float32 km; travel_times[101,27,2] float32 s; and range/depth grids in float32 km. N=1616, P=50214 and M=608577. Every preprocessed field is checked against independently captured original arrays.

physics_model.travel_time(table,xgrid,zgrid,phase,distance,depth) broadcasts P/S phase codes over array-shaped queries and returns float32 travel times. It handles the declared zero-corner extrapolation and the source's negative-depth surface correction; other out-of-domain queries raise an error. relocate_pair(center,g,table,xgrid,zgrid,nit=15,box=3.) performs the complete explicit relative 3D grid search with analytic median time elimination. g contains the per-observation event offsets, station coordinates, phases and differential times. Returns six centroid quantities, relative origin difference, residual vector, separation, RMS, median absolute residual and nominal resolution. Geographic values are float64; computed depths and residual/time quantities preserve their native float32 arithmetic. The independent original first-search fixture checks all returned physical values.

solvers.heap_order(values) reproduces the original ascending heap indices. quality_order(d,rmin=.6,max_distance=80.) returns float32 pair quality and its heap order. reconstruct_catalog(d,verbose=False,stop_after=None,rmin=.6,nit=15) runs the full hierarchy and returns latitude, longitude, depth, origin correction, internal cluster labels, accepted-merger trace and trial count. stop_after is an optional diagnostic merge cap and is not used by the standard run. reconstruct(data,verbose=False,rmin=.6,nit=15) preprocesses and runs the complete catalog solver, returning result and auxiliary arrays. The result contains reconstruction[1,1616,4] float64. main.main loads the standard raw observations, processes every pair, writes output/reconstruction.npz and reports actual runtime. No library import changes the Matplotlib backend.

physics_model.physical_residuals(data,q) evaluates the declared double-precision response for all observations and returns residual[M] seconds plus the fixed quality mask[M]. q has shape[N,4], float64, in the output-contract order. observation_components(data) returns connected-component labels from all public event pairs. physical_metrics(data,q) returns the four likelihood and anchoring metrics. No fitted clusters or hidden reference positions define those constraints. The standalone Judge has its own explicit physical routines and imports no solver or submitted code. It validates the exact four-metric configuration, finite positive boundaries and required prediction key, shape, dtype and physical domain. Paths for acquisition assets resolve relative to the evaluator. JSON status and exit codes distinguish pass, valid quality failure and evaluator/input error; report-write failures are handled explicitly.

visualization.local_coordinates(q,reference) converts geographic coordinates to local east/north kilometres for display. catalog_maps(data,catalogs,labels,title) plots explicitly supplied catalogs over the largest public observation component. The label array used for this display comes from the public graph, not fitted clustering. All 1616 events and all 575672 qualified observations remain evaluated, including those outside the displayed zoom. The Notebook actively runs the full standard case and three complete diagnostics, loads the separately identified actual original catalog, shows physical metric tables and compares maps, sections, residuals and perturbation sensitivity. It invokes the standalone Judge with explicit UTF8 subprocess decoding.

The losslessly compressed upstream_inputs fixture contains output_* original preprocessing, calibration, quality and order arrays. upstream_relative_search contains param_centroid, input_* and output_* values from the first original search. upstream_final_catalog contains output_* final original memory arrays for pipeline parity. All expected arrays were captured before the local implementation. Notebook reference upstream_catalog identifies the executed original method result. There is no independently known final-hypocenter truth, and no synthetic released observation or data generator is introduced.
