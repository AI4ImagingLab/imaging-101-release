## Quality and ordering
For each pair, source station range is computed from the initial event-pair centroid and station using cosine of their mean latitude, g = 111.1949266 km/degree, a = 180/3.1415927 degree/radian. Float32 observation-quality score equals count times average observed correlation among correlation>=rmin(default.6), range<=80 km. Sequential float32 accumulation/division/multiplication preserves source rounding. Heapsort explicitly preserves original equal-score order. Start1616 singleton clusters and visit pairs from highest to lowest score. Already joined pairs are skipped; old cluster-centroid separation>8 km skips the trial. Up to ten strongest still-unprocessed pairs linking the two clusters supply every retained observation for that trial. ## Relative L1 search
Each cluster keeps its internal event offsets fixed. The two trial centroids are symmetric around their old unweighted midpoint: latitude1=midlat+delta_lat, latitude2=midlat-delta_lat, likewise longitude/depth. Event offsets are added to each trial centroid. Horizontal distance uses the midpoint latitude cosine, and source DIFCLUST's float32 degkm111.19493, degrad=float32(180/3.1415927), dx/dy/range conventions. Bilinear lookup preserves source operation order. Negative internal trial depths use depthzero plus |z|/surfaceverticalspeed; final accepted event depths are nonnegative in this bound experiment. Zero table corners invoke nearest valid adjacent range pair independently at each depth, then interpolate in depth. Public evaluation instead restricts finaldepth0..26 km and uses the explicitly declared double-precision interpolant.

At fixed spatial trial, predicted differential is travel2+internal_time2-(travel1+internal_time1). Subtract from observed dt. Median residual gives the analytic minimizing relative origin-time difference for the L1 objective. Sum absolute deviations about that median; choose first strict minimum in source iy, ix, iz loop order. Default search evaluates3³trials in each of15 iterations. Initial horizontal box3 km, half widths1.5 km converted to degrees; depth half width adjusted near surface using zbox=min(1, box) for negative centroid, max(1,2 z) for0<=z<box/2. Each dimension shrinks by float32.67 after each iteration. No gradient solver substitutes for grid search. Sequential float32 residual sums preserve upstream conventions.

## Trial acceptance and merging
Reject negative accepted centroid depth, RMS residual>.2 s, median absolute residual>.1 s, new centroid separation>6 km. Compute old/new combined centroids weighted by event counts. Remove their common spatial offset and reject either individual centroid displacement>2 km horizontally or>2 km vertically. Relative origin difference must be within 50 s. Accepted cluster1 receives negative half origin difference, cluster2 positive half; apply centroid offsets uniformly to their member events. Merge with first cluster ID. Sort members by catalog row and recenter merged positions to the original catalog centroid; subtract mean time correction. Preserve double lat/lon sums and float32 depth/time sequential sums. Continue every50214 pairs; no bootstrap in the standard selected run (originalnboot = 0). Standard output all 1616events, including unchanged isolated events. Source final cluster membership is an internal result, not a public constraint or scoring identity.
