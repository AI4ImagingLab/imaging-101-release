# Shipped interfaces and data flow

`python -m src.main` calls `main()` without arguments. It resolves task-relative paths from its own file, creates `output/`, calls `reconstruct(path)` on `data/raw_data.npz`, and writes `output/reconstruction.npz`. No plotting backend is selected at import or runtime.

`preprocessing.load_data(path)` reads NPZ with `allow_pickle=False` and returns `(signal, calibration, mask)`: uint16 `(256,256,256)` photon counts, uint64 `(1,1,256)` pooled standard counts, and bool `(256,256)` support. It validates bound shapes and observation dtypes. No normalization or spatial change occurs.

`physics_model.normalized_phasor(signal)` converts computation to float64 and returns mean intensity, cosine phasor and positive-sine phasor along the final axis, each with that axis removed. Intensity has units photons/bin and phasors are dimensionless. Zero intensity gives internally undefined phasors. `single_exponential_phasor(lifetime_ns, frequency_mhz=FREQUENCY_MHZ)` returns the two analytic dimensionless coordinates. `calibrate(real, imag, calibration)` returns calibrated coordinate arrays, with matching input shapes; it obtains calibration's global normalized harmonic and uses the fixed independent 4.1 ns standard. `lifetimes(real, imag, frequency_mhz=FREQUENCY_MHZ)` returns phase and modulation apparent lifetimes in ns; upstream reports zero modulation lifetime when squared phasor radius exceeds one and infinity at zero radius, but both cases are excluded by the benchmark support.

`solvers.reconstruct(path)` calls loader → normalized_phasor → calibrate → lifetimes → fixed mask application. It returns a dict of float64 `(1,256,256)` arrays named `reconstruction` and `modulation_lifetime`. This function has no file-writing side effects. Only main writes submission output.

`visualization.metrics(estimate, reference)` returns uncentered NCC and dynamic-range NRMSE. `comparison(fresh, reference, mask=None)` returns a Matplotlib Figure with one reference, fresh and difference panel for each required key; optional mask is accepted for a common plotting interface and does not change scoring. No plot is substituted for a fresh computation.

`evaluation/judge.py` independently validates NPZ keys, exact shapes, float64 real dtype and finiteness, resolves hidden assets relative to its own directory, computes both reference metrics for each map, and writes UTF-8 JSON. Its `observation_error(pred)` independently recomputes measured/calibrated first harmonics from public counts, converts the paired predicted lifetimes back to positive-real phasor coordinates, and returns RMS coordinate mismatch on fixed support; this must also be at most 1e-6. Exit codes are 0 pass, 1 valid poor result, 2 malformed input/evaluator/report error. It imports no solver module. Both required outputs must pass. CLI paths are caller-relative.

The notebook actively calls reconstruct on complete bound observations; it loads identified reproduced upstream maps for comparison, measures runtime, renders both lifetime maps and differences, and presents consistent metrics and paired reference-agreement bars. Upstream source, original JSON, capture code and logs are private archive assets, never runtime inputs. Frozen sampled stage fixtures and full upstream outputs are consumed by parity tests; analytic tests verify units, signs, calibration and apparent-lifetime identities. There is no synthetic generator because no synthetic benchmark observations are created.
