# Shipped interfaces and execution flow

The independent CPU runtime uses NumPy2.4.6,SciPy1.17.1,Matplotlib3.11.1. Source/GPL notices identify DENSS extraction; original packages/checkouts are private. Every NPZ uses allow_pickle=False. No generator exists because observations are reused.

`preprocessing.load_observations(path: str|Path='data/raw_data.npz')->dict[str,ndarray]` loads q,intensity,sigma,smoothed_intensity,measured_mask each shape(1,485), float64 except boolean mask. It validates shape/dtype/finite values, increasing q and positive sigma/smooth fit. SIZE64,SIDE240A,VOXEL3.75A,DMAX40A match public metadata. The returned dict contains only public measurements/legitimate same-observation preprocessing.

`physics_model.shell_grid(size: int=64,side: float=240)->dict` returns labels(64,64,33) integer, weights same-shape float64, counts(shell),q(shell),size,side,voxel. Means use explicit Hermitian multiplicity. `shell_mean(values: ndarray,grid: dict)->ndarray` sums weighted values per shell. `forward_scattering(density: ndarray,grid: dict|None=None)->tuple[ndarray,ndarray]` accepts real density in A^-3 on64^3, multiplies by voxel volume, FFTs, returns q in1/A and normalized shell intensities. No spatial reference is involved.

`scattering_target(data: dict,grid: dict)->tuple[ndarray,ndarray,ndarray]` returns shell target, interpolated errors and boolean selected-shell array, normalized by original fitted I(0), with explicit Porod continuation. `reciprocal_projection(rho: ndarray,target: ndarray,selected: ndarray,grid: dict)->tuple[ndarray,dict]` accepts per-voxel integrated density; returns inverse-FFT real-space projection plus projected fourier,preprojection intensity,factors arrays. FFT workers1 keeps bounded CPU parallelism. `profile_chi2(qcalc,intensity,data,original_scale_fit=True)->float` implements only original monitor's weighted amplitude fit and cubic interpolation; it is not the standalone output score.

`center_integer(rho,maximum_first=True)->ndarray` does periodic integer translation based only on rho; `update_support(rho,sigma,threshold=.2)->tuple[ndarray,ndarray]` recenters and returns blurred-threshold boolean support; `keep_connected(rho,support)->tuple[ndarray,ndarray]` retains the positive-mass dominant26-connected component; `real_space_update(projected,support,iteration,sigma)->tuple[ndarray,ndarray,float]` applies source error reduction, scheduled recentering, density-threshold shrinkwrap/sigma decay and iteration500 connectivity. All quantities are explicit local mathematics and generic SciPy primitives.

`solvers.reconstruct(data: dict,seed: int=41,max_steps: int=6000,convergence_fraction: float=.01,return_history: bool=False)->dict` performs the complete64^3 alternating-projection inverse on all observations, returning reconstruction(1,64,64,64) realfloat64A^-3. With return_history it additionally returns a history dict containing chi,rg,support_volume (one-dimensional arrays of executed length),iterations integer,last_support boolean64^3,target and q shell arrays. This optional history is for notebook/tests and is never written as a required solver output. Seed is reproducibility control only, not a hidden truth/quality reference. Canonical does no file read; caller supplies data.

`main.run(input_path='data/raw_data.npz',output_path='output/reconstruction.npz')->dict` loads public data, reconstructs with defaults, creates output parents and writes only the declared reconstruction NPZ. `python -m src.main` with optional --input/--output is the standard entrypoint. Importing main or any library never changes plotting backend. Notebook actively invokes reconstructed modules with fresh computations, compares five separately recorded original seeds and unmodified source/method variants, then evaluates strict standalone Judge.

`evaluation/judge.py::evaluate(prediction: str|Path)->tuple[dict,int]` is independent of solver. It resolves metrics and public data relative to its own location. It loads ground_truth.npz when present, otherwise baseline_reference.npz, requiring a finite realfloat64 reconstruction of the exact output shape; malformed/missing selected assets are evaluator errors. It compares complete scattering curves as a rotation/translation/handedness invariant, never spatial phase. The forward model there uses a complete complex FFT and independent shell binning, not solver imports. It validates mandatory numeric/finite/nonbool/nonnegative thresholds, fraction ranges<=1, every input/calibration shape/dtype/finiteness and score finiteness. Overflow/divide/invalid computation raises an evaluator error with empty metrics. CLI --prediction/--report are caller-relative paths, returns0pass,1valid below boundary,2malformed/evaluator/report-write failures. UTF8JSON contains status,passed,metrics,thresholds,errors. Physical metrics are the seven quantities in README/metrics.json; undefined zero-density radius is assigned radius0 and fails physical normalization/Rg rather than emitting a NaN. The eighth criterion reference_scattering_nrmse is RMS discrepancy between independently fullFFT-binned scattering curves sampled at all468 measured q, divided by the reference-scattering dynamic range. A zero reference range is an evaluator error. `scattering_samples(density,data)` and `reference_scattering_nrmse(density,reference,data)` implement this separately from solver imports. No submitted code is imported/executed.

`test/fixtures/upstream_stages.npz` is captured qualified-original numeric evidence: single grid/target arrays and original inputs/outputs at iterations0,1,101,201,301. Every key is consumed by the stage parity test. `evaluation/baseline_reference.npz` contains final density of seed41 as reconstruction, additional final densities42–45, and the canonical original monitor traces; full parity, original-seed quality tests and notebook consume them. These are identified reference-method solutions, never truth. `notebooks/reference_outputs/measurements.json` identifies original/current code runs and metric categories, without duplicate density arrays. Private full source/PDF/downloads/logs/captures and temporary executed notebook remain outside the task.

Visualization consumes the original unmodified final density/monitor and independently derived half-space/full-space symmetry curves from baseline_reference for explicitly labeled source-bias comparisons. Other-seed unused monitor arrays were removed; all retained arrays have notebook/test consumers. `visualization.align_for_display(reference,moving)` uses inertia, all48 signed-axis permutations and Powell rigid refinement on a coarse grid, returning a display-resampled map and diagnostic raw/core cosines and transform. No registration enters physical scoring. `make_figures(data,canonical,upstream,comparisons,scores)` returns six figures/numeric arrays/measurements from caller-supplied freshly computed comparisons, canonical history, independently captured original references and scores. `export_figures(figures,numeric,metrics,directory)` writes PNG/SVG/PDF,NPZ/JSON and hashes; no backend choice. Active notebook exports only if an optional maintainer-selected IMAGING101_FIGURE_DIR environment variable is set; normal execution still computes and displays all six groups.
