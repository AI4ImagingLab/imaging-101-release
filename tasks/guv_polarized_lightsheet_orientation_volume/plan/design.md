# Shipped implementation and execution flow

The cleaned runtime requires NumPy2.4.6, SciPy1.17.1 and Matplotlib3.11.1. TIFF codecs, DIPY, VTK, SymPy and the original Polaris package are upstream-only private verification dependencies. No shared environment is modified. Each task module imports only standard-library utilities and the declared general numerical primitives.

## Public interface

`data/raw_data.npz` contains uint16 `observations(1,77,55,80,21,2)` and `lake_calibration(1,30,30,30,21,2)` in digital counts. Shape order is batch,X,Y,Z,state,view. State order and all physical constants match README. The real observations are author registered/deskewed data; preprocessing here starts after those published processing stages. Calibration comes from a different uniform specimen recorded in the same acquisition session, not from any target fit.

The standard command is `python -m src.main`. It writes `output/reconstruction.npz`, containing exactly float64 `reconstruction(1,77,55,80,15)` in relative instrument-intensity SH coefficient units. Default output paths are relative to the caller's working directory. Default input is resolved relative to the task source. `--input` and `--output` override those paths. `run(input_path=None,output_path='output/reconstruction.npz')` actively reconstructs and returns a small runtime/forward-residual/output-path dictionary. Importing the module changes no Matplotlib backend.

## Modules and signatures

`preprocessing.load_data(path)` loads NPZ without pickle, copies the two arrays, and strictly validates exact keys, shapes and uint16 dtypes. It returns the raw mapping. `subset_indices(subset='ALL')` returns the two published state-index arrays or raises for an unknown group. `calibration_fit(lake)` accepts XYZPV counts of shape(30,30,30,21,2), computes the original float32 means and six double-precision least-squares curves, and returns `(offset,means,coefficients,offsets)` with shapes scalar degrees,(21,2),(6,3),(6,)degrees. `polarization_vectors(ia,ib,offset)` returns unit vectors(2,P,3) in XYZ coordinates. `prepare_observations(raw,subset='ALL')` returns a dictionary containing selected float32 observations, unit polarizations, selected calibration means, offset and all calibration-fit diagnostics; it does not read a reference.

`physics_model.real_harmonics(theta,phi,lmax=4)` broadcasts angle arrays in radians and appends the SH axis of length15 or6. `angular_coupling()` computes and caches the read-only15×6×3 real tensor for the actually used detector subspace. `angular_product(illumination,detection)` broadcasts six-component illumination/detection coefficients and returns15 product coefficients. `rotate_quadrupole(c)` applies the explicit source six-by-six rotation. `detector_coefficients(radius,na,view)` returns six radial detector SH coefficients, rotating for view1. Radius and NA are dimensionless.

`transfer_fields(pols,shape=(77,55,80))` returns a dictionary with float32 Hxy(39,28,15,P), float32 Hyz(28,41,15,P), float64 Hx(39,) and float32 Hz(41,) for the standard shape. It calculates all angular products and physical responses locally. `frequency_matrix(h,z,shape,positive_only=False)` expands those factors at one rFFT Z bin into coefficient-by-measurement matrices(X,Y,15,2P); the positive-only option returns the corresponding nonnegative XY quadrant. `forward_linear(f,h)` accepts XYZ15 real coefficients and returns XYZPV float64 unnormalized predicted intensities. Fourier contraction is stored complex64 before the explicit double-precision inverse transform.

`solvers.tikhonov_inverse(g,h,eta=.7)` accepts real XYZPV observations, known factors and a finite nonnegative eta. It returns float64 XYZ15 coefficients after batched SVD, the source singular cutoff, correct odd-frequency pairing and inverse FFT. `reconstruct(raw,subset='ALL',eta=None,calibrate=True)` actively recomputes calibration and OTFs, calculates the unit-isotropic calibration response, applies the published correction, reconstructs, predicts and evaluates the complete observations. If eta is omitted it is.1 for SIX-NO-TILT and.7 otherwise. Setting `calibrate=False` is a notebook ablation, not the standard path. Returned dictionary keys identify reconstruction, prediction, corrected_observations, transfer_fields, relative_forward_residual, model_averages, calibration, eta, subset and calibrated. These arrays are newly computed; no hidden assets are read.

`solvers.isotropic_null_residuals(g,h,eta=.7)` is a notebook-only diagnostic. It returns full observed relative-L2 errors for zero enhancement, the best one-scalar uniform isotropic object, a spatially varying isotropic object with no ridge and the same object with the specified ridge. The unregularized scalar Fourier inverse uses the same1e−7 singular cutoff. It uses complete signed-frequency matrices, exact rFFT Parseval weights and the same observed support. Its fitted uniform amplitude is a null-model parameter, never calibration for the standard reconstruction.

`visualization` contains maintainer plotting/metric helpers used by the active notebook; it never selects a plotting backend. It is not called by the standard reconstruction CLI. No synthetic generator is shipped because all notebook observations and comparisons reuse the existing real acquisition; angular integration and mathematical unit examples are operator checks, not newly generated benchmark observations.

## Hidden evaluator and tests

`evaluation/judge.py` implements its own public-count calibration, direct angular quadrature and signed-frequency forward model. It imports no source or submitted-code module. `load_field(path)` validates exactly one real float64 array of the declared batch-first shape with all finite entries. `evaluate(prediction)` loads finite metric definitions and actual truth first if present; invalid truth is an evaluator error with no fallback. At present it uses a method reference. It independently measures all45 field metrics plus the full forward residual. Each must pass. `main(argv=None)` writes UTF-8 JSON with status,passed,metrics,thresholds,errors; its native exit codes are0pass,1valid-but-below-boundary,2malformed/evaluator/report-write error. Hidden paths resolve from the evaluator file, while command-line prediction/report paths resolve from the caller.

Stage tests consume `test/fixtures/upstream_stages.npz`, captured from the qualified original before local implementation: lake means/offset, selected polarizations, H factors, unit-object response, angular product kernel and fixed observation probes. Full-pipeline parity uses the same complete qualified source coefficient reference that the Judge uses; it is never called truth. The two other published-group references under `notebooks/reference_outputs/` are consumed by notebook upstream comparisons. All arrays have documented consumers. Mathematical tests independently check dipole response, harmonic orthogonality, aperture support, conjugate-pair coverage, numerical precision and metric formulas. Contract tests exercise malformed NPZ, every required coefficient, reference priority, valid poor outputs and report I/O errors.

## Notebook and private archives

The canonical notebook is the executed `notebooks/guv_polarized_lightsheet_orientation_volume.ipynb`. It actively reconstructs the standard input and all three published groups through local modules, evaluates a fresh saved prediction, and explains problem,data,physics,method,results,conclusion. Comparisons and plots are computed during execution. Frozen upstream arrays are loaded only for clearly labelled original-run comparisons. Figures are exported privately as PNG,SVG,PDF with paired numerical NPZ/JSON and content hashes. Private source checkouts, complete calibration TIFFs, source ROI byte-range hashes, papers, original/qualified runs, source diff and logs remain outside the task. `test/validation.md` indexes these records and records all gates and limitations.
