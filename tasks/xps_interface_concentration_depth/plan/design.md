# Shipped interfaces and data flow

`src.preprocessing.load_data(path=None)` reads raw NPZ with allow_pickle=False and returns copied unbatched float64 arrays: observations(199,10), system_matrix(10,201), depth_nm(201), attenuation_length_nm(10). Its default resolves relative to the task location, independent of cwd. `mean_observation(observations)` returns channelwise mean(10), µm³.

`src.physics_model.forward(profile,system_matrix)` maps dimensionless(201) to µm³(10); `adjoint(values,system_matrix)` returns(201); `second_difference(n)` returns float64(n−2,n), without boundary conditions or spacing normalization; `objective(profile,matrix,mean,variance,prior_variance)` returns the scalar sum of squared whitened data and second-difference residuals.

`src.solvers.dual_prox(values,target,sigma,covariance_diagonal)` returns the explicit quadratic conjugate proximal vector. `reconstruct(system_matrix,observations,iterations=100000,prior_factor=1.,save_every=1000)` returns `(profile,diagnostics)`. Float64 profile has201 entries. Diagnostics contains integer iterations, final scalar tau, primal_path(201,51), dual_path(209,51), tau_path(51), history(rows,4) with update/objective/median_relative_data_error/relative_step, and dual(209). Short runs preserve only available first50 updates. No hidden paths, imported upstream functions or cached reconstruction enters this function.

`src.main.run(output=None)` loads public input, executes the complete selected reconstruction, writes float64 reconstruction(1,201) to output/reconstruction.npz by default, creates its parent directory, and returns profile,diagnostics,elapsed_seconds. Standard entry point is `python -m src.main`. Importing it neither imports plotting nor changes a notebook backend.

`src.visualization.metrics(x,reference)` independently implements cosine NCC and range NRMSE for notebook comparisons. `experiments(data,truth)` actively computes the named comparison profiles and numeric diagnostics. `figures(data,truth,fresh,diagnostics,comparisons,upstream)` returns six Matplotlib figures from these actual arrays. Notebook exports PNG/SVG/PDF only when an explicit private export environment variable is supplied. No upstream runtime imports are used.

The active notebook calls cleaned reconstruct on public input and compares the fresh result with clearly labeled frozen original outputs and author truth. It also recomputes sensitivity experiments and the independent quadratic optimum; these are review comparisons, outside the standard runtime. Standalone evaluation/judge.py imports no solver, validates exact float64 batch shape and finite values, prefers actual ground_truth.npz, and writes the strict report contract. Tests consume frozen original fixtures, never the private repository. Every stored reference and fixture has a consumer described in validation.md.
